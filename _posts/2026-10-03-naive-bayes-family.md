나이브베이즈는 **클래스마다 각 특징이 얼마나 자연스러운지 계산하고, 가장 가능성이 큰 클래스를 고르는 분류기**입니다.

입력 형태에 따라 가우시안, 다항, 베르누이 나이브베이즈로 나뉩니다.

<blockquote class="prompt-info">
<p>한 줄: 사전확률 × 가능도들을 곱해서 가장 큰 클래스를 고릅니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

가우시안 = 연속형 숫자, 다항 = 횟수, 베르누이 = 존재 여부

</details>

## 1. 출발점은 베이즈 정리

우리가 궁금한 것은 다음과 같습니다.

$$P(y\mid x)$$

예를 들어 다음 질문입니다.

```text
키가 170인 사람은 남자일 가능성이 얼마나 되는가?
```

베이즈 정리는 다음과 같습니다.

$$P(y\mid x)=\frac{P(x\mid y)P(y)}{P(x)}$$

## 2. 네 가지 확률

| 이름 | 식 | 의미 |
| --- | --- | --- |
| 사후확률 | P(y│x) | 값을 본 뒤 해당 클래스일 가능성 |
| 가능도 | P(x│y) | 그 클래스에서 이 값이 얼마나 자연스러운가 |
| 사전확률 | P(y) | 값을 보기 전 클래스 비율 |
| 증거 | P(x) | 클래스와 무관하게 이 값이 얼마나 흔한가 |

한 줄로 읽으면 다음과 같습니다.

```text
사후확률
= 그 클래스에서 이 값이 자연스러운 정도
× 그 클래스가 원래 얼마나 많은지
÷ 이 값 자체가 얼마나 흔한지
```

## 3. 왜 분모를 생략할 수 있는가

남자와 여자를 비교할 때 두 클래스 모두 분모 P(x)는 같습니다.

따라서 누가 더 큰지만 비교한다면 분모를 생략할 수 있습니다.

$$\hat{y}=\arg\max_y P(y)P(x\mid y)$$

<mark>분류 결과만 고르면 P(x)는 생략할 수 있지만 실제 사후확률 값을 구하려면 분모가 필요합니다.</mark>

## 4. MAP

MAP는 사후확률이 가장 큰 클래스를 고르는 방법입니다.

사전확률이 크면 애매한 관측값에서는 원래 많이 존재하던 클래스가 유리할 수 있습니다.

## 5. 희귀병 예시

유병률 1%, 민감도 90%, 특이도 95%라면 다음과 같습니다.

$$P(병\mid+)=\frac{0.90\times0.01}{0.90\times0.01+0.05\times0.99}\approx0.154$$

양성이라고 해도 실제 환자일 확률은 약 15.4%입니다.

<mark>희귀 사건에서는 사전확률이 매우 중요합니다.</mark>

## 6. 왜 나이브가 필요한가

특징이 여러 개라면 원래는 결합확률이 필요합니다.

$$P(키,몸무게,신발\mid 남)$$

하지만 여러 특징의 조합을 직접 세면 데이터가 너무 잘게 쪼개집니다.

각 변수를 10구간으로 나누면 변수 3개는 1,000칸, 변수 5개는 100,000칸입니다.

## 7. 나이브 독립 가정

나이브베이즈는 클래스가 주어졌을 때 특징들이 서로 독립이라고 가정합니다.

$$P(x_1,\dots,x_p\mid y)\approx\prod_{j=1}^{p}P(x_j\mid y)$$

예를 들어 다음과 같습니다.

$$P(키,몸무게,신발\mid 남)\approx P(키\mid 남)P(몸무게\mid 남)P(신발\mid 남)$$

<mark>같이 나타나는 패턴 대신 각 특징이 그 클래스에서 얼마나 자연스러운지를 따로 계산해 곱합니다.</mark>

## 8. 왜 나이브라고 부르는가

실제로 관련된 특징도 클래스 안에서는 독립이라고 가정하기 때문입니다.

현실에서는 정확하지 않아도 계산이 단순하고 빠른 장점이 있습니다.

## 9. 정보가 겹치면 생기는 문제

상관된 특징은 같은 정보를 두 번 반영해 사후확률을 과하게 키울 수 있습니다.

<blockquote class="prompt-warning">
<p>분류 결과는 맞아도 확률값은 과신될 수 있습니다.</p>
</blockquote>

## 10. 상관된 변수를 무조건 빼야 하는가

분류 결과만 중요하면 그대로 쓸 수 있지만, 확률값이나 특징 조합 자체가 중요하면 중복 정보를 줄이거나 다른 모델을 고려할 수 있습니다.

## 11. 나이브베이즈 계열 비교

| 모델 | 입력 형태 | 핵심 |
| --- | --- | --- |
| 가우시안 NB | 연속형 숫자 | 클래스별 정규분포 |
| 다항 NB | 횟수 | 단어·사건 횟수 |
| 베르누이 NB | 0 또는 1 | 특징의 존재·부재 |

## 12. 가우시안 나이브베이즈

키, 점수, 온도처럼 연속형 숫자를 사용하는 나이브베이즈입니다.

클래스마다 각 특징이 정규분포를 따른다고 가정합니다.

예를 들어 남자 키는 175 근처, 여자 키는 162 근처에서 종 모양으로 퍼진다고 보는 방식입니다.

## 13. 가우시안 가능도

클래스 c에서 특징 x가 평균 mu, 분산 sigma 제곱의 정규분포를 따른다고 가정합니다.

$$P(x\mid y=c)=\frac{1}{\sqrt{2\pi\sigma_c^2}}\exp\left(-\frac{(x-\mu_c)^2}{2\sigma_c^2}\right)$$

평균에 가까울수록 가능도가 커지고 너무 멀어질수록 작아집니다.

## 14. 가우시안에서 학습하는 것

클래스마다 각 특징의 평균·분산과 클래스 비율을 계산합니다.

예측에서는 다음 점수를 비교합니다.

$$P(c)\prod_jP(x_j\mid c)$$

## 15. 가우시안의 분산 0 문제

특정 클래스의 특징값이 모두 같으면 분산이 0이 되어 계산 문제가 생길 수 있습니다.

구현에서는 작은 값을 더해 분산을 안정화할 수 있습니다.

## 16. var_smoothing

가우시안 나이브베이즈에서 분산이 너무 작거나 0이 되는 문제를 완화하는 장치입니다.

<mark>var_smoothing은 가우시안의 분산 문제를 위한 것이고, 라플라스 스무딩은 횟수 0 문제를 위한 것입니다.</mark>

## 17. 다항 나이브베이즈

단어가 **몇 번 나왔는지**를 보고 클래스를 고르는 모델입니다.

| 단어 | 횟수 |
| --- | ---: |
| 무료 | 3 |
| 당첨 | 2 |
| 회의 | 0 |
| 첨부 | 1 |

입력은 단어별 횟수 벡터입니다.

## 18. 다항 나이브베이즈의 확률

클래스 c에서 단어 j의 확률을 theta라고 하면 다음 형태입니다.

$$P(\mathbf{x}\mid y=c)\propto\prod_j\theta_{c,j}^{x_j}$$

x_j가 지수로 들어갑니다.

즉, 어떤 단어가 여러 번 등장하면 그 단어의 영향도 반복해서 들어갑니다.

## 19. 다항 나이브베이즈의 학습

$$\hat{\theta}_{c,j}=\frac{N_{c,j}}{N_c}$$

학습은 각 클래스에서 단어가 몇 번 등장했는지 세는 과정입니다.

## 20. 다항 예시

새 메일이 무료 2회, 당첨 0회, 회의 1회라면 다음 형태가 들어갑니다.

$$\theta_{무료}^{2}\theta_{당첨}^{0}\theta_{회의}^{1}$$

<mark>다항 나이브베이즈에서는 횟수가 지수로 들어갑니다.</mark>

## 21. 제로 확률 문제

특정 클래스에서 한 번도 본 적 없는 단어의 확률은 0이 되어 전체 곱을 0으로 만들 수 있습니다.

이를 막기 위해 라플라스 스무딩을 사용합니다.

## 22. 다항의 라플라스 스무딩

단어 종류 수가 V개라면 다음과 같이 쓸 수 있습니다.

$$\hat{\theta}_{c,j}=\frac{N_{c,j}+\alpha}{N_c+\alpha V}$$

alpha가 1이면 각 단어에 가짜 횟수 1을 더하는 것과 비슷합니다.

분모의 alpha V를 빼먹으면 전체 단어 확률 합이 1이 되지 않습니다.

## 23. 다항 나이브베이즈를 쓰는 경우

스팸·감성·주제 분류처럼 입력이 단어 횟수나 빈도일 때 빠른 기준 모델로 사용할 수 있습니다.

단어 순서나 보정된 확률이 중요할 때는 약할 수 있습니다.

## 24. 다항에서 잘 놓치는 핵심

- 한 칸은 횟수
- x_j가 지수
- theta는 해당 클래스 안에서 단어 비율
- 학습은 단어 횟수 세기
- 라플라스는 제로 확률 방지
- P(x)는 승부에서 생략 가능
- 사후확률 숫자는 과신될 수 있음

## 25. 베르누이 나이브베이즈

단어가 몇 번 나왔는지는 버리고 **있었는지 없었는지**만 사용합니다.

| 단어 | 다항 입력 | 베르누이 입력 |
| --- | ---: | ---: |
| 무료 | 2 | 1 |
| 당첨 | 1 | 1 |
| 회의 | 0 | 0 |

무료가 두 번이든 열 번이든 베르누이에서는 1입니다.

## 26. 이진화

횟수가 기준값 이상이면 1, 아니면 0으로 바꿉니다.

```text
없음 → 0
있음 → 1
```

베르누이 NB에서는 이 이진화가 중요한 전처리입니다.

## 27. 베르누이 한 특징의 확률

클래스 c에서 특징 j가 나타날 확률을 theta라고 하면 다음과 같습니다.

$$P(x_j\mid y=c)=\theta_{c,j}^{x_j}(1-\theta_{c,j})^{1-x_j}$$

x_j가 1이면 theta가, 0이면 1-theta가 들어갑니다.

## 28. 없는 단어도 증거다

다항에서는 횟수 0인 항의 영향이 사라지지만 베르누이에서는 부재도 1-theta로 점수에 들어갑니다.

## 29. 베르누이 로그 점수

$$\log P(c\mid x)=\log P(c)+\sum_j[x_j\log\theta_{c,j}+(1-x_j)\log(1-\theta_{c,j})]$$

있는 단어와 없는 단어의 점수를 모두 더합니다.

<mark>베르누이는 존재뿐 아니라 부재도 증거로 사용합니다.</mark>

## 30. 베르누이 학습

다항은 단어의 총 등장 횟수를 셉니다.

베르누이는 해당 단어가 등장한 **문서 수**를 셉니다.

즉, 학습 기준이 다릅니다.

## 31. 베르누이의 라플라스 스무딩

클래스 c의 문서 수를 n_c라고 하고, 단어 j가 등장한 문서 수를 n_c,j라고 하면 다음과 같습니다.

$$\hat{\theta}_{c,j}=\frac{n_{c,j}+\alpha}{n_c+2\alpha}$$

분모에 2 alpha가 들어가는 이유는 있음과 없음 두 경우가 있기 때문입니다.

## 32. 베르누이를 쓰는 경우

체크박스, 이진 플래그, 단어 존재 여부, 짧은 문서에 적합합니다.

반복 횟수 자체가 중요하다면 다항 방식이 더 자연스럽습니다.

## 33. 베르누이의 약점

단어 종류가 매우 많으면 없는 단어 항이 노이즈가 될 수 있어 단어 수를 줄이거나 다항 NB를 고려할 수 있습니다.

## 34. 다항과 베르누이 비교

| 구분 | 다항 NB | 베르누이 NB |
| --- | --- | --- |
| 입력 | 횟수 | 0 또는 1 |
| 반복 횟수 | 중요 | 무시 |
| 없는 단어 | 영향 거의 없음 | 1-theta로 반영 |
| 학습 기준 | 단어 총횟수 | 등장한 문서 수 |
| 대표 사용 | 긴 텍스트·빈도 | 짧은 문서·존재 여부 |

## 35. 세 계열 비교

| 구분 | 가우시안 | 다항 | 베르누이 |
| --- | --- | --- | --- |
| 입력 | 연속형 숫자 | 횟수 | 0/1 |
| 학습 | 평균·분산 | 단어 횟수 | 등장 문서 수 |
| 대표 문제 | 키·점수·센서값 | 스팸·주제 | 단어 존재·플래그 |
| 0 문제 | 분산 0 | 단어 횟수 0 | 등장 문서 수 0 |
| 보정 | var_smoothing | 라플라스 | 라플라스 |

## 36. 로그를 쓰는 이유

작은 확률을 계속 곱하면 값이 매우 작아질 수 있어 로그를 사용합니다.

$$\log\prod_jP(x_j\mid y)=\sum_j\log P(x_j\mid y)$$

## 37. MAP와 MLE 구분

MLE는 가능도를, MAP는 사전확률까지 포함한 사후확률을 최대화합니다.

나이브베이즈 분류는 MAP 관점으로 이해하면 쉽습니다.

## 38. 잘 놓치는 핵심

### 1. 승자만 고르면 P(x)는 생략 가능

분모가 모든 클래스에서 같기 때문입니다.

### 2. 실제 사후확률이 필요하면 P(x)가 필요

몇 퍼센트인지 계산하려면 정규화가 필요합니다.

### 3. 나이브 가정은 클래스 안에서 특징 독립

현실에서 완벽히 맞지 않아도 분류는 잘 될 수 있습니다.

### 4. 상관된 특징은 확률 과신을 만들 수 있다

같은 정보를 중복 반영할 수 있습니다.

### 5. 가우시안은 연속형 숫자

평균과 분산을 학습합니다.

### 6. 다항은 횟수

횟수가 지수로 들어갑니다.

### 7. 베르누이는 존재 여부

없는 특징도 점수에 들어갑니다.

### 8. 라플라스와 var_smoothing은 다르다

라플라스는 제로 확률, var_smoothing은 분산 0 문제를 완화합니다.

## 39. 시험·면접 핵심

- 베이즈 정리: 사후 = 가능도 × 사전 / 증거
- MAP: 사후확률 최대 클래스 선택
- P(x): 클래스 비교에서는 생략 가능
- 나이브 가정: 클래스 조건부 독립
- 가우시안 NB: 연속형 숫자
- 다항 NB: 횟수
- 베르누이 NB: 존재·부재
- 다항의 x_j: 지수로 들어감
- 베르누이: 0인 특징도 점수에 포함
- 라플라스: 제로 확률 방지
- var_smoothing: 분산 안정화
- 로그확률: 곱셈을 덧셈으로 변환
- 상관 특징: 확률 과신 가능

## 40. 객관식 문제

### 문제 1

나이브베이즈에서 클래스를 비교할 때 P(x)를 생략할 수 있는 이유는?

① 항상 1이기 때문  
② 모든 클래스에서 같은 분모이기 때문  
③ 가능도가 0이기 때문  
④ 사전확률과 같기 때문

<details>
