`UPDATE`는 <mark>이미 존재하는 Row의 값을 수정하는 DML 명령어</mark>입니다.

`SET`에서 변경할 값을 지정하고, `WHERE`에서 어떤 Row를 수정할지 결정합니다.

<blockquote class="prompt-info">
<p>한 줄: UPDATE는 기존 Row의 값을 바꾸고, WHERE로 수정 대상을 정합니다.</p>
</blockquote>

<details markdown="1">
<summary>한 줄로</summary>

`UPDATE`는 기존 데이터를 수정하는 명령어입니다.

</details>

## 대표 예시

직원1의 급여를 2890에서 3200으로 변경한다고 가정합니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | SALARY |
| --- | --- | ---: |
| 1001 | 직원1 | 2890 |
| 1002 | 직원2 | 2980 |

```sql
UPDATE EMPLOYEE
SET SALARY = 3200
WHERE EMP_ID = 1001;
```

### 결과 Table

| EMP_ID | EMP_NAME | SALARY |
| --- | --- | ---: |
| 1001 | 직원1 | 3200 |
| 1002 | 직원2 | 2980 |

`WHERE EMP_ID = 1001` 조건을 만족하는 Row만 수정됩니다.

```text
UPDATE
→ 수정할 Table

SET
→ 바꿀 값

WHERE
→ 수정할 Row
```

## 기본 문법

```sql
UPDATE Table명
SET Column명 = 값
WHERE 조건;
```

`UPDATE`에서 가장 중요한 부분은 `WHERE`입니다.

WHERE 조건이 없으면 Table의 모든 Row가 수정될 수 있습니다.

## 여러 Column 동시에 수정

한 Row에서 여러 Column을 한 번에 변경할 수 있습니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | SALARY | BONUS |
| --- | --- | ---: | ---: |
| 1001 | 직원1 | 2890 | 200 |

```sql
UPDATE EMPLOYEE
SET
    SALARY = 3500,
    BONUS = 500
WHERE EMP_ID = 1001;
```

### 결과 Table

| EMP_ID | EMP_NAME | SALARY | BONUS |
| --- | --- | ---: | ---: |
| 1001 | 직원1 | 3500 | 500 |

`SET`에서 쉼표로 여러 Column을 나누어 지정합니다.

## 여러 Row 수정

WHERE 조건을 만족하는 Row가 여러 개라면 모두 수정됩니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | DEPT_ID | BONUS |
| --- | --- | --- | ---: |
| 1001 | 직원1 | 10 | 200 |
| 1002 | 직원2 | 20 | 300 |
| 1003 | 직원3 | 10 | 400 |

```sql
UPDATE EMPLOYEE
SET BONUS = 500
WHERE DEPT_ID = 10;
```

### 결과 Table

| EMP_ID | EMP_NAME | DEPT_ID | BONUS |
| --- | --- | --- | ---: |
| 1001 | 직원1 | 10 | 500 |
| 1002 | 직원2 | 20 | 300 |
| 1003 | 직원3 | 10 | 500 |

`DEPT_ID = 10`인 직원1과 직원3이 모두 수정됩니다.

## 기존 값을 이용해 수정

현재 값을 기준으로 계산해서 변경할 수도 있습니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | SALARY |
| --- | --- | ---: |
| 1001 | 직원1 | 3000 |
| 1002 | 직원2 | 4000 |

```sql
UPDATE EMPLOYEE
SET SALARY = SALARY + 500;
```

### 결과 Table

| EMP_ID | EMP_NAME | SALARY |
| --- | --- | ---: |
| 1001 | 직원1 | 3500 |
| 1002 | 직원2 | 4500 |

기존 `SALARY` 값에 500을 더한 값으로 변경됩니다.

이 Query에는 WHERE가 없으므로 모든 Row가 수정됩니다.

<blockquote class="prompt-warning">
<p>UPDATE에서 WHERE를 생략하면 Table의 모든 Row가 수정될 수 있으므로 반드시 수정 범위를 확인합니다.</p>
</blockquote>

## NULL로 변경

Column이 NULL을 허용한다면 값을 NULL로 바꿀 수도 있습니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | BONUS |
| --- | --- | ---: |
| 1001 | 직원1 | 200 |
| 1002 | 직원2 | 300 |

```sql
UPDATE EMPLOYEE
SET BONUS = NULL
WHERE EMP_ID = 1001;
```

### 결과 Table

| EMP_ID | EMP_NAME | BONUS |
| --- | --- | --- |
| 1001 | 직원1 | NULL |
| 1002 | 직원2 | 300 |

단, `NOT NULL` 제약조건이 있는 Column에는 NULL을 넣을 수 없습니다.

## UPDATE와 ALTER 차이

둘 다 무언가를 바꾼다는 점에서 자주 헷갈립니다.

### UPDATE

```sql
UPDATE EMPLOYEE
SET SALARY = 4000
WHERE EMP_ID = 1001;
```

```text
실제 Row 값 변경
→ DML
```

### ALTER

```sql
ALTER TABLE EMPLOYEE
ADD COLUMN EMAIL TEXT;
```

```text
Table 구조 변경
→ DDL
```

| 명령 | 변경 대상 |
| --- | --- |
| UPDATE | 실제 데이터 |
| ALTER | Table 구조 |

## UPDATE와 INSERT 차이

`INSERT`는 새로운 Row를 추가하고, `UPDATE`는 이미 존재하는 Row를 수정합니다.

```text
INSERT
→ 새로운 Row 추가

UPDATE
→ 기존 Row 수정
```

### INSERT

```sql
INSERT INTO DEPARTMENT
VALUES (30, '영업', '대전');
```

### UPDATE

```sql
UPDATE DEPARTMENT
SET REGION = '서울'
WHERE DEPT_ID = 30;
```

## 잘 놓치는 핵심

### 1. UPDATE는 기존 Row를 수정한다

새로운 Row를 만드는 명령이 아닙니다.

### 2. SET에서 변경 내용을 지정한다

```text
SET Column = 값
```

### 3. WHERE가 수정 범위를 결정한다

WHERE 조건을 만족하는 모든 Row가 수정됩니다.

### 4. WHERE가 없으면 전체 Row가 대상이 될 수 있다

시험과 실무 모두에서 가장 중요한 주의점입니다.

## 시험·면접

### 핵심 암기

```text
UPDATE
→ 기존 Row 수정
→ DML
```

```text
SET
→ 변경할 값
```

```text
WHERE
→ 변경할 Row
```

```text
WHERE 생략
→ 전체 Row 수정 가능
```

### 시험 함정

`UPDATE`는 Column 구조를 변경하지 않습니다.

Column을 추가하거나 이름을 변경하는 것은 `ALTER`, 실제 Row 값을 바꾸는 것은 `UPDATE`입니다.

### 면접 짧은 답변

`UPDATE`는 기존 Table의 Row 값을 수정하는 DML 명령어입니다. `SET`에서 변경할 Column과 값을 지정하고, `WHERE`에서 수정할 Row를 제한합니다. WHERE를 생략하면 모든 Row가 수정될 수 있으므로 수정 범위를 반드시 확인해야 합니다.

## 객관식 문제

### 문제 1 · UPDATE

다음 중 `UPDATE`의 역할은?

① 새로운 Table 생성  
② 새로운 Row 추가  
③ 기존 Row 값 수정  
④ Table 구조 삭제

<details markdown="1">
<summary>정답</summary>

③

`UPDATE`는 기존 Row의 값을 수정합니다.

</details>

### 문제 2 · 결과 확인

#### 입력 Table

| EMP_ID | EMP_NAME | SALARY |
| --- | --- | ---: |
| 1001 | 직원1 | 3000 |
| 1002 | 직원2 | 4000 |

```sql
UPDATE EMPLOYEE
SET SALARY = 3500
WHERE EMP_ID = 1001;
```

결과로 옳은 것은?

① 직원1의 급여만 3500으로 변경된다.  
② 직원2의 급여만 3500으로 변경된다.  
③ 두 직원의 급여가 모두 3500이 된다.  
④ 새로운 직원 Row가 추가된다.

<details markdown="1">
<summary>정답</summary>

①

`EMP_ID = 1001`인 Row만 수정됩니다.

| EMP_ID | EMP_NAME | SALARY |
| --- | --- | ---: |
| 1001 | 직원1 | 3500 |
| 1002 | 직원2 | 4000 |

</details>

### 문제 3 · WHERE 생략

다음 Query의 의미는?

```sql
UPDATE EMPLOYEE
SET BONUS = 500;
```

① 한 Row만 수정  
② 모든 EMPLOYEE Row의 BONUS를 500으로 수정  
③ BONUS Column 삭제  
④ EMPLOYEE Table 삭제

<details markdown="1">
<summary>정답</summary>

②

WHERE 조건이 없기 때문에 모든 Row가 수정 대상이 됩니다.

</details>

### 문제 4 · 여러 Column 수정

다음 SQL에 대한 설명으로 옳은 것은?

```sql
UPDATE EMPLOYEE
SET
    SALARY = 4000,
    BONUS = 300
WHERE EMP_ID = 1001;
```

① SALARY만 변경된다.  
② BONUS만 변경된다.  
③ 두 Column을 함께 수정한다.  
④ 새로운 Row를 추가한다.

<details markdown="1">
<summary>정답</summary>

③

`SET`에서 쉼표로 여러 Column의 변경값을 지정할 수 있습니다.

</details>

### 문제 5 · ALTER와 UPDATE

다음 중 옳은 연결은?

① UPDATE → Schema 변경  
② ALTER → 실제 Row 값 변경  
③ UPDATE → 실제 데이터 수정  
④ ALTER → 새로운 Row 추가

<details markdown="1">
<summary>정답</summary>

③

`UPDATE`는 실제 데이터를 수정하고, `ALTER`는 Table 구조를 변경합니다.

</details>
