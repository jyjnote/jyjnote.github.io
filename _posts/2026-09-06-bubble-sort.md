버블 정렬은 **이웃한 두 원소를 비교해, 앞이 더 크면 자리를 바꾸는** 정렬입니다.  
한 패스가 끝나면 그 패스에서 본 구간 안의 최댓값이 맨 뒤로 확정됩니다.

<blockquote class="prompt-info">
  <p>제자리, 안정 정렬. 최악·평균 비교는 $$\dfrac{n(n-1)}{2}=\Theta(n^2)$$. 교환이 한 번도 없는 패스가 나오면 이미 정렬된 것이라 멈출 수 있고, 그때 최선은 $$\Theta(n)$$입니다. 차트는 <code>https://jyjnote.github.io/assets/plotly/bubble-sort-charts.html</code> 입니다.</p>
</blockquote>

## 한 줄 규칙

오름차순을 기준으로 둡니다.

1. 위치 $$i$$와 $$i+1$$을 본다
2. $$A[i] > A[i+1]$$이면 둘을 교환한다
3. 끝까지 가면 가장 큰 값이 맨 뒤에 있다
4. 맨 뒤를 제외하고 1~3을 반복한다

기호:

- $$n$$: 배열 길이. 아래 예에서 $$n=5$$
- $$A[i]$$: $$i$$번 위치의 값. $$i$$는 $$0$$부터
- 패스: 앞에서 아직 확정되지 않은 끝까지 한 바퀴
- 확정: 더 이상 안 움직이는 뒤쪽 구간

큰 값이 뒤로 밀리는 모습이 거품이 떠오르는 것과 같아서 붙은 이름입니다.  
동작의 핵심은 이름이 아니라 <mark>인접 비교 + 교환</mark>입니다.

비교 1번, 교환 0번.

합계: 비교 $$10$$회, 교환 $$6$$회.

## 비교 횟수

패스마다 보는 이웃 쌍의 수는

$$
(n-1)+(n-2)+\cdots+1=\frac{n(n-1)}{2}
$$

$$n=5$$면

$$
\frac{5\cdot 4}{2}=10
$$

위에서 센 비교와 같습니다.

최악·평균(기본형, 조기 종료 없음):

$$
T_{\text{worst}}(n)=\frac{n(n-1)}{2}=\Theta(n^2)
$$

이미 정렬된 배열에서 **교환 여부 깃발**을 쓰면 패스 1만 돌고 끝납니다. 비교 $$n-1$$번.

$$
T_{\text{best}}(n)=n-1=\Theta(n)
$$

깃발이 없으면 정렬이 되어 있어도 $$\dfrac{n(n-1)}{2}$$번을 봅니다.  
최선 $$\Theta(n)$$은 <span style="color:#c0392b"><strong>조기 종료를 넣었을 때</strong></span>의 이야기입니다.

교환 횟수는 입력에 따라 다릅니다.  
역순 $$[90,80,70,60,55]$$이면 모든 이웃이 뒤집혀 있어 교환도 $$\dfrac{n(n-1)}{2}$$번입니다.

## 공간

교환용 변수 하나면 됩니다.

$$
t \leftarrow A[i],\quad A[i]\leftarrow A[i+1],\quad A[i+1]\leftarrow t
$$

$$
S_{\text{aux}}(n)=\Theta(1)
$$

제자리입니다. 시간은 제곱이어도 보조 공간은 상수입니다.

## 안정성

같은 값 두 개의 **원래 순서**를 지키면 안정입니다.

$$
A=[70_a,\ 55,\ 70_b]
$$

버블은 $$70_a$$와 $$70_b$$를 비교할 때 $$>$$ 만 교환하고 $$=$$는 그대로 둡니다.  
그래서 $$70_a$$가 계속 앞에 남습니다. 안정 정렬입니다.

시험 문장이 “같은 키의 상대 순서를 유지하는가”이면 버블은 예입니다.  
선택 정렬은 보통 아니오입니다. 다음 글에서 비교합니다.

## 의사코드

~~~
for p ← 0 부터 n-2 까지
    swapped ← false
    for i ← 0 부터 n-2-p 까지
        if A[i] > A[i+1]
            A[i]와 A[i+1]을 교환
            swapped ← true
    if swapped = false
        종료
~~~

- 바깥 반복: 패스. 최대 $$n-1$$번
- 안쪽 끝 $$n-2-p$$: 이미 확정된 뒤를 다시 안 봄
- `swapped`: 이번 패스에 교환이 있었는가. 없으면 전체 정렬 완료

안쪽을 항상 $$n-2$$까지 돌리면 맞기는 하지만 비교가 더 많습니다.  
확정된 뒤를 빼는 것이 기본 최적화입니다.

아래 두 코드는 위 의사코드와 같습니다.  
본문 예 $$[80,55,90,70,60]$$을 넣으면 $$[55,60,70,80,90]$$이 나옵니다.

### C

~~~c
#include <stdio.h>

void bubble_sort(int a[], int n) {
    for (int p = 0; p < n - 1; p++) {
        int swapped = 0;
        for (int i = 0; i < n - 1 - p; i++) {
            if (a[i] > a[i + 1]) {
                int t = a[i];
                a[i] = a[i + 1];
                a[i + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
}

int main(void) {
    int a[] = {80, 55, 90, 70, 60};
    int n = 5;
    bubble_sort(a, n);
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
~~~

- `p`: 패스. $$0$$부터 $$n-2$$까지
- `n - 1 - p`: 확정된 뒤를 뺀 안쪽 끝
- `swapped`: 이번 패스에 교환이 있으면 1. 0이면 종료
- `t`: 교환용 임시 변수. 보조 공간 $$\Theta(1)$$

### Python

~~~python
def bubble_sort(a):
    n = len(a)
    for p in range(n - 1):
        swapped = False
        for i in range(n - 1 - p):
            if a[i] > a[i + 1]:
                a[i], a[i + 1] = a[i + 1], a[i]
                swapped = True
        if not swapped:
            break
    return a

scores = [80, 55, 90, 70, 60]
print(bubble_sort(scores))
~~~

- `range(n - 1)`: 바깥 패스 최대 $$n-1$$번
- `range(n - 1 - p)`: 안쪽 비교 구간
- `a[i], a[i + 1] = a[i + 1], a[i]`: C의 임시 변수 $$t$$와 같은 교환
- 리스트를 제자리에서 바꾸므로 새 배열을 만들지 않음

두 코드 모두 $$=$$에서는 교환하지 않습니다. 안정성이 그대로입니다.

## 언제 쓰나

쓰는 때:

- 정렬이 무엇인지 손으로 추적할 때
- $$n$$이 매우 작고, 코드가 짧은 것이 중요할 때
- 거의 정렬된 입력 + 조기 종료

약한 때:

- $$n$$이 수천을 넘김. $$\Theta(n^2)$$ 비교
- 실무 기본 정렬. 보통 언어 표준 라이브러리의 혼합 정렬· Timsort · 퀵/힙

$$n=1000$$이면 비교 약

$$
\frac{1000\cdot 999}{2}=499{,}500
$$

병합·힙의 $$n\log_2 n \approx 1000\cdot 10=10{,}000$$과 두 자릿수가 다릅니다.

## 잘 놓치는 핵심

### 1. 한 패스면 전체가 정렬된다

한 패스는 **최댓값 하나**만 뒤로 보냅니다. 전체는 최대 $$n-1$$ 패스입니다.

### 2. 최선도 항상 $$\Theta(n^2)$$이다

깃발이 있으면 이미 정렬된 입력은 $$\Theta(n)$$입니다. 문제 코드에 깃발이 있는지 봐야 합니다.

### 3. 버블은 불안정하다

인접 교환이고 같으면 안 바꾸므로 안정입니다.

### 4. 비교와 교환을 같은 횟수로 센다

비교는 매 이웃마다. 교환은 앞이 더 클 때만입니다. 위 예에서 비교 10, 교환 6입니다.

### 5. 큰 값이 앞으로 간다

오름차순이면 큰 값이 **뒤로** 갑니다. 내림차순으로 바꾸면 부등호만 뒤집습니다.

### 6. 제자리 = 빠르다

제자리는 공간 이야기입니다. 시간은 여전히 $$\Theta(n^2)$$일 수 있습니다.

## 시험·면접

<blockquote class="prompt-info">
  <p>단골: 인접 비교, 한 패스에 최댓값 확정, 비교 $$\dfrac{n(n-1)}{2}$$, 제자리, 안정, 조기 종료 최선 $$\Theta(n)$$, 선택 정렬과의 안정성 차이.</p>
</blockquote>

전공자 체크:

- 칵테일 정렬은 앞·뒤를 번갈아 스캔하는 버블 변형
- 교환 횟수는 역전(inversion) 수와 같습니다. $$i<j$$인데 $$A[i]>A[j]$$인 쌍의 개수

위 예에서 역전을 세면

- $$80$$: 뒤의 $$55,70,60$$ → 3
- $$55$$: 없음
- $$90$$: 뒤의 $$70,60$$ → 2
- $$70$$: 뒤의 $$60$$ → 1
- $$60$$: 없음

합 $$6$$. 교환 6회와 같습니다.
