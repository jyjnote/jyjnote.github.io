부스팅은 **앞 모델이 부족했던 부분을 다음 모델이 순서대로 보완하는 앙상블**입니다.

배깅처럼 여러 모델을 독립적으로 평균하지 않고, 앞 단계의 실수를 다음 단계가 이어받습니다.

<blockquote class="prompt-info">
<p>한 줄: AdaBoost는 틀린 데이터의 무게, GBM은 기울기, XGBoost는 2차 미분과 규제, LightGBM은 잎, CatBoost는 범주형이 핵심입니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

약한 학습기를 순차적으로 쌓으면서 이전 단계가 못 맞힌 부분을 계속 보완합니다.

</details>

## 1. 부스팅의 기본 생각

```text
모델 1 → 부족한 부분 확인
→ 모델 2 → 남은 부족한 부분 확인
→ 모델 3 → 계속 보완
```

배깅은 병렬이고 부스팅은 순차입니다.

| 구분 | 배깅 | 부스팅 |
| --- | --- | --- |
| 학습 | 병렬 | 순차 |
| 핵심 | 평균으로 분산 감소 | 앞 오류를 다음이 보완 |
| 대표 | Random Forest | AdaBoost, GBM |

한 모델이 너무 강하면 학습 데이터를 한 번에 외울 수 있습니다.

그래서 부스팅에서는 보통 얕은 트리를 여러 개 이어 붙입니다.

<mark>약한 모델 여러 개를 순차적으로 합쳐 강한 모델을 만드는 것이 부스팅의 기본 감각입니다.</mark>

## 2. AdaBoost

AdaBoost는 **직전에 틀린 데이터의 가중치를 키우는 부스팅**입니다.

같은 데이터를 계속 보지만 데이터마다 중요도가 달라집니다.

```text
처음 → 모든 점의 무게 비슷
1번째 학습기 → 틀린 점 발견
가중치 갱신 → 틀린 점의 무게 증가
2번째 학습기 → 그 점을 더 중요하게 봄
```

i번째 데이터의 가중치를 다음처럼 둡니다.

$$w_i$$

t번째 학습기의 오류는 틀린 개수가 아니라 **틀린 데이터의 가중치 합**입니다.

$$\epsilon_t=\sum_{i:y_i\neq h_t(x_i)}w_i$$

가중치가 큰 데이터를 틀리면 더 큰 오류로 계산됩니다.

t번째 학습기의 영향력은 다음과 같이 계산할 수 있습니다.

$$\alpha_t=\frac{1}{2}\ln\frac{1-\epsilon_t}{\epsilon_t}$$

오류가 작을수록 발언권이 커집니다.

오류가 0.5이면 다음과 같습니다.

$$\alpha_t=0$$

이진 분류의 최종 예측은 다음처럼 가중합합니다.

$$H(x)=sign\left(\sum_t\alpha_t h_t(x)\right)$$

`sign`은 가중치를 조절하는 함수가 아닙니다.

최종 합이 양수인지 음수인지 보고 클래스를 결정합니다.

AdaBoost에서는 깊이 1 트리인 결정 그루터기를 자주 사용합니다.

```text
특징 ≤ 임계값?
├─ 예
└─ 아니오
```

질문 하나만 하므로 전체 데이터를 한 번에 외우지 못하고 다음 학습기가 보완할 자리가 남습니다.

다만 계속 틀리는 데이터의 가중치가 커지므로 이상치나 잘못된 라벨에 민감할 수 있습니다.

<blockquote class="prompt-warning">
<p>AdaBoost는 어려운 점과 잘못된 라벨을 구분하지 못하면 이상치에 지나치게 집중할 수 있습니다.</p>
</blockquote>

핵심은 다음과 같습니다.

- 갱신 대상은 표본 가중치
- 틀린 점의 가중치 증가
- 약한 학습기를 순차적으로 학습
- 최종 결과는 단순 다수결이 아닌 가중 투표
- 이상치와 라벨 노이즈에 민감

## 3. GBM

GBM은 앞 모델이 남긴 **오차 방향을 다음 나무가 학습하는 부스팅**입니다.

회귀에서는 잔차를 따라가는 모습으로 이해하면 쉽습니다.

```text
실제값 100 → 현재 예측 70
남은 오차 +30 → 다음 나무가 학습
```

예측은 다음처럼 계속 보완됩니다.

```text
70 → +20 → +7 → +3
최종 예측: 100
```

AdaBoost와의 차이는 다음과 같습니다.

```text
AdaBoost
→ 어떤 데이터를 더 중요하게 볼까?

GBM
→ 현재 예측을 어느 방향으로 고칠까?
```

GBM은 현재 손실을 줄이는 방향을 알아내기 위해 손실함수를 예측값에 대해 미분합니다.

<mark>GBM의 다음 나무는 손실함수의 음의 기울기를 학습합니다.</mark>

제곱오차에서는 이 음의 기울기가 잔차와 같은 방향이 됩니다.

그래서 회귀에서는 **이전 모델의 잔차를 다음 나무가 학습한다**고 이해해도 좋습니다.

현재 모델은 다음처럼 갱신할 수 있습니다.

$$F_m(x)=F_{m-1}(x)+\nu f_m(x)$$

ν는 학습률입니다.

```text
큰 학습률 → 빠른 수정, 과적합 위험 증가 가능
작은 학습률 → 느린 수정, 더 많은 나무 필요
```

한 나무가 너무 깊으면 현재 잔차를 지나치게 외울 수 있습니다.

그래서 GBM도 보통 얕거나 중간 깊이의 트리를 사용합니다.

나무 수를 계속 늘리면 작은 오차까지 따라갈 수 있으므로 검증 손실을 보며 반복 횟수를 정하는 것이 중요합니다.

## 4. XGBoost

XGBoost는 GBM을 더 정교하게 만든 트리 부스팅입니다.

핵심은 **1차 미분 + 2차 미분 + 규제**입니다.

<blockquote class="prompt-info">
<p>한 줄: XGBoost = GBM + 2차 미분 + 규제 + 효율적인 학습 구조</p>
</blockquote>

1차 미분은 어느 방향으로 예측을 고칠지 알려줍니다.

2차 미분은 그 주변 손실 곡선의 휘어짐을 알려줍니다.

$$g_i=\frac{\partial L}{\partial \hat{y}_i}$$

$$h_i=\frac{\partial^2 L}{\partial \hat{y}_i^2}$$

한 잎에 들어간 데이터의 값을 합합니다.

$$G=\sum_i g_i$$

$$H=\sum_i h_i$$

이를 이용해 잎의 예측값을 계산합니다.

대표적인 형태는 다음과 같습니다.

$$w^*=-\frac{G}{H+\lambda}$$

λ가 커지면 잎 값이 지나치게 커지는 것을 억제합니다.

XGBoost는 아무 분할이나 허용하지 않습니다.

손실 감소가 복잡도 증가 비용보다 충분히 커야 분할합니다.

γ는 새 분할을 만들기 위해 넘어야 하는 최소 이득과 관련됩니다.

<mark>η는 학습률이고 γ는 분할 이득 기준입니다.</mark>

과적합을 줄이기 위해 다음 장치를 사용할 수 있습니다.

- 잎 값 규제
- 새 가지 생성 벌점
- 학습률
- 행 일부 추출
- 특징 일부 추출

결측값도 반드시 미리 평균 등으로 채워야만 하는 것은 아닙니다.

학습 과정에서 결측값을 어느 방향으로 보낼지 정할 수 있습니다.

직관적으로는 다음처럼 기억하면 됩니다.

```text
AdaBoost
→ 틀린 데이터의 무게

GBM
→ 손실의 기울기

XGBoost
→ 기울기 + 곡률 + 규제
```

## 5. LightGBM

LightGBM도 그래디언트 부스팅 계열입니다.

대표적인 특징은 **분할 이득이 가장 큰 잎부터 먼저 성장시키는 방식**입니다.

```text
층 중심 → 같은 깊이를 비교적 고르게 성장
잎 중심 → 가장 이득 큰 잎부터 성장
```

중요한 점은 **데이터가 가장 많이 몰린 잎을 고르는 것이 아니라는 것**입니다.

지금 한 번 더 분할했을 때 손실이 가장 많이 줄어드는 잎을 고릅니다.

$$j^*=\arg\max_j Gain(j)$$

특정 잎에서 계속 큰 이득이 나오면 그 가지를 연속으로 분할합니다.

따라서 한쪽 가지가 다른 쪽보다 훨씬 깊어질 수 있습니다.

이 방식은 성능을 빠르게 높일 수 있지만 작은 데이터에서는 특정 영역을 너무 깊게 파서 과적합할 수 있습니다.

그래서 잎 수, 최소 잎 데이터 수, 깊이 등을 제어합니다.

LightGBM은 연속값을 많은 개별 값 그대로 비교하기보다 여러 구간으로 묶는 히스토그램 기반 분할을 사용합니다.

```text
많은 연속값 → 구간으로 압축 → 분할 탐색
```

이를 통해 계산량과 메모리를 줄일 수 있습니다.

LightGBM에서 알려진 기법 중 하나가 GOSS입니다.

기울기가 큰 데이터는 많이 남기고 작은 데이터는 일부만 사용해 계산량을 줄이는 아이디어입니다.

기울기가 크다는 것은 현재 모델이 아직 잘 맞추지 못하고 있다는 뜻으로 볼 수 있습니다.

EFB는 동시에 값이 나타나는 경우가 드문 희소 특징들을 묶어 특징 수를 줄이는 기법입니다.

XGBoost와 비교하면 다음과 같습니다.

| 구분 | XGBoost | LightGBM |
| --- | --- | --- |
| 공통 | 그래디언트 부스팅 | 그래디언트 부스팅 |
| 강조 | 2차 근사·규제 | 빠른 분할·잎 중심 |
| 성장 감각 | 비교적 균형 있게 제한 가능 | 이득 큰 잎 우선 |
| 주의 | 깊이·나무 수 | 한쪽 가지 과성장 |

## 6. CatBoost

CatBoost는 **범주형 변수가 많은 표 데이터에 특히 강한 부스팅**입니다.

범주 정보를 사용하면서 타깃 누수와 예측 편향을 줄이는 데 초점을 둡니다.

범주형 값을 단순 숫자로 바꾸면 가짜 순서가 생길 수 있습니다.

```text
서울 = 1
부산 = 2
광주 = 3
```

원핫 인코딩은 범주가 많으면 열 수가 크게 늘 수 있습니다.

범주별 정답 평균을 숫자로 바꾸는 타깃 인코딩도 주의가 필요합니다.

```text
서울 합격률 계산
→ 내 합격 여부 포함
→ 그 값으로 다시 나를 예측
```

이렇게 하면 자기 정답을 간접적으로 미리 보는 타깃 누수가 생깁니다.

CatBoost는 데이터에 순서를 정한 뒤 현재 데이터보다 앞에 있는 데이터만 이용해 범주 통계를 만듭니다.

```text
1번 → 앞 데이터 없음
2번 → 1번만 사용
3번 → 1, 2번 사용
```

현재 데이터의 정답이 자신의 변환값에 직접 들어가는 것을 막습니다.

<mark>CatBoost는 범주 정보를 쓰면서 자기 정답을 직접 엿보지 않도록 설계합니다.</mark>

또한 부스팅 과정에서도 같은 데이터의 정답이 자기 잔차 계산과 학습에 지나치게 재사용되며 생기는 편향을 줄이려 합니다.

이와 관련된 대표적인 문제가 prediction shift입니다.

CatBoost는 대표적으로 같은 깊이에서 같은 분기 조건을 사용하는 대칭 트리 구조를 활용합니다.

```text
1층 → 모든 노드가 같은 질문
2층 → 모든 노드가 또 같은 질문
```

범주형 변수가 많고 원핫 인코딩이 부담되거나 타깃 인코딩 누수가 걱정될 때 특히 유용합니다.

## 7. 전체 비교

| 모델 | 다음 단계가 집중하는 것 | 핵심 |
| --- | --- | --- |
| AdaBoost | 틀린 데이터 | 표본 가중치 |
| GBM | 손실의 음의 기울기 | 잔차 방향 보완 |
| XGBoost | 1차·2차 미분 | 규제된 2차 근사 |
| LightGBM | 이득 큰 잎 | 잎 중심 빠른 성장 |
| CatBoost | 범주형·순서 정보 | 누수·편향 완화 |

한 문장으로 기억하면 다음과 같습니다.

- AdaBoost: 틀린 사람의 목소리를 키운다.
- GBM: 남은 오차 방향을 다음 나무가 따라간다.
- XGBoost: 기울기와 곡률을 보고 규제까지 건다.
- LightGBM: 가장 이득 큰 잎부터 깊게 판다.
- CatBoost: 범주형 정보를 쓰되 자기 정답은 숨긴다.

## 잘 놓치는 핵심

- AdaBoost는 잔차가 아니라 **표본 가중치**를 갱신합니다.
- `sign`은 가중치 조절이 아니라 최종 가중합의 부호를 클래스로 바꿉니다.
- GBM은 단순 잔차보다 넓게 **손실함수의 음의 기울기**를 학습합니다.
- XGBoost는 2차 미분과 명시적인 규제가 추가됩니다.
- LightGBM은 데이터가 많은 잎이 아니라 **분할 이득이 가장 큰 잎**을 먼저 자릅니다.
- CatBoost는 자동 원핫이 아니라 순서 기반 범주 통계와 부스팅으로 누수와 편향을 줄입니다.

## 시험·면접에서 기억할 것

1. AdaBoost의 갱신 대상은 표본 가중치
2. AdaBoost 최종 결과는 가중 투표
3. GBM은 손실의 음의 기울기를 학습
4. XGBoost는 1차·2차 미분을 사용
5. XGBoost는 잎 값과 분할에 규제
6. LightGBM은 잎 중심 성장
7. LightGBM은 히스토그램 기반 분할
8. CatBoost는 순서형 범주 통계
9. CatBoost는 prediction shift 완화를 목표로 함
10. 부스팅 계열은 순차 학습
11. 트리 기반이면 표준화는 보통 필수가 아님
12. 나무 수가 지나치게 많으면 과적합 가능

## 예시로 한 바퀴

실제값 100, 현재 예측 70이라면 **AdaBoost**는 틀린 점의 무게를 키우고, **GBM**은 남은 +30 방향을 학습합니다.

**XGBoost**는 1차·2차 미분과 규제를 함께 보고, **LightGBM**은 손실을 가장 많이 줄일 잎을 먼저 자릅니다.

**CatBoost**는 범주형 특징에서 자기 정답을 직접 보지 않도록 순서 기반 통계를 사용합니다.
