`MIN`과 `MAX`는 **여러 값 중 가장 작은 값과 가장 큰 값을 찾는 집계 함수**입니다.

숫자뿐 아니라 비교 가능한 날짜나 문자열에도 사용할 수 있습니다.

<blockquote class="prompt-info">
<p>한 줄: MIN은 최솟값, MAX는 최댓값입니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

MIN = 최소, MAX = 최대입니다.

</details>

이 글에서는 `EMPLOYEE.SALARY`, `EMPLOYEE.HIRE_DATE`, `PRODUCT.PRICE`를 중심으로 봅니다.

## 가장 먼저 핵심

```text
MIN
→ 가장 작은 값

MAX
→ 가장 큰 값
```

<mark>MIN과 MAX는 여러 Row 중 최솟값과 최댓값 하나를 반환합니다.</mark>

## MIN

급여의 최솟값을 구합니다.

```sql
SELECT MIN(SALARY)
FROM EMPLOYEE;
```

가장 낮은 급여 하나가 결과로 반환됩니다.

## MAX

급여의 최댓값을 구합니다.

```sql
SELECT MAX(SALARY)
FROM EMPLOYEE;
```

가장 높은 급여 하나를 반환합니다.

## MIN과 MAX 함께 사용

```sql
SELECT
    MIN(SALARY) AS MIN_SALARY,
    MAX(SALARY) AS MAX_SALARY
FROM EMPLOYEE;
```

최저 급여와 최고 급여를 한 번에 확인할 수 있습니다.

## WHERE와 함께 사용

특정 부서만 대상으로 계산할 수 있습니다.

```sql
SELECT
    MIN(SALARY),
    MAX(SALARY)
FROM EMPLOYEE
WHERE DEPT_ID = 10;
```

10번 부서의 최소·최대 급여입니다.

## 날짜에도 사용

날짜가 비교 가능한 형식이라면 가장 이른 날짜와 가장 늦은 날짜를 찾을 수 있습니다.

```sql
SELECT
    MIN(HIRE_DATE) AS FIRST_HIRE,
    MAX(HIRE_DATE) AS LAST_HIRE
FROM EMPLOYEE;
```

저장 형식이 일관되어 있다는 전제가 중요합니다.

## 문자열에도 사용 가능

문자열도 DBMS의 정렬 규칙에 따라 비교할 수 있습니다.

```sql
SELECT MIN(EMP_NAME), MAX(EMP_NAME)
FROM EMPLOYEE;
```

다만 문자열의 실제 순서는 문자 정렬 규칙에 영향을 받을 수 있습니다.

## NULL 처리

MIN과 MAX는 일반적으로 NULL 값을 제외하고 비교합니다.

예를 들어

```text
100
200
NULL
300
```

이라면 개념적으로

```text
MIN
→ 100

MAX
→ 300
```

입니다.

모든 값이 NULL인 경우 결과도 NULL이 될 수 있습니다.

## ORDER BY와 차이

최댓값 하나를 찾는 방법으로 ORDER BY와 LIMIT을 사용할 수도 있습니다.

```sql
SELECT SALARY
FROM EMPLOYEE
ORDER BY SALARY DESC
LIMIT 1;
```

하지만 목적이 단순히 최댓값이라면 다음이 더 직접적입니다.

```sql
SELECT MAX(SALARY)
FROM EMPLOYEE;
```

차이는 다음과 같습니다.

| 구분 | MAX | ORDER BY + LIMIT |
| --- | --- | --- |
| 목적 | 최댓값 계산 | 정렬 후 Row 선택 |
| 결과 | 값 중심 | Row 정보까지 조회 가능 |
| 대표 상황 | 최고 급여 값 | 최고 급여 직원 정보 |

## 최고 급여 직원 정보

MAX만 사용하면 최고 급여 값만 쉽게 구할 수 있습니다.

직원 이름까지 필요하다면 다른 방식이 필요합니다.

입문 단계에서는 다음처럼 ORDER BY와 LIMIT을 사용할 수 있습니다.

```sql
SELECT EMP_NAME, SALARY
FROM EMPLOYEE
ORDER BY SALARY DESC
LIMIT 1;
```

이 차이를 구분하면 좋습니다.

## GROUP BY와 함께 사용

부서별 최소·최대 급여를 구할 수 있습니다.

```sql
SELECT
    DEPT_ID,
    MIN(SALARY),
    MAX(SALARY)
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

GROUP BY는 다음 글에서 자세히 다룹니다.

## 잘 놓치는 핵심

### 1. MIN은 최솟값이다

가장 작은 값 하나를 반환합니다.

### 2. MAX는 최댓값이다

가장 큰 값 하나를 반환합니다.

### 3. 일반적으로 NULL은 제외한다

모든 값이 NULL이면 결과도 NULL일 수 있습니다.

### 4. 날짜에도 사용할 수 있다

저장 형식이 비교 가능해야 합니다.

### 5. MAX 값과 최고값 Row 전체는 다르다

직원 이름까지 필요하면 추가 쿼리가 필요합니다.

## 시험·면접

### 핵심 암기

```text
MIN → 최솟값
MAX → 최댓값
```

### 시험 함정

`MAX(SALARY)`는 최고 급여 값이지 최고 급여 직원의 모든 Column을 자동으로 반환하는 것은 아닙니다.

### 면접에서 짧게 답한다면

MIN과 MAX는 집계 함수로 여러 Row 중 최솟값과 최댓값을 반환합니다.

숫자뿐 아니라 비교 가능한 날짜나 문자열에도 사용할 수 있으며, 일반적으로 NULL은 제외하고 계산합니다.
