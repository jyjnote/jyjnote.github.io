연관규칙은 거래 데이터에서 **같이 자주 등장하는 항목집합을 찾고, 그 조합으로 규칙을 만드는 비지도학습 방법**입니다.  
Apriori, FP-Growth, Eclat는 찾는 빈발 항목집합은 같지만 탐색 방식과 자료구조가 다릅니다.

<blockquote class="prompt-info">
<p>한 줄: 지지도는 전체 빈도, 신뢰도는 조건 안의 비율, 향상도는 우연보다 얼마나 더 같이 나오는지를 봅니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>
Apriori는 후보를 만들고, FP-Growth는 트리를 타고, Eclat는 거래번호 집합의 교집합으로 같은 빈발 항목집합을 찾습니다.
</details>

# 1. 거래와 규칙
다음 거래 데이터를 사용합니다.
| 거래 | 항목 |
| --- | --- |
| T1 | 빵, 우유 |
| T2 | 빵, 기저귀, 맥주 |
| T3 | 우유, 기저귀, 맥주 |
| T4 | 빵, 우유, 기저귀 |
| T5 | 빵, 우유, 기저귀, 맥주 |
거래 수는 다음과 같습니다.
$$N=5$$
연관규칙의 형태는 다음과 같습니다.
$$A\Rightarrow B$$
- \(A\): 조건 항목집합
- \(B\): 결과 항목집합
- \(A\cap B=\varnothing\)
예:
```text
{기저귀} ⇒ {맥주}
```
뜻은 “기저귀를 산 거래에서 맥주도 함께 산 비율이 얼마나 되는가”입니다.
<mark>연관규칙은 분류기가 아니며 정답 라벨을 예측하는 모델이 아닙니다.</mark>

# 2. 지지도

## 2.1 정의
항목집합 \(A\)의 지지도는 전체 거래 중 \(A\)가 등장한 비율입니다.
$$\operatorname{supp}(A)=\frac{A를\ 포함한\ 거래수}{N}$$
규칙에서 두 항목집합이 같이 나타나는 지지도는
$$\operatorname{supp}(A\cup B)=\frac{A와\ B를\ 모두\ 포함한\ 거래수}{N}$$
입니다.

## 2.2 예시
```text
기저귀
→ T2, T3, T4, T5
→ 4건
```
$$\operatorname{supp}(\text{기저귀})=\frac45=0.8$$
```text
맥주
→ T2, T3, T5
→ 3건
```
$$\operatorname{supp}(\text{맥주})=\frac35=0.6$$
```text
기저귀 + 맥주
→ T2, T3, T5
→ 3건
```
$$\operatorname{supp}(\text{기저귀,맥주})=\frac35=0.6$$

# 3. 신뢰도

## 3.1 정의
신뢰도는 조건 \(A\)가 나온 거래 중 결과 \(B\)도 나온 비율입니다.
$$\operatorname{conf}(A\Rightarrow B)=\frac{\operatorname{supp}(A\cup B)}{\operatorname{supp}(A)}$$

## 3.2 계산
```text
기저귀 거래
→ 4건
기저귀와 맥주 동시
→ 3건
```
따라서
$$\operatorname{conf}(\text{기저귀}\Rightarrow\text{맥주})=\frac{0.6}{0.8}=0.75$$
기저귀를 산 거래 4건 중 3건에 맥주가 있습니다.
<mark>지지도의 분모는 전체 거래 수, 신뢰도의 분모는 조건 A가 나온 거래 수입니다.</mark>

# 4. 향상도

## 4.1 정의
향상도는 조건 \(A\)를 알고 있을 때 \(B\)가 나타나는 비율이, 원래 \(B\)의 등장률보다 얼마나 높은지를 봅니다.
$$\operatorname{lift}(A\Rightarrow B)=\frac{\operatorname{conf}(A\Rightarrow B)}{\operatorname{supp}(B)}$$
또는
$$\operatorname{lift}(A\Rightarrow B)=\frac{\operatorname{supp}(A\cup B)}{\operatorname{supp}(A)\operatorname{supp}(B)}$$

## 4.2 계산
$$\operatorname{lift}=\frac{0.75}{0.6}=1.25$$

## 4.3 해석
```text
향상도 = 1
→ 독립과 비슷
향상도 > 1
→ 같이 나타나는 경향
향상도 < 1
→ 함께 나타나는 정도가 독립보다 낮음
```
신뢰도가 높아도 결과 항목 \(B\) 자체가 원래 자주 등장한다면 특별한 규칙이 아닐 수 있습니다.

# 5. 신뢰도 방향성
규칙은 방향이 있으므로 \(A\Rightarrow B\)와 \(B\Rightarrow A\)의 신뢰도는 다를 수 있습니다.
$$\operatorname{conf}(\text{기저귀}\Rightarrow\text{맥주})=0.75$$
$$\operatorname{conf}(\text{맥주}\Rightarrow\text{기저귀})=1$$
반면 같은 두 항목의 향상도는 방향을 바꿔도 같습니다.

# 6. 신뢰도만 보면 안 되는 이유
빵과 맥주를 봅니다.
```text
빵
→ 4건
빵 + 맥주
→ 2건
```
$$\operatorname{conf}(\text{빵}\Rightarrow\text{맥주})=\frac{0.4}{0.8}=0.5$$
맥주의 전체 지지도는 0.6이므로
$$\operatorname{lift}=\frac{0.5}{0.6}\approx0.83$$
신뢰도는 50%지만 향상도는 1보다 작습니다.
즉, 빵을 샀을 때 맥주 구매 비율은 그냥 맥주가 등장하는 비율보다 오히려 낮습니다.

# 7. Apriori

## 7.1 핵심
Apriori는 빈발 항목집합을 작은 크기부터 찾고 점점 큰 집합으로 확장합니다.
핵심 성질은 다음과 같습니다.
> 어떤 항목집합이 빈발하지 않으면, 그 항목집합을 포함하는 더 큰 집합도 빈발할 수 없습니다.
예:
```text
{빵, 맥주}
→ 최소 지지도 미달
그러면
{빵, 맥주, 기저귀}
{빵, 맥주, 우유}
...
→ 확인할 필요 없음
```

## 7.2 이유
더 많은 항목을 동시에 요구할수록 해당 거래 수는 늘어날 수 없습니다.
따라서
$$\operatorname{supp}(A\cup B)\le\operatorname{supp}(A)$$
입니다.

## 7.3 탐색 순서
1. 크기 1 빈발 항목집합 \(L_1\)을 찾습니다.
2. \(L_k\)를 이용해 크기 \(k+1\) 후보 \(C_{k+1}\)을 만듭니다.
3. 후보의 부분집합이 빈발하지 않으면 후보를 제거합니다.
4. 거래를 다시 읽어 후보 지지도를 계산합니다.
5. 최소 지지도를 넘긴 것만 \(L_{k+1}\)에 남깁니다.

## 7.4 최소 지지도 0.6
거래 5건이므로 최소 3건 등장해야 합니다.
| 항목 | 건수 | 지지도 | 빈발 |
| --- | ---: | ---: | --- |
| 빵 | 4 | 0.8 | O |
| 우유 | 4 | 0.8 | O |
| 기저귀 | 4 | 0.8 | O |
| 맥주 | 3 | 0.6 | O |

## 7.5 크기 2
| 항목집합 | 건수 | 지지도 | 빈발 |
| --- | ---: | ---: | --- |
| 빵, 우유 | 3 | 0.6 | O |
| 빵, 기저귀 | 3 | 0.6 | O |
| 빵, 맥주 | 2 | 0.4 | X |
| 우유, 기저귀 | 3 | 0.6 | O |
| 우유, 맥주 | 2 | 0.4 | X |
| 기저귀, 맥주 | 3 | 0.6 | O |
{빵, 맥주}가 탈락했으므로 이를 포함하는 크기 3 후보는 가지치기할 수 있습니다.

## 7.6 규칙 생성
빈발 항목집합을 모두 찾은 뒤 규칙을 만듭니다.
즉,
```text
빈발 항목집합 탐색
→ 끝난 뒤
→ 규칙 생성
→ 신뢰도·향상도 계산
```

# 8. FP-Growth

## 8.1 핵심
FP-Growth도 Apriori와 같은 빈발 항목집합을 찾습니다.
차이는 **후보 항목집합을 매 단계 명시적으로 많이 만들지 않고 FP-트리로 거래를 압축한다는 점**입니다.

## 8.2 전체 흐름
1. 최소 지지도를 넘는 1-항목만 남깁니다.
2. 항목을 빈도 순으로 정렬합니다.
3. 거래를 FP-트리에 삽입합니다.
4. 공통 접두 경로는 노드를 공유하고 횟수만 증가시킵니다.
5. 각 항목의 조건부 패턴 베이스를 만듭니다.
6. 조건부 FP-트리에서 빈발 패턴을 찾습니다.

## 8.3 거래 정렬
빈도 동률의 순서를 다음과 같이 고정했다고 합시다.
```text
빵 → 우유 → 기저귀 → 맥주
```
정렬 후 거래는 같은 순서 기준으로 트리에 삽입됩니다.

## 8.4 FP-트리 감각
공통 앞부분을 공유하는 거래는 같은 노드를 사용합니다.
예:
```text
빵(4)
├─ 우유(3)
│  └─ 기저귀(2)
│     └─ 맥주(1)
└─ 기저귀(1)
   └─ 맥주(1)
우유(1)
└─ 기저귀(1)
   └─ 맥주(1)
```
같은 항목이 여러 곳에 있으면 헤더 테이블이 해당 노드들을 연결합니다.

## 8.5 조건부 패턴 베이스
맥주로 끝나는 경로의 앞부분만 모읍니다.
| 경로 | 횟수 |
| --- | ---: |
| 빵, 기저귀 | 1 |
| 빵, 우유, 기저귀 | 1 |
| 우유, 기저귀 | 1 |
이것이 맥주의 조건부 패턴 베이스입니다.
여기서 다시 빈도를 세면
```text
기저귀
→ 3건
→ 빈발
빵
→ 2건
→ 탈락
우유
→ 2건
→ 탈락
```
따라서 {기저귀, 맥주}가 빈발 항목집합으로 남습니다.

## 8.6 Apriori와 차이
FP-Growth는 후보 생성을 크게 줄이고 FP-트리와 조건부 패턴 베이스를 사용합니다. 지지도·신뢰도·향상도 공식은 Apriori와 같습니다.

# 9. Eclat

## 9.1 핵심
Eclat는 거래를 가로가 아니라 세로 형태로 저장합니다.
```text
Apriori
거래 → 항목
Eclat
항목 → 거래번호 집합
```
거래번호 집합을 tidset이라고 합니다.

## 9.2 세로 형식
| 항목 | tidset | 크기 |
| --- | --- | ---: |
| 빵 | {1,2,4,5} | 4 |
| 우유 | {1,3,4,5} | 4 |
| 기저귀 | {2,3,4,5} | 4 |
| 맥주 | {2,3,5} | 3 |

## 9.3 지지도
항목집합 \(A\)의 거래번호 집합을 \(t(A)\)라고 하면
$$\operatorname{supp}(A)=\frac{|t(A)|}{N}$$
입니다.

## 9.4 교집합이 핵심
두 항목을 동시에 포함하는 거래번호는 교집합입니다.
$$t(A\cup B)=t(A)\cap t(B)$$
따라서
$$\operatorname{supp}(A\cup B)=\frac{|t(A)\cap t(B)|}{N}$$

## 9.5 계산 예시
기저귀:
```text
{2,3,4,5}
```
맥주:
```text
{2,3,5}
```
교집합:
```text
{2,3,5}
```
따라서
$$\operatorname{supp}(\text{기저귀,맥주})=\frac35=0.6$$

## 9.6 희소 집합 가지치기
빵과 맥주의 tidset 교집합은 `{2,5}`이므로 지지도는 \(2/5=0.4\)입니다. 이미 최소 지지도에 못 미치므로 더 확장하지 않습니다.

# 10. 세 알고리즘 비교
| 구분 | Apriori | FP-Growth | Eclat |
| --- | --- | --- | --- |
| 데이터 표현 | 가로 거래 | FP-트리 | 세로 tidset |
| 지지도 계산 | 거래 재스캔 | 트리 경로 횟수 | 교집합 크기 |
| 후보 | 직접 생성 | 후보 생성 크게 감소 | 교집합 확장 |
| 핵심 | Apriori 성질 | 조건부 패턴 베이스 | tidset 교집합 |
| 장점 | 단순·이해 쉬움 | 반복 거래 압축 | 교집합으로 빠른 계산 |
| 약점 | 후보 폭증 | 트리가 커질 수 있음 | tidset이 길면 부담 |
최소 지지도가 같고 구현이 정확하다면 세 알고리즘은 같은 빈발 항목집합을 찾습니다.

# 11. 공통점과 차이
공통점:
- 최소 지지도를 사용
- 빈발 항목집합을 찾음
- 희소 집합의 상위 집합도 희소라는 성질 활용
- 빈발 집합 뒤 규칙 생성
- 지지도·신뢰도·향상도 공식 동일

차이:
```text
Apriori
→ 후보 생성 + 거래 재스캔

FP-Growth
→ FP-트리 + 조건부 패턴 베이스

Eclat
→ tidset + 교집합
```

# 12. 계산 문제에서 분모 찾기
# 13. 계산 문제에서 분모 찾기
```text
지지도
→ 전체 거래 수 N
신뢰도
→ 조건 A가 등장한 거래 수
향상도
→ 신뢰도 ÷ 결과 B의 지지도
```
이 세 분모를 구분하면 대부분의 계산 문제를 빠르게 풀 수 있습니다.

# 14. 잘 놓치는 핵심
- 연관규칙은 분류가 아님
- 지지도는 전체 거래 기준
- 신뢰도는 조건 거래 기준
- 향상도는 1이 기준
- 신뢰도가 높다고 반드시 좋은 규칙은 아님
- \(A\Rightarrow B\)와 \(B\Rightarrow A\)의 신뢰도는 다를 수 있음
- 같은 두 항목의 향상도는 방향을 바꿔도 같음
- Apriori는 작은 항목집합부터 확장
- 희소 집합을 포함하는 상위 집합도 희소
- FP-Growth는 후보를 많이 생성하지 않고 FP-트리 사용
- 조건부 패턴 베이스는 특정 항목으로 가는 앞쪽 경로
- Eclat는 세로 자료구조
- Eclat의 핵심은 tidset 교집합
- 세 방법의 지표 공식은 같음

# 15. 시험·면접에서 기억할 것
1. Apriori의 핵심은 가지치기
2. FP-Growth의 핵심은 FP-트리와 조건부 패턴 베이스
3. Eclat의 핵심은 tidset 교집합
4. 최소 지지도가 같으면 빈발 항목집합은 동일
5. 규칙은 빈발 집합을 찾은 뒤 생성
6. 신뢰도는 방향성이 있음
7. 향상도 1은 독립 기준
8. 결과 항목 자체의 빈도가 높으면 신뢰도가 과장될 수 있음
