`WHERE`는 **Table에서 조건을 만족하는 Row만 선택하는 절**입니다.

`SELECT`와 `FROM`으로 조회 대상을 정한 뒤, `WHERE`로 필요한 Row만 걸러냅니다.

<blockquote class="prompt-info">
<p>한 줄: WHERE는 조건에 맞는 Row만 선택합니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

WHERE = 조회할 Row의 조건을 지정하는 절입니다.

</details>

## 가장 먼저 기본 구조

WHERE를 포함한 가장 기본적인 조회문은 다음과 같습니다.

```sql
SELECT Column
FROM Table
WHERE 조건;
```

예를 들어 개발 부서 직원만 조회한다고 해봅시다.

```sql
SELECT EMP_ID, EMP_NAME
FROM EMPLOYEE
WHERE DEPT_ID = 10;
```

구조를 그대로 읽으면 됩니다.

```text
SELECT
→ 어떤 Column을 볼지

FROM
→ 어느 Table에서 가져올지

WHERE
→ 어떤 Row만 남길지
```

<mark>WHERE는 Column을 고르는 것이 아니라 Row를 고르는 절입니다.</mark>


## WHERE의 역할

WHERE는 조건식을 이용해 Row를 선택합니다.

```text
조건이 TRUE
→ 결과에 포함

조건이 FALSE
→ 결과에서 제외
```

예를 들어

```sql
SELECT *
FROM EMPLOYEE
WHERE SALARY >= 3000;
```

는 급여가 3000 이상인 직원만 선택합니다.

## 숫자 조건

숫자 값은 비교 연산자로 조건을 만듭니다.

```sql
SELECT EMP_NAME, SALARY
FROM EMPLOYEE
WHERE SALARY >= 3000;
```

| 연산 | 의미 |
| --- | --- |
| = | 같다 |
| <> | 같지 않다 |
| > | 크다 |
| < | 작다 |
| >= | 크거나 같다 |
| <= | 작거나 같다 |

비교 연산자는 다음 글에서 자세히 다룹니다.


## 문자열 조건

문자열 값은 작은따옴표로 감싸는 것이 기본입니다.

DEPARTMENT 일부입니다.

| DEPT_ID | DEPT_NAME | REGION |
| ---: | --- | --- |
| 10 | 개발 | 서울 |
| 20 | 인사 | 부산 |
| 30 | 영업 | 대전 |
| 40 | 회계 | 광주 |
| 50 | 마케팅 | 서울 |

서울 지역 부서만 조회합니다.

```sql
SELECT DEPT_NAME, REGION
FROM DEPARTMENT
WHERE REGION = '서울';
```

숫자와 문자열의 차이를 기억해야 합니다.

```text
숫자
→ 10

문자열
→ '서울'
```

## 여러 Column 중 결과 Column과 조건 Column은 달라도 된다

SELECT에 적은 Column과 WHERE에 적은 Column이 같을 필요는 없습니다.

예를 들어

```sql
SELECT EMP_NAME
FROM EMPLOYEE
WHERE SALARY >= 3000;
```

에서는

```text
SELECT
→ EMP_NAME 출력

WHERE
→ SALARY로 Row 선택
```

합니다.

즉 조건에 사용하는 Column을 반드시 결과에 표시할 필요는 없습니다.

<mark>WHERE에 사용한 Column은 SELECT에 없어도 됩니다.</mark>

## WHERE 없이 조회하면

WHERE가 없으면 기본적으로 대상 Table의 모든 Row가 조회 대상이 됩니다.

```sql
SELECT EMP_NAME
FROM EMPLOYEE;
```

반면 WHERE를 추가하면 일부 Row만 남습니다.

```sql
SELECT EMP_NAME
FROM EMPLOYEE
WHERE DEPT_ID = 10;
```

정리하면 다음과 같습니다.

```text
WHERE 없음
→ 전체 Row 대상

WHERE 있음
→ 조건을 만족하는 Row만 대상
```


## UPDATE와 DELETE에서도 WHERE 사용

WHERE는 SELECT뿐 아니라 UPDATE와 DELETE에서도 특정 Row를 지정할 때 사용합니다.

```sql
UPDATE EMPLOYEE
SET SALARY = 3500
WHERE EMP_ID = 1001;
```

```sql
DELETE FROM EMPLOYEE
WHERE EMP_ID = 1001;
```

즉 WHERE의 핵심 역할은 항상 비슷합니다.

```text
조건에 맞는 Row 지정
```

## WHERE를 빼면 위험할 수 있다

UPDATE나 DELETE에서 WHERE를 생략하면 대상 Row가 크게 늘어날 수 있습니다.

예를 들어

```sql
UPDATE EMPLOYEE
SET SALARY = 3500;
```

조건이 없습니다.

따라서 여러 Row가 모두 수정될 수 있습니다.

DELETE도 마찬가지입니다.

```sql
DELETE FROM EMPLOYEE;
```

Table 구조는 남지만 전체 Row가 삭제 대상이 됩니다.

<blockquote class="prompt-danger">
<p>UPDATE와 DELETE에서는 WHERE를 빠뜨리면 여러 Row가 한꺼번에 변경되거나 삭제될 수 있으므로 반드시 조건을 확인해야 합니다.</p>
</blockquote>

## WHERE와 SELECT · FROM 비교

| 절 | 역할 | 연결 개념 |
| --- | --- | --- |
| SELECT | 출력할 값 선택 | Column |
| FROM | 조회 대상 지정 | Table |
| WHERE | 조건으로 대상 선택 | Row |

한 줄로 정리하면 다음과 같습니다.

```text
SELECT → Column
FROM → Table
WHERE → Row
```

## 작성 순서와 논리적 처리

SQL은 다음 순서로 작성합니다.

```text
SELECT
FROM
WHERE
```

하지만 논리적으로는 다음처럼 이해하면 쉽습니다.

```text
FROM → Table 결정
WHERE → Row 필터링
SELECT → 결과 Column 결정
```

즉 작성 순서와 논리적 처리 순서는 다를 수 있습니다.

## WHERE에서 여러 조건 사용

여러 조건을 함께 사용할 수도 있습니다.

예를 들어

```text
부서가 10이고
급여가 3000 이상
```

같은 조건입니다.

이때 `AND`, `OR`, `NOT` 같은 논리 연산자를 사용합니다.

```sql
SELECT EMP_NAME
FROM EMPLOYEE
WHERE DEPT_ID = 10
  AND SALARY >= 3000;
```

논리 연산자는 다음 글에서 비교 연산자와 함께 자세히 다룹니다.

## 잘 놓치는 핵심

### 1. WHERE는 Row를 고른다

```text
SELECT → Column
FROM → Table
WHERE → Row
```

이 연결을 가장 먼저 기억합니다.

### 2. WHERE Column은 SELECT에 없어도 된다

```sql
SELECT EMP_NAME
FROM EMPLOYEE
WHERE SALARY >= 3000;
```

SALARY는 조건에만 사용됩니다.

### 3. 문자열은 작은따옴표를 사용한다

```sql
WHERE REGION = '서울';
```

숫자는 일반적으로 따옴표 없이 작성합니다.

```sql
WHERE DEPT_ID = 10;
```

### 4. WHERE는 SELECT만의 기능이 아니다

UPDATE와 DELETE에서도 조건 Row를 정할 때 사용합니다.

### 5. UPDATE·DELETE에서 WHERE 생략은 특히 주의한다

조건이 없으면 여러 Row가 한꺼번에 영향을 받을 수 있습니다.

## 시험·면접

### 핵심 암기

```text
WHERE
= 조건에 맞는 Row 선택
```

### 기본 구조

```sql
SELECT Column
FROM Table
WHERE 조건;
```

### 함께 기억하기

```text
SELECT → Column
FROM → Table
WHERE → Row
```

### 시험 함정 1

다음 문장은 틀렸습니다.

```text
WHERE는 결과에 출력할 Column을 선택한다.
```

결과 Column은 SELECT에서 선택합니다.

WHERE는 Row 조건을 지정합니다.

### 시험 함정 2

WHERE에 사용한 Column이 반드시 SELECT에도 있어야 하는 것은 아닙니다.

### 시험 함정 3

UPDATE와 DELETE에서도 WHERE를 사용할 수 있습니다.

### 면접에서 짧게 답한다면

WHERE는 SELECT, UPDATE, DELETE 등에서 조건을 만족하는 Row만 대상으로 지정하는 절입니다.

각 Row에 대해 조건식을 평가하고 조건을 만족하는 Row만 조회하거나 수정·삭제 대상으로 선택합니다.

②

① WHERE SALARY =< 3000  
② WHERE SALARY >= 3000  
③ WHERE SALARY <> 3000만 가능  
④ FROM SALARY >= 3000

②

① WHERE REGION = 서울  
② WHERE REGION = '서울'  
③ WHERE 'REGION' = 서울  
④ SELECT REGION = 서울

<details>

②

</details>

① WHERE에 사용한 Column은 반드시 SELECT에도 있어야 한다.  
② SELECT는 Row, WHERE는 Table을 선택한다.  
③ WHERE에 사용한 Column은 SELECT에 없어도 된다.  
④ WHERE는 UPDATE에서 사용할 수 없다.

<details>

③

</details>

② 여러 Row가 한꺼번에 수정될 수 있다.  
③ Primary Key가 자동 삭제된다.  
④ 권한이 자동 회수된다.

<details>
<summary>정답</summary>

②

</details>

### 6. SELECT · FROM · WHERE의 연결로 옳은 것은?

① SELECT - Table, FROM - Row, WHERE - Column  
② SELECT - Column, FROM - Table, WHERE - Row  
③ SELECT - Row, FROM - Column, WHERE - Table  
④ 모두 같은 역할
