교차검증은 **데이터를 여러 번 나누어 모델의 성능을 반복 평가하는 방법**으로, 한 번만 나누는 것보다 성능을 더 안정적으로 확인할 수 있습니다.

<blockquote class="prompt-info">
<p>한 줄: 교차검증은 훈련 데이터를 여러 부분으로 나누고, 검증 역할을 번갈아 수행하게 합니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

교차검증 = 훈련과 검증을 여러 번 반복해 성능을 안정적으로 평가

</details>

## 1. 왜 교차검증이 필요한가

데이터를 한 번만 훈련 데이터와 검증 데이터로 나누면 어떤 데이터가 검증에 들어갔는지에 따라 결과가 달라질 수 있습니다.

특히 데이터가 적으면 검증 데이터의 구성에 따라 성능 차이가 크게 나타날 수 있습니다.

<mark>교차검증은 한 번의 데이터 분할에 지나치게 의존하는 문제를 줄이기 위해 사용합니다.</mark>

## 2. 단순 분할과 교차검증

가장 단순한 방법은 데이터를 한 번 나누는 것입니다.

```text
전체 데이터
→ 훈련 데이터
→ 검증 데이터
```

이 방법은 빠르고 간단하지만 데이터가 적을 때 평가 결과가 불안정할 수 있습니다.

교차검증은 훈련과 검증 역할을 여러 번 바꾸어 평가합니다.

| 구분 | 단순 분할 | 교차검증 |
| --- | --- | --- |
| 데이터 분할 | 한 번 | 여러 번 |
| 검증 결과 | 한 번 | 여러 번 |
| 계산량 | 적음 | 많음 |
| 안정성 | 상대적으로 낮음 | 상대적으로 높음 |
| 데이터가 적을 때 | 불리할 수 있음 | 유용함 |

## 3. K-겹 교차검증

가장 대표적인 방법은 K-겹 교차검증입니다.

전체 훈련 데이터를 K개의 비슷한 크기 조각으로 나눕니다.

각 반복에서 한 조각은 검증 데이터로 사용하고 나머지는 훈련 데이터로 사용합니다.

예를 들어 K가 5라면 데이터를 다섯 조각으로 나눕니다.

```text
1회: 1번 검증 / 2, 3, 4, 5번 훈련
2회: 2번 검증 / 1, 3, 4, 5번 훈련
3회: 3번 검증 / 1, 2, 4, 5번 훈련
4회: 4번 검증 / 1, 2, 3, 5번 훈련
5회: 5번 검증 / 1, 2, 3, 4번 훈련
```

모든 조각이 한 번씩 검증 데이터 역할을 합니다.

## 4. K-겹 교차검증의 결과

각 반복마다 검증 성능이 하나씩 나옵니다.

예를 들어 다섯 번의 정확도가 다음과 같다고 가정합니다.

```text
0.84
0.87
0.85
0.86
0.88
```

이 결과들의 평균을 대표 성능으로 사용할 수 있습니다.

$$Score=\frac{1}{K}\sum_{i=1}^{K}Score_i$$

한 번의 결과만 보는 것보다 여러 번의 결과를 종합할 수 있다는 장점이 있습니다.

## 5. K의 의미

K는 데이터를 몇 개의 조각으로 나눌지를 의미합니다.

예를 들어 K가 5면 5-겹 교차검증이고, K가 10이면 10-겹 교차검증입니다.

K가 커질수록 한 번의 학습에서 사용하는 훈련 데이터의 비율은 커집니다.

반면 반복 횟수도 늘어나므로 계산량이 증가합니다.

<blockquote class="prompt-warning">
<p>K를 크게 만든다고 항상 더 좋은 것은 아닙니다. 데이터 크기와 계산 비용을 함께 고려해야 합니다.</p>
</blockquote>

## 6. 5-겹과 10-겹

실무나 학습에서는 5-겹 또는 10-겹 교차검증이 자주 사용됩니다.

| 구분 | 5-겹 | 10-겹 |
| --- | --- | --- |
| 반복 횟수 | 5회 | 10회 |
| 한 번에 검증에 사용하는 비율 | 약 20% | 약 10% |
| 계산량 | 상대적으로 적음 | 상대적으로 많음 |
| 훈련에 사용하는 비율 | 약 80% | 약 90% |

항상 10-겹이 정답인 것은 아닙니다.

## 7. 교차검증의 기본 흐름

전체 과정은 다음과 같습니다.

1. 훈련 데이터를 K개의 조각으로 나눈다.
2. 한 조각을 검증 데이터로 사용한다.
3. 나머지 조각으로 모델을 학습한다.
4. 검증 성능을 기록한다.
5. 검증 조각을 바꾸며 반복한다.
6. 모든 성능을 평균하여 모델을 평가한다.

<mark>핵심은 모든 데이터가 훈련에도 사용되고 검증에도 한 번씩 사용된다는 점입니다.</mark>

## 8. 테스트 데이터와 교차검증

교차검증을 사용한다고 해서 테스트 데이터가 필요 없어지는 것은 아닙니다.

일반적인 흐름은 다음과 같습니다.

```text
전체 데이터
→ 훈련 데이터
→ 테스트 데이터
```

훈련 데이터 안에서 교차검증을 수행해 모델과 설정을 선택하고, 마지막에 테스트 데이터로 최종 성능을 평가합니다.

<blockquote class="prompt-info">
<p>교차검증은 모델 선택용이고, 테스트 데이터는 최종 평가용입니다.</p>
</blockquote>

## 9. 왜 테스트 데이터는 따로 남겨두는가

교차검증 결과를 보고 모델을 선택하거나 초매개변수를 조정합니다.

즉, 교차검증 결과는 모델 개발 과정에 사용됩니다.

따라서 최종 성능을 공정하게 확인하려면 별도의 테스트 데이터가 필요합니다.

## 10. 초매개변수 선택

교차검증은 초매개변수 선택에도 많이 사용됩니다.

예를 들어 의사결정나무의 최대 깊이를 비교한다고 가정합니다.

```text
깊이 3
깊이 5
깊이 7
```

각 설정에 대해 교차검증을 수행하고 평균 성능을 비교합니다.

가장 적절한 설정을 선택한 뒤 마지막에 테스트 데이터로 최종 평가합니다.

## 11. 층화 K-겹 교차검증

분류 문제에서는 각 범주의 비율을 유지하면서 데이터를 나누는 것이 중요할 수 있습니다.

예를 들어 정상 데이터가 90%, 이상 데이터가 10%라고 가정합니다.

단순하게 나누면 어떤 조각에는 이상 데이터가 거의 없을 수 있습니다.

층화 K-겹 교차검증은 각 조각에서도 원래의 범주 비율이 비슷하게 유지되도록 나눕니다.

<mark>층화 교차검증은 특히 범주 비율이 불균형한 분류 문제에서 중요합니다.</mark>

## 12. 일반 K-겹과 층화 K-겹 비교

| 구분 | 일반 K-겹 | 층화 K-겹 |
| --- | --- | --- |
| 분할 기준 | 비슷한 크기 | 크기와 범주 비율 |
| 범주 비율 유지 | 보장하지 않음 | 최대한 유지 |
| 주 사용 | 회귀 등 | 분류 |
| 불균형 분류 | 주의 필요 | 더 적합할 수 있음 |

분류 문제에서는 층화 방식이 자주 사용됩니다.

## 13. 회귀에서의 교차검증

회귀 문제에서도 K-겹 교차검증을 사용할 수 있습니다.

각 반복에서 평균제곱오차, 평균절대오차 등의 값을 계산합니다.

예를 들어 각 검증 결과의 평균제곱오차가 다음과 같다고 가정합니다.

```text
12.4
11.7
13.1
12.0
11.9
```

평균을 이용해 모델의 전반적인 성능을 확인할 수 있습니다.

## 14. 분류에서의 교차검증

분류에서는 정확도뿐 아니라 정밀도, 재현율 등의 평가 기준을 사용할 수 있습니다.

데이터가 불균형하다면 정확도만 평균내는 것보다 문제에 맞는 평가 기준을 선택하는 것이 중요합니다.

예를 들어 이상 거래 탐지에서는 재현율이 중요한 경우가 있을 수 있습니다.

## 15. 시계열 데이터와 교차검증

시계열 데이터는 일반적인 무작위 K-겹 교차검증을 그대로 사용하면 문제가 생길 수 있습니다.

미래 데이터를 이용해 과거를 예측하는 구조가 생길 수 있기 때문입니다.

시계열에서는 시간 순서를 유지해야 합니다.

```text
1회: 과거 1 → 미래 2 검증
2회: 과거 1, 2 → 미래 3 검증
3회: 과거 1, 2, 3 → 미래 4 검증
```

<blockquote class="prompt-danger">
<p>시계열 데이터에서는 미래 정보가 과거 학습에 들어가지 않도록 시간 순서를 반드시 지켜야 합니다.</p>
</blockquote>

## 16. 시계열 교차검증의 핵심

시계열에서는 훈련 데이터가 항상 검증 데이터보다 과거에 있어야 합니다.

| 훈련 | 검증 |
| --- | --- |
| 과거 | 미래 |
| 이전 기간 | 이후 기간 |

일반적인 무작위 섞기를 사용하면 미래 정보가 학습에 포함될 수 있으므로 주의합니다.

## 17. 데이터 누수와 교차검증

교차검증을 사용해도 데이터 누수가 생길 수 있습니다.

대표적인 예가 전체 데이터에서 먼저 전처리 기준을 계산한 뒤 교차검증을 수행하는 경우입니다.

예를 들어 전체 훈련 데이터의 평균과 표준편차를 먼저 계산하면 검증 조각의 정보가 훈련 과정에 들어갈 수 있습니다.

## 18. 올바른 전처리 순서

각 교차검증 반복 안에서 전처리를 수행해야 합니다.

```text
훈련 조각
→ 평균과 표준편차 계산
→ 훈련 조각 변환
→ 같은 기준으로 검증 조각 변환
→ 모델 학습 및 평가
```

이 과정을 다음 반복에서도 다시 수행합니다.

<mark>전처리 기준도 각 반복의 훈련 데이터에서만 계산해야 합니다.</mark>

## 19. 교차검증과 표준화

표준화는 평균과 표준편차를 이용합니다.

$$z=\frac{x-\mu}{\sigma}$$

교차검증에서는 각 반복의 훈련 조각에서 평균과 표준편차를 계산해야 합니다.

검증 조각 자체의 평균과 표준편차를 사용하는 것이 아닙니다.

## 20. 교차검증의 장점과 단점

교차검증은 데이터를 여러 번 활용해 한 번의 분할에 대한 의존을 줄이고, 모델의 평균적인 성능을 확인할 수 있다는 장점이 있습니다.

반면 K번 반복해 모델을 학습해야 하므로 계산량이 증가합니다.

<blockquote class="prompt-warning">
<p>교차검증은 평가를 안정적으로 만들 수 있지만 계산 비용은 증가합니다.</p>
</blockquote>

## 21. 평균 점수만 보면 되는가

평균은 대표 성능을 보여주지만 각 반복의 점수 차이도 확인해야 합니다.

같은 평균이라도 분할마다 성능 차이가 크다면 모델의 평가가 불안정할 수 있습니다.

## 22. 잘 놓치는 핵심

### 1. 교차검증은 테스트 데이터에서 하는 것이 아니다

일반적으로 훈련 데이터 안에서 수행합니다.

### 2. 모든 조각이 검증 역할을 한 번씩 한다

K-겹 교차검증에서는 K개의 조각이 각각 한 번씩 검증 데이터가 됩니다.

### 3. 분류에서는 층화 교차검증을 자주 사용한다

각 범주의 비율을 유지하기 위해서입니다.

### 4. 시계열은 무작위로 섞으면 안 될 수 있다

미래 정보가 과거 학습에 들어갈 수 있습니다.

### 5. 전처리도 반복 내부에서 수행한다

검증 데이터의 정보가 훈련 과정에 들어가지 않도록 해야 합니다.

### 6. 교차검증 평균이 최종 테스트 성능은 아니다

최종 평가는 따로 남겨둔 테스트 데이터에서 확인합니다.

## 23. 시험·면접에서 기억할 것

### 핵심 암기

- K-겹 교차검증: K개의 조각으로 나누어 K번 평가
- 각 조각: 한 번씩 검증 데이터 역할
- 최종 성능: 각 반복 성능을 평균
- 층화 교차검증: 범주 비율 유지
- 시계열 교차검증: 시간 순서 유지
- 테스트 데이터: 마지막까지 별도 보관
- 데이터 누수: 검증 정보가 훈련에 들어가지 않도록 주의

### 자주 나오는 질문

**교차검증을 사용하는 이유는 무엇인가요?**

한 번의 데이터 분할에 따른 우연한 영향을 줄이고 모델의 성능을 더 안정적으로 평가하기 위해 사용합니다.

**K-겹 교차검증에서 K가 5라는 것은 무엇인가요?**

데이터를 다섯 조각으로 나누고 각 조각을 한 번씩 검증 데이터로 사용하여 총 다섯 번 평가한다는 뜻입니다.

**층화 교차검증은 언제 사용하나요?**

분류 문제에서 각 범주의 비율을 각 조각에서도 비슷하게 유지하고 싶을 때 사용합니다.

**교차검증을 하면 테스트 데이터가 필요 없나요?**

아닙니다.

교차검증은 모델 선택과 검증에 사용하고 최종 성능은 별도의 테스트 데이터에서 확인하는 것이 일반적입니다.

## 24. 예시로 한 바퀴

고객의 연체 여부를 분류하고 훈련 데이터 1천 건에 5-겹 교차검증을 사용한다고 가정합니다.

각 반복에서 약 800건으로 학습하고 200건으로 검증하며, 검증 조각을 바꾸어 총 다섯 번 평가합니다.

다섯 번의 성능을 평균해 모델과 설정을 비교하고 마지막에는 별도의 테스트 데이터로 최종 성능을 확인합니다.
