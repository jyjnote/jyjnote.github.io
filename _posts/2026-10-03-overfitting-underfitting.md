과적합과 과소적합은 **모델이 데이터를 얼마나 적절하게 학습했는지 판단하는 핵심 개념**입니다.

과소적합은 너무 적게 학습한 상태이고, 과적합은 훈련 데이터에 지나치게 맞춘 상태입니다.

<blockquote class="prompt-info">
<p>한 줄: 과소적합은 너무 단순하고, 과적합은 훈련 데이터에 너무 맞춘 상태입니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

과소적합 = 훈련도 못 맞춤, 과적합 = 훈련만 잘 맞춤

</details>

## 1. 왜 중요한가

머신러닝의 목표는 훈련 데이터를 외우는 것이 아닙니다.

처음 보는 데이터에서도 좋은 성능을 내는 것이 중요합니다.

모델이 너무 단순하면 중요한 패턴을 학습하지 못합니다.

반대로 너무 복잡하면 훈련 데이터의 잡음까지 학습할 수 있습니다.

<mark>좋은 모델은 훈련 데이터와 새로운 데이터 모두에서 적절한 성능을 내야 합니다.</mark>

## 2. 과소적합이란

과소적합은 모델이 데이터의 중요한 패턴을 충분히 학습하지 못한 상태입니다.

모델이 지나치게 단순하거나 학습이 충분하지 않을 때 발생할 수 있습니다.

훈련 데이터에서도 성능이 낮다는 것이 중요한 특징입니다.

<blockquote class="prompt-info">
<p>과소적합은 훈련 데이터조차 제대로 설명하지 못하는 상태입니다.</p>
</blockquote>

## 3. 과소적합의 특징

과소적합에서는 보통 다음과 같은 모습이 나타납니다.

- 훈련 성능이 낮다.
- 검증 성능도 낮다.
- 모델이 너무 단순할 수 있다.
- 중요한 패턴을 충분히 학습하지 못한다.

즉, 훈련과 검증 모두에서 성능이 부족합니다.

## 4. 과소적합 예시

실제 데이터가 곡선 형태라고 가정합니다.

그런데 모델이 직선 하나만 사용한다면 복잡한 관계를 충분히 표현하지 못할 수 있습니다.

```text
실제 관계: 복잡한 곡선
사용 모델: 단순한 직선
```

이 경우 훈련 데이터에서도 오차가 크게 나타날 수 있습니다.

## 5. 과소적합과 높은 편향

과소적합은 높은 편향과 연결됩니다.

편향이 높다는 것은 모델이 실제 데이터의 규칙을 지나치게 단순하게 가정한다는 의미입니다.

따라서 복잡한 패턴을 제대로 표현하지 못할 수 있습니다.

<mark>높은 편향 → 과소적합</mark>

## 6. 과적합이란

과적합은 모델이 훈련 데이터에 지나치게 맞춰진 상태입니다.

훈련 데이터의 중요한 패턴뿐 아니라 잡음이나 우연한 특징까지 학습할 수 있습니다.

훈련 데이터에서는 매우 좋은 성능을 보이지만 새로운 데이터에서는 성능이 떨어질 수 있습니다.

## 7. 과적합의 특징

과적합에서는 보통 다음과 같은 모습이 나타납니다.

- 훈련 성능이 매우 높다.
- 검증 성능은 상대적으로 낮다.
- 모델이 지나치게 복잡할 수 있다.
- 훈련 데이터의 작은 변화에 민감하다.

<blockquote class="prompt-warning">
<p>훈련 성능이 매우 높다고 해서 항상 좋은 모델인 것은 아닙니다.</p>
</blockquote>

## 8. 과적합 예시

시험 문제와 답을 그대로 외운 학생을 생각할 수 있습니다.

연습했던 문제는 거의 완벽하게 맞히지만 조금만 형태가 바뀌면 풀지 못합니다.

머신러닝에서도 훈련 데이터 자체를 지나치게 외우면 비슷한 문제가 발생합니다.

<mark>과적합은 원리를 학습한 것이 아니라 훈련 데이터의 세부적인 특징까지 지나치게 학습한 상태라고 볼 수 있습니다.</mark>

## 9. 과적합과 높은 분산

과적합은 높은 분산과 연결됩니다.

분산이 높다는 것은 훈련 데이터가 조금 달라졌을 때 모델의 결과가 크게 달라질 수 있다는 뜻입니다.

훈련 데이터에 지나치게 민감한 모델은 새로운 데이터에서 불안정할 수 있습니다.

<mark>높은 분산 → 과적합</mark>

## 10. 과소적합과 과적합 비교

| 구분 | 과소적합 | 적절한 학습 | 과적합 |
| --- | --- | --- | --- |
| 모델 복잡도 | 낮음 | 적절함 | 높음 |
| 훈련 성능 | 낮음 | 높음 | 매우 높음 |
| 검증 성능 | 낮음 | 높음 | 상대적으로 낮음 |
| 편향 | 높음 | 적절함 | 낮음 |
| 분산 | 낮음 | 적절함 | 높음 |

시험에서는 이 관계를 자주 확인합니다.

## 11. 훈련 오차와 검증 오차

과소적합과 과적합은 훈련 오차와 검증 오차를 비교하면 이해하기 쉽습니다.

| 상태 | 훈련 오차 | 검증 오차 |
| --- | --- | --- |
| 과소적합 | 큼 | 큼 |
| 적절한 학습 | 작음 | 작음 |
| 과적합 | 매우 작음 | 상대적으로 큼 |

<mark>훈련 오차와 검증 오차의 차이가 크게 벌어지면 과적합을 의심할 수 있습니다.</mark>

## 12. 모델 복잡도와 적합 상태

모델이 너무 단순하면 중요한 규칙을 표현하지 못해 과소적합이 발생할 수 있습니다.

반대로 모델이 지나치게 복잡하면 훈련 데이터의 잡음까지 학습해 과적합이 발생할 수 있습니다.

| 모델 복잡도 | 가능성 |
| --- | --- |
| 너무 낮음 | 과소적합 |
| 적절함 | 일반화 성능 양호 |
| 너무 높음 | 과적합 |

## 13. 일반화

일반화는 학습하지 않은 새로운 데이터에서도 좋은 성능을 내는 능력입니다.

머신러닝에서 최종적으로 원하는 것은 높은 훈련 성능 자체가 아니라 좋은 일반화 성능입니다.

<blockquote class="prompt-info">
<p>과적합과 과소적합을 판단하는 최종 기준은 새로운 데이터에서의 성능입니다.</p>
</blockquote>

## 14. 과소적합과 과적합의 원인

과소적합은 모델이 너무 단순하거나 중요한 특성이 부족하고, 규제가 지나치게 강하거나 학습이 충분하지 않을 때 발생할 수 있습니다.

과적합은 모델이 지나치게 복잡하거나 데이터가 적고, 잡음이나 불필요한 특성이 많을 때 발생할 수 있습니다.

## 15. 과소적합을 줄이는 방법

더 복잡한 모델을 사용하고, 유용한 특성을 추가하며, 지나치게 강한 규제를 줄이는 방법을 생각할 수 있습니다.

## 16. 과적합을 줄이는 방법

모델 복잡도를 줄이고, 더 많은 데이터를 사용하며, 규제·교차검증·조기 종료 등을 활용할 수 있습니다.

<mark>과적합을 줄이는 목적은 훈련 성능이 아니라 검증과 테스트 성능을 높이는 것입니다.</mark>

## 17. 규제

규제는 모델이 지나치게 복잡해지는 것을 막는 방법입니다.

선형 모델에서는 계수가 지나치게 커지지 않도록 벌점을 추가할 수 있습니다.

대표적인 방법으로 릿지와 라쏘가 있습니다.

규제를 강화하면 모델이 단순해져 과적합을 줄이는 데 도움이 될 수 있습니다.

## 18. 규제를 너무 강하게 하면

규제가 강할수록 모델은 단순해집니다.

적절한 규제는 과적합을 줄일 수 있습니다.

하지만 규제가 지나치게 강하면 중요한 패턴까지 표현하지 못해 과소적합이 발생할 수 있습니다.

<blockquote class="prompt-warning">
<p>규제는 강할수록 무조건 좋은 것이 아니라 적절한 수준을 찾아야 합니다.</p>
</blockquote>

## 19. 데이터와 특성의 영향

데이터가 많아지면 특정 훈련 데이터의 우연한 패턴에 덜 의존해 과적합 완화에 도움이 될 수 있습니다.

반면 불필요한 특성이 지나치게 많으면 잡음까지 학습할 수 있으므로 특성을 무조건 많이 사용하는 것이 좋은 것은 아닙니다.

## 20. 교차검증

교차검증은 데이터를 여러 번 나누어 모델의 검증 성능을 확인하는 방법입니다.

모델의 복잡도나 초매개변수를 선택할 때 교차검증을 사용하면 특정 데이터 분할에만 맞춘 선택을 줄일 수 있습니다.

<mark>교차검증은 과적합 여부를 직접 제거하는 방법이라기보다 일반화 성능을 더 안정적으로 평가하고 모델을 선택하는 데 사용합니다.</mark>

## 21. 조기 종료

신경망처럼 반복해서 학습하는 모델에서는 훈련을 오래 할수록 훈련 성능이 계속 좋아질 수 있습니다.

하지만 어느 순간부터 검증 성능이 나빠질 수 있습니다.

이때 학습을 중단하는 방법이 조기 종료입니다.

```text
훈련 손실: 계속 감소
검증 손실: 감소하다가 다시 증가
→ 학습 중단
```

## 22. 학습 곡선으로 확인하기

학습 곡선은 훈련 성능과 검증 성능이 학습 과정에서 어떻게 변하는지 보여줍니다.

```text
과소적합: 훈련 낮음 / 검증 낮음
과적합: 훈련 매우 높음 / 검증 상대적으로 낮음
```

훈련 성능은 좋아지는데 검증 성능이 나빠지기 시작한다면 과적합을 의심할 수 있습니다.

## 23. 알고리즘에서 보는 예시

의사결정나무는 깊이가 너무 얕으면 과소적합, 지나치게 깊으면 과적합이 발생할 수 있습니다.

최근접 이웃에서는 이웃 수가 너무 많으면 지나치게 단순해질 수 있고, 너무 적으면 개별 데이터에 민감해질 수 있습니다.

<mark>초매개변수는 모델의 복잡도와 과적합·과소적합에 직접 영향을 줄 수 있습니다.</mark>

## 24. 편향·분산과의 관계

과소적합과 과적합은 편향과 분산으로 연결해서 기억하면 쉽습니다.

| 개념 | 연결 |
| --- | --- |
| 높은 편향 | 과소적합 |
| 높은 분산 | 과적합 |
| 낮은 복잡도 | 높은 편향 가능 |
| 높은 복잡도 | 높은 분산 가능 |

<mark>과소적합은 높은 편향, 과적합은 높은 분산과 연결됩니다.</mark>

## 25. 테스트 데이터는 마지막에 사용한다

모델의 복잡도나 규제를 조정할 때 테스트 데이터를 반복해서 사용하면 안 됩니다.

검증 데이터나 교차검증을 이용해 모델을 선택한 뒤 테스트 데이터는 마지막 최종 평가에 사용합니다.

테스트 결과를 보고 계속 모델을 수정하면 테스트 데이터에도 과적합될 수 있습니다.

## 26. 데이터 누수와 과적합

데이터 누수가 발생하면 검증이나 테스트 성능이 실제보다 높게 보일 수 있습니다.

이 경우 일반화 성능이 좋은 것처럼 착각할 수 있습니다.

따라서 전처리 기준은 훈련 데이터에서 계산하고 검증과 테스트 데이터에는 같은 기준을 적용해야 합니다.

<blockquote class="prompt-danger">
<p>검증 성능이 지나치게 좋다면 데이터 누수 가능성도 함께 확인해야 합니다.</p>
</blockquote>

## 27. 잘 놓치는 핵심

### 1. 과소적합은 훈련 성능도 낮다

모델이 기본적인 패턴조차 충분히 학습하지 못한 상태입니다.

### 2. 과적합은 훈련 성능만 보면 발견하기 어렵다

검증 데이터와 비교해야 합니다.

### 3. 복잡한 모델이 항상 좋은 것은 아니다

훈련 성능은 좋아져도 일반화 성능은 나빠질 수 있습니다.

### 4. 규제가 너무 강하면 과소적합이 발생할 수 있다

모델의 표현력이 지나치게 제한될 수 있기 때문입니다.

### 5. 데이터 증가가 과적합 완화에 도움이 될 수 있다

특정 데이터에 대한 의존을 줄일 수 있습니다.

### 6. 테스트 데이터로 모델을 조정하면 안 된다

모델 선택에는 검증 데이터나 교차검증을 사용합니다.

## 28. 시험·면접에서 기억할 것

### 핵심 암기

- 과소적합: 훈련 성능 낮음, 검증 성능 낮음
- 과적합: 훈련 성능 매우 높음, 검증 성능 상대적으로 낮음
- 과소적합: 높은 편향
- 과적합: 높은 분산
- 규제 강화: 복잡도 감소
- 데이터 증가: 과적합 완화에 도움
- 교차검증: 모델 선택과 일반화 성능 평가
- 조기 종료: 검증 성능이 나빠지기 전에 학습 중단

### 자주 나오는 질문

**과적합과 과소적합의 차이는 무엇인가요?**

과소적합은 모델이 너무 단순해서 훈련 데이터의 패턴도 충분히 학습하지 못한 상태입니다.

과적합은 훈련 데이터에는 지나치게 잘 맞지만 새로운 데이터에서는 성능이 떨어지는 상태입니다.

**과적합은 어떻게 확인할 수 있나요?**

훈련 성능은 매우 높지만 검증 성능이 상대적으로 낮고 두 성능의 차이가 크다면 과적합을 의심할 수 있습니다.

**과적합을 줄이는 방법은 무엇인가요?**

모델 단순화, 데이터 증가, 규제, 특성 선택, 교차검증, 조기 종료 등을 사용할 수 있습니다.

## 29. 예시로 한 바퀴

너무 단순한 모델이 훈련 데이터에서도 패턴을 제대로 구분하지 못하면 과소적합입니다.

반대로 훈련 고객의 세부적인 패턴까지 거의 완벽하게 외워 훈련 성능은 매우 높지만 새로운 고객에서 성능이 떨어지면 과적합입니다.

좋은 모델은 중요한 패턴은 학습하면서 특정 훈련 데이터의 잡음에는 지나치게 반응하지 않습니다.
