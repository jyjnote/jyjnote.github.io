군집은 **라벨 없이 비슷한 관측값끼리 묶는 비지도학습**입니다.  
하지만 무엇을 “비슷하다”고 보는지는 알고리즘마다 다릅니다.

<blockquote class="prompt-info">
<p>한 줄: K-means는 중심 거리, K-medoids는 실제 대표점, K-modes는 범주 불일치, 계층적 군집은 연결 구조, DBSCAN은 밀도, Mean Shift는 밀도 봉우리, Spectral은 그래프 연결을 봅니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>
대표 중심을 찾는 계열과 밀도·그래프 구조를 찾는 계열을 구분하고, 각 알고리즘이 요구하는 하이퍼파라미터와 잘 맞는 군집 모양을 기억합니다.
</details>

| --- | --- | --- | --- | --- |

| K-medoids | 대표점까지 거리 | 필요 | 실제 데이터 점 | 이상치에 상대적으로 강함 |

| 계층적 군집 | 군집 사이 연결 거리 | 처음엔 불필요 | 트리 구조 | 계층 관계 확인 |

시험에서 먼저 물어볼 것은 두 가지입니다.
1. **K를 미리 넣는가**
2. **무엇을 기준으로 가까움을 정의하는가**

# 2. K-means

## 2.1 핵심
K-means는 점을 가장 가까운 중심에 붙이고, 그 군집의 평균으로 중심을 다시 옮기는 군집입니다.
라벨은 없고 군집 수 \(K\)는 사용자가 정합니다.
목표는 군집 내부 제곱거리 합을 줄이는 것입니다.
$$J=\sum_{k=1}^{K}\sum_{x_i\in C_k}\|x_i-\mu_k\|^2$$
<mark>K-means의 목표는 분류 정확도가 아니라 군집 내부 제곱거리 합을 줄이는 것입니다.</mark>

## 2.2 한 라운드
1. 초기 중심 \(K\)개를 고릅니다.
2. 각 점을 가장 가까운 중심에 배정합니다.
3. 각 군집의 평균으로 중심을 갱신합니다.
4. 배정이 바뀌지 않거나 최대 반복 횟수에 도달하면 멈춥니다.

## 2.3 중심은 항상 데이터 점인가
아닙니다.
초기 중심은 실제 데이터 점에서 고르는 경우가 흔하지만, 평균으로 갱신한 중심은 실제 데이터에 존재하지 않는 좌표일 수 있습니다.
```text
시작 중심
→ 실제 점일 수 있음
갱신 중심
→ 군집 평균
→ 데이터에 없는 좌표 가능
```

## 2.4 손계산 핵심
배정만 비교할 때는 제곱근을 생략해도 거리 순위가 같습니다.
하지만 목적함수 SSE에는 **제곱거리**를 더해야 합니다.
```text
배정
→ 거리² 비교 가능
SSE
→ 거리² 자체를 합함
```

## 2.5 K-means++
초기 중심을 더 안정적으로 잡기 위한 방법입니다.
1. 첫 중심은 데이터 점 하나를 선택합니다.
2. 다음 중심은 기존 중심에서 먼 점일수록 선택될 가능성을 높입니다.
3. \(K\)개를 고른 뒤 일반 K-means를 수행합니다.
초기값에 따라 결과가 달라질 수 있으므로 여러 시작을 시험하고 목적함수가 작은 해를 고를 수 있습니다.

## 2.6 K 선택
대표적인 방법은 다음과 같습니다.
- 엘보우
- 실루엣
- 도메인 지식
K를 늘리면 군집 내부 제곱거리 합은 대체로 감소합니다.
따라서 <mark>목적함수가 작다는 이유만으로 K가 클수록 좋은 것은 아닙니다.</mark>
\(K=N\)이면 각 점이 하나의 군집이 되어 목적함수는 0이 될 수 있습니다.

## 2.7 잘 맞는 데이터
둥글고 비슷한 크기의 군집에는 잘 맞습니다. 달 모양·길쭉한 군집·이상치·밀도 차이가 큰 군집에는 약합니다.

## 2.8 스케일
거리 기반이므로 변수 스케일이 매우 중요합니다.
```text
키: 0 ~ 2
소득: 0 ~ 100000
```
이라면 표준화하지 않았을 때 소득이 거리를 거의 결정할 수 있습니다.

# 3. K-medoids

## 3.1 핵심
K-medoids는 평균 좌표 대신 **실제 데이터 점 하나**를 군집 대표로 사용합니다.
군집 \(k\)의 메도이드는 다음과 같습니다.
$$m_k=\arg\min_{x_j\in C_k}\sum_{x_i\in C_k}d(x_i,x_j)$$
즉, 같은 군집의 다른 점들과의 거리 합이 가장 작은 실제 점입니다.

## 3.2 K-means와 차이
| 구분 | K-means | K-medoids |
| --- | --- | --- |
| 대표 | 평균 좌표 | 실제 데이터 점 |
| 거리 | 유클리드 제곱거리 중심 | 다양한 거리 가능 |
| 이상치 | 민감 | 상대적으로 덜 민감 |
| 계산량 | 작은 편 | 큰 편 |
| 해석 | 평균 프로필 | 대표 샘플 |

## 3.3 PAM 감각
1. 초기 메도이드 \(K\)개를 정합니다.
2. 각 점을 가장 가까운 메도이드에 붙입니다.
3. 다른 실제 점으로 대표를 바꿨을 때 거리 합이 줄어드는지 확인합니다.
4. 더 이상 좋아지는 교체가 없으면 멈춥니다.
대표 후보가 실제 데이터 점으로 제한되므로 K-means보다 계산 부담이 커질 수 있습니다.

# 4. K-modes

## 4.1 왜 필요한가
범주형 데이터에서는 평균이 의미가 없습니다.
```text
서울 = 1
부산 = 2
제주 = 3
```
처럼 숫자로 바꿔 평균 1.7을 구해도 1.7번 도시는 없습니다.
그래서 K-modes는
```text
평균
→ 최빈값
유클리드 거리
→ 불일치 개수
```
로 바꿉니다.

## 4.2 불일치 거리
$$d(x,z)=\sum_{j=1}^{p}\mathbf{1}[x_j\ne z_j]$$
두 관측값에서 값이 다른 범주형 변수의 개수를 셉니다.

## 4.3 중심
군집 중심은 각 열에서 가장 많이 등장한 값의 조합입니다.
$$m_{k,j}=\operatorname{mode}\{x_{ij}:x_i\in C_k\}$$
예를 들어 한 군집에서 도시가
```text
서울 7명
부산 2명
제주 1명
```
이라면 도시 변수의 중심은 서울입니다.

# 5. K-prototypes
숫자형 변수와 범주형 변수가 함께 있을 때 사용합니다.
```text
숫자형
→ 평균 + 제곱거리
범주형
→ 최빈값 + 불일치
둘을 가중하여 합침
```
시험 한 줄:
> 범주형만 있으면 K-modes, 숫자형과 범주형이 섞이면 K-prototypes.

# 6. 계층적 군집

## 6.1 핵심
처음부터 평평한 K개 군집을 만드는 대신, 군집이 합쳐지거나 쪼개지는 과정을 나무 형태로 만듭니다.
이 나무가 **덴드로그램**입니다.

## 6.2 두 방향
### 병합식
1. 각 점을 하나의 군집으로 시작합니다.
2. 가장 가까운 두 군집을 합칩니다.
3. 하나의 군집이 될 때까지 반복합니다.
### 분할식
1. 전체 데이터를 하나의 군집으로 시작합니다.
2. 군집을 계속 나눕니다.
3. 필요한 수준까지 분할합니다.
시험에서는 병합식이 더 기본적입니다.

## 6.3 링키지
계층적 군집의 핵심은 **군집과 군집 사이 거리를 어떻게 정하는가**입니다.
### 단일 연결
$$D(A,B)=\min_{a\in A,b\in B}d(a,b)$$
가장 가까운 점 한 쌍을 봅니다.
- 사슬 효과
- 길게 이어진 모양에 상대적으로 유리
- 작은 연결 다리에도 군집이 합쳐질 수 있음
### 완전 연결
$$D(A,B)=\max_{a\in A,b\in B}d(a,b)$$
가장 먼 점 한 쌍을 봅니다.
- 조밀한 덩어리 선호
- 길쭉한 군집은 늦게 합쳐짐
### 평균 연결
모든 점 쌍 거리의 평균을 사용합니다.
단일과 완전 연결의 중간 감각입니다.
### Ward
두 군집을 합쳤을 때 SSE가 얼마나 증가하는지를 봅니다.
<mark>Ward는 SSE 증가가 가장 작은 군집 쌍을 합칩니다.</mark>

## 6.4 덴드로그램
덴드로그램의 높이는 시간 순서가 아니라 **군집이 합쳐질 때의 거리**를 나타냅니다.
트리를 먼저 만든 뒤 원하는 높이에서 잘라 최종 군집 수를 정할 수 있습니다.

# 7. DBSCAN

## 7.1 핵심
DBSCAN은 중심이나 K를 사용하지 않고 **밀도가 높은 점들의 연결**을 군집으로 봅니다.
필요한 핵심 값은 두 개입니다.
- \(\varepsilon\): 이웃으로 볼 거리
- 최소 표본 수: 핵심점이 되기 위한 최소 이웃 수
점 \(x\)의 이웃은 다음과 같습니다.
$$N_{\varepsilon}(x)=\{y:d(x,y)\le\varepsilon\}$$

## 7.2 세 종류의 점
### 핵심점
\(\varepsilon\) 안의 점 수가 최소 표본 수 이상입니다.
자기 자신도 포함합니다.
### 경계점
자기 주변만 보면 핵심점 조건을 만족하지 못하지만 어떤 핵심점의 이웃 안에 들어갑니다.
### 노이즈
핵심점도 아니고 어떤 핵심점에도 연결되지 않습니다.
보통 노이즈 라벨은 \(-1\)입니다.

## 7.3 군집 확장
```text
핵심점 발견
→ 이웃을 같은 군집에 포함
→ 이웃 중 다른 핵심점이 있으면 그 이웃까지 확장
→ 연결이 끊길 때까지 반복
```
따라서 군집은 꼭 둥글 필요가 없습니다.
점들이 밀도 있게 이어져 있으면 달 모양처럼 굽은 군집도 만들 수 있습니다.

## 7.4 매개변수 영향
```text
ε 증가
→ 이웃 범위 증가
→ 군집이 커지거나 서로 합쳐질 수 있음
→ 노이즈 감소 가능
최소 표본 수 증가
→ 핵심점 조건이 엄격해짐
```

## 7.5 약점
군집별 밀도가 크게 다르면 하나의 \(\varepsilon\)로 모두 잡기 어렵고, 고차원에서는 거리 구분력도 약해질 수 있습니다.

# 8. Mean Shift

## 8.1 핵심
Mean Shift는 각 점을 주변 점의 평균 방향으로 반복 이동시켜 **밀도가 높은 봉우리**에 모이게 합니다.
군집 수 K를 직접 넣지 않습니다.
<mark>봉우리의 개수가 결과적으로 군집 수가 됩니다.</mark>

## 8.2 이동
평평한 창을 사용한 단순한 감각은 다음과 같습니다.
$$m(x)=\frac{\sum_i x_i\mathbf{1}[\|x_i-x\|\le h]}{\sum_i\mathbf{1}[\|x_i-x\|\le h]}$$
그다음 현재 점을 주변 평균으로 이동시킵니다.
$$x\leftarrow m(x)$$

## 8.3 bandwidth
\(h\)는 얼마나 넓은 주변을 볼지 정합니다.
```text
h 작음
→ 작은 봉우리까지 분리
→ 군집 수 증가 가능
h 큼
→ 여러 봉우리가 합쳐짐
→ 군집 수 감소 가능
```
bandwidth는 학습률이 아닙니다.

## 8.4 DBSCAN과 차이
둘 다 밀도와 관련 있지만 기준이 다릅니다.
```text
DBSCAN
→ 핵심·경계·노이즈
→ 밀도 연결
Mean Shift
→ 주변 평균으로 이동
→ 밀도 봉우리 탐색
```

# 9. Spectral Clustering

## 9.1 핵심
Spectral Clustering은 원래 좌표에서 평균 중심을 직접 찾지 않습니다.
먼저 비슷한 점들을 그래프로 연결한 뒤, 그래프의 구조를 새로운 좌표로 바꾸고 그 공간에서 군집합니다.
<mark>평균이 가까운가가 아니라 서로 얼마나 단단히 연결되어 있는가를 봅니다.</mark>

## 9.2 유사도 그래프
대표적인 유사도는 RBF 형태입니다.
$$W_{ij}=\exp(-\gamma\|x_i-x_j\|^2)$$
- 가까운 점 → 큰 유사도
- 먼 점 → 0에 가까운 유사도
또는 최근접 이웃 그래프를 만들 수 있습니다.

## 9.3 차수 행렬
점 \(i\)의 연결 강도 합을 대각 성분에 둡니다.
$$D_{ii}=\sum_j W_{ij}$$

## 9.4 그래프 라플라시안
비정규화 라플라시안은 다음과 같습니다.
$$L=D-W$$
정규화된 형태도 사용할 수 있습니다.
$$L_{sym}=I-D^{-1/2}WD^{-1/2}$$

## 9.5 고유벡터가 새 좌표
라플라시안의 고유벡터를 이용해 데이터를 새로운 공간에 펼칩니다.
$$Lu=\lambda u$$
이 새 공간에서는 원래 달 모양처럼 복잡했던 군집이 더 쉽게 나뉠 수 있습니다.
그 뒤 K-means를 적용하는 방식이 흔합니다.

## 9.6 시험 핵심
```text
유사도 행렬 W
→ 차수 행렬 D
→ 라플라시안 L
→ 고유벡터
→ 새 좌표
→ K-means
```
Spectral Clustering은 K가 여전히 필요합니다.
DBSCAN처럼 군집 수가 자동으로 결정되는 방식은 아닙니다.

# 10. 알고리즘 선택 지도
| 데이터 상황 | 우선 떠올릴 방법 |
| --- | --- |
| 숫자형·둥근 군집·속도 중요 | K-means |
| 실제 대표 샘플 필요·이상치 존재 | K-medoids |
| 범주형 변수만 존재 | K-modes |
| 숫자형 + 범주형 혼합 | K-prototypes |
| 계층 관계와 덴드로그램 필요 | 계층적 군집 |
| K를 모르고 노이즈도 분리 | DBSCAN |
| 밀도 봉우리 자체를 찾고 싶음 | Mean Shift |
| 달 모양·그래프 연결 구조 중요 | Spectral Clustering |

# 11. K와 대표값 비교
| 방법 | K | 대표·핵심 구조 |
| --- | --- | --- |
| K-means | 필요 | 평균 |
| K-medoids | 필요 | 실제 점 |
