FP-Growth는 Apriori와 **같은 빈발 항목집합**을 찾습니다.  
다른 점은 후보 $$C_{k}$$를 매번 만들지 않고, 거래를 **FP-트리**에 한 번 올려 둔 뒤 트리를 타고 패턴을 키운다는 것입니다.

<blockquote class="prompt-info">
  <p>FP-Growth = Frequent Pattern Growth. 지지도·신뢰도·향상도 정의는 Apriori와 같습니다. 바뀌는 것은 빈발 집합을 찾는 방법입니다.</p>
</blockquote>

## Apriori와 무엇이 다른가

Apriori:

1. 크기 $$k$$ 빈발 집합을 구함
2. 그것을 이어 크기 $$k+1$$ 후보를 만듦
3. 거래 전체를 다시 읽어 지지도를 셈

FP-Growth:

1. 거래에서 빈발한 개별 항목만 남김
2. 빈도 순으로 정렬해 FP-트리에 삽입
3. 항목마다 조건부 패턴 베이스를 읽고, 작은 트리를 다시 만듦
4. 후보 집합을 일일히 생성하지 않음

출력되는 빈발 집합은 최소 지지도가 같으면 Apriori와 같습니다.  
규칙 $$A\Rightarrow B$$의 신뢰도·향상도 공식도 같습니다.

## 같은 거래

| 거래 | 항목 |
| :---: | :--- |
| T1 | 빵, 우유 |
| T2 | 빵, 기저귀, 맥주 |
| T3 | 우유, 기저귀, 맥주 |
| T4 | 빵, 우유, 기저귀 |
| T5 | 빵, 우유, 기저귀, 맥주 |

$$N=5$$, 최소 지지도 $$0.6$$(3건).

개별 빈도:

| 항목 | 건수 | 지지도 | 빈발 |
| :--- | ---: | ---: | :---: |
| 빵 | 4 | 0.8 | 예 |
| 우유 | 4 | 0.8 | 예 |
| 기저귀 | 4 | 0.8 | 예 |
| 맥주 | 3 | 0.6 | 예 |

네 항목 모두 남습니다.  
트리에 넣을 때는 빈도 내림차순으로 정렬합니다. 빈도가 같으면 이름을 고정합니다. 여기선

$$
\text{빵} \to \text{우유} \to \text{기저귀} \to \text{맥주}
$$

로 둡니다.

정렬 후 거래:

| 거래 | 삽입 순서 |
| :---: | :--- |
| T1 | 빵, 우유 |
| T2 | 빵, 기저귀, 맥주 |
| T3 | 우유, 기저귀, 맥주 |
| T4 | 빵, 우유, 기저귀 |
| T5 | 빵, 우유, 기저귀, 맥주 |

희소 항목을 먼저 지우지 않으면 트리가 커지고, 최소 지지도를 못 넘는 가지가 생깁니다.

## FP-트리

루트는 빈 노드입니다. 거래를 앞에서부터 한 경로로 넣습니다.  
이미 있는 가지를 지나가면 그 노드의 숫자만 1 올립니다. 없으면 노드를 새로 답니다.

다섯 거래를 넣은 뒤:

- 빵(4)
  - 우유(3) ← T1, T4, T5
    - 기저귀(2) ← T4, T5
      - 맥주(1) ← T5
  - 기저귀(1) ← T2
    - 맥주(1) ← T2
- 우유(1) ← T3
  - 기저귀(1)
    - 맥주(1) ← T3

읽는 법:

- 빵(4): 빵이 네 거래에 있음
- 빵–우유(3): 빵 다음 우유가 세 거래(T1, T4, T5)
- T2는 우유가 없어서 빵 아래 다른 가지(빵–기저귀–맥주)
- T3는 빵이 없어서 루트에서 우유로 시작

같은 항목이 여러 가지에 있으면 **헤더 테이블**이 그 노드들을 연결합니다.  
맥주 노드가 세 곳에 있으므로, 맥주를 볼 때 세 경로만 따라가면 됩니다.

## 조건부 패턴 베이스

빈발 패턴은 빈도 낮은 항목부터 올립니다. 맥주부터 보겠습니다.

맥주로 가는 경로(맥주는 빼고 앞쪽만):

| 경로 | 횟수 |
| :--- | ---: |
| 빵, 기저귀 | 1 |
| 빵, 우유, 기저귀 | 1 |
| 우유, 기저귀 | 1 |

이것이 맥주의 **조건부 패턴 베이스**입니다.  
“맥주가 나온 거래에서, 맥주보다 앞선 빈발 항목들”입니다.

이 세 경로만으로 지지도를 다시 셉니다.

- 기저귀: 1+1+1=3 → 지지도 $$0.6$$. 남음
- 빵: 1+1=2 → $$0.4$$. 탈락
- 우유: 1+1=2 → $$0.4$$. 탈락

맥주와 같이 빈발한 앞 항목은 기저귀뿐입니다.  
따라서 빈발 집합 {기저귀, 맥주}가 나옵니다. 지지도 $$3/5=0.6$$.

빵·우유는 맥주와 함께일 때 3건을 못 채우므로 {빵, 맥주}, {우유, 맥주}는 빈발이 아닙니다. Apriori 표와 같습니다.

기저귀로 올라가면 {빵, 기저귀}, {우유, 기저귀}가 각각 3건으로 남고, 빵·우유·기저귀 세 개는 2건이라 탈락합니다. 앞 글과 동일한 $$L_{k}$$입니다.

## 규칙

빈발 집합을 구한 뒤의 규칙은 Apriori와 한 줄도 다르지 않습니다.

$$
\mathrm{conf}(\{\text{기저귀}\}\Rightarrow\{\text{맥주}\})=\frac{0.6}{0.8}=0.75
$$

$$
\mathrm{lift}=\frac{0.75}{0.6}=1.25
$$

FP-Growth가 신뢰도 공식을 바꾸는 것이 아닙니다.  
바꾸는 것은 “어떤 조합을 세러 거래를 몇 번 훑느냐”입니다.

## 왜 빠른가

- 희소 항목을 버린 뒤, 거래를 트리 경로로 압축함
- 같은 앞부분이 반복되면 노드 숫자만 증가
- 후보 $$C_{k}$$를 전부 만들지 않음
- 조건부 베이스는 해당 항목 경로만 읽음

거래가 비슷비슷하면 트리가 얇아져 이득이 큽니다.  
거의 모든 거래가 서로 다른 항목 조합이면 트리가 거래 수만큼 넓어져, Apriori와 부담이 비슷해질 수 있습니다.

최소 지지도를 너무 낮추면 개별 항목이 많이 남아 트리가 커집니다.  
최소 지지도의 의미는 Apriori와 같습니다.

## 시험·면접

<blockquote class="prompt-info">
  <p>단골: 후보 비생성, FP-트리 + 헤더 테이블, 빈도 순 삽입, 조건부 패턴 베이스, 지표 공식은 Apriori와 동일.</p>
</blockquote>

## 잘 놓치는 핵심

- 찾는 빈발 집합은 Apriori와 같음
- 다른 것은 탐색 방식
- 넣기 전에 희소 1-항목을 버리고 빈도 순으로 정렬
- 조건부 베이스 = 그 항목으로 가는 앞쪽 경로
- 신뢰도·향상도는 빈발 집합을 구한 다음에 계산
- 트리가 항상 작은 것은 아님
