앙상블은 **여러 모델의 예측을 합쳐 하나의 더 안정적인 예측을 만드는 방법**입니다.

이 글에서는 배깅, 랜덤포레스트, 엑스트라 트리를 중심으로 정리합니다.

<blockquote class="prompt-info">
<p>한 줄: 배깅은 데이터, 랜덤포레스트는 데이터+특징, 엑스트라 트리는 특징+임계값에 무작위성을 더합니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

Bagging = Bootstrap + Aggregating  
Random Forest = Bagging + 분기별 특징 무작위  
Extra Trees = 특징 무작위 + 임계값 무작위

</details>

## 1. 앙상블의 기본 생각

모델 하나의 예측은 학습 데이터에 따라 흔들릴 수 있습니다.

여러 모델을 만들고 예측을 평균하거나 투표하면 이런 흔들림을 줄일 수 있습니다.

분류에서는 다수결이나 확률 평균을, 회귀에서는 평균을 주로 사용합니다.

## 2. 약한 학습기와 강한 학습기

약한 학습기는 단순하고 단독 성능이 낮은 모델, 강한 학습기는 단독 또는 결합 후 높은 성능을 내는 모델입니다.

앙상블에서는 개별 모델의 오류가 서로 다르게 나타나는 것이 중요합니다.

## 3. Bagging

Bagging은 Bootstrap Aggregating의 줄임말입니다.

같은 종류의 모델을 서로 다른 부트스트랩 표본으로 여러 개 학습한 뒤 예측을 합칩니다.

```text
원 데이터
→ 부트스트랩 표본 1 → 모델 1
→ 부트스트랩 표본 2 → 모델 2
→ 부트스트랩 표본 3 → 모델 3
→ 평균 또는 투표
```

## 4. 부트스트랩

크기 n인 원 데이터에서 **복원추출로 n개를 다시 뽑는 것**입니다.

- 같은 행이 여러 번 들어갈 수 있음
- 어떤 행은 한 번도 안 뽑힐 수 있음

즉, 뽑은 데이터를 다시 넣고 또 뽑습니다.

## 5. 한 점이 선택되지 않을 확률

한 번 뽑을 때 특정 점이 선택되지 않을 확률은 다음과 같습니다.

$$1-\frac{1}{n}$$

n번 모두 선택되지 않을 확률은 다음과 같습니다.

$$\left(1-\frac{1}{n}\right)^n\approx\frac{1}{e}\approx0.368$$

즉, 한 부트스트랩 표본에서 약 36.8%는 빠집니다.

## 6. 고유 표본과 OOB

부트스트랩 표본에는 원 데이터의 약 63.2% 정도가 고유하게 포함됩니다.

```text
고유하게 포함 ≈ 63.2%
포함되지 않음 ≈ 36.8%
```

빠진 약 36.8%가 OOB입니다.

## 7. OOB

OOB는 Out-of-Bag의 약자입니다.

특정 나무의 부트스트랩 표본에 들어가지 않은 데이터입니다.

그 나무 입장에서는 학습 중 보지 못한 데이터입니다.

## 8. OOB 평가는 학습이 아니다

OOB는 다음 나무를 학습시키는 입력이 아닙니다.

학습이 끝난 뒤 성능을 평가하는 데 사용합니다.

각 데이터에 대해 자신을 학습에 사용하지 않은 나무들의 예측만 모읍니다.

## 9. OOB 분류와 회귀

분류는 OOB 나무들의 투표·확률 평균, 회귀는 평균으로 OOB 예측을 만들고 실제 정답과 비교합니다.

## 10. 배깅의 회귀 집계

B개의 모델을 평균하면 다음과 같습니다.

$$\hat{y}(x)=\frac{1}{B}\sum_{b=1}^{B}f_b(x)$$

f_b는 b번째 모델의 예측입니다.

## 11. 배깅은 같은 모델을 여러 번 쓴다

배깅은 다른 알고리즘을 섞는 것이 아닙니다.

같은 종류의 모델을 다른 부트스트랩 표본에 학습시킵니다.

```text
같은 모델
+
다른 학습 표본
```

## 12. 배깅이 줄이는 것은 주로 분산

분산은 학습 데이터가 바뀔 때 예측이 얼마나 흔들리는지를 나타냅니다.

배깅은 여러 모델의 서로 다른 흔들림을 평균해 분산을 줄입니다.

<mark>배깅의 핵심 효과는 분산 감소입니다.</mark>

## 13. 왜 편향은 남는가

모든 모델의 구조가 같다면 구조적 한계도 공유합니다.

예를 들어 모든 나무를 깊이 2로 제한하면 어느 가방을 사용해도 매우 거친 계단형 모델만 만듭니다.

여러 개를 평균해도 이 구조적 한계는 남습니다.

```text
데이터 변화에서 오는 흔들림 → 분산
모델 구조 자체의 한계 → 편향
```

## 14. 그루 수만 늘리면 충분한가

나무 수를 늘리면 평균은 안정되지만 모델 구조 자체의 편향은 그대로 남습니다.

## 15. 배깅의 약점

중요한 특징이 하나 압도적이면 거의 모든 나무가 그 특징으로 먼저 자를 수 있습니다.

그러면 나무들의 예측이 서로 비슷해집니다.

즉, 나무 사이 상관이 높아집니다.

## 16. 왜 상관이 문제인가

여러 모델이 같은 방향으로 틀리면 평균의 효과가 작습니다.

```text
나무 1이 틀림
나무 2도 비슷하게 틀림
나무 3도 비슷하게 틀림
```

랜덤포레스트는 이 상관을 줄이기 위해 특징 무작위성을 추가합니다.

## 17. Random Forest

랜덤포레스트는 배깅 결정트리에 **노드마다 특징 일부만 무작위로 공개하는 방법**을 추가합니다.

```text
부트스트랩
+
분기별 특징 무작위 선택
```

## 18. 한 노드에서 하는 일

전체 특징이 p개라고 합시다.

노드를 자를 때 p개를 모두 보지 않고 m개만 무작위로 뽑습니다.

그 m개 안에서 지니 또는 SSE 기준으로 가장 좋은 분기를 선택합니다.

## 19. p와 m

p는 전체 특징 수입니다.

m은 한 노드에서 공개하는 특징 수입니다.

예를 들어 p=10, m=3이면 매 노드마다 10개 중 3개만 후보로 봅니다.

## 20. 특징은 노드마다 다시 뽑는다

루트에서 쓴 특징을 제거하지 않습니다.

각 노드마다 전체 p개에서 m개를 다시 뽑습니다.

```text
루트 → p개 중 m개
왼쪽 자식 → 다시 p개 중 m개
오른쪽 자식 → 다시 p개 중 m개
```

## 21. 같은 특징을 다시 사용할 수 있다

한 노드에서 쓴 특징도 다음 노드에서 다시 후보가 될 수 있습니다.

## 22. 같은 변수 연속 분할

`몸무게 ≤ 70` 다음에 `몸무게 ≤ 55`처럼 같은 변수를 다른 임계값으로 다시 나누는 것은 정상입니다.

## 23. 랜덤포레스트의 핵심 목적

중요한 특징을 모든 나무가 항상 보지 못하게 합니다.

그래서 나무들이 서로 다른 질문을 하게 됩니다.

<mark>랜덤포레스트의 특징 무작위화 목적은 나무 사이 상관도를 낮추는 것입니다.</mark>

## 24. m=p이면

매 노드에서 모든 특징을 볼 수 있습니다.

특징 무작위성이 사라져 랜덤포레스트는 배깅과 가까워집니다.

## 25. m=1이면

무작위성이 매우 강해집니다.

좋은 특징을 못 보는 노드가 많아질 수 있어 분기 품질이 떨어지고 편향이 커질 수 있습니다.

## 26. 랜덤포레스트는 부스팅이 아니다

나무들은 앞 나무의 오류나 잔차를 이어받지 않습니다.

서로 독립적으로 학습할 수 있으므로 병렬 학습이 가능합니다.

```text
배깅·랜덤포레스트 → 병렬
부스팅 → 순차
```

## 27. 표준화는 필수가 아니다

트리는 거리나 계수 크기를 직접 비교하지 않습니다.

임계값 기준으로 순서를 나누므로 표준화가 필수는 아닙니다.

## 28. 다수결과 확률 평균은 다를 수 있다

세 나무의 양성 확률이 다음과 같다고 합시다.

```text
0.49
0.49
0.90
```

단순 클래스 투표는 음성 2표, 양성 1표입니다.

확률 평균은 다음과 같습니다.

$$\frac{0.49+0.49+0.90}{3}\approx0.627$$

확률 평균 기준에서는 양성이 될 수 있습니다.

## 29. 랜덤포레스트와 OOB

랜덤포레스트는 부트스트랩을 사용하므로 OOB 평가를 사용할 수 있습니다.

OOB는 유용한 내부 평가지만 최종 테스트셋과 같은 개념은 아닙니다.

## 30. 불균형 데이터와 부트스트랩

소수 클래스가 매우 적으면 일부 부트스트랩 표본에서 소수 클래스가 더 줄 수 있으므로 불균형 처리를 별도로 고려합니다.

## 31. 랜덤포레스트 회귀의 외삽

각 회귀나무는 끝 잎의 평균을 반환합니다.

랜덤포레스트는 그 끝 잎 평균들을 다시 평균합니다.

따라서 학습 범위를 벗어난 외삽에는 약합니다.

## 32. Extra Trees

Extra Trees는 Extremely Randomized Trees의 줄임말입니다.

랜덤포레스트보다 분기 임계값까지 더 강하게 무작위화한 나무 숲입니다.

## 33. Random Forest와 Extra Trees 차이

랜덤포레스트는 선택된 특징 안에서 좋은 임계값을 탐색합니다.

엑스트라 트리는 임계값 자체도 무작위 후보로 뽑고 그중 나은 것을 선택합니다.

```text
RF → 특징 무작위, 임계값 최적 탐색
ET → 특징 무작위, 임계값도 무작위 후보
```

## 34. Extra Trees 한 노드

한 노드에서는 다음 순서로 진행됩니다.

1. 전체 p개 특징 중 m개 선택
2. 선택된 특징마다 임계값을 무작위로 생성
3. 그 랜덤 후보 분기 중 가장 좋은 것을 선택

분류에서는 지니 등을, 회귀에서는 SSE 등을 사용할 수 있습니다.

## 35. 임계값 예시

값이 `10, 20, 30, 40`일 때 RF는 여러 후보 임계값을 평가하지만 Extra Trees는 무작위 후보 일부만 평가할 수 있습니다.

## 36. Extra Trees가 빠른 이유

가능한 임계값을 전부 정교하게 탐색하지 않습니다.

따라서 분기 탐색 비용이 줄어 학습이 더 빠를 수 있습니다.

## 37. Extra Trees의 기본 부트스트랩

엑스트라 트리는 기본적으로 부트스트랩을 사용하지 않습니다.

각 트리가 원 학습 데이터 전체를 사용할 수 있습니다.

그럼에도 임계값 무작위성 때문에 나무들이 서로 달라집니다.

## 38. 왜 기본 부트스트랩이 필요 없나

엑스트라 트리는 분기 위치 자체를 강하게 무작위화합니다.

즉, 데이터까지 다시 뽑지 않아도 나무 사이 차이가 충분히 생길 수 있습니다.

<mark>트리가 잘 갈라져서가 아니라, 이미 임계값 무작위화로 트리 상관을 줄이기 때문입니다.</mark>

## 39. Extra Trees에서도 부트스트랩 가능

원하면 다음처럼 부트스트랩을 켤 수 있습니다.

```text
bootstrap = True
```

그러면 각 트리는 복원추출한 표본으로 학습합니다.

## 40. Extra Trees와 OOB

부트스트랩을 사용하지 않으면 OOB 데이터가 없습니다.

따라서 기본 Extra Trees에서는 OOB 평가를 사용할 수 없습니다.

부트스트랩을 켜면 OOB가 생기므로 OOB 평가도 가능합니다.

```text
bootstrap = True
oob_score = True
```

## 41. Extra Trees의 장점과 단점

장점은 트리 간 상관 감소와 빠른 학습이고, 단점은 랜덤 임계값 때문에 편향이 커질 수 있다는 점입니다.

## 42. Bagging, RF, Extra Trees 비교

| 항목 | Bagging | Random Forest | Extra Trees |
| --- | --- | --- | --- |
| 부트스트랩 | O | O | 기본 X |
| 특징 무작위 | X | O | O |
| 임계값 무작위 | X | X | O |
| OOB | O | O | 부트스트랩 시 O |
| 핵심 | 분산 감소 | 상관 감소 추가 | 더 강한 무작위화 |

## 43. 무작위성과 상관도

무작위성이 커질수록 나무 사이 상관은 줄어드는 경향이 있습니다.

하지만 개별 나무의 분기 품질은 낮아질 수 있습니다.

```text
무작위성 증가
→ 상관 감소
→ 분산 감소에 도움
→ 너무 강하면 편향 증가 가능
```

## 44. 배깅과 부스팅의 차이

배깅 계열은 각 모델을 독립적으로 학습합니다.

부스팅은 앞 모델이 잘못 맞힌 부분을 다음 모델이 이어받습니다.

```text
배깅 → 병렬
부스팅 → 순차
```

## 45. 언제 무엇을 쓰나

- Bagging: 기본 모델의 분산이 큰 경우
- Random Forest: 표 데이터에서 안정적이고 강한 기준 모델이 필요할 때
- Extra Trees: 더 빠른 학습과 낮은 트리 상관을 원할 때

## 46. 잘 놓치는 핵심

- Bagging은 같은 모델을 다른 부트스트랩 표본에 학습
- OOB는 해당 나무가 보지 않은 평가용 데이터
- Bagging은 주로 분산 감소
- Random Forest는 노드마다 특징 일부를 다시 뽑음
- 같은 특징은 다음 노드에서 다시 사용할 수 있음
- m=p이면 Bagging과 가까워짐
- Extra Trees는 임계값까지 무작위
- Extra Trees 기본은 부트스트랩 없음
- Extra Trees도 bootstrap=True면 OOB 가능

## 47. 시험·면접 핵심

- Bagging = Bootstrap Aggregating
- 부트스트랩 = 복원추출
- OOB ≈ 36.8%, 고유 표본 ≈ 63.2%
- RF = Bagging + 노드별 특징 무작위
- Extra Trees = 특징 무작위 + 임계값 무작위
- RF·ET는 부스팅이 아닌 병렬 앙상블
- 트리 계열은 표준화가 필수 아님
- 회귀 숲은 외삽에 약함
