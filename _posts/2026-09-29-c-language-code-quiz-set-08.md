## 문제 1. 배열 인덱스와 전위·후위 증가

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a[] = {10, 20, 30, 40};
    int i = 1;

    int x = a[i++];
    int y = a[++i];

    printf("%d %d %d\n", i, x, y);

    return 0;
}
```

① `2 20 30`  
② `3 20 40`  
③ `3 30 40`  
④ `2 20 40`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>3 20 40</code></strong>입니다.</p>

### 1. 실행 전 상태

배열:

```text
인덱스   0   1   2   3
값      10  20  30  40
```

변수:

```text
i = 1
```

### 2. 첫 번째 문장

```c
int x = a[i++];
```

후위 증가이므로 현재 `i` 값을 먼저 사용합니다.

현재:

```text
i = 1
```

따라서 먼저:

```text
a[1] = 20
```

을 읽습니다.

```text
x = 20
```

그 후 `i`가 증가합니다.

```text
i = 2
```

### 3. 두 번째 문장

```c
int y = a[++i];
```

이번에는 전위 증가입니다.

먼저 `i`가 증가합니다.

```text
i = 3
```

그 후:

```text
a[3] = 40
```

을 읽습니다.

```text
y = 40
```

### 4. 최종 상태

```text
i = 3
x = 20
y = 40
```

따라서:

```text
3 20 40
```

### 반드시 알아야 할 개념

배열 인덱스 안에서도 전위·후위 증가 규칙은 그대로 적용됩니다.

```c
a[i++]
```

는 현재 인덱스를 사용한 후 `i`를 증가시킵니다.

```c
a[++i]
```

는 `i`를 먼저 증가시킨 뒤 그 인덱스를 사용합니다.

### 자주 하는 실수

두 표현 모두 `i`를 증가시키므로 같은 인덱스를 읽는다고 생각하면 안 됩니다.

<mark>배열에서는 증가 시점이 곧 어떤 원소를 읽는지를 결정합니다.</mark>

</details>

## 문제 2. 중첩 반복문의 실행 횟수

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;

    for (int i = 1; i <= 3; i++) {
        for (int j = 0; j < i; j++) {
            sum += i;
        }
    }

    printf("%d\n", sum);

    return 0;
}
```

① `6`  
② `9`  
③ `14`  
④ `18`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>③ <code>14</code></strong>입니다.</p>

### 1. 핵심 구조

안쪽 반복문의 조건은:

```c
j < i
```

입니다.

따라서 바깥쪽 `i` 값에 따라 안쪽 반복 횟수가 달라집니다.

### 2. i = 1

```text
j = 0
```

한 번 실행됩니다.

매번 `sum += i`이므로:

```text
sum = 0 + 1 = 1
```

### 3. i = 2

안쪽 반복은:

```text
j = 0
j = 1
```

총 두 번입니다.

각 반복마다 2를 더합니다.

```text
sum = 1 + 2 + 2
    = 5
```

### 4. i = 3

안쪽 반복은:

```text
j = 0
j = 1
j = 2
```

총 세 번입니다.

각 반복마다 3을 더합니다.

```text
sum = 5 + 3 + 3 + 3
    = 14
```

### 5. 최종 출력

```text
14
```

### 빠른 계산

각 `i`가 자신의 값만큼 반복됩니다.

따라서:

```text
1 × 1
+ 2 × 2
+ 3 × 3
= 1 + 4 + 9
= 14
```

### 반드시 알아야 할 개념

중첩 반복문에서는 단순히:

```text
1 + 2 + 3
```

을 계산하는 것이 아닙니다.

각 바깥 반복마다 **안쪽 반복이 몇 번 실행되는지** 확인해야 합니다.

### 자주 하는 실수

안쪽 반복문에서 더해지는 값이 `j`가 아니라 `i`라는 점을 놓치면 안 됩니다.

</details>

## 문제 3. 조건 연산자의 결합 방향

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a = 3;
    int b = 5;
    int c = 4;

    int x = a > b ? a : b > c ? b : c;

    printf("%d\n", x);

    return 0;
}
```

① `3`  
② `4`  
③ `5`  
④ `0`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>③ <code>5</code></strong>입니다.</p>

### 1. 조건 연산자 구조

조건 연산자는 다음 형태입니다.

```c
조건 ? 참일때값 : 거짓일때값
```

이번 식은:

```c
a > b ? a : b > c ? b : c
```

입니다.

조건 연산자는 오른쪽부터 결합하므로 다음처럼 볼 수 있습니다.

```c
a > b ? a : (b > c ? b : c)
```

### 2. 첫 번째 조건

```text
a = 3
b = 5
```

따라서:

```text
a > b
3 > 5
→ 거짓
```

입니다.

그러므로 `a`는 선택되지 않습니다.

### 3. 두 번째 조건

거짓 부분:

```c
b > c ? b : c
```

를 계산합니다.

현재:

```text
b = 5
c = 4
```

따라서:

```text
5 > 4 → 참
```

입니다.

따라서:

```text
x = b = 5
```

### 4. 최종 출력

```text
5
```

### 반드시 알아야 할 개념

중첩된 조건 연산자는 괄호가 없으면 오른쪽부터 묶입니다.

```c
A ? B : C ? D : E
```

는:

```c
A ? B : (C ? D : E)
```

처럼 해석됩니다.

### 자주 하는 실수

조건식을 왼쪽부터 임의로 묶어 계산하면 안 됩니다.

</details>

## 문제 4. 산술·비교·논리 연산자 우선순위

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a = 2;
    int b = 3;
    int c = 0;

    int result = a + b * 2 > 7 && !c;

    printf("%d\n", result);

    return 0;
}
```

① `0`  
② `1`  
③ `7`  
④ `8`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>1</code></strong>입니다.</p>

### 1. 전체 식

```c
a + b * 2 > 7 && !c
```

복잡해 보이지만 우선순위 순서대로 나눕니다.

### 2. 곱셈 먼저 계산

```text
b * 2
= 3 × 2
= 6
```

### 3. 덧셈 계산

```text
a + 6
= 2 + 6
= 8
```

따라서 식은:

```text
8 > 7 && !c
```

가 됩니다.

### 4. 비교 연산

```text
8 > 7 → 참 → 1
```

### 5. 논리 NOT

현재:

```text
c = 0
```

C에서는 0이 거짓입니다.

```text
!0 = 1
```

따라서:

```text
1 && 1
```

이 됩니다.

### 6. 논리 AND

두 값 모두 참이므로:

```text
1 && 1 = 1
```

### 7. 최종 출력

```text
1
```

### 반드시 알아야 할 개념

이 문제의 계산 순서는 크게 다음과 같습니다.

```text
곱셈
→ 덧셈
→ 비교
→ 논리 연산
```

### 자주 하는 실수

논리식의 결과를 원래 계산값 8이라고 생각하면 안 됩니다.

비교·논리 연산의 최종 결과는 참이면 1, 거짓이면 0입니다.

</details>

## 문제 5. 재귀 함수의 반환값

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int f(int n)
{
    if (n <= 1)
        return 1;

    return n + f(n - 2);
}

int main(void)
{
    printf("%d\n", f(5));

    return 0;
}
```

① `8`  
② `9`  
③ `10`  
④ `15`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>9</code></strong>입니다.</p>

### 1. 첫 번째 호출

```text
f(5)
```

`5 > 1`이므로:

```text
f(5) = 5 + f(3)
```

### 2. 두 번째 호출

```text
f(3)
```

역시 종료 조건이 아닙니다.

```text
f(3) = 3 + f(1)
```

### 3. 종료 조건

```text
f(1)
```

에서:

```c
if (n <= 1)
    return 1;
```

이 실행됩니다.

따라서:

```text
f(1) = 1
```

### 4. 반환값을 거꾸로 계산

```text
f(3)
= 3 + 1
= 4
```

다시:

```text
f(5)
= 5 + 4
= 9
```

### 5. 최종 출력

```text
9
```

### 반드시 알아야 할 개념

재귀 함수는 호출식을 그대로 펼치면 이해하기 쉽습니다.

```text
f(5)
= 5 + f(3)
= 5 + 3 + f(1)
= 5 + 3 + 1
= 9
```

### 자주 하는 실수

`n - 2`인데 `n - 1`처럼 계산해서:

```text
5 + 4 + 3 + ...
```

로 풀면 안 됩니다.

재귀 인자가 얼마씩 감소하는지 반드시 확인해야 합니다.

</details>

## 문제 6. strcpy와 문자열 종료 문자

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[20] = "ABCD";

    strcpy(s + 1, "XY");

    printf("%s %zu\n",
           s,
           strlen(s));

    return 0;
}
```

① `AXY 3`  
② `AXYD 4`  
③ `ABXY 4`  
④ `AXYCD 5`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>AXY 3</code></strong>입니다.</p>

### 1. 실행 전 상태

초기 문자열:

```text
인덱스   0   1   2   3   4
문자     A   B   C   D  \0
```

### 2. strcpy의 목적지

```c
strcpy(s + 1, "XY");
```

목적지는:

```text
s + 1 → s[1]
```

입니다.

원본 문자열 `"XY"`는 실제로:

```text
X Y \0
```

세 문자를 복사합니다.

### 3. 실제 복사 과정

복사 결과:

```text
s[1] = 'X'
s[2] = 'Y'
s[3] = '\0'
```

따라서 배열 앞부분은:

```text
A X Y \0 D ...
```

가 됩니다.

### 4. 문자열 출력

`%s`는 첫 번째 `\0`까지 출력합니다.

따라서:

```text
AXY
```

만 출력됩니다.

원래의 `D`가 뒤쪽 메모리에 남아 있더라도 문자열의 일부로 출력되지 않습니다.

### 5. strlen

첫 번째 종료 문자 전까지:

```text
A X Y
```

세 문자입니다.

따라서:

```text
strlen(s) = 3
```

### 6. 최종 출력

```text
AXY 3
```

### 반드시 알아야 할 개념

`strcpy`는 눈에 보이는 문자만 복사하는 것이 아닙니다.

마지막 종료 문자 `\0`까지 복사합니다.

따라서 기존 문자열의 중간부터 복사하면 그 위치 이후 문자열 길이가 달라질 수 있습니다.

### 자주 하는 실수

원래 있던 `D`가 메모리에 남아 있다는 이유로 `AXYD`가 출력된다고 생각하면 안 됩니다.

문자열은 첫 번째 `\0`에서 끝납니다.

</details>

## 문제 7. 포인터와 배열 표현의 관계

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a[] = {2, 4, 6, 8};

    int *p = &a[1];

    int x = p[1] + *(p - 1);

    p++;

    int y = *p;

    printf("%d %d\n", x, y);

    return 0;
}
```

① `6 6`  
② `8 6`  
③ `8 8`  
④ `10 6`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>8 6</code></strong>입니다.</p>

### 1. 배열과 포인터 초기 상태

배열:

```text
인덱스   0   1   2   3
값       2   4   6   8
```

포인터:

```c
int *p = &a[1];
```

따라서:

```text
p → a[1] → 4
```

### 2. p[1] 계산

```c
p[1]
```

는 다음과 같습니다.

```c
*(p + 1)
```

현재 `p`가 `a[1]`을 가리키므로:

```text
p + 1 → a[2]
```

따라서:

```text
p[1] = 6
```

### 3. *(p - 1) 계산

```text
p - 1 → a[0]
```

따라서:

```text
*(p - 1) = 2
```

### 4. x 계산

```text
x = 6 + 2 = 8
```

### 5. 포인터 이동

```c
p++;
```

따라서:

```text
p → a[2] → 6
```

### 6. y 계산

```c
int y = *p;
```

따라서:

```text
y = 6
```

### 7. 최종 출력

```text
8 6
```

### 반드시 알아야 할 개념

포인터에서도 배열 인덱스 표기를 사용할 수 있습니다.

```c
p[i]
```

는:

```c
*(p + i)
```

와 같은 의미입니다.

### 자주 하는 실수

`p[1]`을 원본 배열의 `a[1]`이라고 생각하면 안 됩니다.

인덱스는 **현재 포인터 위치를 기준**으로 계산됩니다.

</details>

## 문제 8. 문자 숫자와 정수의 변환

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    char c = '3';

    int x = c - '0';
    char d = '0' + (x + 4);

    printf("%d %c\n", x, d);

    return 0;
}
```

① `3 7`  
② `51 7`  
③ `3 4`  
④ `7 7`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>3 7</code></strong>입니다.</p>

### 1. 문자 '3'과 정수 3은 다르다

```c
char c = '3';
```

`c`에는 숫자 3 자체가 아니라 문자 `'3'`의 문자 코드값이 저장됩니다.

### 2. 숫자 문자에서 정수값 구하기

```c
int x = c - '0';
```

숫자 문자 `'0'`부터 `'9'`까지는 연속된 값으로 표현됩니다.

따라서:

```text
'3' - '0' = 3
```

이 됩니다.

```text
x = 3
```

### 3. 다시 숫자 문자 만들기

```c
char d = '0' + (x + 4);
```

먼저:

```text
x + 4 = 7
```

따라서:

```text
'0' + 7 = '7'
```

이 됩니다.

```text
d = '7'
```

### 4. 최종 출력

```c
printf("%d %c\n", x, d);
```

따라서:

```text
3 7
```

### 반드시 알아야 할 개념

숫자 문자와 정수를 변환할 때 자주 사용하는 패턴입니다.

문자 → 정수:

```c
int n = c - '0';
```

정수 → 문자:

```c
char c = '0' + n;
```

단, 숫자 한 자리 범위에서 사용하는 것이 기본입니다.

### 자주 하는 실수

문자 `'3'`을 정수 `3`과 같은 값으로 직접 취급하면 안 됩니다.

</details>

## 문제 9. do-while 반복문의 실행 순서

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int i = 5;
    int sum = 0;

    do {
        sum += i;
        i -= 2;
    } while (i > 0);

    printf("%d %d\n", i, sum);

    return 0;
}
```

① `1 8`  
② `-1 9`  
③ `0 9`  
④ `-1 8`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>-1 9</code></strong>입니다.</p>

### 1. 초기 상태

```text
i = 5
sum = 0
```

`do-while`은 조건을 보기 전에 본문을 먼저 실행합니다.

### 2. 첫 번째 반복

```text
sum = 0 + 5 = 5
i = 5 - 2 = 3
```

조건:

```text
3 > 0 → 참
```

### 3. 두 번째 반복

```text
sum = 5 + 3 = 8
i = 3 - 2 = 1
```

조건:

```text
1 > 0 → 참
```

### 4. 세 번째 반복

```text
sum = 8 + 1 = 9
i = 1 - 2 = -1
```

조건:

```text
-1 > 0 → 거짓
```

반복을 종료합니다.

### 5. 최종 상태

```text
i = -1
sum = 9
```

따라서:

```text
-1 9
```

### 반드시 알아야 할 개념

`while`과 `do-while`의 가장 큰 차이는 조건 검사 시점입니다.

```c
while
```

은 본문 실행 전에 조건을 검사합니다.

```c
do-while
```

은 본문을 먼저 한 번 실행한 뒤 조건을 검사합니다.

### 자주 하는 실수

`i = 1`인 상태에서 조건을 먼저 검사한다고 생각하면 마지막 `1`이 합계에서 빠지게 됩니다.

`do-while`은 본문을 먼저 실행합니다.

</details>

## 문제 10. break와 continue

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;

    for (int i = 1; i <= 6; i++) {

        if (i % 2 == 0)
            continue;

        if (i == 5)
            break;

        sum += i;
    }

    printf("%d\n", sum);

    return 0;
}
```

① `4`  
② `9`  
③ `12`  
④ `16`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>4</code></strong>입니다.</p>

### 1. i = 1

```text
1 % 2 != 0
```

이므로 `continue`를 실행하지 않습니다.

```text
i == 5 → 거짓
```

따라서:

```text
sum = 0 + 1 = 1
```

### 2. i = 2

```text
2 % 2 == 0
```

이므로:

```c
continue;
```

가 실행됩니다.

그 아래의:

```c
if (i == 5)
```

와:

```c
sum += i;
```

는 실행되지 않습니다.

### 3. i = 3

홀수이므로 `continue`를 건너뜁니다.

`i == 5`도 거짓입니다.

따라서:

```text
sum = 1 + 3 = 4
```

### 4. i = 4

짝수이므로 `continue`가 실행됩니다.

합계는 그대로:

```text
sum = 4
```

### 5. i = 5

홀수이므로 첫 번째 `continue`는 실행되지 않습니다.

다음 조건:

```c
if (i == 5)
    break;
```

가 참입니다.

따라서 반복문 전체를 즉시 종료합니다.

`sum += i`는 실행되지 않습니다.

### 6. 최종 출력

```text
4
```

### 반드시 알아야 할 개념

`continue`와 `break`는 역할이 다릅니다.

```text
continue → 현재 반복의 남은 부분만 건너뜀
break    → 반복문 전체 종료
```

### 자주 하는 실수

`i = 5`일 때 5를 더한 뒤 종료된다고 생각하면 안 됩니다.

코드 순서를 보면 `break`가 `sum += i`보다 먼저 실행됩니다.

</details>

## 잘 놓치는 핵심

### 1. 배열 인덱스에서도 전위·후위 증가 시점이 중요하다

`a[i++]`와 `a[++i]`는 서로 다른 원소를 읽을 수 있습니다.

### 2. 중첩 반복문은 안쪽 반복 횟수를 먼저 센다

바깥 변수 값에 따라 반복 횟수가 달라질 수 있습니다.

### 3. 조건 연산자는 오른쪽부터 결합한다

중첩된 `? :`는 괄호를 다시 그려 보는 것이 안전합니다.

### 4. 비교·논리 연산 결과는 0 또는 1이다

산술 계산 결과를 그대로 출력하는 것이 아닙니다.

### 5. 재귀는 종료 조건과 인자 변화량을 먼저 본다

`n - 1`인지 `n - 2`인지에 따라 호출 횟수가 달라집니다.

### 6. strcpy는 종료 문자까지 복사한다

중간 위치에 복사하면 기존 문자열의 뒤쪽 내용이 출력에서 사라질 수 있습니다.

### 7. 포인터 인덱스는 현재 포인터 위치 기준이다

`p[1]`은 항상 원본 배열의 `a[1]`을 의미하지 않습니다.

### 8. 숫자 문자와 정수는 다르다

`'3' - '0'`을 이용하면 정수 3을 얻을 수 있습니다.

### 9. do-while은 본문을 최소 한 번 실행한다

조건 검사 시점이 `while`과 다릅니다.

### 10. continue와 break는 코드 위치를 확인한다

그 아래 문장이 실행되는지 여부를 반드시 추적해야 합니다.

## 시험·면접에서 바로 보는 포인트

- 배열 인덱스 안의 `++`가 전위인지 후위인지 먼저 표시합니다.
- 중첩 반복문은 표를 그리거나 `i별 반복 횟수 × 더하는 값`으로 계산합니다.
- 조건 연산자가 연속되면 괄호를 추가해 해석합니다.
- 복잡한 논리식은 산술 → 비교 → 논리 순으로 나눠 계산합니다.
- 재귀는 식을 직접 펼쳐 쓰면 빠르게 풀 수 있습니다.
- `strcpy`는 `\0`까지 덮어쓴다는 점을 기억합니다.
- `p[i]`는 `*(p + i)`로 바꿔 생각합니다.
- 숫자 문자 변환은 `'0'`을 기준으로 계산합니다.
- `do-while`은 본문을 먼저 실행합니다.
- `break`, `continue`보다 아래에 있는 문장이 실행되는지 확인합니다.
