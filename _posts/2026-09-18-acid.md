ACID는 신뢰할 수 있는 Transaction이 가져야 하는 Atomicity, Consistency, Isolation, Durability의 네 가지 성질입니다.

이 글에서는 용어를 외우는 데서 끝내지 않고 Transaction의 시간 순서와 실제 결과를 연결해서 봅니다.

## Atomicity · 원자성

Transaction의 작업은 모두 성공하거나 모두 실패해야 한다는 성질입니다.

```text
재고 감소 성공
주문 상태 변경 실패
```

이런 경우 재고 감소만 남으면 안 됩니다.

필요하면 전체를 ROLLBACK합니다.

## Consistency · 일관성

Transaction 전후에 데이터베이스가 정의된 무결성 규칙을 만족해야 한다는 성질입니다.

예를 들어 다음 규칙을 생각합니다.

```text
STOCK >= 0
Foreign Key 유효
Primary Key 중복 금지
```

정상적인 Transaction은 이런 규칙을 깨지 않아야 합니다.

## Isolation · 격리성

동시에 실행되는 Transaction이 서로의 중간 상태에 부적절하게 영향을 주지 않도록 하는 성질입니다.

완전히 직렬 실행한 것과 같은 수준을 목표로 할 수도 있지만 실제 DBMS는 성능과 동시성을 위해 여러 Isolation Level을 제공합니다.

## Durability · 지속성

COMMIT된 결과는 장애가 발생해도 보존되어야 한다는 성질입니다.

DBMS는 Log, WAL, Flush, Recovery 같은 기법을 이용해 이를 지원합니다.

## ACID 한눈에

| 성질 | 핵심 질문 |
| --- | --- |
| Atomicity | 전부 성공하거나 전부 실패하는가 |
| Consistency | 무결성 규칙을 지키는가 |
| Isolation | 동시 Transaction이 부적절하게 간섭하지 않는가 |
| Durability | COMMIT 결과가 장애 후에도 남는가 |

시험에서는 정의를 서로 바꾸어 출제하는 경우가 많습니다.

## Atomicity와 ROLLBACK

원자성은 실패 시 이전 상태로 되돌리는 처리와 연결됩니다.

하지만 ROLLBACK 명령 하나만으로 원자성을 설명하는 것은 부족합니다.

DBMS 내부 Log와 Recovery가 함께 동작합니다.

## Consistency와 Constraint

Consistency는 단순히 모든 Column 값이 같다는 뜻이 아닙니다.

```text
Schema 규칙
Constraint
업무 규칙
```

이런 정의된 규칙을 만족하는 상태를 유지한다는 의미입니다.

## Isolation과 동시성

Isolation을 높이면 이상 현상을 줄일 수 있지만 Lock 대기나 충돌이 늘어날 수 있습니다.

```text
높은 격리
→ 안정성 증가
→ 동시성 감소 가능
```

성능과 일관성의 균형이 중요합니다.

## Durability와 Recovery

COMMIT 직후 장애가 나더라도 확정된 변경을 복구할 수 있어야 합니다.

Log와 Checkpoint가 Recovery 파트에서 중요한 이유입니다.

## 시험·면접

### 핵심 암기

```text
ACID = Atomicity + Consistency + Isolation + Durability
```

### 시험 접근 순서

```text
1. Transaction 시작점 확인
2. Read와 Write 순서 확인
3. COMMIT 여부 확인
4. Lock 또는 Isolation 확인
5. 다른 Transaction이 보는 값 확인
6. 최종 상태 확인
```

### 시험 함정

같은 용어라도 실제 DBMS의 구현에 따라 세부 동작이 달라질 수 있습니다.

시험에서는 문제에서 제시한 표준 정의를 우선하고, 실무에서는 사용하는 DBMS의 실제 구현을 확인합니다.

### 면접에서 짧게 답한다면

ACID는 신뢰할 수 있는 Transaction이 가져야 하는 Atomicity, Consistency, Isolation, Durability의 네 가지 성질입니다.

핵심은 데이터 일관성을 유지하면서 동시에 여러 작업을 안전하게 처리하고, 장애가 발생해도 정상 상태로 복구하는 것입니다.
