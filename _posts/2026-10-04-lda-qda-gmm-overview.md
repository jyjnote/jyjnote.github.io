LDA와 QDA는 **라벨이 있는 정규분포 기반 분류 모델**, GMM은 **라벨 없이 여러 정규분포의 혼합으로 데이터를 설명하는 모델**입니다.
세 모델은 모두 평균과 공분산을 이용하지만, 라벨 사용 여부와 공분산을 공유하는 방식이 다릅니다.

</blockquote>

# 1. LDA
## 1.1 LDA의 핵심
LDA는 라벨을 보고 다음 두 조건을 동시에 만족하는 방향을 찾습니다.
```text
클래스 사이
→ 최대한 멀게
클래스 내부
→ 최대한 좁게
```
즉, 같은 클래스끼리는 뭉치고 다른 클래스끼리는 벌어지는 방향을 찾습니다.
## 1.2 판별 방향 w
두 클래스라면 대표적으로 다음 기준을 최대화합니다.
$$J(w)=\frac{w^\top S_Bw}{w^\top S_Ww}$$
- \(S_B\): 클래스 사이 산포
- \(S_W\): 클래스 내부 산포
- \(w\): 데이터를 사영할 방향
## 1.3 w의 의미
w는 원래 변수들을 어떤 비율로 섞을지 정하는 방향 벡터입니다.
예를 들어 특징이 세 개라면 다음과 같습니다.
$$x=(x_1,x_2,x_3)$$
$$w=(w_1,w_2,w_3)$$
각 관찰값을 다음처럼 사영합니다.
$$z=w^\top x$$
즉, 여러 특징을 하나의 판별축 위 값으로 바꿉니다.
## 1.4 직관
```text
원래 공간
A ● ●
  ●        B × ×
●            ×
      ↓ 판별축으로 사영
────●●●────────────×××────
    A                 B
```
좋은 판별축은 A 내부는 좁게 모으고 B와는 멀리 떨어뜨립니다.

## 1.5 입력 차원과 판별축 수
입력 특징 수는 많아도 됩니다.
예를 들어 특징이 100개라면 w도 100차원 벡터입니다.
하지만 만들 수 있는 판별축의 최대 개수는 제한됩니다.
$$\min(p,C-1)$$
- \(p\): 원래 특징 수
- \(C\): 클래스 수

## 1.6 왜 최대 C-1인가
클래스 평균이 C개 있어도 평균 차이들이 만드는 독립적인 방향은 최대 C-1개입니다.
즉, 클래스 사이 산포 행렬의 랭크가 최대 C-1이기 때문입니다.
```text
클래스 2개, 변수 100개
→ 최대 1축
클래스 3개, 변수 2개
→ 최대 2축
클래스 10개, 변수 5개
→ 최대 5축
```

## 1.7 항상 C-1개의 축이 필요한가
아닙니다.
최대가 C-1개일 뿐이고, 실제 데이터에서 유효한 분리 정보가 더 낮은 차원에만 존재할 수 있습니다.
예를 들어 세 클래스가 한 줄로 나열되어 있다면 최대 2축까지 만들 수 있어도 한 축만으로 충분할 수 있습니다.
<mark>시험에서는 “항상 C-1개”가 아니라 “최대 C-1개”로 기억합니다.</mark>

## 1.8 PCA와 LDA 비교
| 구분 | PCA | LDA |
| --- | --- | --- |
| 라벨 사용 | 안 함 | 사용 |
| 목적 | 전체 분산 크게 | 클래스 분리 크게 |
| 기준 | 데이터 전체 퍼짐 | 클래스 사이·내부 산포 |
| 최대 축 수 | 원래 특징 수까지 | 클래스 수에 제한 |
| 성격 | 비지도 차원축소 | 지도 판별·차원축소 |
시험 한 줄:
> PCA는 전체 분산, LDA는 클래스 분리.

# 2. LDA의 확률모형 관점

## 2.1 LDA의 가정
LDA는 각 클래스가 정규분포를 따른다고 봅니다.
클래스마다 평균은 다를 수 있지만 공분산은 하나를 공유합니다.
```text
클래스 A
→ 평균 A
→ 공분산 Σ
클래스 B
→ 평균 B
→ 공분산 Σ
```
즉, 중심은 다르지만 퍼진 모양은 같다고 봅니다.

## 2.2 왜 경계가 선형인가
두 클래스의 판별식을 비교할 때 공통 공분산 때문에 이차항이 상쇄됩니다.
```text
같은 공분산
→ 제곱항 상쇄
→ 선형 경계
```

## 2.3 사전확률
클래스별 사전확률도 판별에 들어갑니다.
한 클래스가 훨씬 많다면 애매한 점에서 많은 클래스 쪽이 유리해질 수 있습니다.

# 3. QDA

## 3.1 QDA의 핵심
QDA는 클래스마다 정규분포를 두되, 공분산도 클래스마다 따로 둡니다.
```text
LDA
→ 평균 다름
→ 공분산 하나 공유
QDA
→ 평균 다름
→ 공분산도 클래스마다 다름
```

## 3.2 왜 QDA 경계는 굽는가
LDA는 공분산이 같아서 이차항이 상쇄됩니다.
QDA는 클래스마다 공분산이 다르므로 이차항이 남습니다.
따라서 결정경계가 이차식이 됩니다.
<mark>QDA의 핵심은 클래스마다 공분산이 달라 굽은 경계를 만들 수 있다는 점입니다.</mark>

## 3.3 마할라노비스 거리 관점
공분산의 역행렬은 각 클래스의 퍼진 모양을 반영한 거리 저울 역할을 합니다.
```text
분산이 큰 방향
→ 같은 거리도 덜 멀게 봄
분산이 작은 방향
→ 같은 거리도 더 멀게 봄
```

## 3.4 넓은 클래스가 먼 점을 가져가는 이유
넓게 퍼진 클래스는 그 방향의 거리에 작은 벌점을 줍니다.
따라서 물리적으로 더 멀어 보여도 QDA 기준으로는 더 가까울 수 있습니다.
이것은 이상치 탐지가 아닙니다.
<mark>QDA는 이상치를 찾는 모델이 아니라 클래스마다 다른 퍼짐을 이용해 분류하는 모델입니다.</mark>

## 3.5 공분산 역행렬 문제
QDA는 클래스마다 공분산 행렬을 추정하고 역행렬도 계산해야 합니다.
다음 상황에서는 문제가 생길 수 있습니다.
- 클래스별 표본 수가 적음
- 특징 수가 많음
- 변수끼리 강하게 종속됨
- 데이터가 낮은 차원 공간에 몰림
이 경우 공분산 행렬이 특이해져 역행렬 계산이 불안정할 수 있습니다.

## 3.6 LDA가 더 안전한 경우
표본이 적고 특징이 많은 상황에서는 QDA보다 LDA가 더 안정적인 경우가 많습니다.
QDA는 클래스마다 공분산 전체를 따로 추정해야 하므로 필요한 표본이 더 많습니다.

# 4. Gaussian NB · LDA · QDA

## 4.1 핵심 비교
| 구분 | Gaussian NB | LDA | QDA |
| --- | --- | --- | --- |
| 라벨 | 있음 | 있음 | 있음 |
| 분포 | 정규분포 | 정규분포 | 정규분포 |
| 변수 상관 | 무시 | 반영 | 반영 |
| 공분산 | 클래스별 대각 | 하나 공유 | 클래스별 전체 |
| 경계 | 보통 이차 | 선형 | 이차 |
| 추정량 | 적음 | 중간 | 많음 |

## 4.2 언제 무엇을 쓰나
```text
변수 상관을 무시해도 됨
→ Gaussian NB
상관은 있지만 클래스 내부 모양이 비슷함
→ LDA
클래스마다 퍼진 모양도 다름
→ QDA
```

## 4.3 Gaussian NB가 대각 공분산인 이유
가우시안 나이브 베이즈는 조건부 독립을 가정합니다.
그래서 변수 사이 공분산을 0으로 보는 것과 같은 효과가 납니다.

# 5. LDA와 QDA 선택 감각
| 상황 | 더 자연스러운 선택 |
| --- | --- |
| 클래스 공분산이 비슷함 | LDA |
| 클래스마다 퍼짐이 다름 | QDA |
| 표본이 적고 특징이 많음 | LDA가 상대적으로 안정적 |
| 클래스별 표본이 충분하고 굽은 경계 필요 | QDA |
QDA는 클래스마다 공분산 전체를 추정하므로 LDA보다 더 많은 표본을 요구합니다.

# 6. GMM

## 6.1 GMM의 핵심
GMM은 라벨 없이 여러 정규분포를 섞어 데이터를 설명하는 모델입니다.
즉, 데이터 전체가 하나의 종 모양이 아니라 여러 개의 종 모양이 섞여 만들어졌다고 봅니다.

## 6.2 혼합분포
성분이 K개라면 전체 밀도는 다음과 같습니다.
$$p(x)=\sum_{k=1}^{K}\pi_k\mathcal{N}(x\mid\mu_k,\Sigma_k)$$
- \(\pi_k\): k번째 성분의 혼합 비율
- \(\mu_k\): k번째 성분의 평균
- \(\Sigma_k\): k번째 성분의 공분산
혼합 비율의 합은 1입니다.

## 6.3 생성 과정
```text
1. 어떤 성분에서 나올지 선택
   → πk
2. 선택된 성분의 정규분포에서 점 생성
   → N(μk, Σk)
```
각 성분은 숨어 있는 그룹입니다.

## 6.4 QDA와 닮은 점
QDA도 클래스마다 정규분포를 둡니다.
차이는 라벨입니다.
```text
QDA
→ 클래스 라벨을 알고 있음
GMM
→ 어떤 성분에서 나왔는지 모름
```
그래서 GMM은 **비지도 QDA에 가까운 관점**으로 이해할 수 있습니다.

# 7. GMM의 소프트 군집

## 7.1 책임값
한 점이 k번째 성분에서 나왔을 사후확률을 책임값이라고 합니다.
$$\gamma_{ik}=\frac{\pi_k\mathcal{N}(x_i\mid\mu_k,\Sigma_k)}{\sum_j\pi_j\mathcal{N}(x_i\mid\mu_j,\Sigma_j)}$$

## 7.2 책임값 해석
```text
성분 1
→ 0.8
성분 2
→ 0.2
```
한 점은 여러 성분에 걸칠 수 있습니다.

## 7.3 K-means와 차이
```text
K-means
→ 가장 가까운 중심 하나
→ 하드 군집
GMM
→ 성분별 소속 확률
→ 소프트 군집
```

## 7.4 K-means와 GMM 비교
| 구분 | K-means | GMM |
| --- | --- | --- |
| 소속 | 하나의 군집 | 성분별 확률 |
| 기준 | 중심까지 거리 | 확률밀도 |
| 모양 | 원형에 가까움 | 타원 가능 |
| 공분산 | 직접 모델링 안 함 | 모델링 |
| 혼합 비율 | 직접 사용 안 함 | 사용 |
| 출력 | 군집 번호 | 책임값 + 군집 |

## 7.5 언제 GMM이 더 자연스러운가
- 군집이 길쭉한 타원형
- 군집이 서로 겹침
- 경계 근처 점의 애매함을 표현하고 싶음
- 군집 번호뿐 아니라 확률이 필요함

# 8. EM 알고리즘

## 8.1 왜 EM이 필요한가
QDA는 라벨이 있으므로 클래스별 평균과 공분산을 바로 계산할 수 있습니다.
GMM은 어떤 점이 어떤 성분에서 나왔는지 모르므로 바로 계산할 수 없습니다.
그래서 소속과 분포 모수를 번갈아 추정합니다.

## 8.2 E-step
현재 평균·공분산·혼합비율을 이용해 각 점의 책임값을 계산합니다.
```text
현재 성분 모양
→ 각 점의 소속 확률 추정
```

## 8.3 M-step
E-step에서 얻은 책임값을 가중치로 사용해 평균·공분산·혼합비율을 다시 계산합니다.
```text
소속 확률
→ 성분 모수 재추정
```

## 8.4 반복
```text
E-step
→ 소속 추정
M-step
→ 분포 다시 계산
E-step
→ 다시 소속 추정
...
```
더 이상 크게 변하지 않을 때까지 반복합니다.

## 8.5 시작값 문제
EM은 시작값에 따라 다른 해에 도달할 수 있습니다.
따라서 여러 초기값으로 반복해 더 좋은 해를 찾는 방식이 흔합니다.

# 9. GMM의 성분 수 K

## 9.1 K는 하이퍼파라미터
K는 몇 개의 가우시안 성분을 사용할지 정합니다.
```text
K 너무 작음
→ 다른 덩어리를 한 분포에 합침
→ 과소적합
K 너무 큼
→ 몇 점만 설명하는 작은 성분 생성
→ 과적합 가능
```

## 9.2 K 선택
대표적으로 다음을 봅니다.
- AIC
- BIC
- 검증 가능도
- 성분 중복 여부
- 분석 목적
<mark>GMM의 K가 현실의 진짜 그룹 수와 항상 같다는 보장은 없습니다.</mark>

# 10. GMM 공분산 구조
| 형태 | 의미 | 연결해서 기억 |
| --- | --- | --- |
| 구형 | 모든 방향 분산 동일 | K-means에 가까움 |
| 대각 | 축별 분산만 사용 | Gaussian NB와 유사 |
| 공유 전체 | 모든 성분이 같은 공분산 | LDA와 유사 |
| 성분별 전체 | 각 성분마다 다른 타원 | QDA와 유사 |
공분산을 자유롭게 둘수록 복잡한 군집을 표현하지만 추정은 더 불안정해집니다.

# 11. 전체 비교
| 모델 | 라벨 | 평균 | 공분산 | 주된 결과 |
| --- | --- | --- | --- | --- |
| Gaussian NB | 있음 | 클래스별 | 클래스별 대각 | 분류 |
| LDA | 있음 | 클래스별 | 하나 공유 | 선형 분류·판별축 |
| QDA | 있음 | 클래스별 | 클래스별 전체 | 이차 분류 |
| GMM | 없음 | 성분별 | 성분별 설정 | 밀도·군집 |

## 11.1 한 줄 관계
```text
Gaussian NB
→ 변수 상관을 무시한 생성 분류
LDA
→ 공분산 공유
QDA
→ 공분산도 클래스별
GMM
→ 라벨 없이 성분을 찾음
```

# 잘 놓치는 핵심
- LDA는 클래스 사이 산포를 크게, 내부 산포를 작게 하는 방향을 찾음
- LDA 판별축은 최대 \(\min(p,C-1)\)
- 최대 C-1이지 반드시 C-1개의 유효축이 있는 것은 아님
- LDA는 클래스마다 평균은 다르지만 공분산은 공유
- QDA는 클래스마다 평균과 공분산이 모두 다름
- LDA는 선형 경계, QDA는 이차 경계
- QDA에서 넓은 클래스가 먼 점을 가져갈 수 있음
- 이것은 이상치 탐지가 아님
- Gaussian NB는 변수 사이 상관을 무시
- GMM은 라벨 없는 가우시안 혼합
- GMM은 소프트 군집
- 책임값은 성분 소속 사후확률
- EM은 E-step과 M-step을 반복
- GMM의 K는 하이퍼파라미터
- K가 실제 그룹 수와 항상 같은 것은 아님

# 시험·면접에서 기억할 것
1. PCA는 전체 분산, LDA는 클래스 분리
2. LDA 판별축 최대 수는 \(\min(p,C-1)\)
3. LDA는 공분산 하나
4. QDA는 클래스마다 공분산
5. 같은 공분산이면 이차항이 상쇄되어 선형 경계
6. 다른 공분산이면 이차항이 남아 QDA
7. 마할라노비스 거리는 공분산을 반영한 거리
8. Gaussian NB는 변수 상관을 무시
9. GMM은 라벨 없이 여러 정규분포를 혼합
10. 책임값은 소프트 소속 확률
11. EM의 E는 소속 추정, M은 모수 재추정
12. GMM의 성분 수 K는 하이퍼파라미터
