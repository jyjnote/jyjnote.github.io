`GROUP BY`는 **같은 값을 가진 Row들을 하나의 그룹으로 묶는 절**입니다.

집계 함수와 함께 사용하면 부서별 인원수, 지역별 고객 수, 카테고리별 평균 가격처럼 그룹별 통계를 계산할 수 있습니다.

<blockquote class="prompt-info">
<p>한 줄: GROUP BY는 같은 값을 가진 Row를 그룹으로 묶습니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

GROUP BY = 그룹 생성입니다.

</details>

## 가장 먼저 핵심

전체 직원 수는 다음처럼 구합니다.

```sql
SELECT COUNT(*)
FROM EMPLOYEE;
```

부서별 직원 수를 구하려면 GROUP BY를 사용합니다.

```sql
SELECT DEPT_ID, COUNT(*)
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

<mark>GROUP BY는 전체 집계를 그룹별 집계로 바꿔주는 핵심 절입니다.</mark>

## 그룹이란

EMPLOYEE의 DEPT_ID가 다음과 같다고 해봅시다.

```text
10
20
10
30
20
10
```

GROUP BY DEPT_ID를 적용하면 개념적으로 다음처럼 묶입니다.

```text
10 그룹
→ 3명

20 그룹
→ 2명

30 그룹
→ 1명
```

## 기본 문법

```sql
SELECT 그룹Column, 집계함수
FROM Table
GROUP BY 그룹Column;
```

예를 들어

```sql
SELECT DEPT_ID, COUNT(*)
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

입니다.

## COUNT와 GROUP BY

부서별 인원 수를 구합니다.

```sql
SELECT
    DEPT_ID,
    COUNT(*) AS EMP_COUNT
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

각 DEPT_ID 그룹마다 COUNT가 계산됩니다.

## AVG와 GROUP BY

부서별 평균 급여를 구합니다.

```sql
SELECT
    DEPT_ID,
    AVG(SALARY) AS AVG_SALARY
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

전체 평균이 아니라 각 부서 그룹의 평균입니다.

## SUM과 GROUP BY

부서별 급여 합계를 구합니다.

```sql
SELECT
    DEPT_ID,
    SUM(SALARY) AS TOTAL_SALARY
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

## MIN · MAX와 GROUP BY

부서별 최소·최대 급여도 구할 수 있습니다.

```sql
SELECT
    DEPT_ID,
    MIN(SALARY) AS MIN_SALARY,
    MAX(SALARY) AS MAX_SALARY
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

## 여러 Column으로 그룹화

두 개 이상의 Column을 기준으로 그룹을 만들 수 있습니다.

```sql
SELECT REGION, GRADE, COUNT(*)
FROM CUSTOMER
GROUP BY REGION, GRADE;
```

이 경우 그룹 기준은 조합입니다.

```text
REGION + GRADE
→ 하나의 그룹 기준
```

DISTINCT에서 여러 Column 조합을 보는 것과 비슷해 보이지만 목적은 다릅니다.

## DISTINCT와 GROUP BY

| 구분 | DISTINCT | GROUP BY |
| --- | --- | --- |
| 핵심 목적 | 중복 제거 | 그룹 생성 |
| 대표 사용 | 서로 다른 값 조회 | 그룹별 집계 |
| 집계 함수 | 필수 아님 | 자주 함께 사용 |

```text
DISTINCT
→ 중복 제거

GROUP BY
→ 그룹별 계산
```

## WHERE와 GROUP BY

WHERE는 그룹을 만들기 전에 Row를 필터링합니다.

```sql
SELECT DEPT_ID, AVG(SALARY)
FROM EMPLOYEE
WHERE SALARY >= 3000
GROUP BY DEPT_ID;
```

흐름은 다음과 같습니다.

```text
WHERE
→ 급여 3000 이상 Row만 남김

GROUP BY
→ 남은 Row를 부서별로 묶음

AVG
→ 각 그룹 평균 계산
```

## 일반 Column과 집계 함수

GROUP BY를 사용하는 SELECT에서는 그룹 기준 Column과 집계 함수를 함께 사용하는 형태가 기본입니다.

```sql
SELECT DEPT_ID, AVG(SALARY)
FROM EMPLOYEE
GROUP BY DEPT_ID;
```

GROUP BY에 없는 일반 Column을 무작정 SELECT하면 어떤 Row의 값을 보여줄지 모호해질 수 있습니다.

DBMS별 허용 범위가 다를 수 있으므로 표준적인 그룹 규칙을 지키는 것이 좋습니다.

<blockquote class="prompt-warning">
<p>GROUP BY 쿼리에서는 그룹 기준 Column과 집계 함수의 관계를 명확하게 작성합니다.</p>
</blockquote>

## 작성 순서

```sql
SELECT DEPT_ID, AVG(SALARY)
FROM EMPLOYEE
WHERE SALARY >= 3000
GROUP BY DEPT_ID;
```

작성 순서는 다음과 같습니다.

```text
SELECT
FROM
WHERE
GROUP BY
```

HAVING과 ORDER BY가 추가되면 뒤에 이어집니다.

## 논리적 처리 관점

```text
FROM
→ 대상 Table

WHERE
→ Row 필터링

GROUP BY
→ 그룹 생성

집계 함수
→ 그룹별 계산

SELECT
→ 결과 생성
```

다음 글에서 HAVING이 추가됩니다.

## 잘 놓치는 핵심

### 1. GROUP BY는 그룹을 만든다

같은 값을 가진 Row를 하나의 그룹으로 묶습니다.

### 2. 집계 함수와 함께 자주 사용한다

COUNT, SUM, AVG, MIN, MAX가 대표적입니다.

### 3. 여러 Column이면 조합이 그룹 기준이다

```text
REGION + GRADE
```

### 4. WHERE는 그룹 생성 전에 적용한다

먼저 Row를 거른 뒤 그룹화합니다.

### 5. DISTINCT와 목적이 다르다

중복 제거와 그룹별 집계를 구분합니다.

## 시험·면접

### 핵심 암기

```text
GROUP BY
= 같은 값을 가진 Row를 그룹으로 묶음
```

### 기본 형태

```sql
SELECT 그룹Column, 집계함수
FROM Table
GROUP BY 그룹Column;
```

### 시험 함정

WHERE는 그룹을 만든 뒤 그룹 자체를 거르는 절이 아닙니다.

그룹 생성 전 Row를 필터링합니다.

그룹 결과에 조건을 걸 때는 HAVING을 사용합니다.

### 면접에서 짧게 답한다면

GROUP BY는 동일한 값을 가진 Row를 하나의 그룹으로 묶고 각 그룹마다 COUNT, SUM, AVG 같은 집계 함수를 계산할 때 사용하는 절입니다.

WHERE는 그룹화 전에 Row를 필터링하고 그룹화된 결과에 대한 조건은 HAVING을 사용합니다.

## 다음에 이을 글

**HAVING**입니다.
