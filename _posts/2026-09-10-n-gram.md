연속된 $$n$$개의 Token을 **하나의 묶음으로 보는 방법**입니다.  
단어 하나만 보는 것보다 주변 문맥을 조금 더 반영할 수 있습니다.

<blockquote class="prompt-info">
<p>N-gram = 연속해서 등장한 n개의 Token 묶음입니다.</p>
</blockquote>

예:

```text
I love machine learning
```

Bigram:

```text
I love
love machine
machine learning
```

<mark>n이 커질수록 더 긴 문맥을 보지만, 가능한 조합 수가 급격히 늘어납니다.</mark>

<details>
<summary>한 줄로</summary>

Unigram은 1개, Bigram은 2개, Trigram은 3개의 연속 Token을 묶습니다.

</details>

## 기본 개념

문장:

```text
I love machine learning
```

### Unigram

$$n=1$$입니다.

```text
I
love
machine
learning
```

### Bigram

$$n=2$$입니다.

```text
I love
love machine
machine learning
```

### Trigram

$$n=3$$입니다.

```text
I love machine
love machine learning
```

정리하면 다음과 같습니다.

```text
Unigram  → n = 1
Bigram   → n = 2
Trigram  → n = 3
```

## 몇 개가 만들어지나

Token이 $$L$$개인 문장에서 N-gram 개수는 $$L-n+1$$입니다.

예:

```text
I love machine learning
```

Token 수는 $$L=4$$입니다.

Bigram 개수는 $$4-2+1=3$$입니다.

Trigram 개수는 $$4-3+1=2$$입니다.

<mark>길이 L인 문장에서 N-gram 개수는 L-n+1입니다.</mark>

## 왜 쓰나

Unigram만 사용하면 단어의 인접 순서를 알기 어렵습니다.

다음 두 문장을 보겠습니다.

```text
dog bites man
man bites dog
```

사용된 단어는 같습니다.

```text
dog
bites
man
```

하지만 Bigram은 다릅니다.

첫 번째 문장:

```text
dog bites
bites man
```

두 번째 문장:

```text
man bites
bites dog
```

Bigram을 사용하면 바로 옆 Token의 순서 정보가 일부 살아납니다.

<blockquote class="prompt-info">
<p>Unigram은 Token 자체를 보고, Bigram 이상은 인접한 Token의 순서까지 일부 반영합니다.</p>
</blockquote>

## 한국어에서

한국어에서도 단어 또는 형태소를 기준으로 N-gram을 만들 수 있습니다.

문장:

```text
나는 사과를 먹었다
```

공백 기준 Bigram:

```text
나는 사과를
사과를 먹었다
```

형태소 분석 후:

```text
나 / 는 / 사과 / 를 / 먹 / 었 / 다
```

형태소 Bigram:

```text
나 는
는 사과
사과 를
를 먹
먹 었
었 다
```

어떤 단위를 Token으로 정하느냐에 따라 만들어지는 N-gram도 달라집니다.

<blockquote class="prompt-warning">
<p>N-gram은 Tokenization 결과를 이용합니다. Token 단위가 달라지면 N-gram도 달라집니다.</p>
</blockquote>

## n이 커지면

$$n$$이 커질수록 더 긴 문맥을 볼 수 있습니다.

```text
Unigram → Token 하나
Bigram  → 인접한 두 Token
Trigram → 인접한 세 Token
```

하지만 가능한 조합 수도 빠르게 증가합니다.

Vocabulary 크기가 $$V$$라면 가능한 N-gram 조합 공간은 대략 $$V^n$$ 수준으로 커질 수 있습니다.

예를 들어 Vocabulary 크기가 $$V=10{,}000$$이면 가능한 Bigram 조합 수는 이론적으로 $$10{,}000^2=100{,}000{,}000$$입니다.

실제로 모든 조합이 등장하지는 않지만 가능한 공간 자체는 매우 큽니다.

<blockquote class="prompt-danger">
<p>n을 크게 잡으면 문맥 정보는 늘지만 희소성도 함께 커집니다.</p>
</blockquote>

## 희소성 문제

학습 Corpus에 없는 N-gram은 빈도가 0입니다.

학습 문장:

```text
I love AI
I love NLP
```

새로운 문장:

```text
I love robots
```

Bigram:

```text
I love
love robots
```

`love robots`가 학습 Corpus에 한 번도 없었다면 해당 Bigram의 빈도는 0입니다.

이처럼 학습에서 보지 못한 조합을 **Unseen N-gram**이라고 합니다.

## N-gram 언어모델

N-gram은 다음 단어의 확률을 앞의 몇 단어만 보고 근사하는 데 사용할 수 있습니다.

문장 전체 확률은 $$P(w_1,w_2,\ldots,w_T)$$처럼 나타낼 수 있습니다.

Bigram 모델은 긴 과거 전체 대신 바로 이전 한 Token만 사용합니다.

$$P(w_t\mid w_1,\ldots,w_{t-1})\approx P(w_t\mid w_{t-1})$$

Trigram 모델은 바로 이전 두 Token을 사용합니다.

$$P(w_t\mid w_1,\ldots,w_{t-1})\approx P(w_t\mid w_{t-2},w_{t-1})$$

<mark>N-gram 언어모델은 긴 문맥 전체 대신 최근 n-1개의 Token만 사용합니다.</mark>

## Bigram 확률

Bigram 확률은 보통 등장 빈도로 추정합니다.

$$P(w_i\mid w_{i-1})=\frac{C(w_{i-1},w_i)}{C(w_{i-1})}$$

예:

```text
I love AI
I love NLP
I love AI
```

`I love`는 3번 등장하고 `I`도 3번 등장합니다.

따라서 $$P(love\mid I)=\frac{3}{3}=1$$입니다.

`love AI`는 2번 등장하고 `love`는 3번 등장합니다.

따라서 $$P(AI\mid love)=\frac{2}{3}$$입니다.

<blockquote class="prompt-info">
<p>Bigram 확률은 앞 Token이 등장했을 때 뒤 Token이 함께 등장한 비율로 이해하면 쉽습니다.</p>
</blockquote>

## Zero Probability

한 번도 보지 못한 Bigram이면 $$C(w_{i-1},w_i)=0$$입니다.

따라서 $$P(w_i\mid w_{i-1})=0$$이 됩니다.

문장 확률을 여러 조건부 확률의 곱으로 계산할 때 하나라도 0이면 전체 문장 확률도 0이 될 수 있습니다.

```text
Unseen N-gram
→ 빈도 0
→ 확률 0
→ 전체 문장 확률도 0이 될 수 있음
```

이 문제를 완화하기 위해 **Smoothing**을 사용합니다.

## Smoothing

Smoothing은 관측되지 않은 조합에도 작은 확률을 부여하는 방법입니다.

가장 단순한 예는 Add-one, 즉 Laplace Smoothing입니다.

$$P(w_i\mid w_{i-1})=\frac{C(w_{i-1},w_i)+1}{C(w_{i-1})+V}$$

분자에서는 Bigram 빈도에 1을 더합니다.

분모에는 Vocabulary 크기 $$V$$를 추가합니다.

더 정교한 방법도 있습니다.

```text
Add-k
Good-Turing
Kneser-Ney
```

시험에서는 다음 흐름을 기억하면 됩니다.

```text
Unseen N-gram
→ Zero Probability
→ Smoothing
```

## n 선택

$$n$$이 작으면 데이터가 덜 필요하고 희소성이 낮지만 문맥 정보가 적습니다.

$$n$$이 크면 더 긴 문맥을 볼 수 있지만 조합 수와 희소성이 증가합니다.

| 구분 | 보는 범위 | 특징 |
| --- | --- | --- |
| Unigram | Token 1개 | 단순하고 희소성이 낮음 |
| Bigram | Token 2개 | 인접 순서를 일부 반영 |
| Trigram | Token 3개 | 문맥 증가, 희소성도 증가 |
| 큰 n | 더 긴 문맥 | 데이터와 메모리가 많이 필요 |

항상 큰 $$n$$이 좋은 것은 아닙니다.

## 문서 분류에서

N-gram은 문서 분류 Feature로도 사용할 수 있습니다.

예:

```text
very good
not good
```

Unigram만 사용하면 두 표현 모두 `good`을 포함합니다.

Bigram을 사용하면

```text
very good
not good
```

을 서로 다른 Feature로 볼 수 있습니다.

감성 분석처럼 짧은 표현의 순서가 중요한 문제에서 유용합니다.

## 장점

N-gram의 장점은 구조가 단순하면서도 단어 순서를 일부 반영한다는 점입니다.

- 구현이 단순함
- BoW보다 순서 정보를 더 많이 보존
- 검색과 문서 분류에서 사용 가능
- 고전 언어모델의 기본 구조를 이해하기 쉬움

## 단점

대표적인 약점은 다음과 같습니다.

1. n이 커질수록 Feature 수가 크게 증가
2. 희소성이 빠르게 증가
3. 보지 못한 조합 처리 어려움
4. 긴 문맥 전체를 보기 어려움
5. 의미가 비슷해도 문자열이 다르면 별개

예:

```text
car
automobile
```

두 단어의 의미가 비슷해도 N-gram 자체는 그 관계를 알지 못합니다.

이 문제는 이후 Embedding과 Neural Language Model에서 보완됩니다.

## 현대 LLM과의 차이

N-gram 언어모델은 고정된 길이의 과거만 봅니다.

```text
Bigram  → 이전 1개 Token
Trigram → 이전 2개 Token
```

Transformer는 Attention을 이용해 더 긴 문맥에서 필요한 Token을 참고할 수 있습니다.

```text
N-gram
→ 고정된 짧은 문맥

Transformer
→ 긴 문맥에서 필요한 Token에 Attention
```

<blockquote class="prompt-info">
<p>N-gram은 현대 LLM 이전의 핵심 언어모델 개념이며 조건부 확률과 문맥의 기본 원리를 이해하는 데 중요합니다.</p>
</blockquote>

## 잘 놓치는 핵심

### 1. N-gram은 연속된 Token

임의의 단어 조합이 아닙니다.

### 2. Token 기준에 따라 결과가 달라짐

단어, 형태소, 문자 N-gram이 모두 가능합니다.

### 3. n이 커질수록 항상 좋은 것이 아님

문맥은 늘지만 희소성도 커집니다.

### 4. Unigram은 순서 정보가 거의 없음

Bigram부터 인접한 순서 정보를 일부 반영합니다.

### 5. Unseen N-gram은 확률 0 문제를 만듦

Smoothing으로 보완합니다.

### 6. N-gram 언어모델은 최근 n-1개만 봄

긴 문맥 전체를 사용하는 모델이 아닙니다.

## 시험·면접

<blockquote class="prompt-info">
<p>단골: Unigram·Bigram·Trigram, L-n+1, 희소성, Zero Probability, Smoothing.</p>
</blockquote>

자주 나오는 문장:

- N-gram은 연속된 n개의 Token 묶음이다
- Bigram은 인접한 두 Token을 사용한다
- Trigram은 인접한 세 Token을 사용한다
- n이 커질수록 희소성이 증가한다
- Unseen N-gram은 확률 0 문제를 만들 수 있다
- Smoothing은 관측되지 않은 조합에도 확률을 부여한다

## 예시로 한 바퀴

문장:

```text
the cat eats fish
```

Token 수는 $$L=4$$입니다.

Unigram 개수는 $$4-1+1=4$$입니다.

```text
the
cat
eats
fish
```

Bigram 개수는 $$4-2+1=3$$입니다.

```text
the cat
cat eats
eats fish
```

Trigram 개수는 $$4-3+1=2$$입니다.

```text
the cat eats
cat eats fish
```

4-gram 개수는 $$4-4+1=1$$입니다.

```text
the cat eats fish
```
