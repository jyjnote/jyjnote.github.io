## 문제 1. 정수 나눗셈과 형변환

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a = 7;
    int b = 2;

    double x = (double)(a / b);
    double y = (double)a / b;

    printf("%.1f %.1f\n", x, y);

    return 0;
}
```

① `3.0 3.0`  
② `3.0 3.5`  
③ `3.5 3.5`  
④ `3.5 3.0`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>3.0 3.5</code></strong>입니다.</p>

### 1. 실행 전 상태

```text
a = 7
b = 2
```

두 변수 모두 정수형입니다.

### 2. x 계산

```c
double x = (double)(a / b);
```

괄호 안의:

```c
a / b
```

가 먼저 계산됩니다.

두 피연산자가 모두 정수이므로:

```text
7 / 2 = 3
```

입니다.

소수점 이하가 먼저 버려집니다.

그 후:

```c
(double)3
```

으로 변환됩니다.

따라서:

```text
x = 3.0
```

입니다.

### 3. y 계산

```c
double y = (double)a / b;
```

이번에는 나눗셈 전에 `a`가 실수형으로 변환됩니다.

```text
(double)a = 7.0
```

따라서:

```text
7.0 / 2 = 3.5
```

입니다.

```text
y = 3.5
```

### 4. 최종 출력

```text
3.0 3.5
```

### 반드시 알아야 할 개념

다음 두 표현은 다릅니다.

```c
(double)(a / b)
```

는 **정수 나눗셈 후 형변환**입니다.

```c
(double)a / b
```

는 **형변환 후 실수 나눗셈**입니다.

### 자주 하는 실수

괄호 밖에 `(double)`이 보인다는 이유만으로 첫 번째 식도 `3.5`가 된다고 판단하면 안 됩니다.

<mark>형변환이 연산 전인지 연산 후인지 확인해야 합니다.</mark>

</details>

## 문제 2. 배열의 부분 초기화

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a[5] = {3, 1};

    int sum = 0;

    for (int i = 0; i < 5; i++)
        sum += a[i] * (i + 1);

    printf("%d\n", sum);

    return 0;
}
```

① `4`  
② `5`  
③ `8`  
④ 초기화되지 않은 값 때문에 결과를 알 수 없다.

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>5</code></strong>입니다.</p>

### 1. 배열 초기화 규칙

```c
int a[5] = {3, 1};
```

원소는 5개인데 초기값은 2개만 주어졌습니다.

이 경우 나머지 원소는 자동으로 0으로 초기화됩니다.

따라서:

```text
인덱스   0   1   2   3   4
값       3   1   0   0   0
```

입니다.

### 2. i = 0

```text
sum += a[0] × 1
     = 3 × 1
     = 3
```

```text
sum = 3
```

### 3. i = 1

```text
sum += a[1] × 2
     = 1 × 2
     = 2
```

따라서:

```text
sum = 5
```

### 4. 나머지 반복

```text
a[2] = 0
a[3] = 0
a[4] = 0
```

이므로 더해지는 값은 모두 0입니다.

### 5. 최종 출력

```text
5
```

### 반드시 알아야 할 개념

배열 초기화에서 일부 원소만 지정하면 나머지는 0으로 초기화됩니다.

```c
int a[5] = {3, 1};
```

은:

```text
{3, 1, 0, 0, 0}
```

과 같습니다.

### 자주 하는 실수

일반 지역 변수 하나를 초기화하지 않은 경우와 배열의 부분 초기화를 혼동하면 안 됩니다.

배열 초기화 목록을 사용하면 남은 원소는 0으로 채워집니다.

</details>

## 문제 3. 포인터 증감과 값 변경

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a[] = {10, 20, 30, 40};
    int *p = a + 1;

    int x = *p++;
    int y = (*p)++;
    int z = *++p;

    printf("%d %d %d %d\n",
           x, y, z, a[2]);

    return 0;
}
```

① `20 30 40 31`  
② `20 31 40 31`  
③ `20 30 31 40`  
④ `30 30 40 31`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>20 30 40 31</code></strong>입니다.</p>

### 1. 초기 상태

배열:

```text
인덱스   0   1   2   3
값      10  20  30  40
```

포인터:

```text
p → a[1] → 20
```

### 2. 첫 번째 문장

```c
int x = *p++;
```

이는 다음처럼 해석됩니다.

```c
int x = *(p++);
```

현재 값을 먼저 사용합니다.

```text
x = 20
```

그 후 포인터가 증가합니다.

```text
p → a[2] → 30
```

### 3. 두 번째 문장

```c
int y = (*p)++;
```

이번에는 포인터가 아니라 **p가 가리키는 값**을 후위 증가시킵니다.

현재:

```text
*p = a[2] = 30
```

기존 값이 먼저 `y`에 들어갑니다.

```text
y = 30
```

그 후:

```text
a[2] = 31
```

이 됩니다.

포인터 위치는 그대로입니다.

```text
p → a[2]
```

### 4. 세 번째 문장

```c
int z = *++p;
```

먼저 포인터를 증가시킵니다.

```text
p → a[3] → 40
```

그 후 값을 읽습니다.

```text
z = 40
```

### 5. 최종 상태

```text
x = 20
y = 30
z = 40
a[2] = 31
```

따라서:

```text
20 30 40 31
```

### 반드시 알아야 할 개념

다음 세 표현은 NCS형 코드 문제에서 매우 자주 비교됩니다.

```c
*p++
```

현재 값을 사용한 뒤 포인터 이동.

```c
(*p)++
```

현재 값을 사용한 뒤 실제 값 증가.

```c
*++p
```

포인터를 먼저 이동한 뒤 값 사용.

### 자주 하는 실수

`*p++`와 `(*p)++`를 같은 것으로 보면 안 됩니다.

괄호 위치가 증가 대상 자체를 바꿉니다.

</details>

## 문제 4. 문자열 비교 함수

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char a[] = "CAT";
    char b[] = "CAR";

    int x = strcmp(a, b);

    if (x > 0)
        printf("1");
    else if (x < 0)
        printf("-1");
    else
        printf("0");

    printf(" %zu\n", strlen(b));

    return 0;
}
```

① `1 3`  
② `-1 3`  
③ `0 3`  
④ `1 4`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>1 3</code></strong>입니다.</p>

### 1. 문자열 비교

```c
strcmp(a, b)
```

는 두 문자열을 앞에서부터 비교합니다.

```text
a = C A T
b = C A R
```

첫 번째 문자:

```text
C = C
```

두 번째 문자:

```text
A = A
```

세 번째 문자에서 차이가 납니다.

```text
T > R
```

따라서 `strcmp(a, b)`의 결과는 **0보다 큰 값**입니다.

중요한 점은 반드시 정확히 `1`을 반환하는 것은 아니라는 것입니다.

### 2. 조건문

```c
if (x > 0)
    printf("1");
```

조건이 참이므로:

```text
1
```

이 출력됩니다.

### 3. strlen

```c
strlen(b)
```

에서:

```text
b = "CAR"
```

문자 수는:

```text
3
```

입니다.

종료 문자 `\0`은 길이에 포함하지 않습니다.

### 4. 최종 출력

```text
1 3
```

### 반드시 알아야 할 개념

`strcmp`의 반환 규칙은 다음과 같습니다.

```text
첫 문자열 > 두 번째 문자열 → 양수
두 문자열 같음           → 0
첫 문자열 < 두 번째 문자열 → 음수
```

정확히 `1`, `0`, `-1`을 반환한다고 외우면 안 됩니다.

### 자주 하는 실수

`strcmp(a, b) == 1`처럼 정확한 숫자를 기대하는 코드는 적절하지 않습니다.

보통:

```c
> 0
< 0
== 0
```

으로 판단합니다.

</details>

## 문제 5. switch문의 break 누락

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int n = 1;
    int x = 0;

    switch (n) {
        case 0:
            x += 1;
            break;

        case 1:
            x += 2;

        case 2:
            x *= 3;
            break;

        default:
            x = 9;
    }

    printf("%d\n", x);

    return 0;
}
```

① `2`  
② `3`  
③ `6`  
④ `9`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>③ <code>6</code></strong>입니다.</p>

### 1. 일치하는 case 찾기

현재:

```text
n = 1
```

따라서:

```c
case 1:
```

부터 실행합니다.

### 2. case 1

```c
x += 2;
```

초기값:

```text
x = 0
```

이므로:

```text
x = 2
```

### 3. break 확인

`case 1`에는 `break`가 없습니다.

따라서 바로 다음:

```c
case 2:
```

의 코드도 이어서 실행됩니다.

### 4. case 2

```c
x *= 3;
```

따라서:

```text
x = 2 × 3 = 6
```

그다음:

```c
break;
```

가 실행되어 `switch`를 빠져나옵니다.

### 5. 최종 출력

```text
6
```

### 반드시 알아야 할 개념

`switch`문은 일치하는 `case`부터 실행한 뒤 `break`를 만날 때까지 아래 코드가 계속 실행됩니다.

### 자주 하는 실수

`case 1`이 선택되면 `case 1`만 실행된다고 생각하면 안 됩니다.

항상 `break` 유무를 먼저 표시하는 습관이 좋습니다.

</details>

## 문제 6. 값 전달과 주소 전달

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

void change(int x, int *y)
{
    x += 5;
    *y += x;
}

int main(void)
{
    int a = 2;
    int b = 3;

    change(a, &b);

    printf("%d %d\n", a, b);

    return 0;
}
```

① `2 10`  
② `7 10`  
③ `2 8`  
④ `7 3`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>2 10</code></strong>입니다.</p>

### 1. 함수 호출 전

```text
a = 2
b = 3
```

호출:

```c
change(a, &b);
```

### 2. 첫 번째 인자

```c
int x
```

에는 `a`의 값 2가 복사됩니다.

따라서 함수 내부:

```text
x = 2
```

입니다.

`x`를 변경해도 원본 `a`는 바뀌지 않습니다.

### 3. 두 번째 인자

```c
int *y
```

에는 `b`의 주소가 전달됩니다.

따라서:

```text
y → b
```

입니다.

### 4. x 변경

```c
x += 5;
```

따라서:

```text
x = 7
```

하지만:

```text
a = 2
```

는 그대로입니다.

### 5. b 변경

```c
*y += x;
```

현재:

```text
*y = b = 3
x = 7
```

따라서:

```text
b = 3 + 7 = 10
```

### 6. 최종 출력

```text
a = 2
b = 10
```

따라서:

```text
2 10
```

### 반드시 알아야 할 개념

C의 함수 인자는 기본적으로 값으로 전달됩니다.

원본 값을 바꾸려면 원본 변수의 주소를 전달하고 포인터를 통해 접근해야 합니다.

### 자주 하는 실수

함수 안에서 `x`가 7이 되었으므로 원본 `a`도 7이라고 생각하면 안 됩니다.

`x`는 `a`의 복사본입니다.

</details>

## 문제 7. static 지역 변수

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int calc(void)
{
    static int x = 1;

    x *= 2;

    return x;
}

int main(void)
{
    int a = calc();
    int b = calc();
    int c = calc();

    printf("%d %d %d\n", a, b, c);

    return 0;
}
```

① `2 2 2`  
② `2 4 8`  
③ `1 2 4`  
④ `2 4 6`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>2 4 8</code></strong>입니다.</p>

### 1. static 변수 초기화

```c
static int x = 1;
```

`static` 지역 변수는 함수가 끝나도 값이 유지됩니다.

초기화는 처음 한 번만 이루어집니다.

### 2. 첫 번째 호출

처음:

```text
x = 1
```

실행:

```c
x *= 2;
```

따라서:

```text
x = 2
```

반환:

```text
a = 2
```

### 3. 두 번째 호출

다시 `x = 1`로 초기화되지 않습니다.

이전 값 2에서 시작합니다.

```text
x = 2 × 2 = 4
```

따라서:

```text
b = 4
```

### 4. 세 번째 호출

이전 값 4에서 시작합니다.

```text
x = 4 × 2 = 8
```

따라서:

```text
c = 8
```

### 5. 최종 출력

```text
2 4 8
```

### 반드시 알아야 할 개념

`static` 지역 변수는:

```text
접근 범위 → 함수 내부
수명      → 프로그램 종료까지
```

라는 특징을 가집니다.

### 자주 하는 실수

함수가 호출될 때마다:

```c
static int x = 1;
```

이 다시 실행된다고 생각하면 안 됩니다.

초기화는 한 번만 이루어집니다.

</details>

## 문제 8. 비트 마스크와 시프트

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    unsigned int x = 0x2D;

    unsigned int a = (x & 0x0F) << 1;
    unsigned int b = x >> 4;

    printf("%u %u\n", a, b);

    return 0;
}
```

① `13 2`  
② `26 2`  
③ `26 4`  
④ `45 2`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>26 2</code></strong>입니다.</p>

### 1. 16진수 값을 나누어 보기

```text
x = 0x2D
```

16진수:

```text
2 = 0010
D = 1101
```

따라서:

```text
x = 0010 1101
```

입니다.

### 2. a 계산

```c
x & 0x0F
```

`0x0F`는:

```text
0000 1111
```

입니다.

AND 연산:

```text
0010 1101
0000 1111
---------
0000 1101
```

결과는:

```text
13
```

입니다.

그 후:

```c
<< 1
```

을 수행합니다.

```text
13 × 2 = 26
```

따라서:

```text
a = 26
```

### 3. b 계산

```c
x >> 4
```

4비트 오른쪽 이동:

```text
0010 1101
→ 0000 0010
```

따라서:

```text
b = 2
```

### 4. 최종 출력

```text
26 2
```

### 반드시 알아야 할 개념

비트 문제는 16진수를 4비트씩 나누어 보면 빠르게 풀 수 있습니다.

또한 양의 정수에서 왼쪽으로 1비트 이동하면 일반적으로 2배 효과가 납니다.

### 자주 하는 실수

`x & 0x0F`와 `x >> 4`의 역할을 반대로 생각하면 안 됩니다.

하나는 하위 비트를 남기고, 다른 하나는 상위 비트를 오른쪽으로 이동시킵니다.

</details>

## 문제 9. 구조체 포인터와 배열

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

typedef struct {
    int x;
    int y;
} Point;

int main(void)
{
    Point a[2] = {
        {1, 2},
        {3, 4}
    };

    Point *p = a;

    (p + 1)->x += p->y;
    p->y = (p + 1)->y;

    printf("%d %d\n",
           a[0].y,
           a[1].x);

    return 0;
}
```

① `2 5`  
② `4 5`  
③ `4 3`  
④ `2 3`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>4 5</code></strong>입니다.</p>

### 1. 실행 전 상태

```text
a[0] = {x = 1, y = 2}
a[1] = {x = 3, y = 4}
```

포인터:

```text
p → a[0]
```

### 2. 첫 번째 문장

```c
(p + 1)->x += p->y;
```

현재:

```text
p + 1 → a[1]
```

따라서 왼쪽:

```text
a[1].x = 3
```

오른쪽:

```text
p->y = a[0].y = 2
```

따라서:

```text
a[1].x = 3 + 2 = 5
```

### 3. 두 번째 문장

```c
p->y = (p + 1)->y;
```

오른쪽:

```text
(p + 1)->y = a[1].y = 4
```

따라서:

```text
a[0].y = 4
```

### 4. 최종 상태

```text
a[0] = {1, 4}
a[1] = {5, 4}
```

출력:

```text
4 5
```

### 반드시 알아야 할 개념

구조체 포인터에서:

```c
p->y
```

는:

```c
(*p).y
```

와 같습니다.

또한:

```text
p + 1
```

은 다음 구조체 배열 원소를 가리킵니다.

### 자주 하는 실수

`p + 1`을 구조체 내부의 다음 멤버라고 생각하면 안 됩니다.

포인터는 구조체 전체 크기 단위로 이동합니다.

</details>

## 문제 10. calloc의 초기화 특성

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *p = calloc(4, sizeof(int));

    if (p == NULL)
        return 1;

    p[1] = 3;
    p[3] = 5;

    int sum = 0;

    for (int i = 0; i < 4; i++)
        sum += p[i];

    printf("%d\n", sum);

    free(p);

    return 0;
}
```

① `0`  
② `5`  
③ `8`  
④ 초기값을 알 수 없어 결과를 예측할 수 없다.

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>③ <code>8</code></strong>입니다.</p>

### 1. calloc 실행

```c
int *p = calloc(4, sizeof(int));
```

정수 4개를 저장할 공간을 할당합니다.

`calloc`은 할당된 메모리를 0으로 초기화합니다.

따라서 처음 상태는:

```text
p[0] = 0
p[1] = 0
p[2] = 0
p[3] = 0
```

입니다.

### 2. 값 대입

```c
p[1] = 3;
p[3] = 5;
```

따라서:

```text
p[0] = 0
p[1] = 3
p[2] = 0
p[3] = 5
```

입니다.

### 3. 합 계산

```text
sum = 0 + 3 + 0 + 5
    = 8
```

### 4. 최종 출력

```text
8
```

### 반드시 알아야 할 개념

`malloc`과 `calloc`의 대표적인 차이입니다.

```text
malloc → 초기값을 보장하지 않음
calloc → 할당한 영역을 0으로 초기화
```

또한 `calloc`은 보통:

```c
calloc(원소개수, 원소크기)
```

형태로 사용합니다.

### 자주 하는 실수

`malloc`과 `calloc`을 모두 초기값이 정해지지 않은 함수로 생각하면 안 됩니다.

시험에서는 **0 초기화 여부**가 자주 출제됩니다.

</details>

## 잘 놓치는 핵심

### 1. 형변환 위치가 결과를 바꾼다

```c
(double)(a / b)
```

와:

```c
(double)a / b
```

는 다릅니다.

### 2. 배열의 부분 초기화에서 나머지 원소는 0이다

초기값 목록이 있는 배열의 남은 원소는 자동으로 0으로 채워집니다.

### 3. *p++, (*p)++, *++p를 구분한다

포인터가 이동하는지 실제 값이 증가하는지부터 확인합니다.

### 4. strcmp의 반환값은 부호를 본다

정확히 `1`, `0`, `-1`이라고 외우지 않습니다.

### 5. switch는 break가 없으면 다음 case로 내려간다

일치한 case만 보고 계산을 끝내면 안 됩니다.

### 6. C의 함수 인자는 기본적으로 값 전달이다

원본을 바꾸려면 주소를 전달해야 합니다.

### 7. static 지역 변수는 호출 사이에 값이 유지된다

함수 호출마다 다시 초기화되지 않습니다.

### 8. 비트 마스크와 시프트의 역할을 분리한다

마스크는 비트를 골라내고 시프트는 위치를 이동시킵니다.

### 9. 구조체 포인터는 ->를 사용한다

`p->x`는 `(*p).x`와 같습니다.

### 10. calloc은 메모리를 0으로 초기화한다

`malloc`과 가장 자주 비교되는 기본 개념입니다.

## 시험·면접에서 바로 보는 포인트

- 형변환이 연산 전인지 후인지 먼저 확인합니다.
- 부분 초기화 배열은 남은 원소가 0이라는 점을 바로 적용합니다.
- 증감 연산자 문제는 증가 대상과 증가 시점을 각각 봅니다.
- `strcmp`는 양수·0·음수만 판단합니다.
- `switch`에서는 `break`를 먼저 표시합니다.
- 함수 호출은 값 전달과 주소 전달을 구분합니다.
- `static` 변수 문제는 이전 호출의 값을 적어 둡니다.
- 비트 연산은 2진수 또는 16진수로 바꿔 계산합니다.
- 구조체 포인터는 배열 원소 이동까지 함께 확인합니다.
- `calloc` 문제에서는 0 초기화를 즉시 적용합니다.
