## 문제 1. 정수 나눗셈과 형변환

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 2;

    double x = a / b;
    double y = (double)a / b;

    printf("%.1f %.1f\n", x, y);

    return 0;
}
```

① `2.0 2.0`  
② `2.0 2.5`  
③ `2.5 2.5`  
④ `2.5 2.0`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>2.0 2.5</code></strong>입니다.</p>

### 1. 실행 전 상태

```text
a = 5
b = 2
```

둘 다 자료형은 `int`입니다.

### 2. 첫 번째 식

```c
double x = a / b;
```

왼쪽 변수 `x`가 `double`이라고 해서 나눗셈부터 실수 연산이 되는 것은 아닙니다.

먼저 오른쪽 식:

```c
a / b
```

가 계산됩니다.

두 피연산자가 모두 정수이므로 **정수 나눗셈**이 수행됩니다.

```text
5 / 2 = 2
```

소수점 이하는 버려집니다.

그 후 정수 2가 `double`에 저장됩니다.

```text
x = 2.0
```

### 3. 두 번째 식

```c
double y = (double)a / b;
```

이번에는 `a`가 먼저 `double`로 변환됩니다.

```text
(double)a = 5.0
```

따라서 연산은:

```text
5.0 / 2
```

가 되고 실수 나눗셈이 수행됩니다.

```text
y = 2.5
```

### 4. 최종 출력

```text
2.0 2.5
```

### 반드시 알아야 할 개념

<mark>대입받는 변수의 자료형보다 연산 시점의 피연산자 자료형이 더 중요합니다.</mark>

다음 코드는:

```c
double x = 5 / 2;
```

먼저 `5 / 2`가 정수 연산으로 계산된 뒤 `double`로 저장됩니다.

반면:

```c
double x = (double)5 / 2;
```

는 실수 연산입니다.

### 자주 하는 실수

`double` 변수에 저장하니까 자동으로 `2.5`가 된다고 생각하면 안 됩니다.

형변환은 **나눗셈 전에** 일어나야 합니다.

</details>

## 문제 2. sizeof와 strlen

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "ABC";

    printf("%zu %zu\n",
           sizeof(s),
           strlen(s));

    return 0;
}
```

① `3 3`  
② `4 3`  
③ `4 4`  
④ `3 4`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>4 3</code></strong>입니다.</p>

### 1. 문자열이 실제로 저장되는 형태

```c
char s[] = "ABC";
```

배열에는 다음 네 문자가 저장됩니다.

```text
인덱스   0   1   2    3
문자     A   B   C   \0
```

문자열 끝에는 종료 문자 `\0`이 자동으로 들어갑니다.

### 2. sizeof(s)

```c
sizeof(s)
```

는 배열 전체 크기를 계산합니다.

`char` 한 개의 크기는 1바이트이므로:

```text
문자 4개 × 1바이트 = 4바이트
```

따라서:

```text
sizeof(s) = 4
```

### 3. strlen(s)

```c
strlen(s)
```

은 첫 번째 `\0`이 나오기 전까지의 문자 개수를 셉니다.

실제 문자열 내용은:

```text
A B C
```

세 글자입니다.

따라서:

```text
strlen(s) = 3
```

### 4. 최종 출력

```text
4 3
```

### 반드시 알아야 할 개념

`sizeof`와 `strlen`은 기준이 다릅니다.

| 구분 | 계산 기준 |
| --- | --- |
| `sizeof` | 배열이 실제 차지하는 메모리 크기 |
| `strlen` | 종료 문자 전까지의 문자 개수 |

### 자주 하는 실수

문자열 길이와 문자 배열 크기를 같은 것으로 생각하면 안 됩니다.

문자 배열에는 종료 문자 `\0`도 저장됩니다.

</details>

## 문제 3. 전위 증가와 후위 증가

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a = 5;

    int b = a++;
    int c = ++a;

    printf("%d %d %d\n", a, b, c);

    return 0;
}
```

① `7 5 7`  
② `6 5 7`  
③ `7 6 7`  
④ `7 5 6`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>7 5 7</code></strong>입니다.</p>

### 1. 초기 상태

```text
a = 5
```

### 2. 후위 증가

```c
int b = a++;
```

후위 증가 연산은 현재 값을 먼저 사용하고 그다음 증가합니다.

따라서 먼저:

```text
b = 5
```

가 됩니다.

그 후:

```text
a = 6
```

이 됩니다.

현재 상태:

```text
a = 6
b = 5
```

### 3. 전위 증가

```c
int c = ++a;
```

전위 증가는 먼저 값을 증가시킵니다.

```text
a = 7
```

그다음 증가된 값을 사용합니다.

```text
c = 7
```

### 4. 최종 상태

```text
a = 7
b = 5
c = 7
```

최종 출력:

```text
7 5 7
```

### 반드시 알아야 할 개념

다음 두 표현을 구분해야 합니다.

```c
a++
```

```text
현재 값 사용 → 증가
```

```c
++a
```

```text
증가 → 증가된 값 사용
```

### 자주 하는 실수

둘 다 결국 `a`를 1 증가시키므로 완전히 같다고 생각하면 안 됩니다.

단독 문장으로 사용하면 결과가 비슷하지만 다른 식 안에서 값으로 사용될 때 차이가 발생합니다.

</details>

## 문제 4. switch문과 break

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int n = 2;
    int x = 0;

    switch (n) {
        case 1:
            x += 10;

        case 2:
            x += 20;

        case 3:
            x += 30;
            break;

        default:
            x += 40;
    }

    printf("%d\n", x);

    return 0;
}
```

① `20`  
② `30`  
③ `50`  
④ `60`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>③ <code>50</code></strong>입니다.</p>

### 1. switch 조건 확인

```text
n = 2
```

따라서:

```c
case 2:
```

부터 실행됩니다.

### 2. case 2 실행

```c
x += 20;
```

초기값은:

```text
x = 0
```

이므로:

```text
x = 20
```

### 3. break 확인

`case 2`에는 `break`가 없습니다.

따라서 다음 `case 3`으로 그대로 이어서 실행됩니다.

### 4. case 3 실행

```c
x += 30;
```

따라서:

```text
x = 20 + 30 = 50
```

그다음:

```c
break;
```

가 있으므로 `switch`문을 빠져나옵니다.

### 5. 최종 출력

```text
50
```

### 반드시 알아야 할 개념

`switch`에서 일치하는 `case`를 찾은 뒤에는 `break`가 나올 때까지 아래 `case`의 코드가 계속 실행됩니다.

이를 흔히 **폴스루**라고 부릅니다.

### 자주 하는 실수

각 `case`가 일반 `if`문처럼 독립적으로 끝난다고 생각하면 안 됩니다.

`break`가 없으면 다음 `case`도 실행됩니다.

</details>

## 문제 5. 논리 AND와 단락 평가

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a = 0;
    int b = 5;

    if (a != 0 && ++b > 5)
        b += 10;

    printf("%d\n", b);

    return 0;
}
```

① `5`  
② `6`  
③ `15`  
④ `16`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>5</code></strong>입니다.</p>

### 1. 초기 상태

```text
a = 0
b = 5
```

조건식:

```c
a != 0 && ++b > 5
```

### 2. 왼쪽 조건 계산

```c
a != 0
```

현재:

```text
a = 0
```

이므로:

```text
0 != 0 → 거짓
```

입니다.

### 3. 단락 평가

논리 AND 연산자 `&&`는 왼쪽이 거짓이면 전체 결과가 이미 거짓으로 결정됩니다.

따라서 오른쪽:

```c
++b > 5
```

는 **실행되지 않습니다.**

즉:

```text
b = 5
```

가 그대로 유지됩니다.

### 4. if 본문

조건 전체가 거짓이므로:

```c
b += 10;
```

도 실행되지 않습니다.

### 5. 최종 출력

```text
5
```

### 반드시 알아야 할 개념

논리 연산자는 단순히 참·거짓만 계산하는 것이 아니라 **필요하지 않은 피연산자는 평가하지 않을 수 있습니다.**

```c
A && B
```

에서 `A`가 거짓이면 `B`를 평가하지 않습니다.

```c
A || B
```

에서 `A`가 참이면 `B`를 평가하지 않습니다.

### 자주 하는 실수

조건식 안에 `++b`가 보인다고 해서 반드시 `b`가 증가한다고 생각하면 안 됩니다.

해당 식이 실제로 평가되는지 먼저 확인해야 합니다.

</details>

## 문제 6. 논리 연산과 비트 연산의 차이

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int a = 6;
    int b = 3;

    printf("%d %d\n",
           a && b,
           a & b);

    return 0;
}
```

① `1 2`  
② `2 1`  
③ `1 3`  
④ `6 2`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>1 2</code></strong>입니다.</p>

### 1. 논리 AND

```c
a && b
```

현재:

```text
a = 6
b = 3
```

C에서 0은 거짓이고 0이 아닌 값은 참으로 처리합니다.

따라서:

```text
6 → 참
3 → 참
```

논리 AND 결과:

```text
참 && 참 = 참
```

논리 연산의 참 결과는 정수 `1`입니다.

따라서:

```text
a && b = 1
```

### 2. 비트 AND

```c
a & b
```

이번에는 각 비트를 비교합니다.

```text
6 = 110
3 = 011
```

비트 AND:

```text
110
011
---
010
```

이진수 `010`은 십진수 2입니다.

따라서:

```text
a & b = 2
```

### 3. 최종 출력

```text
1 2
```

### 반드시 알아야 할 개념

다음 두 연산자는 전혀 다릅니다.

```c
&&
```

은 논리 연산입니다.

```c
&
```

은 비트 연산입니다.

### 자주 하는 실수

`&`와 `&&`를 모양이 비슷하다는 이유로 같은 연산으로 생각하면 안 됩니다.

시험에서는 이 둘을 섞어서 출력값을 묻는 문제가 자주 나옵니다.

</details>

## 문제 7. 문자 배열과 문자열 포인터

다음 코드에 대한 설명으로 가장 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    char a[] = "ABC";
    char *b = "ABC";

    a[0] = 'X';
    b[0] = 'X';

    printf("%s %s\n", a, b);

    return 0;
}
```

① 항상 `XBC XBC`를 출력한다.  
② `a[0]` 수정은 가능하지만 문자열 리터럴을 가리키는 `b`를 통해 내용을 수정하는 것은 올바르지 않다.  
③ `a`와 `b` 모두 수정할 수 없다.  
④ `b[0]`만 수정할 수 있다.

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>②</strong>입니다.</p>

### 1. 문자 배열 a

```c
char a[] = "ABC";
```

이 선언은 문자열 내용을 문자 배열에 복사합니다.

메모리 형태:

```text
a[0] = 'A'
a[1] = 'B'
a[2] = 'C'
a[3] = '\0'
```

따라서:

```c
a[0] = 'X';
```

는 유효합니다.

결과:

```text
a = "XBC"
```

### 2. 문자 포인터 b

```c
char *b = "ABC";
```

`b`는 문자열 리터럴 `"ABC"`가 저장된 위치를 가리킵니다.

문자열 리터럴의 내용을 수정하려고 하면 C에서 정의되지 않은 동작이 됩니다.

따라서:

```c
b[0] = 'X';
```

는 올바른 코드로 볼 수 없습니다.

### 3. 핵심 차이

```c
char a[] = "ABC";
```

은 **수정 가능한 배열**입니다.

반면:

```c
char *b = "ABC";
```

에서 `b`는 문자열 리터럴을 가리킵니다.

문자열 리터럴 자체를 수정하면 안 됩니다.

### 반드시 알아야 할 개념

문자열을 수정해야 한다면 배열 형태로 만드는 것이 안전합니다.

```c
char s[] = "ABC";
```

읽기만 할 문자열 리터럴을 포인터로 가리킬 때는 의도를 명확히 하기 위해:

```c
const char *s = "ABC";
```

처럼 사용하는 것이 좋습니다.

### 자주 하는 실수

두 선언이 모두 `%s`로 같은 문자열을 출력한다고 해서 메모리 특성까지 같은 것은 아닙니다.

</details>

## 문제 8. 반복문 경계 조건

다음 코드의 출력 결과로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;

    for (int i = 1; i < 5; i += 2)
        sum += i;

    printf("%d\n", sum);

    return 0;
}
```

① `4`  
② `6`  
③ `9`  
④ `16`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>① <code>4</code></strong>입니다.</p>

### 1. 반복문 구성 확인

```c
for (int i = 1; i < 5; i += 2)
```

세 부분으로 나눕니다.

```text
초기값: i = 1
조건:   i < 5
증가:   i += 2
```

### 2. 첫 번째 반복

```text
i = 1
```

조건:

```text
1 < 5 → 참
```

따라서:

```text
sum = 0 + 1 = 1
```

증가식:

```text
i = 3
```

### 3. 두 번째 반복

조건:

```text
3 < 5 → 참
```

따라서:

```text
sum = 1 + 3 = 4
```

증가식:

```text
i = 5
```

### 4. 세 번째 조건 검사

```text
5 < 5 → 거짓
```

반복 종료.

### 5. 최종 출력

```text
4
```

### 반드시 알아야 할 개념

`i < 5`와 `i <= 5`는 결과가 다릅니다.

이번 반복문에서 실행되는 값은:

```text
1, 3
```

뿐입니다.

### 자주 하는 실수

증가값이 2라는 사실을 놓치고:

```text
1 + 2 + 3 + 4
```

처럼 계산하면 안 됩니다.

반드시 실제 `i` 값의 변화만 적어야 합니다.

</details>

## 문제 9. 구조체 포인터의 . 과 ->

다음 코드에서 빈칸에 들어갈 표현으로 옳은 것은 무엇입니까?

```c
#include <stdio.h>

typedef struct {
    int id;
    int score;
} Student;

int main(void)
{
    Student s = {1, 80};
    Student *p = &s;

    ____________ += 10;

    printf("%d\n", s.score);

    return 0;
}
```

출력 결과를 `90`으로 만들기 위한 코드로 옳은 것은 무엇입니까?

① `p.score`  
② `p->score`  
③ `*p.score`  
④ `&p->score`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>② <code>p->score</code></strong>입니다.</p>

### 1. 실행 전 상태

```text
s.id = 1
s.score = 80
```

포인터:

```text
p → s
```

### 2. 구조체 변수 직접 접근

구조체 변수 자체를 사용할 때는 점 연산자를 사용합니다.

```c
s.score
```

### 3. 구조체 포인터 접근

현재 `p`는 구조체 변수가 아니라 구조체를 가리키는 포인터입니다.

따라서 멤버 접근은:

```c
p->score
```

를 사용합니다.

이 표현은 다음과 같습니다.

```c
(*p).score
```

### 4. 값 변경

```c
p->score += 10;
```

실제로는:

```text
s.score = 80 + 10 = 90
```

입니다.

### 5. 최종 출력

```text
90
```

### 반드시 알아야 할 개념

구조체 접근은 다음처럼 구분합니다.

```text
구조체 변수       → .
구조체 포인터     → ->
```

예:

```c
s.score
p->score
```

### 자주 하는 실수

`p.score`를 사용하면 안 됩니다.

`p`는 구조체가 아니라 **구조체의 주소를 저장하는 포인터 변수**입니다.

</details>

## 문제 10. 동적 메모리 할당 크기

정수 `n`개를 저장할 동적 배열을 만들려고 합니다.

다음 빈칸에 들어갈 코드로 가장 적절한 것은 무엇입니까?

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;

    int *p = __________________________;

    if (p == NULL)
        return 1;

    for (int i = 0; i < n; i++)
        p[i] = (i + 1) * 10;

    printf("%d\n", p[4]);

    free(p);

    return 0;
}
```

① `malloc(n)`  
② `malloc(sizeof(p))`  
③ `malloc(n * sizeof(int))`  
④ `malloc(sizeof(int *))`

<details markdown="1">
<summary>정답 및 해설</summary>

<p>정답은 <strong>③ <code>malloc(n * sizeof(int))</code></strong>입니다.</p>

### 1. 필요한 메모리 개수

저장하려는 것은 정수 `n`개입니다.

현재:

```text
n = 5
```

따라서 필요한 크기는:

```text
정수 하나의 크기 × 5
```

입니다.

### 2. 정수 하나의 크기

C에서는 자료형 크기를 직접 숫자로 가정하지 않고 `sizeof`를 사용하는 것이 안전합니다.

```c
sizeof(int)
```

### 3. 전체 할당 크기

따라서:

```c
malloc(n * sizeof(int))
```

가 됩니다.

### 4. 할당 후 반복문

성공하면 정수 5개를 저장할 수 있습니다.

반복문 이후:

```text
p[0] = 10
p[1] = 20
p[2] = 30
p[3] = 40
p[4] = 50
```

따라서 최종 출력은:

```text
50
```

### 5. 오답 ①

```c
malloc(n)
```

은 5바이트만 할당합니다.

정수 5개에 필요한 메모리라고 보장할 수 없습니다.

### 6. 오답 ②

```c
malloc(sizeof(p))
```

에서 `p`는 포인터입니다.

따라서 정수 배열 크기가 아니라 포인터 변수 하나의 크기만 구합니다.

### 7. 오답 ④

```c
malloc(sizeof(int *))
```

도 정수 포인터 하나의 크기만 할당합니다.

### 반드시 알아야 할 개념

동적 배열을 만들 때는:

```text
원소 개수 × 원소 하나의 크기
```

를 계산합니다.

실무에서는 다음처럼도 많이 작성합니다.

```c
int *p = malloc(n * sizeof *p);
```

이 방식은 `p`가 가리키는 자료형이 바뀌어도 코드를 수정할 부분이 줄어드는 장점이 있습니다.

### 자주 하는 실수

`sizeof(p)`와 `sizeof(*p)`를 혼동하면 안 됩니다.

```text
sizeof(p)  → 포인터 자체 크기
sizeof(*p) → p가 가리키는 int의 크기
```

입니다.

</details>

## 잘 놓치는 핵심

### 1. 정수끼리 나누면 결과도 먼저 정수로 계산된다

실수 결과가 필요하면 연산 전에 적어도 한 피연산자를 실수형으로 바꿉니다.

### 2. sizeof와 strlen은 같은 길이를 재는 함수가 아니다

배열 크기와 문자열 문자 수를 구분합니다.

### 3. 후위 증가는 현재 값을 먼저 사용한다

`a++`와 `++a`는 식 안에서 사용될 때 결과가 다를 수 있습니다.

### 4. switch는 break가 없으면 다음 case까지 실행된다

일치한 case만 실행된다고 생각하면 안 됩니다.

### 5. &&와 ||는 단락 평가를 한다

오른쪽 식이 실행되지 않을 수 있습니다.

### 6. &&와 &는 전혀 다른 연산이다

하나는 논리 연산이고 다른 하나는 비트 연산입니다.

### 7. 문자 배열과 문자열 리터럴 포인터를 구분한다

문자 배열은 수정할 수 있지만 문자열 리터럴 자체를 수정하면 안 됩니다.

### 8. 반복문은 실제 i 값만 추적한다

초기값, 조건, 증가량을 순서대로 적습니다.

### 9. 구조체 변수에는 ., 구조체 포인터에는 ->를 사용한다

`p->x`는 `(*p).x`와 같은 의미입니다.

### 10. malloc 크기는 원소 개수 × 원소 하나의 크기다

`sizeof(p)`와 `sizeof(*p)`를 구분합니다.

## 시험·면접에서 바로 보는 포인트

- `double x = 5 / 2;`가 `2.5`가 아니라는 점을 바로 확인합니다.
- 문자열에서는 `\0`을 포함한 배열 크기와 실제 문자 길이를 구분합니다.
- `a++`, `++a`는 값 사용 시점부터 확인합니다.
- `switch` 코드는 `break`를 먼저 표시합니다.
- `&&`, `||` 안에 증감 연산이나 함수 호출이 있으면 실제 실행 여부를 확인합니다.
- `&`와 `&&`, `|`와 `||`를 혼동하지 않습니다.
- 문자열 리터럴 수정 여부를 확인합니다.
- 반복문의 `<`, `<=`와 증가 폭을 확인합니다.
- 구조체가 변수인지 포인터인지 먼저 봅니다.
- 동적 배열에서는 `sizeof(포인터)`가 아니라 `sizeof(원소)`를 사용해야 하는지 확인합니다.
