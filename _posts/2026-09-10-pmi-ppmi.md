두 단어가 단순히 자주 함께 등장하는지가 아니라, **우연히 기대되는 수준보다 얼마나 더 자주 함께 등장하는지**를 측정하는 방법입니다.  
PMI는 두 단어의 결합 강도를 나타내고, PPMI는 PMI의 음수 값을 0으로 바꾼 형태입니다.

<blockquote class="prompt-info">
<p>PMI = 실제 동시출현이 독립적으로 기대되는 수준보다 얼마나 강한지를 측정하는 값입니다.</p>
</blockquote>

예:

```text
New York

```
`New`와 `York`가 각각 자주 등장하는 것보다 두 단어가 **함께 등장하는 비율이 훨씬 높다면** PMI도 크게 나옵니다.

<mark>PMI는 단순 Count가 아니라 “기대보다 얼마나 더 같이 나왔는가”를 봅니다.</mark>

<details>
<summary>한 줄로</summary>

PMI는 단어 간 연관 강도이고, PPMI는 그중 양의 관계만 남긴 값입니다.

</details>

## 왜 필요한가
동시출현 행렬은 두 단어가 함께 등장한 횟수를 셉니다.
예:

```text
the ↔ dog   → 100
deep ↔ learning → 30

```
단순 Count만 보면 `the`와 `dog`의 관계가 더 강해 보일 수 있습니다.
하지만 `the`는 거의 모든 곳에서 매우 자주 등장할 수 있습니다.
즉,

```text
많이 함께 등장
≠
특별히 강한 관계

```
입니다.
PMI는 이런 문제를 보완합니다.

## 핵심 아이디어
두 단어 $$x$$와 $$y$$가 서로 독립이라면 함께 등장할 확률은 대략
$$P(x)P(y)$$
로 생각할 수 있습니다.
실제 함께 등장할 확률은
$$P(x,y)$$
입니다.
두 값을 비교합니다.

```text
실제 동시출현
────────────
독립일 때 기대 동시출현

```
실제 값이 더 크면 두 단어는 기대보다 자주 함께 나타나는 것입니다.

## PMI 공식
PMI는 Pointwise Mutual Information의 약자입니다.
공식:
$$PMI(x,y)=\log\frac{P(x,y)}{P(x)P(y)}$$
여기서

```text
P(x)
→ x가 등장할 확률

P(y)
→ y가 등장할 확률

P(x,y)
→ x와 y가 함께 등장할 확률

```
입니다.

<blockquote class="prompt-info">
<p>분자는 실제 동시출현 확률, 분모는 두 단어가 독립이라고 가정했을 때의 기대 확률입니다.</p>
</blockquote>

## PMI 값 해석
핵심은 비율입니다.
$$\frac{P(x,y)}{P(x)P(y)}$$
이 값이 1보다 크면

```text
실제 동시출현
>
독립일 때 기대값

```
입니다.
따라서 PMI는 양수가 됩니다.
반대로 1보다 작으면 PMI는 음수가 됩니다.

## PMI가 0인 경우
두 단어가 독립적이라면
$$P(x,y)=P(x)P(y)$$
입니다.
따라서
$$PMI(x,y)=\log 1=0$$
입니다.
즉 PMI가 0이면 두 단어의 동시출현이 독립 가정에서 기대되는 수준과 같습니다.

```text
PMI = 0
→ 특별한 연관 없음

```
으로 이해할 수 있습니다.

## PMI가 양수인 경우
실제 동시출현이 기대값보다 크면
$$P(x,y)>P(x)P(y)$$
입니다.
따라서
$$PMI(x,y)>0$$
입니다.
예:

```text
machine learning
New York
artificial intelligence

```
처럼 자주 함께 묶이는 표현은 높은 PMI를 가질 수 있습니다.

```text
PMI > 0
→ 기대보다 자주 함께 등장
→ 양의 연관

```
입니다.

## PMI가 음수인 경우
실제 동시출현이 기대값보다 작으면
$$P(x,y)<P(x)P(y)$$
입니다.
따라서
$$PMI(x,y)<0$$
입니다.
즉 두 단어가 각각 등장하는 빈도에 비해 함께 등장하는 경우가 적다는 뜻입니다.

```text
PMI < 0
→ 기대보다 덜 함께 등장

```
입니다.

<blockquote class="prompt-warning">
<p>PMI는 양수뿐 아니라 0과 음수도 가질 수 있습니다.</p>
</blockquote>

## 숫자로 계산
어떤 Corpus에서 다음 확률을 얻었다고 하겠습니다.

```text
P(x)   = 0.2
P(y)   = 0.1
P(x,y) = 0.05

```
독립이라고 가정하면 기대 동시출현 확률은
$$P(x)P(y)=0.2\times0.1=0.02$$
입니다.
실제 동시출현은 0.05입니다.
따라서
$$PMI(x,y)=\log\frac{0.05}{0.02}=\log 2.5$$
입니다.
비율이 1보다 크므로 PMI는 양수입니다.

## Count로 계산하기
실제 데이터에서는 확률 대신 Count를 이용해 확률을 추정합니다.
전체 Context Pair 수를 $$N$$이라고 하겠습니다.
$$P(x,y)=\frac{C(x,y)}{N}$$
$$P(x)=\frac{C(x)}{N}$$
$$P(y)=\frac{C(y)}{N}$$
이를 PMI 식에 넣으면 계산할 수 있습니다.
중요한 것은 **Count 자체가 아니라 상대적인 확률 비율**입니다.

## 단순 Count와 차이
단순 Co-occurrence Count:

```text
두 단어가 몇 번 같이 나왔는가

```
PMI:

```text
각 단어의 전체 빈도를 고려했을 때
기대보다 얼마나 더 같이 나왔는가

```
예:

```text
the ↔ dog
→ Count 높을 수 있음

machine ↔ learning
→ Count는 더 낮을 수 있음

```
하지만 `the` 자체가 매우 흔하다면 PMI는 낮아질 수 있습니다.
반면 `machine learning`이 특별히 자주 함께 나타난다면 PMI는 높아질 수 있습니다.

<mark>PMI는 자주 등장하는 흔한 단어가 동시출현 Count를 지배하는 문제를 줄여줍니다.</mark>

## 희귀 단어 문제
PMI에도 약점이 있습니다.
매우 드문 두 단어가 우연히 한 번 함께 등장하면 높은 PMI가 나올 수 있습니다.
예:

```text
x 등장 1회
y 등장 1회
x와 y 함께 등장 1회

```
각 단어가 거의 등장하지 않기 때문에 기대 확률이 매우 작습니다.
그런데 실제로 한 번 같이 등장하면 비율이 크게 올라갈 수 있습니다.

```text
희귀 단어
+
우연한 한 번의 동시출현
→ 높은 PMI 가능

```
입니다.

<blockquote class="prompt-danger">
<p>PMI는 희귀한 사건에 과도하게 높은 값을 줄 수 있습니다.</p>
</blockquote>

## PPMI
PPMI는 Positive Pointwise Mutual Information의 약자입니다.
PMI에서 음수 값을 0으로 바꿉니다.
$$PPMI(x,y)=\max(PMI(x,y),0)$$
즉,

```text
PMI > 0
→ 그대로 사용

PMI = 0
→ 0

PMI < 0
→ 0

```
입니다.

## PMI와 PPMI 비교

| 구분 | PMI | PPMI |
| --- | --- | --- |
| 양수 | 유지 | 유지 |
| 0 | 0 | 0 |
| 음수 | 유지 | 0 |
| 목적 | 전체 연관성 표현 | 양의 연관성 중심 표현 |

PPMI는 NLP의 Count-based Word Representation에서 자주 사용됩니다.

## 동시출현 행렬에 적용
기본 동시출현 행렬:

| Target | drink | hot | car |
| --- | ---: | ---: | ---: |
| coffee | 30 | 20 | 1 |
| tea | 25 | 18 | 0 |
| engine | 0 | 0 | 15 |

여기서 각 Count를 그대로 사용하는 대신 PMI를 계산할 수 있습니다.

```text
Co-occurrence Count
→ Probability
→ PMI
→ PPMI

```
결과적으로 각 칸은 단순 횟수가 아니라 **연관 강도**를 나타냅니다.

## PPMI Matrix
동시출현 Count Matrix를 PPMI 값으로 변환하면 PPMI Matrix를 얻습니다.
예:

```text
Count Matrix
→ 흔한 단어의 큰 Count 포함

```
PPMI 적용:

```text
PPMI Matrix
→ 기대보다 강한 관계만 강조

```
행 하나는 여전히 하나의 단어를 표현하는 Context Vector입니다.
다만 값이 Count가 아니라 PPMI Weight입니다.

<blockquote class="prompt-info">
<p>PPMI Matrix는 동시출현 행렬의 구조는 유지하면서 각 칸을 더 의미 있는 연관성 가중치로 바꿉니다.</p>
</blockquote>

## 단어 유사도와 연결
PPMI Matrix의 각 행을 단어 벡터로 사용할 수 있습니다.
예:

```text
coffee → [2.1, 1.8, 0.0]
tea    → [2.0, 1.7, 0.0]
car    → [0.0, 0.0, 2.5]

```
`coffee`와 `tea`는 비슷한 Pattern을 가집니다.
이 벡터 사이에 Cosine Similarity를 계산할 수 있습니다.
$$\cos(\theta)=\frac{\mathbf{x}\cdot\mathbf{y}}{\|\mathbf{x}\|\|\mathbf{y}\|}$$

```text
PPMI Vector
+
Cosine Similarity
→ 단어 의미 유사도 추정

```
입니다.

## 잘 놓치는 핵심

### 1. PMI는 Count 자체가 아니다
기대 동시출현 대비 실제 동시출현의 비율을 봅니다.

### 2. PMI가 0이면 독립 수준
실제와 기대 동시출현이 같습니다.

### 3. PMI가 양수면 기대보다 자주 함께 등장
강한 양의 연관을 의미합니다.

### 4. PMI는 음수가 될 수 있다
기대보다 덜 함께 등장하면 음수입니다.

### 5. PPMI는 음수를 0으로 만든다
양의 관계만 남깁니다.

### 6. 희귀 단어 편향이 있다
낮은 빈도의 우연한 동시출현에 큰 PMI가 생길 수 있습니다.

## 시험·면접

<blockquote class="prompt-info">
<p>단골: PMI 공식, 값의 부호 해석, PPMI 정의, 단순 Count와 차이, 희귀 단어 문제, PPMI Matrix와 단어 유사도.</p>
</blockquote>

자주 나오는 문장:
- PMI는 실제 동시출현과 독립일 때 기대 동시출현을 비교한다
- PMI가 0이면 독립 수준이다
- PMI가 양수면 기대보다 자주 함께 등장한다
- PMI가 음수면 기대보다 덜 함께 등장한다
- PPMI는 음수 PMI를 0으로 바꾼다
- PMI는 희귀 단어에 과도하게 높은 값을 줄 수 있다

## 예시로 한 바퀴
확률:

```text
P(x)   = 0.2
P(y)   = 0.1
P(x,y) = 0.05

```
독립일 때 기대값:
$$P(x)P(y)=0.2\times0.1=0.02$$
실제 동시출현 확률은 0.05입니다.
따라서
$$PMI(x,y)=\log\frac{0.05}{0.02}=\log 2.5$$
입니다.
비율이 1보다 크므로 PMI는 양수입니다.
따라서 PPMI도 같은 값을 유지합니다.
$$PPMI(x,y)=PMI(x,y)$$
반대로 PMI가 -1이라면
$$PPMI(x,y)=\max(-1,0)=0$$
입니다.
