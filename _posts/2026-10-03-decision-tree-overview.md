결정트리는 **질문을 하나씩 던지면서 데이터를 더 순수한 집단으로 나누는 모델**입니다.

분류에서는 클래스가 얼마나 잘 섞였는지를, 회귀에서는 숫자가 얼마나 퍼졌는지를 줄이는 방향으로 분기합니다.

<blockquote class="prompt-info">
<p>한 줄: 좋은 질문은 자른 뒤 자식 노드가 더 깔끔해지는 질문입니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

ID3 = 정보이득, C4.5 = 이득비율, CART = 분류는 지니·회귀는 SSE

</details>

## 1. 결정트리의 기본 생각

결정트리는 질문을 반복하면서 데이터를 더 순수한 집단으로 나눕니다.

```text
공부시간 ≤ 3시간?
├─ 예 → 불합격
└─ 아니오 → 출석률 ≤ 80%?
           ├─ 예 → 불합격
           └─ 아니오 → 합격
```

<mark>핵심은 어떤 질문으로 나눌 때 가장 깔끔해지는지를 고르는 것입니다.</mark>

## 2. ID3

ID3는 각 후보 특징으로 데이터를 나눠본 뒤 **정보이득이 가장 큰 특징**을 선택합니다.

즉, 한 질문으로 클래스가 얼마나 잘 정리되는지를 봅니다.

ID3의 핵심 기준은 엔트로피와 정보이득입니다.

## 3. 엔트로피

엔트로피는 한 노드 안에 클래스가 얼마나 섞여 있는지를 나타냅니다.

$$H(S)=-\sum_c p_c\log_2p_c$$

여기서 p_c는 클래스 c의 비율입니다.

한 클래스만 있으면 엔트로피는 0입니다.

두 클래스가 반반 섞여 있으면 엔트로피가 큽니다.

## 4. 이진 분류의 엔트로피

$$H(S)=-p\log_2p-(1-p)\log_2(1-p)$$

한 클래스만 있으면 0, 두 클래스가 반반이면 1입니다.

<mark>엔트로피가 작을수록 노드가 더 순수합니다.</mark>

## 5. 정보이득

특징 A로 나누기 전 엔트로피에서 나눈 뒤의 가중 엔트로피를 뺍니다.

$$IG(S,A)=H(S)-\sum_v\frac{|S_v|}{|S|}H(S_v)$$

정보이득이 클수록 해당 질문으로 데이터를 많이 정리했다는 뜻입니다.

## 6. 정보이득 관련 수식 총정리

### 엔트로피

$$H(S)=-\sum_c p_c\log_2p_c$$

### 분할 후 가중 엔트로피

$$H(S\mid A)=\sum_v\frac{|S_v|}{|S|}H(S_v)$$

### 정보이득

$$IG(S,A)=H(S)-H(S\mid A)$$

### 펼쳐 쓴 정보이득

$$IG(S,A)=H(S)-\sum_v\frac{|S_v|}{|S|}H(S_v)$$

<mark>정보이득은 부모의 불순도가 자식으로 가면서 얼마나 줄었는지를 나타냅니다.</mark>

## 7. ID3의 약점

- 범주형 특징 중심
- 연속형 처리에 약함
- 값의 종류가 많은 특징을 편애
- 기본 가지치기 없음
- 결측값 처리에 약함

## 8. 값이 많은 특징을 왜 좋아하나

주민번호처럼 값이 많은 특징은 데이터를 아주 잘게 쪼개 자식 노드를 순수하게 만들 수 있습니다.

그래서 정보이득이 크게 보일 수 있지만 일반화에는 불리할 수 있습니다.

## 9. C4.5

C4.5는 ID3를 확장해 연속형 처리, 결측값 처리, 가지치기, 값이 많은 특징 편향을 개선합니다.

핵심 분기 기준은 **이득비율**입니다.

## 10. 분할정보

특징 A가 데이터를 얼마나 잘게 나누는지를 측정합니다.

$$H_A=-\sum_v\frac{|S_v|}{|S|}\log_2\frac{|S_v|}{|S|}$$

분할정보가 클수록 많은 가지로 잘게 쪼개졌다는 뜻입니다.

## 11. 이득비율

C4.5는 정보이득을 분할정보로 나눕니다.

$$GR(S,A)=\frac{IG(S,A)}{H_A}$$

즉,

```text
이득비율
=
실제로 얻은 정보이득
÷
얼마나 잘게 쪼갰는가
```

<mark>잘게 쪼개서 얻은 가짜 정보이득을 깎는 것이 핵심입니다.</mark>

## 12. C4.5 정보 관련 수식 총정리

### 엔트로피

$$H(S)=-\sum_c p_c\log_2p_c$$

### 정보이득

$$IG(S,A)=H(S)-\sum_v\frac{|S_v|}{|S|}H(S_v)$$

### 분할정보

$$H_A=-\sum_v\frac{|S_v|}{|S|}\log_2\frac{|S_v|}{|S|}$$

### 이득비율

$$GR(S,A)=\frac{IG(S,A)}{H_A}$$

## 13. ID3, C4.5, CART 비교

| 구분 | ID3 | C4.5 | CART |
| --- | --- | --- | --- |
| 분류 기준 | 정보이득 | 이득비율 | 지니 감소 |
| 회귀 | 기본적으로 X | 기본적으로 분류 중심 | O |
| 연속형 | 약함 | O | O |
| 분할 형태 | 다지 분할 가능 | 다지 분할 가능 | 이진 분할 |
| 가지치기 | 기본 없음 | O | O |
| 결측 처리 | 약함 | 개선 | 구현에 따라 다름 |

## 14. CART

CART는 Classification and Regression Trees의 약자입니다.

분류와 회귀를 같은 트리 구조로 다룹니다.

CART의 가장 큰 특징은 **항상 이진 분할**을 한다는 점입니다.

```text
x ≤ 3.5 ?
├─ 예
└─ 아니오
```

## 15. CART 분류의 지니 불순도

분류에서는 지니 불순도를 주로 사용합니다.

$$G=1-\sum_c p_c^2$$

한 클래스만 있으면 지니는 0입니다.

클래스가 많이 섞일수록 지니가 커집니다.

## 16. 지니 감소

좋은 분기는 자식 노드들의 가중 지니를 작게 만듭니다.

$$\Delta G=G_{parent}-\left(\frac{n_L}{n}G_L+\frac{n_R}{n}G_R\right)$$

지니 감소가 클수록 좋은 분기입니다.

## 17. 엔트로피와 지니

둘 다 클래스가 얼마나 섞였는지 보는 불순도 지표이며 순수 노드에서는 0입니다.

| 기준 | 대표 알고리즘 |
| --- | --- |
| 엔트로피·정보이득 | ID3, C4.5 |
| 지니 | CART |

## 18. CART는 어떻게 자르나

한 노드에서 가능한 특징과 임계값 후보를 시험합니다.

연속형이면 다음처럼 나눕니다.

```text
x ≤ 3.5
x > 3.5
```

분류에서는 지니가 가장 많이 줄어드는 분할을 선택합니다.

회귀에서는 자식 SSE 합이 가장 작아지는 분할을 선택합니다.

## 19. 결정트리의 장점

- 규칙 해석이 쉬움
- 비선형 관계 표현 가능
- 교호작용을 질문의 조합으로 표현 가능
- 스케일에 덜 민감해 표준화가 필수는 아님

## 20. 결정트리의 약점

- 깊으면 과적합
- 축에 평행한 계단형 경계
- 데이터 변화에 민감
- 한 그루가 불안정함

## 21. 가지치기

트리가 너무 깊어지는 것을 막아 과적합을 줄입니다.

```text
사전 가지치기 → 미리 성장 제한
사후 가지치기 → 다 키운 뒤 불필요한 가지 제거
```

## 22. 주요 사전 가지치기 초매개변수

| 초매개변수 | 의미 |
| --- | --- |
| max_depth | 최대 깊이 |
| min_samples_split | 분할에 필요한 최소 표본 수 |
| min_samples_leaf | 잎에 남겨야 하는 최소 표본 수 |

값을 강하게 제한하면 과적합은 줄지만 과소적합이 생길 수 있습니다.

## 23. 회귀나무

회귀나무는 숫자를 예측하는 결정트리입니다.

각 잎에서 예측값은 해당 잎에 속한 학습 y의 평균입니다.

예를 들어 잎에 다음 값이 있다면

```text
2, 2, 4
```

예측값은 다음과 같습니다.

$$\hat{y}=\frac{2+2+4}{3}=\frac{8}{3}$$

## 24. 회귀나무와 선형회귀

$$\hat{y}=\beta_0+\beta_1x_1+\cdots$$

선형회귀는 하나의 평면, 회귀나무는 구간마다 상수를 예측하는 **구간별 상수 함수**입니다.

## 25. 회귀나무는 계단 함수

같은 잎 안에서는 x가 달라도 예측값이 같고, 깊이를 늘리면 계단이 잘게 나뉘어 곡선을 흉내 내지만 과적합 위험이 커집니다.

## 26. 회귀나무의 SSE

한 노드의 예측값은 평균입니다.

노드 안의 오차는 다음 SSE로 측정합니다.

$$SSE=\sum_i(y_i-\bar{y})^2$$

좋은 분기는 자식 노드의 SSE 합을 작게 만듭니다.

## 27. 회귀나무의 분기 개선량

부모 SSE에서 자식 SSE 합을 뺍니다.

$$\Delta=SSE_{parent}-(SSE_L+SSE_R)$$

Delta가 클수록 좋은 분기입니다.

<mark>분류의 지니 감소와 회귀의 SSE 감소는 같은 위치에서 쓰이는 분기 품질 기준입니다.</mark>

## 28. 회귀나무의 외삽 약점

학습 데이터보다 훨씬 큰 x가 들어와도 가장 오른쪽 잎의 평균을 그대로 반환합니다.

즉, 학습 범위 밖으로 직선을 연장하지 않습니다.

<blockquote class="prompt-warning">
<p>회귀나무는 학습 잎의 평균을 예측하므로 범위 밖 외삽에 약합니다.</p>
</blockquote>

## 29. 왜 앙상블로 넘어가나

한 그루는 불안정하므로 여러 나무를 묶습니다.

- 배깅: 여러 나무의 평균·투표
- 랜덤포레스트: 배깅 + 특징 무작위성
- 부스팅: 이전 오차를 다음 나무가 보완

## 30. 전체 알고리즘 비교

| 알고리즘 | 핵심 기준 | 분할 | 특징 |
| --- | --- | --- | --- |
| ID3 | 정보이득 | 다지 가능 | 범주형 중심 |
| C4.5 | 이득비율 | 다지 가능 | 연속형·가지치기 개선 |
| C5.0 | C4.5 계열 | 계열 특성 유지 | 효율화 |
| CART | 지니 / SSE | 이진 | 분류·회귀 통합 |

## 31. 정보이득 계열 수식 한 번에 보기

### 엔트로피

$$H(S)=-\sum_c p_c\log_2p_c$$

### 조건부 가중 엔트로피

$$H(S\mid A)=\sum_v\frac{|S_v|}{|S|}H(S_v)$$

### 정보이득

$$IG(S,A)=H(S)-H(S\mid A)$$

### 분할정보

$$H_A=-\sum_v\frac{|S_v|}{|S|}\log_2\frac{|S_v|}{|S|}$$

### 이득비율

$$GR(S,A)=\frac{IG(S,A)}{H_A}$$

### 지니

$$G=1-\sum_c p_c^2$$

### 지니 감소

$$\Delta G=G_{parent}-\left(\frac{n_L}{n}G_L+\frac{n_R}{n}G_R\right)$$

### 회귀 SSE

$$SSE=\sum_i(y_i-\bar{y})^2$$

### 회귀 분기 개선량

$$\Delta=SSE_{parent}-(SSE_L+SSE_R)$$

## 32. 잘 놓치는 핵심

### 1. 정보이득은 엔트로피 감소량

부모보다 자식이 얼마나 순수해졌는지를 봅니다.

### 2. ID3는 값이 많은 특징을 좋아할 수 있다

이 문제를 C4.5의 이득비율이 보완합니다.

### 3. CART는 항상 이진 분할

범주형도 두 묶음으로 나눕니다.

### 4. 분류 CART는 지니

라벨의 섞임을 줄입니다.

### 5. 회귀 CART는 SSE

숫자의 퍼짐을 줄입니다.

### 6. 회귀나무 잎 예측은 평균

기울기가 아닙니다.

### 7. 회귀나무는 계단 함수

같은 잎 안에서는 예측값이 같습니다.

### 8. 회귀나무는 외삽에 약함

끝 잎 평균을 반복합니다.

## 33. 시험·면접 핵심

- ID3 → 정보이득
- C4.5 → 이득비율
- C5.0 → C4.5 후속
- CART → 항상 이진 분할
- 분류 CART → 지니
- 회귀 CART → SSE·MSE
- 엔트로피·지니 0 → 순수
- 값 많은 특징 편향 → ID3 약점
- 가지치기 → 과적합 완화
- 트리 → 표준화 필수 아님
- 회귀나무 잎 → 평균
- 회귀나무 → 계단형 예측

## 35. 마지막 정리

결정트리는 **불순도를 가장 많이 줄이는 질문을 반복적으로 선택하는 모델**입니다.

ID3는 정보이득, C4.5는 이득비율, CART는 분류에서 지니와 회귀에서 SSE를 사용합니다.

</blockquote>
