SVM은 **경계와 가장 가까운 점 사이의 여유 공간인 마진을 최대화하는 모델**입니다.
선형 분리가 어렵다면 소프트 마진과 커널을 사용하고, 같은 원리는 회귀와 이상치 탐지에도 확장됩니다.

<blockquote class="prompt-info">
<p>한 줄: SVM은 경계 주변의 몇 개 핵심 점으로 최대 마진 경계를 찾습니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>
선형 SVM → 마진 최대화  
소프트 마진 → 일부 위반 허용  
커널 SVM → 고차원 내적을 직접 계산  
SVR → ε 안의 오차 무시  
One-Class SVM → 정상 영역 학습
</details>

## 1. 선형 SVM
이진 분류에서는 보통 양성을 +1, 음성을 -1로 둡니다.
$$f(x)=w^\top x+b$$
- x: 한 관찰값의 특징 벡터
- w: 가중치 벡터이자 결정경계의 법선
- b: 절편
- f(x): 한 관찰값에 대한 스칼라 점수
결정경계는 다음 조건을 만족하는 x들의 집합입니다.
$$w^\top x+b=0$$
```text
f(x) > 0 → +1
f(x) < 0 → -1
```
2차원에서는 직선, 3차원에서는 평면, 더 높은 차원에서는 초평면입니다.

## 2. w는 무엇인가
w는 여러 벡터의 모임이 아니라 **하나의 가중치 벡터**입니다.
$$x=(x_1,x_2,x_3)$$
$$w=(w_1,w_2,w_3)$$
w가 바뀌면 경계의 방향이 바뀌고, b가 바뀌면 경계가 평행이동합니다.

## 3. x가 선이 되는가
학습 후 w와 b는 고정됩니다.
$$w^\top x+b=0$$
을 만족하는 모든 x를 모으면 결정경계가 됩니다.
즉, x 하나가 선이 아니라 **조건을 만족하는 x들의 집합이 선**입니다.

## 4. 마진
SVM은 가능한 여러 경계 중 클래스와의 여유 공간이 가장 넓은 경계를 고릅니다.
점 x에서 경계까지 거리는 다음과 같습니다.
$$\frac{|w^\top x+b|}{\|w\|}$$
하드 마진의 양쪽 경계는 다음처럼 둘 수 있습니다.
$$w^\top x+b=1$$
$$w^\top x+b=-1$$
전체 마진 폭은 다음과 같습니다.
$$\frac{2}{\|w\|}$$
<mark>마진을 크게 만드는 것 = \(\|w\|\)를 작게 만드는 것입니다.</mark>

## 5. 왜 1이 나오나
하드 마진 제약은 다음과 같습니다.
$$y_i(w^\top x_i+b)\ge1$$
여기서 1은 실제 거리 1이 아닙니다.
w와 b의 스케일을 고정하기 위해 가장 가까운 점의 함수값을 1로 둔 것입니다.

## 6. Hard Margin
모든 데이터를 완벽하게 분리할 수 있을 때 사용합니다.
$$\min_{w,b}\frac{1}{2}\|w\|^2$$
$$y_i(w^\top x_i+b)\ge1$$
점이 섞이거나 이상치가 있으면 조건을 만족하지 못할 수 있습니다.

# Soft Margin

## 7. Soft Margin의 아이디어
일부 마진 침범과 오분류를 허용합니다.
$$y_i(w^\top x_i+b)\ge1-\xi_i$$
$$\xi_i\ge0$$
ξ는 각 데이터가 규칙을 얼마나 위반했는지 나타내는 슬랙 변수입니다.

## 8. 슬랙 해석
```text
ξ = 0
→ 마진 바깥에서 안전하게 맞음
0 < ξ < 1
→ 분류는 맞지만 마진 안쪽
ξ = 1
→ 결정경계 위
ξ > 1
→ 오분류
```
슬랙은 **얼마나 봐줬는가**라고 생각하면 쉽습니다.

## 9. Soft Margin 목적함수
$$\min_{w,b,\xi}\frac{1}{2}\|w\|^2+C\sum_i\xi_i$$
- 첫 항: 마진을 넓히려는 항
- 둘째 항: 마진 침범·오분류 벌점
- C: 슬랙 1단위의 가격

## 10. C의 의미
C가 크면 오분류를 강하게 벌합니다.
```text
C 큼
→ 슬랙을 적게 허용
→ 학습 데이터를 더 맞추려 함
→ 좁은 마진도 감수
→ 규제 약함
```
C가 작으면 일부 오차를 더 허용합니다.
```text
C 작음
→ 슬랙 허용
→ 넓은 마진 선호
→ 더 단순한 경계
→ 규제 강함
```

## 11. 큰 C가 왜 약한 규제인가
C는 모델 복잡도 벌점이 아니라 **오분류 벌점**입니다.
큰 C는 오분류를 막기 위해 모델이 학습 데이터에 더 자유롭게 맞춰지도록 합니다.
> 큰 C = 오분류 벌점 큼 = 모델 규제 약함

# Hinge Loss

## 12. Hinge Loss
$$\ell_i=\max(0,1-y_if(x_i))$$
```text
y f(x) ≥ 1
→ 충분히 멀리 맞음
→ 손실 0
0 < y f(x) < 1
→ 맞았지만 마진 안쪽
→ 손실 존재
y f(x) ≤ 0
→ 오분류
→ 손실 큼
```

## 13. 왜 Hinge Loss를 쓰나
SVM은 단순히 맞혔는지만 보지 않습니다.
**충분히 여유 있게 맞혔는지**까지 봅니다.
마진 바깥의 안전한 점은 더 이상 신경 쓰지 않습니다.

## 14. 슬랙과 Hinge Loss
$$\xi_i=\max(0,1-y_if(x_i))$$
따라서 소프트 마진 목적함수는 다음처럼 쓸 수 있습니다.
$$\frac{1}{2}\|w\|^2+C\sum_i\max(0,1-y_if(x_i))$$

# Support Vector

## 15. Support Vector란
결정경계를 실제로 떠받치는 핵심 점입니다.
하드 마진에서는 주로 다음 점들입니다.
$$y_if(x_i)=1$$
소프트 마진에서는 마진 위, 마진 안, 오분류 점도 경계에 영향을 줄 수 있습니다.
마진 바깥에서 안전하게 맞은 점은 영향이 작습니다.

## 16. w와 Support Vector
$$w=\sum_{i\in S}\alpha_i y_i x_i$$
- S: 서포트 벡터 집합
- α_i: 해당 점의 영향력
- α_i=0이면 직접 기여하지 않음

# Kernel SVM

## 17. 왜 커널이 필요한가
XOR처럼 원래 공간에서 직선으로 나누기 어려운 데이터가 있습니다.
더 높은 차원의 특징공간으로 옮기면 선형 분리가 가능해질 수 있습니다.
```text
원래 데이터 x
→ φ(x)로 고차원 변환
→ 고차원에서 선형 SVM
```

## 18. Kernel Trick
고차원 벡터를 직접 만들지 않고 고차원에서 필요한 내적만 계산합니다.
$$K(x,z)=\phi(x)^\top\phi(z)$$
x와 z는 둘 다 실제 관찰 데이터 벡터입니다.
<mark>커널은 데이터 분포 가정이 아니라 고차원 특징공간에서의 내적 규칙입니다.</mark>

## 19. 커널 트릭의 흐름
```text
관찰 데이터 x, z
↓
φ(x), φ(z)를 직접 만들지 않음
↓
K(x,z)를 바로 계산
↓
이 값 = φ(x)ᵀφ(z)
```
고차원 좌표 자체가 아니라 **고차원에서 필요한 관계만 계산**합니다.

## 20. 커널 행렬
데이터가 여러 개라면 모든 쌍의 커널값을 계산할 수 있습니다.
$$K_{ij}=K(x_i,x_j)$$
이 값들을 모은 것이 커널 행렬입니다.

## 21. 선형 커널
$$K(x,z)=x^\top z$$
원래 공간에서의 내적입니다.

## 22. 다항 커널
$$K(x,z)=(x^\top z+c)^d$$
- d: 차수
- c: 상수항
d가 커질수록 더 복잡한 관계를 표현할 수 있지만 과적합 위험도 커질 수 있습니다.

## 23. RBF 커널
$$K(x,z)=\exp(-\gamma\|x-z\|^2)$$
같은 점이면 1이고, 멀어질수록 0에 가까워집니다.

## 24. γ의 의미
γ는 **거리가 멀어질 때 유사도가 얼마나 빨리 줄어드는지**를 조절합니다.
```text
γ 작음
→ 먼 점까지 비슷하게 봄
→ 영향 범위 넓음
→ 부드러운 경계
→ 과소적합 가능
γ 큼
→ 가까운 점만 비슷하게 봄
→ 영향 범위 좁음
→ 복잡한 경계
→ 과적합 가능
```

## 25. γ와 C
```text
γ
→ RBF의 영향 범위
→ 경계의 국소적 복잡도
C
→ 슬랙 가격
→ 오분류 허용 정도
```
> γ는 RBF 폭, C는 슬랙 가격

# 표준화와 다중분류

## 26. 표준화
SVM은 거리와 내적에 특징 크기가 직접 영향을 줄 수 있습니다.
특히 RBF는 다음 값을 사용합니다.
$$\|x-z\|^2$$
따라서 특징별 단위가 크게 다르면 큰 스케일의 특징 하나가 거리를 지배할 수 있습니다.
보통 학습 데이터 기준으로 표준화하고 테스트 데이터에는 같은 변환을 적용합니다.

## 27. 다중분류
기본 SVM 하나는 이진 분류기입니다.
여러 이진 SVM을 조합하면 다중분류가 가능합니다.
```text
A vs B
A vs C
B vs C
```

# SVR

## 28. SVR의 아이디어
SVR은 SVM의 회귀 버전입니다.
분류 SVM이 클래스 사이 마진을 만든다면, SVR은 예측선 주변에 **ε-튜브**를 둡니다.
$$f(x)=w^\top x+b$$
$$|y-f(x)|\le\epsilon$$
ε 안의 오차는 손실 0으로 봅니다.

## 29. ε의 의미
ε는 **무시할 오차의 폭**입니다.
```text
ε 큼
→ 더 많은 오차를 무시
→ 넓은 튜브
→ 더 단순한 적합
ε 작음
→ 조금만 벗어나도 오차
→ 좁은 튜브
→ 더 타이트한 적합
```

## 30. SVR의 슬랙
슬랙은 선의 위치가 좋은지 직접 판단하는 값이 아닙니다.
**각 점이 ε-튜브를 얼마나 벗어났는지**를 나타냅니다.
```text
ε=2, 실제 80, 예측 81
→ 오차 1
→ 튜브 안
→ 슬랙 0
ε=2, 실제 80, 예측 86
→ 오차 6
→ 허용 2 초과
→ 슬랙 4
```

## 31. ε-insensitive Loss
$$\ell_\epsilon(y,f)=\max(0,|y-f|-\epsilon)$$
```text
튜브 안
→ 손실 0
튜브 밖
→ 벗어난 만큼 손실
```
<mark>ε-insensitive는 ε 안쪽의 오차는 신경 쓰지 않는다는 뜻입니다.</mark>

## 32. SVR의 C
C는 튜브 밖 오차에 대한 벌점 크기입니다.
```text
C 큼
→ 튜브 밖 오차를 강하게 맞추려 함
C 작음
→ 튜브 밖 오차를 더 허용
```
정리하면:
- ε: 어디까지 오차를 무시할지
- 슬랙: 허용 범위를 얼마나 초과했는지
- C: 그 초과를 얼마나 세게 벌할지

## 33. SVR의 Support Vector
ε-튜브 안쪽의 점은 손실이 0입니다.
주로 튜브 경계 또는 바깥의 점이 모델을 결정합니다.

## 34. 커널 SVR
$$f(x)=\sum_{i\in S}(\alpha_i-\alpha_i^*)K(x_i,x)+b$$
커널을 사용하면 비선형 회귀도 가능합니다.

# One-Class SVM

## 35. One-Class SVM의 아이디어
정상 데이터만 보고 정상 덩어리의 영역을 학습합니다.
```text
정상 데이터만 학습
→ 정상 영역 학습
→ 안쪽: 정상
→ 바깥쪽: 이상
```
일반 이진분류처럼 정상과 이상 라벨이 모두 필요한 것은 아닙니다.

## 36. 출력
대표적인 구현에서는 다음처럼 반환합니다.
```text
+1 → 정상
-1 → 이상
```
확률값은 아닙니다.

## 37. ν의 의미
ν는 정상 데이터 중 어느 정도가 경계 밖으로 밀려나는 것을 허용할지와 관련됩니다.
```text
ν 작음
→ 경계 밖 허용 적음
→ 더 많은 학습점을 정상 영역에 포함
ν 큼
→ 더 많은 점이 경계 밖에 있을 수 있음
→ 정상 영역이 더 엄격해질 수 있음
```
ν=0.05가 정확히 5%를 이상치로 만든다는 뜻은 아닙니다.

## 38. One-Class SVM과 RBF
$$K(x,z)=\exp(-\gamma\|x-z\|^2)$$
γ가 크면 가까운 점만 비슷하게 보고 정상 울타리가 세밀해집니다.
γ가 작으면 먼 점도 비슷하게 봐 정상 영역이 넓어질 수 있습니다.

## 39. One-Class SVM과 표준화
거리 기반 커널을 사용하므로 스케일이 중요합니다.
표준화는 정상 학습 데이터 기준으로 맞춥니다.
테스트의 이상치까지 포함해 스케일을 맞추면 정상 영역이 왜곡될 수 있습니다.

## 40. SVM 전체 비교
| 종류 | 목표 | 핵심 값 |
| --- | --- | --- |
| Linear SVM | 선형 분류 | w, b, C |
| Kernel SVM | 비선형 분류 | Kernel, C, γ |
| SVR | 회귀 | ε, C, Kernel |
| One-Class SVM | 이상치 탐지 | ν, γ |

## 잘 놓치는 핵심
- w는 가중치 벡터이며 결정경계의 법선
- f(x)는 스칼라
- f(x)=0인 x들의 집합이 결정경계
- 전체 마진 폭은 2/||w||
- 식의 1은 실제 거리 1이 아님
- 큰 C = 오분류 벌점 큼 = 규제 약함
- Hinge Loss는 충분히 멀리 맞힌 점에 손실 0
- 서포트 벡터가 경계를 결정
- Kernel은 분포 가정이 아님
- Kernel Trick은 고차원 좌표 대신 내적을 계산
- γ는 RBF 영향 범위
- SVM은 표준화가 중요
- 기본 SVM은 이진분류지만 다중분류로 확장 가능
- SVR의 ε는 무시할 오차 폭
- SVR 슬랙은 튜브 초과량
- One-Class SVM은 정상 데이터만으로 학습 가능

## 시험·면접에서 기억할 것
1. 결정경계: wᵀx+b=0
2. 전체 마진: 2/||w||
3. Hard Margin은 완전 분리 필요
4. Soft Margin은 ξ로 위반 허용
5. C가 클수록 오분류를 덜 허용하고 규제는 약함
6. Hinge Loss는 max(0, 1-yf)
7. 서포트 벡터가 경계를 결정
8. Kernel은 고차원 내적을 직접 계산
9. RBF에서 γ가 크면 좁고 복잡한 영향 영역
10. SVR의 ε는 무시할 오차 폭
11. SVR 슬랙은 ε-튜브 초과량
12. One-Class SVM의 ν는 정상 영역 엄격함과 관련

C가 커질 때 가장 적절한 설명은?
① 오분류를 더 허용한다.  
② 오분류 벌점이 커지고 규제는 약해진다.
