지도학습은 **입력 데이터와 정답을 함께 주고, 입력에서 정답을 예측하는 규칙을 학습시키는 방법**입니다.

새로운 입력이 들어왔을 때 정답에 가까운 값을 예측하는 것이 목적입니다.

<blockquote class="prompt-info">
<p>한 줄: 지도학습은 정답이 있는 데이터로 학습하고, 처음 보는 데이터의 정답을 예측합니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

지도학습 = 입력과 정답을 함께 학습 → 새로운 입력의 정답 예측

</details>

## 1. 지도학습이란

머신러닝은 데이터에서 규칙을 찾는 방법입니다.

그중 지도학습은 학습 데이터에 **정답이 포함되어 있는 경우**입니다.

예를 들어 아파트 정보를 이용해 가격을 예측한다고 해봅시다.

| 입력 데이터 | 정답 |
| --- | --- |
| 면적, 위치, 층수 | 아파트 가격 |
| 고객 정보 | 대출 연체 여부 |
| 사진 | 고양이 또는 강아지 |
| 공부 시간 | 시험 점수 |

여기서 입력 데이터는 예측에 사용하는 정보이고, 정답은 모델이 맞혀야 하는 값입니다.

<mark>지도학습의 핵심은 학습할 때 정답을 알고 있다는 점입니다.</mark>

## 2. 가장 간단한 예시

학생의 공부 시간으로 시험 점수를 예측한다고 가정합니다.

| 공부 시간 | 시험 점수 |
| --- | ---: |
| 1시간 | 55점 |
| 2시간 | 63점 |
| 3시간 | 72점 |
| 4시간 | 81점 |

모델은 공부 시간과 시험 점수의 관계를 학습하고, 새로운 학생의 시험 점수를 예측합니다.

과정은 다음과 같습니다.

1. 입력과 정답을 준비한다.
2. 모델이 입력과 정답의 관계를 학습한다.
3. 새로운 입력을 넣는다.
4. 모델이 정답을 예측한다.

## 3. 왜 필요한가

현실에서는 사람이 모든 예측 규칙을 직접 작성하기 어렵습니다.

지도학습은 과거의 입력과 정답에서 패턴을 학습해 새로운 데이터의 결과를 예측합니다.

<blockquote class="prompt-info">
<p>정답이 충분히 있는 예측 문제라면 지도학습을 먼저 떠올리면 됩니다.</p>
</blockquote>

## 4. 지도학습의 기본 구조

지도학습은 크게 입력, 정답, 모델, 예측으로 구성됩니다.

| 구분 | 의미 |
| --- | --- |
| 입력 | 모델에 넣는 데이터 |
| 정답 | 모델이 맞혀야 하는 값 |
| 모델 | 입력과 정답의 관계를 학습하는 구조 |
| 예측 | 새로운 입력에 대해 모델이 만든 결과 |

입력을 x, 실제 정답을 y, 예측값을 y의 추정값이라고 하면 기본 관계는 다음처럼 생각할 수 있습니다.

$$\hat{y}=f(x)$$

학습의 목적은 입력으로 만든 예측값이 실제 정답과 최대한 가까워지도록 모델을 조정하는 것입니다.

## 5. 지도학습의 두 가지 대표 문제

지도학습은 크게 **회귀**와 **분류**로 나눌 수 있습니다.

| 구분 | 예측 대상 | 예시 |
| --- | --- | --- |
| 회귀 | 연속적인 숫자 | 집값, 매출, 온도 |
| 분류 | 정해진 범주 | 정상·이상, 합격·불합격, 고양이·강아지 |

<mark>숫자의 크기를 예측하면 회귀, 어느 범주인지 예측하면 분류라고 생각하면 쉽습니다.</mark>

## 6. 회귀

회귀는 결과가 연속적인 숫자인 문제입니다.

예를 들어 다음 문제는 회귀입니다.

- 아파트 가격 예측
- 내일의 전력 사용량 예측
- 다음 달 매출 예측
- 학생의 시험 점수 예측

예측 결과가 72점, 81.5점, 3억 2천만 원처럼 연속적인 값으로 나타날 수 있습니다.

### 회귀에서 오차를 보는 방법

실제값과 예측값의 차이를 이용해 모델이 얼마나 틀렸는지 계산합니다.

예를 들어 실제값이 80이고 예측값이 75라면 오차는 5입니다.

여러 데이터의 오차를 종합해 모델을 개선합니다.

대표적인 방식 중 하나는 오차를 제곱한 뒤 평균을 구하는 것입니다.

$$\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2$$

값이 작을수록 실제값과 예측값의 차이가 작다는 뜻입니다.

## 7. 분류

분류는 데이터를 정해진 범주 중 하나로 구분하는 문제입니다.

예를 들어 다음 문제는 분류입니다.

- 이메일이 스팸인지 정상인지 구분
- 거래가 정상인지 이상인지 구분
- 사진이 고양이인지 강아지인지 구분
- 대출 신청자의 연체 여부 예측

결과는 연속적인 숫자 자체보다 **어느 범주에 속하는가**가 중요합니다.

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 이진 분류 | 두 범주 중 하나 | 정상·이상 |
| 다중 분류 | 세 개 이상의 범주 중 하나 | 사과·배·복숭아 |

## 8. 지도학습은 어떻게 학습하는가

기본적인 흐름은 다음과 같습니다.

### 1. 데이터 준비

입력과 정답이 함께 있는 데이터를 준비합니다.

예를 들어 고객의 나이, 소득, 거래 이력과 실제 연체 여부를 준비할 수 있습니다.

### 2. 모델에 예측시키기

처음에는 모델의 예측이 정확하지 않을 수 있습니다.

모델은 현재 상태에서 입력을 이용해 예측값을 만듭니다.

### 3. 실제 정답과 비교하기

예측값과 실제 정답이 얼마나 다른지 계산합니다.

이 차이를 수치로 표현하는 기준이 **손실 함수**입니다.

### 4. 모델 조정하기

손실이 작아지도록 모델의 내부 값을 조정합니다.

### 5. 반복하기

예측 → 비교 → 조정을 여러 번 반복합니다.

<mark>학습은 정답을 외우는 것이 아니라, 정답과의 오차가 작아지도록 규칙을 조정하는 과정입니다.</mark>

## 9. 손실 함수

손실 함수는 모델의 예측이 실제 정답과 얼마나 다른지를 수치로 나타냅니다.

손실이 크면 예측이 많이 틀렸다는 뜻이고, 손실이 작으면 실제 정답에 가까운 예측을 했다는 뜻입니다.

지도학습은 일반적으로 이 손실을 줄이는 방향으로 모델을 학습합니다.

<blockquote class="prompt-warning">
<p>손실 함수의 값이 작다고 해서 새로운 데이터에서도 반드시 성능이 좋은 것은 아닙니다.</p>
</blockquote>

학습 데이터만 지나치게 잘 맞히면 과적합이 발생할 수 있기 때문입니다.

## 10. 훈련 데이터와 테스트 데이터

모델을 제대로 평가하려면 학습에 사용한 데이터와 평가에 사용할 데이터를 나누는 것이 중요합니다.

| 구분 | 역할 |
| --- | --- |
| 훈련 데이터 | 모델이 규칙을 학습할 때 사용 |
| 테스트 데이터 | 학습이 끝난 모델을 최종 평가할 때 사용 |

시험 문제를 미리 보고 답을 외운 학생을 평가할 수 없는 것과 비슷합니다.

모델이 학습한 데이터를 그대로 평가에 사용하면 실제보다 성능이 좋게 보일 수 있습니다.

<mark>모델의 목적은 훈련 데이터를 잘 맞히는 것이 아니라 새로운 데이터를 잘 맞히는 것입니다.</mark>

## 11. 일반화

일반화는 모델이 학습하지 않은 새로운 데이터에서도 좋은 예측을 하는 능력입니다.

좋은 지도학습 모델은 훈련 데이터뿐 아니라 처음 보는 데이터에서도 성능이 유지되어야 합니다.

따라서 단순히 훈련 데이터의 정확도만 보는 것은 부족합니다.

## 12. 과적합

과적합은 모델이 훈련 데이터에 지나치게 맞춰진 상태입니다.

훈련 데이터에서는 매우 잘 맞히지만 새로운 데이터에서는 성능이 떨어질 수 있습니다.

예를 들어 시험 문제와 답을 통째로 외웠지만 문제의 원리를 이해하지 못한 경우와 비슷합니다.

과적합이 발생하면 보통 다음과 같은 모습이 나타납니다.

- 훈련 데이터 성능은 매우 높다.
- 새로운 데이터 성능은 상대적으로 낮다.
- 데이터의 일반적인 규칙보다 세부적인 잡음까지 학습한다.

<blockquote class="prompt-warning">
<p>훈련 성능이 매우 높다는 사실만으로 좋은 모델이라고 판단하면 안 됩니다.</p>
</blockquote>

## 13. 과소적합

과소적합은 모델이 데이터의 중요한 규칙조차 충분히 학습하지 못한 상태입니다.

훈련 데이터에서도 성능이 낮고 새로운 데이터에서도 성능이 낮은 경우가 많습니다.

예를 들어 복잡한 관계를 지나치게 단순한 규칙 하나로 설명하려는 경우입니다.

| 구분 | 훈련 데이터 | 새로운 데이터 |
| --- | --- | --- |
| 과소적합 | 성능이 낮음 | 성능이 낮음 |
| 적절한 학습 | 성능이 좋음 | 성능이 좋음 |
| 과적합 | 성능이 매우 좋음 | 성능이 상대적으로 낮음 |

## 14. 지도학습에서 중요한 데이터 구성

지도학습에서는 입력과 정답의 품질이 중요합니다.

입력은 예측에 사용하는 정보이고, 정답은 모델이 맞혀야 하는 값입니다.

데이터가 너무 적거나 잘못된 정답이 많으면 모델이 올바른 규칙을 찾기 어렵습니다.

<mark>좋은 알고리즘뿐 아니라 충분하고 신뢰할 수 있는 데이터가 필요합니다.</mark>

## 15. 대표적인 지도학습 알고리즘

| 알고리즘 | 주로 사용하는 문제 | 핵심 특징 |
| --- | --- | --- |
| 선형 회귀 | 회귀 | 입력과 결과의 관계를 직선 형태로 학습 |
| 로지스틱 회귀 | 분류 | 범주에 속할 가능성을 이용 |
| 의사결정나무 | 회귀·분류 | 조건을 순서대로 나누어 예측 |
| 최근접 이웃 | 회귀·분류 | 가까운 데이터의 정보를 이용 |
| 신경망 | 회귀·분류 | 복잡한 패턴을 여러 층에서 학습 |

지금은 알고리즘 이름보다 **회귀와 분류가 모두 지도학습이라는 점**을 먼저 기억하면 됩니다.

## 16. 지도학습의 장점과 한계

지도학습은 실제 정답과 예측을 직접 비교할 수 있어 성능을 평가하기 쉽습니다.

충분한 양의 정답 데이터가 있다면 회귀와 분류 문제에서 높은 예측 성능을 얻을 수 있습니다.

반면 정답 데이터를 만드는 데 비용이 들 수 있고, 잘못된 정답이나 편향된 데이터가 많으면 모델도 잘못된 규칙을 학습할 수 있습니다.

또한 훈련 데이터에 지나치게 맞춰지면 과적합이 발생할 수 있습니다.

## 18. 지도학습과 비지도학습 비교

지도학습과 비지도학습의 가장 큰 차이는 **정답 데이터의 존재 여부**입니다.

| 구분 | 지도학습 | 비지도학습 |
| --- | --- | --- |
| 정답 | 있음 | 없음 |
| 목적 | 정답 예측 | 데이터 구조 발견 |
| 대표 문제 | 회귀, 분류 | 군집화, 차원 축소 |
| 예시 | 집값 예측 | 고객 유형 묶기 |

<mark>정답이 있으면 지도학습, 정답 없이 데이터의 구조를 찾으면 비지도학습이라고 먼저 구분하면 됩니다.</mark>

## 19. 잘 놓치는 핵심

### 1. 지도학습은 정답이 있는 학습이다

입력만 있는 것이 아니라 입력과 정답이 한 쌍으로 존재합니다.

### 2. 회귀와 분류는 모두 지도학습이다

회귀는 숫자를 예측하고, 분류는 범주를 예측합니다.

### 3. 훈련 데이터 성능만 높으면 충분하지 않다

새로운 데이터에서도 성능이 좋아야 합니다.

이 능력이 일반화입니다.

### 4. 과적합은 훈련 데이터를 너무 잘 학습한 상태이다

훈련 성능은 높지만 새로운 데이터에서 성능이 떨어질 수 있습니다.

### 5. 테스트 데이터는 학습용이 아니다

테스트 데이터는 학습이 끝난 모델의 성능을 확인하기 위한 데이터입니다.

## 20. 시험·면접에서 기억할 것

### 핵심 암기

- 지도학습: 입력과 정답을 함께 사용
- 회귀: 연속적인 숫자 예측
- 분류: 범주 예측
- 손실 함수: 예측과 실제 정답의 차이를 수치화
- 과적합: 훈련 데이터에는 강하지만 새로운 데이터에는 약함
- 일반화: 새로운 데이터에서도 좋은 성능을 내는 능력

### 자주 나오는 질문

**지도학습과 비지도학습의 차이는 무엇인가요?**

지도학습은 정답이 있는 데이터를 이용해 입력과 정답의 관계를 학습합니다.

비지도학습은 정답 없이 데이터 내부의 구조나 패턴을 찾습니다.

**회귀와 분류의 차이는 무엇인가요?**

회귀는 연속적인 숫자를 예측하고, 분류는 정해진 범주를 예측합니다.

**과적합이 무엇인가요?**

훈련 데이터에는 지나치게 잘 맞지만 새로운 데이터에 대한 예측 성능이 떨어지는 현상입니다.

## 21. 예시로 한 바퀴

은행에서 고객의 대출 연체 여부를 예측한다고 가정합니다.

### 입력

고객의 소득, 거래 이력, 대출 금액 등이 입력 데이터가 될 수 있습니다.

### 정답

과거 고객이 실제로 연체했는지 여부가 정답입니다.

### 문제 유형

결과가 연체 또는 정상이라는 두 범주이므로 **분류 문제**입니다.

### 학습

모델은 과거 고객의 입력 정보와 실제 연체 여부를 이용해 규칙을 학습합니다.

### 예측

새로운 고객 정보가 들어오면 학습한 규칙을 이용해 연체 가능성이 높은지 낮은지 판단합니다.

### 평가

학습에 사용하지 않은 데이터로 예측 결과가 실제 정답과 얼마나 일치하는지 확인합니다.

이것이 지도학습의 전체 흐름입니다.
