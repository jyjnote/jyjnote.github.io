비지도학습은 **정답이 없는 데이터에서 숨겨진 구조나 패턴을 찾는 머신러닝 방법**입니다.

데이터가 어떻게 묶이는지, 어떤 특징이 중요한지 스스로 찾아내는 것이 핵심입니다.

<blockquote class="prompt-info">
<p>한 줄: 비지도학습은 정답 없이 데이터 자체의 구조를 찾습니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

비지도학습 = 정답 없이 데이터의 구조, 패턴, 그룹을 찾는 학습

</details>

## 1. 비지도학습이란

지도학습은 입력과 정답을 함께 사용합니다.

반면 비지도학습은 정답 없이 입력 데이터만 사용합니다.

예를 들어 고객들의 구매 기록은 있지만 고객 유형에 대한 정답은 없다고 가정해봅시다.

이때 비슷한 구매 패턴을 가진 고객끼리 자동으로 묶을 수 있습니다.

<mark>비지도학습의 핵심은 정답이 없다는 점입니다.</mark>

## 2. 가장 간단한 예시

다음과 같은 고객 데이터가 있다고 가정합니다.

| 고객 | 월 구매 횟수 | 평균 구매 금액 |
| --- | ---: | ---: |
| 고객 1 | 2회 | 3만 원 |
| 고객 2 | 3회 | 4만 원 |
| 고객 3 | 15회 | 25만 원 |
| 고객 4 | 14회 | 23만 원 |

고객 유형이라는 정답은 없습니다.

하지만 데이터를 보면 고객 1과 고객 2가 비슷하고, 고객 3과 고객 4가 비슷합니다.

비지도학습은 이런 유사성을 이용해 데이터를 자동으로 묶습니다.

## 3. 왜 필요한가

현실에서는 모든 데이터에 정답을 붙이기 어렵습니다.

고객 유형, 문서 주제, 사용자 행동 패턴처럼 처음부터 정답이 정해져 있지 않은 문제도 많습니다.

비지도학습은 이런 데이터에서 사람이 미리 정하지 않은 구조를 발견할 수 있습니다.

<blockquote class="prompt-info">
<p>정답은 없지만 데이터 안에 어떤 구조가 있는지 알고 싶다면 비지도학습을 생각하면 됩니다.</p>
</blockquote>

## 4. 비지도학습의 기본 구조

비지도학습은 보통 입력 데이터만 주어집니다.

모델은 데이터 사이의 거리, 유사성, 분산, 밀도 등을 이용해 구조를 찾습니다.

| 구분 | 의미 |
| --- | --- |
| 입력 | 분석할 데이터 |
| 정답 | 없음 |
| 모델 | 데이터의 구조나 패턴을 찾는 방법 |
| 결과 | 그룹, 새로운 표현, 이상 데이터 등 |

지도학습처럼 실제 정답과 예측값을 직접 비교하는 구조가 아니라는 점이 중요합니다.

## 5. 비지도학습의 대표 문제

비지도학습에서 자주 다루는 문제는 다음과 같습니다.

| 문제 | 목적 | 예시 |
| --- | --- | --- |
| 군집화 | 비슷한 데이터끼리 묶기 | 고객 유형 분류 |
| 차원 축소 | 많은 특성을 적은 정보로 압축 | 시각화, 데이터 압축 |
| 이상 탐지 | 일반적인 패턴과 다른 데이터 찾기 | 이상 거래 탐지 |
| 연관 규칙 | 함께 나타나는 항목 관계 찾기 | 장바구니 분석 |

<mark>비지도학습은 하나의 정답을 맞히는 문제보다 데이터의 구조를 발견하는 문제에 가깝습니다.</mark>

## 6. 군집화

군집화는 비슷한 데이터끼리 그룹으로 묶는 방법입니다.

정답으로 주어진 그룹이 없기 때문에 모델이 데이터의 특징을 보고 스스로 그룹을 만듭니다.

예를 들어 고객 데이터를 구매 횟수와 구매 금액으로 분석하면 비슷한 소비 패턴을 가진 고객끼리 묶을 수 있습니다.

군집화에서는 같은 군집 안의 데이터는 서로 비슷하고, 다른 군집의 데이터는 서로 다르도록 묶는 것이 핵심입니다.

군집화 결과는 정답이 아니라 **데이터를 바라보는 하나의 구조**입니다.

## 7. K-means

K-means는 대표적인 군집화 알고리즘입니다.

미리 군집의 개수 K를 정하고 데이터를 K개의 그룹으로 나눕니다.

작동 흐름은 다음과 같습니다.

1. K개의 중심점을 정한다.
2. 각 데이터를 가장 가까운 중심점에 배정한다.
3. 각 군집의 중심을 다시 계산한다.
4. 군집이 크게 변하지 않을 때까지 반복한다.

<blockquote class="prompt-warning">
<p>K-means는 군집의 개수 K를 사용자가 미리 정해야 합니다.</p>
</blockquote>

K-means에서는 데이터와 중심점 사이의 거리를 이용합니다.

두 점의 거리는 다음처럼 표현할 수 있습니다.

$$d=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$$

거리가 가까운 데이터끼리 같은 군집에 들어갈 가능성이 높습니다.

## 8. K-means의 특징

K-means는 구조가 단순하고 계산이 비교적 빠릅니다.

하지만 모든 데이터에서 좋은 결과를 내는 것은 아닙니다.

| 장점 | 한계 |
| --- | --- |
| 이해하기 쉽다 | K를 미리 정해야 한다 |
| 계산이 비교적 빠르다 | 초기 중심점에 영향을 받을 수 있다 |
| 큰 데이터에도 적용하기 쉽다 | 복잡한 모양의 군집에는 약할 수 있다 |
| 군집 구조를 직관적으로 볼 수 있다 | 이상값에 영향을 받을 수 있다 |

## 9. 계층적 군집화

계층적 군집화는 데이터를 단계적으로 합치거나 나누면서 군집 구조를 만드는 방법입니다.

비슷한 데이터를 먼저 묶고, 다시 비슷한 그룹끼리 합치는 방식으로 생각할 수 있습니다.

결과를 나무 형태로 표현할 수 있다는 특징이 있습니다.

<mark>계층적 군집화는 군집들이 어떻게 합쳐지는지 과정을 확인하기 좋습니다.</mark>

## 10. DBSCAN

DBSCAN은 데이터가 밀집된 영역을 기준으로 군집을 만드는 방법입니다.

K-means와 달리 군집의 개수를 미리 정하지 않아도 됩니다.

또한 주변에 데이터가 거의 없는 점을 이상값처럼 따로 처리할 수 있습니다.

| 구분 | K-means | DBSCAN |
| --- | --- | --- |
| 군집 개수 | 미리 정함 | 미리 정하지 않음 |
| 기준 | 중심점과의 거리 | 데이터의 밀도 |
| 이상값 처리 | 상대적으로 약함 | 가능 |
| 복잡한 모양 | 약할 수 있음 | 비교적 잘 처리 |

## 11. 차원 축소

차원은 데이터가 가진 특성의 개수라고 생각할 수 있습니다.

예를 들어 고객 데이터에 나이, 소득, 방문 횟수, 구매 금액, 구매 횟수가 있다면 여러 개의 차원을 가진 데이터입니다.

차원 축소는 많은 특성을 더 적은 수의 새로운 특성으로 줄이는 방법입니다.

특성이 너무 많으면 계산량이 증가하고 시각화와 학습이 복잡해질 수 있습니다.

차원 축소는 중요한 정보를 최대한 유지하면서 특성의 수를 줄이는 데 사용됩니다.

## 12. PCA

PCA는 대표적인 차원 축소 방법입니다.

데이터가 가장 많이 퍼져 있는 방향을 찾아 새로운 축을 만듭니다.

쉽게 말하면 데이터의 중요한 변화 방향을 남기고 덜 중요한 방향을 줄이는 방법입니다.

<blockquote class="prompt-info">
<p>PCA는 데이터의 분산을 최대한 유지하면서 차원을 줄이는 방법입니다.</p>
</blockquote>

PCA가 새롭게 만든 축을 주성분이라고 합니다.

첫 번째 주성분은 데이터의 분산을 가장 많이 설명하고, 다음 주성분은 그다음으로 많은 분산을 설명합니다.

## 13. 차원 축소의 예시

학생 데이터를 다음과 같이 여러 특성으로 가지고 있다고 가정합니다.

- 수학 점수
- 과학 점수
- 국어 점수
- 영어 점수
- 사회 점수

이 데이터를 두 개의 새로운 축으로 줄이면 전체적인 학업 성향을 간단하게 표현할 수 있습니다.

이렇게 줄인 데이터는 시각화하거나 다른 모델의 입력으로 사용할 수 있습니다.

## 14. 이상 탐지

이상 탐지는 대부분의 데이터와 크게 다른 데이터를 찾는 문제입니다.

예를 들어 정상적인 카드 결제 패턴과 매우 다른 거래가 나타나면 이상 거래로 의심할 수 있습니다.

비지도학습에서는 정상과 이상이라는 정답이 없어도 데이터의 분포나 밀도를 이용해 이상한 데이터를 찾을 수 있습니다.

대표적인 예시는 금융 이상 거래, 제조 장비 이상, 네트워크 침입, 센서 오류 탐지입니다.

<mark>이상 탐지는 대부분의 데이터와 다른 패턴을 찾는 것이 핵심입니다.</mark>

## 15. 연관 규칙

연관 규칙은 여러 항목이 함께 나타나는 관계를 찾는 방법입니다.

대표적인 예시는 장바구니 분석입니다.

어떤 고객들이 빵을 살 때 우유도 자주 함께 산다면 두 상품 사이에 연관성이 있다고 볼 수 있습니다.

연관 규칙에서는 어떤 항목들이 자주 함께 등장하는지 분석합니다.

## 16. 대표적인 비지도학습 알고리즘

| 알고리즘 | 주요 목적 | 핵심 특징 |
| --- | --- | --- |
| K-means | 군집화 | 중심점을 기준으로 군집 생성 |
| 계층적 군집화 | 군집화 | 군집을 단계적으로 합치거나 분리 |
| DBSCAN | 군집화 | 밀도를 기준으로 군집 생성 |
| PCA | 차원 축소 | 분산을 최대한 유지하며 차원 축소 |
| Apriori | 연관 규칙 | 함께 나타나는 항목 관계 분석 |

지금 단계에서는 알고리즘 이름보다 **군집화와 차원 축소가 대표적인 비지도학습 문제라는 점**을 먼저 기억하면 됩니다.

## 17. 지도학습과 비지도학습 비교

두 방법의 가장 큰 차이는 정답 데이터의 존재 여부입니다.

| 구분 | 지도학습 | 비지도학습 |
| --- | --- | --- |
| 정답 | 있음 | 없음 |
| 목적 | 정답 예측 | 구조와 패턴 발견 |
| 대표 문제 | 회귀, 분류 | 군집화, 차원 축소 |
| 결과 | 예측값 또는 범주 | 그룹, 축, 패턴 |
| 예시 | 집값 예측 | 고객 유형 묶기 |

<mark>정답이 있으면 지도학습, 정답 없이 구조를 찾으면 비지도학습입니다.</mark>

## 18. 비지도학습의 장점과 한계

비지도학습은 정답이 없어도 데이터를 분석할 수 있다는 장점이 있습니다.

사람이 미리 알지 못한 패턴이나 그룹을 발견하는 데도 유용합니다.

반면 명확한 정답이 없기 때문에 결과가 얼마나 좋은지 평가하기 어려울 수 있습니다.

또한 알고리즘과 설정에 따라 서로 다른 구조가 만들어질 수 있습니다.

<blockquote class="prompt-warning">
<p>비지도학습의 결과는 항상 하나의 정답으로 해석할 수 있는 것은 아닙니다.</p>
</blockquote>

## 19. 비지도학습 결과는 어떻게 평가하는가

지도학습은 실제 정답과 예측을 비교할 수 있습니다.

하지만 비지도학습은 정답이 없는 경우가 많기 때문에 평가가 더 어렵습니다.

군집화에서는 다음과 같은 기준을 볼 수 있습니다.

- 같은 군집의 데이터가 서로 얼마나 가까운가
- 다른 군집끼리 얼마나 잘 떨어져 있는가
- 실제 분석 목적에 의미 있는 군집인가

즉, 수치적인 평가뿐 아니라 결과의 해석 가능성도 중요합니다.

## 20. 잘 놓치는 핵심

### 1. 비지도학습에는 정답이 없다

입력 데이터만 이용해 구조를 찾습니다.

### 2. 군집화와 분류는 다르다

분류는 정답이 있는 지도학습입니다.

군집화는 정답 없이 비슷한 데이터끼리 묶는 비지도학습입니다.

### 3. K-means는 K를 미리 정한다

K는 만들고 싶은 군집의 개수입니다.

### 4. PCA는 군집화가 아니다

PCA의 목적은 비슷한 데이터를 묶는 것이 아니라 차원을 줄이는 것입니다.

### 5. 비지도학습 결과에는 명확한 정답이 없을 수 있다

결과가 실제 분석 목적에 유용한지도 함께 판단해야 합니다.

## 21. 시험·면접에서 기억할 것

### 핵심 암기

- 비지도학습: 정답 없는 데이터 사용
- 군집화: 비슷한 데이터끼리 묶기
- K-means: K개의 군집으로 나누기
- DBSCAN: 밀도를 이용한 군집화
- PCA: 분산을 유지하면서 차원 축소
- 이상 탐지: 일반적인 패턴과 다른 데이터 찾기

### 자주 나오는 질문

**지도학습과 비지도학습의 차이는 무엇인가요?**

지도학습은 정답이 있는 데이터를 이용해 예측 규칙을 학습합니다.

비지도학습은 정답 없이 데이터 자체의 구조나 패턴을 찾습니다.

**군집화와 분류의 차이는 무엇인가요?**

분류는 미리 정해진 정답 범주를 예측합니다.

군집화는 정답 없이 비슷한 데이터끼리 새로운 그룹을 만듭니다.

**PCA를 사용하는 이유는 무엇인가요?**

데이터가 가진 중요한 정보를 최대한 유지하면서 특성의 수를 줄이기 위해 사용합니다.

## 22. 예시로 한 바퀴

쇼핑몰 고객 데이터를 분석한다고 가정합니다.

### 입력

고객의 구매 횟수, 평균 구매 금액, 방문 횟수 등의 정보가 있습니다.

### 정답

고객이 어떤 유형인지에 대한 정답은 없습니다.

### 목표

비슷한 구매 패턴을 가진 고객끼리 묶고 싶습니다.

### 방법

군집화 알고리즘을 이용합니다.

예를 들어 K-means를 사용해 고객을 여러 그룹으로 나눌 수 있습니다.

### 결과

구매 금액이 높은 고객군, 자주 방문하지만 구매 금액이 낮은 고객군 등 데이터의 특성에 따라 여러 그룹이 만들어질 수 있습니다.

이처럼 정답 없이 데이터의 구조를 찾는 것이 비지도학습입니다.

## 24. 마지막 정리

비지도학습은 **정답이 없는 데이터에서 구조와 패턴을 찾는 머신러닝 방법**입니다.
