FastText는 **단어 자체뿐 아니라 단어 내부의 Character N-gram까지 이용해 Word Embedding을 학습하는 방법**입니다.  
<blockquote class="prompt-info">
<p>FastText = 하나의 단어를 통째로만 학습하지 않고 Character N-gram 단위의 Subword까지 함께 학습하는 Word Embedding 방법입니다.</p>
</blockquote>

예를 들어 `where`라는 단어가 있다고 하겠습니다.

```text
where
```

경계를 표시하면

```text
<where>
```

이고 Character 3-gram을 일부 만들면

```text
<wh
whe
her
ere
re>
```

처럼 나눌 수 있습니다.

FastText는 이런 Subword의 Vector를 함께 활용합니다.

<mark>FastText의 핵심은 Word를 Character N-gram들의 조합으로 표현한다는 것입니다.</mark>

<details>
<summary>한 줄로</summary>

단어 내부의 글자 조각까지 Embedding해서 희귀 단어와 새로운 단어를 더 유연하게 표현합니다.

</details>

## 왜 FastText가 필요한가

기본 Word2Vec을 생각해봅시다.

```text
cat
cats
```

두 단어는 서로 관련이 깊지만 Vocabulary에서는 별개의 Word입니다.

```text
cat  → Vector A
cats → Vector B
```

Word2Vec은 기본적으로 단어 내부 철자 구조를 직접 이용하지 않습니다.

FastText는 단어를 Character N-gram으로 나눠 내부 구조를 공유할 수 있게 합니다.

```text
cat
cats
 ↓
공통 Character N-gram 존재
```

따라서 형태가 비슷한 단어 사이의 정보를 활용할 수 있습니다.

## Subword란

Subword는 Word보다 작은 단위를 의미합니다.

FastText에서는 대표적으로 Character N-gram을 사용합니다.

예:

```text
playing
```

을 Character 조각으로 나누면

```text
pla
lay
ayi
yin
ing
```

같은 부분 문자열을 생각할 수 있습니다.

실제 FastText에서는 단어 경계를 나타내는 기호도 사용합니다.

```text
<playing>
```


## Character N-gram

N-gram은 연속된 $$n$$개의 단위를 묶는 방법입니다.

Character N-gram에서는 단위가 **문자 Character**입니다.

예:

```text
word = apple
```

3-gram을 단순하게 만들면

```text
app
ppl
ple
```

입니다.

FastText에서는 여러 크기의 Character N-gram을 함께 사용할 수 있습니다.

```text
3-gram
4-gram
5-gram
...
```

## Word2Vec과 가장 큰 차이

Word2Vec:

```text
Word
 ↓
하나의 Word Vector
```

FastText:

```text
Word
 ↓
Word 자체 + 여러 Character N-grams
 ↓
Vector 조합
```

즉 Word2Vec이 Word를 기본 단위로 본다면 FastText는 **Word 내부 구조까지 이용**합니다.

| 구분 | Word2Vec | FastText |
| --- | --- | --- |
| 기본 정보 | Word | Word + Subword |
| 내부 철자 | 직접 활용하지 않음 | Character N-gram 활용 |
| OOV | 직접 처리 어려움 | Subword로 추정 가능 |
| 형태 정보 | 제한적 | 상대적으로 잘 활용 |
| 결과 | Dense Vector | Dense Vector |

## FastText의 Word Vector

단어 $$w$$를 구성하는 Character N-gram 집합을 $$G_w$$라고 하겠습니다.

단순화하면 Word Vector는 Subword Vector들의 합으로 생각할 수 있습니다.

$$\mathbf{v}_w=\sum_{g\in G_w}\mathbf{z}_g$$

여기서

```text
G_w → Word w를 구성하는 Subword 집합
z_g → 각 Character N-gram의 Vector
```

입니다.

실제 모델에서는 Word 자체를 나타내는 정보도 함께 사용할 수 있습니다.

핵심은 하나의 Word가 여러 Subword Parameter를 공유한다는 점입니다.

## 예시

다음 두 단어를 생각해봅시다.

```text
play
playing
```

Character N-gram을 사용하면 일부 조각을 공유할 수 있습니다.

```text
play
→ pla, lay, ...

playing
→ pla, lay, ayi, yin, ing, ...
```

`pla`, `lay` 같은 Subword가 겹칩니다.

따라서 두 단어는 완전히 독립적인 Vector만 사용하는 것이 아니라 일부 학습 정보를 공유할 수 있습니다.

<blockquote class="prompt-info">
<p>형태가 비슷한 단어는 공통 Character N-gram을 통해 일부 Embedding 정보를 공유할 수 있습니다.</p>
</blockquote>

## OOV 문제

OOV는 **Out-of-Vocabulary**의 약자입니다.

학습 Vocabulary에 없던 단어가 새로 들어오는 상황입니다.

기본 Word2Vec에서는

```text
새로운 Word
→ 학습된 Word Vector 없음
```

이라는 문제가 발생할 수 있습니다.

FastText는 새로운 단어를 Character N-gram으로 분해할 수 있다면 이미 학습된 Subword Vector를 이용해 표현을 구성할 수 있습니다.

```text
Unknown Word
 ↓
Character N-grams
 ↓
Known Subword Vectors
 ↓
Word Representation
```

<mark>FastText의 대표적인 장점은 Subword 정보를 이용해 OOV Word의 Vector를 구성할 수 있다는 점입니다.</mark>

## Skip-gram과 FastText

FastText의 대표적인 학습 방식은 Word2Vec의 Skip-gram과 연결됩니다.

Skip-gram:

```text
Target Word
   ↓
Context Words 예측
```

FastText에서는 Target Word를 하나의 단일 Vector로만 보지 않고 여러 Subword Vector의 조합으로 표현합니다.

```text
Target Word
 ↓
Character N-grams
 ↓
Subword Vectors
 ↓
Context 예측
```

즉 **예측 구조는 Word2Vec과 유사하지만 입력 표현이 더 세분화**됩니다.

## GloVe와 비교

```text
Word2Vec → Context Prediction
GloVe    → Global Co-occurrence
FastText → Subword + Context Prediction
```

GloVe가 Corpus 전체의 동시출현 통계를 강조한다면 FastText의 핵심은 Character N-gram 기반 Subword 정보입니다.

## FastText와 BERT의 Subword 차이

둘 다 `Subword`라는 표현이 등장하지만 같은 방식은 아닙니다.

FastText:

```text
Word
→ Character N-grams
→ Word Embedding 구성
```

BERT 계열 Tokenizer:

```text
Text
→ WordPiece 등의 Subword Token
→ Transformer 입력 Token
```

FastText의 Character N-gram은 Word Vector를 구성하는 내부 Feature에 가깝습니다.

BERT의 Subword Tokenization과 동일한 개념으로 보면 안 됩니다.

<mark>FastText의 Subword는 Character N-gram 기반 Word Embedding이고, BERT의 Subword Token은 입력 Tokenization 방식입니다.</mark>

## 잘 놓치는 핵심

### 1. FastText는 Word 내부를 본다

Word 자체뿐 아니라 Character N-gram을 이용합니다.

### 2. N-gram의 단위는 Character다

앞서 언어 모델에서 본 Word N-gram과 구분해야 합니다.

### 3. OOV에 대응할 수 있다

새 Word도 이미 학습된 Character N-gram을 조합해 Vector를 만들 수 있습니다.

### 4. Word2Vec과 완전히 별개의 아이디어는 아니다

Skip-gram 같은 예측 학습을 확장하면서 Target 표현에 Subword를 포함할 수 있습니다.

### 5. 철자 유사성이 의미 유사성을 보장하지 않는다

Subword의 장점과 동시에 한계입니다.

### 6. FastText도 기본적으로 Static Embedding이다

문맥마다 같은 Word가 자동으로 다른 Vector를 갖는 Contextual Embedding은 아닙니다.

### 7. BERT의 Subword Tokenization과 구분한다

FastText는 Character N-gram Vector를 이용해 Word Representation을 구성합니다.

## 시험·면접

<blockquote class="prompt-info">
<p>단골: Character N-gram, Subword, Word2Vec과 차이, OOV 처리, 형태 정보, FastText와 BERT Subword의 차이.</p>
</blockquote>

핵심 암기:

- FastText는 Character N-gram 기반 Subword 정보를 사용한다
- Word를 여러 Subword Vector의 조합으로 표현한다
- Word2Vec의 Skip-gram 구조를 확장할 수 있다
- OOV Word도 학습된 Subword를 이용해 표현 가능하다
- 형태적으로 관련된 Word가 정보를 공유할 수 있다
- 기본 FastText는 Static Word Embedding이다
- BERT의 Subword Tokenization과 같은 개념은 아니다

## 예시로 한 바퀴

학습 Corpus에 다음 단어가 있다고 하겠습니다.

```text
play
played
playing
```

FastText는 각 Word를 Character N-gram으로 나눕니다.

```text
play
→ pla, lay, ...

played
→ pla, lay, aye, yed, ...

playing
→ pla, lay, ayi, yin, ing, ...
```

공통 Subword:

```text
pla
lay
```

이 Subword Vector는 여러 Word의 학습에서 반복해서 업데이트될 수 있습니다.

이후 Vocabulary에 없던

```text
player
```

가 들어오더라도 Character N-gram으로 분해해 기존에 학습된 Subword 정보를 활용할 수 있습니다.

```text
New Word
 ↓
Character N-grams
 ↓
Subword Embeddings
 ↓
Vector Combination
 ↓
Word Representation
```

이것이 FastText의 핵심 흐름입니다.
