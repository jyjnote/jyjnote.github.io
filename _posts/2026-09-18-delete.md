`DELETE`는 <mark>기존 Table에서 Row를 삭제하는 DML 명령어</mark>입니다.

`WHERE` 조건을 사용하면 특정 Row만 삭제할 수 있고, WHERE를 생략하면 모든 Row가 삭제 대상이 됩니다.

<blockquote class="prompt-info">
<p>한 줄: DELETE는 Table 구조는 남기고 조건에 맞는 Row를 삭제합니다.</p>
</blockquote>

<details markdown="1">
<summary>한 줄로</summary>

`DELETE`는 기존 Row를 삭제하는 명령어입니다.

</details>

## 대표 예시

EMPLOYEE Table에서 `EMP_ID = 1002`인 직원을 삭제한다고 가정합니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | DEPT_ID |
| --- | --- | --- |
| 1001 | 직원1 | 10 |
| 1002 | 직원2 | 20 |
| 1003 | 직원3 | 10 |

```sql
DELETE FROM EMPLOYEE
WHERE EMP_ID = 1002;
```

### 결과 Table

| EMP_ID | EMP_NAME | DEPT_ID |
| --- | --- | --- |
| 1001 | 직원1 | 10 |
| 1003 | 직원3 | 10 |

`WHERE EMP_ID = 1002`를 만족하는 Row만 삭제됩니다.

```text
DELETE FROM
→ 삭제할 Table

WHERE
→ 삭제할 Row
```

## 기본 문법

```sql
DELETE FROM Table명
WHERE 조건;
```

`DELETE`에서 가장 중요한 부분은 `WHERE`입니다.

WHERE 조건을 만족하는 모든 Row가 삭제됩니다.

## 여러 Row 삭제

조건을 만족하는 Row가 여러 개라면 모두 삭제됩니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | DEPT_ID |
| --- | --- | --- |
| 1001 | 직원1 | 10 |
| 1002 | 직원2 | 20 |
| 1003 | 직원3 | 10 |
| 1004 | 직원4 | 30 |

```sql
DELETE FROM EMPLOYEE
WHERE DEPT_ID = 10;
```

### 결과 Table

| EMP_ID | EMP_NAME | DEPT_ID |
| --- | --- | --- |
| 1002 | 직원2 | 20 |
| 1004 | 직원4 | 30 |

`DEPT_ID = 10`인 직원1과 직원3이 모두 삭제됩니다.

## WHERE를 생략하면

WHERE가 없으면 Table의 모든 Row가 삭제됩니다.

### 입력 Table · DEPARTMENT

| DEPT_ID | DEPT_NAME |
| --- | --- |
| 10 | 개발 |
| 20 | 인사 |
| 30 | 영업 |

```sql
DELETE FROM DEPARTMENT;
```

### 결과 Table

| DEPT_ID | DEPT_NAME |
| --- | --- |
| 데이터 없음 | 데이터 없음 |

Table 구조는 남아 있지만 Row는 모두 제거됩니다.

<blockquote class="prompt-warning">
<p>DELETE에서 WHERE를 생략하면 전체 Row가 삭제될 수 있으므로 삭제 범위를 반드시 확인합니다.</p>
</blockquote>

## DELETE와 DROP 차이

`DELETE`는 Row를 삭제하고, `DROP`은 Table 자체를 삭제합니다.

### DELETE

```sql
DELETE FROM EMPLOYEE;
```

```text
Row 삭제
→ Table 구조 유지
```

### DROP

```sql
DROP TABLE EMPLOYEE;
```

```text
Row 삭제
+
Table 구조 삭제
+
Table 자체 제거
```

| 명령 | Row 삭제 | 구조 삭제 |
| --- | --- | --- |
| DELETE | O | X |
| DROP | O | O |

## DELETE와 TRUNCATE 차이

둘 다 Table의 전체 Row를 제거할 수 있지만 용도가 다릅니다.

### DELETE

```sql
DELETE FROM EMPLOYEE;
```

WHERE를 사용하면 일부 Row만 삭제할 수 있습니다.

```sql
DELETE FROM EMPLOYEE
WHERE DEPT_ID = 10;
```

### TRUNCATE

```sql
TRUNCATE TABLE EMPLOYEE;
```

Table의 모든 Row를 제거하는 용도로 사용하며 일반적으로 WHERE 조건을 사용하지 않습니다.

| 구분 | DELETE | TRUNCATE |
| --- | --- | --- |
| 일부 Row 삭제 | 가능 | 불가 |
| WHERE 사용 | 가능 | 일반적으로 불가 |
| 전체 Row 삭제 | 가능 | 가능 |
| Table 구조 | 유지 | 유지 |

현재 실습 환경인 SQLite에서는 `TRUNCATE TABLE`을 직접 지원하지 않으므로 전체 Row 삭제 시 `DELETE FROM Table명`을 사용할 수 있습니다.

## 조건을 조합해서 삭제

WHERE에는 여러 조건을 함께 사용할 수 있습니다.

### 입력 Table · EMPLOYEE

| EMP_ID | EMP_NAME | DEPT_ID | SALARY |
| --- | --- | --- | ---: |
| 1001 | 직원1 | 10 | 2800 |
| 1002 | 직원2 | 10 | 3500 |
| 1003 | 직원3 | 20 | 2900 |

```sql
DELETE FROM EMPLOYEE
WHERE DEPT_ID = 10
  AND SALARY < 3000;
```

### 결과 Table

| EMP_ID | EMP_NAME | DEPT_ID | SALARY |
| --- | --- | --- | ---: |
| 1002 | 직원2 | 10 | 3500 |
| 1003 | 직원3 | 20 | 2900 |

두 조건을 모두 만족하는 직원1만 삭제됩니다.

## 참조 관계 주의

Foreign Key로 다른 Table이 현재 Row를 참조하고 있다면 DELETE가 제한될 수 있습니다.

예를 들어 주문이 특정 고객을 참조하고 있다고 가정합니다.

```text
ORDERS.CUSTOMER_ID
→ CUSTOMER.CUSTOMER_ID
```

참조 중인 고객 Row를 삭제하려 하면 Foreign Key 설정에 따라 삭제가 실패하거나 별도의 처리 규칙이 적용될 수 있습니다.

이 부분은 Foreign Key 글에서 따로 다룹니다.

## 잘 놓치는 핵심

### 1. DELETE는 Row를 삭제한다

Table 구조 자체를 없애는 명령이 아닙니다.

### 2. WHERE가 삭제 범위를 결정한다

```text
WHERE 있음
→ 조건에 맞는 Row 삭제

WHERE 없음
→ 전체 Row 삭제 가능
```

### 3. 여러 Row가 한 번에 삭제될 수 있다

WHERE 조건을 만족하는 Row가 여러 개라면 모두 삭제됩니다.

### 4. Foreign Key가 있으면 삭제가 제한될 수 있다

다른 Table이 현재 Row를 참조하고 있는지 확인해야 합니다.

## 시험·면접

### 핵심 암기

```text
DELETE
→ 기존 Row 삭제
→ DML
```

```text
WHERE
→ 삭제 대상 지정
```

```text
WHERE 생략
→ 전체 Row 삭제 가능
```

```text
DELETE
→ 구조 유지

DROP
→ 구조까지 삭제
```

### 시험 함정

`DELETE FROM Table명`에서 WHERE가 없다고 Table 자체가 삭제되는 것은 아닙니다.

모든 Row가 삭제되더라도 Table 구조는 남아 있습니다.

### 면접 짧은 답변

`DELETE`는 기존 Table에서 Row를 삭제하는 DML 명령어입니다. WHERE 조건으로 삭제 대상을 제한할 수 있으며, WHERE를 생략하면 모든 Row가 삭제될 수 있습니다. Table 구조는 유지되며, 구조까지 삭제하는 DROP과는 차이가 있습니다.

## 객관식 문제

### 문제 1 · DELETE

다음 중 `DELETE`의 역할은?

① Table 구조 생성  
② 기존 Row 삭제  
③ Column 추가  
④ Table 이름 변경

<details markdown="1">
<summary>정답</summary>

②

`DELETE`는 기존 Table의 Row를 삭제합니다.

</details>

### 문제 2 · 결과 확인

#### 입력 Table

| EMP_ID | EMP_NAME |
| --- | --- |
| 1001 | 직원1 |
| 1002 | 직원2 |

```sql
DELETE FROM EMPLOYEE
WHERE EMP_ID = 1001;
```

결과로 옳은 것은?

① 직원1만 남는다.  
② 직원2만 남는다.  
③ 두 Row가 모두 삭제된다.  
④ EMPLOYEE Table 자체가 삭제된다.

<details markdown="1">
<summary>정답</summary>

②

`EMP_ID = 1001`인 직원1만 삭제됩니다.

| EMP_ID | EMP_NAME |
| --- | --- |
| 1002 | 직원2 |

</details>

### 문제 3 · WHERE 생략

다음 SQL의 결과로 옳은 것은?

```sql
DELETE FROM EMPLOYEE;
```

① EMPLOYEE Table 구조까지 삭제된다.  
② 첫 번째 Row만 삭제된다.  
③ 모든 Row가 삭제되고 Table 구조는 남는다.  
④ 아무 일도 일어나지 않는다.

<details markdown="1">
<summary>정답</summary>

③

WHERE가 없으므로 모든 Row가 삭제 대상이 되지만 Table 자체는 남아 있습니다.

</details>

### 문제 4 · DELETE와 DROP

다음 중 옳은 연결은?

① DELETE → Table 구조 삭제  
② DROP → Row만 삭제하고 구조 유지  
③ DELETE → Row 삭제, 구조 유지  
④ DROP → 특정 Row만 삭제

<details markdown="1">
<summary>정답</summary>

③

`DELETE`는 Row를 삭제하지만 Table 구조는 유지합니다.

</details>

#### 입력 Table

| EMP_ID | DEPT_ID |
| --- | --- |
| 1001 | 10 |
| 1002 | 20 |
| 1003 | 10 |

```sql
DELETE FROM EMPLOYEE
WHERE DEPT_ID = 10;
```

삭제되는 Row 수는?

① 1개  
② 2개  
③ 3개  
④ 0개

<details markdown="1">
<summary>정답</summary>

②

</details>
