보팅과 스태킹은 **서로 다른 모델의 예측을 결합하는 앙상블**입니다.

보팅은 결합 규칙이 미리 정해져 있고, 스태킹은 결합 규칙 자체를 메타 모형이 학습합니다.

<blockquote class="prompt-info">
<p>한 줄: Voting은 정해진 규칙으로 합치고, Stacking은 1층 예측을 새 특징으로 만들어 2층이 합치는 법을 배웁니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

Voting = 고정 결합  
Stacking = 학습된 결합  
Blending = 홀드아웃 한 덩어리로 만드는 간단한 Stacking

</details>

## 1. Voting의 기본 생각

보팅은 서로 다른 모델에게 같은 문제를 물어보고 답을 모으는 앙상블입니다.

```text
로지스틱 회귀
결정트리
SVM
→ 각자 예측
→ 투표 또는 평균
→ 최종 예측
```

배깅처럼 같은 모델을 여러 번 흔드는 것이 아닙니다.

부스팅처럼 앞 모델의 오차를 다음 모델이 이어받는 것도 아닙니다.

## 2. 배깅·부스팅·보팅 비교

| 방식 | 핵심 |
| --- | --- |
| Bagging | 같은 모형 + 다른 가방 |
| Boosting | 앞 오차를 다음 모델이 보완 |
| Voting | 서로 다른 모형 + 고정 결합 |
| Stacking | 서로 다른 모형 + 메타 모형이 결합 학습 |

보팅에는 메타 학습이 없습니다.

결합 규칙은 다수결 또는 평균처럼 미리 정해져 있습니다.

## 3. Hard Voting

Hard Voting은 각 모델이 **클래스 라벨 하나**를 냅니다.

가장 많이 나온 클래스가 최종 예측입니다.

$$\hat{y}=mode(h_1(x),h_2(x),\ldots,h_T(x))$$

- h_t(x): t번째 모델의 클래스 예측
- T: 모델 수
- mode: 가장 많이 나온 값
- ŷ: 최종 클래스

## 4. 가중 Hard Voting

모든 모델의 표를 같은 크기로 둘 필요는 없습니다.

성능이 더 좋은 모델에 더 큰 가중치를 줄 수 있습니다.

$$\hat{y}=\arg\max_c\sum_{t=1}^{T}w_t\mathbf{1}[h_t(x)=c]$$

w_t는 t번째 모델의 발언권입니다.

## 5. Soft Voting

Soft Voting은 클래스 라벨이 아니라 **클래스 확률**을 합칩니다.

$$\hat{p}(c|x)=\sum_{t=1}^{T}w_t p_t(c|x)$$

$$\hat{y}=\arg\max_c\hat{p}(c|x)$$

각 모델이 얼마나 자신 있게 예측했는지도 반영됩니다.

## 6. Soft Voting 예시

합격 확률이 다음과 같다고 합시다.

```text
트리 → 0.90
로지스틱 → 0.55
SVM → 0.40
```

같은 가중치를 사용하면 평균은 다음과 같습니다.

$$\frac{0.90+0.55+0.40}{3}\approx0.617$$

따라서 최종 합격 확률은 약 61.7%입니다.

## 7. Hard와 Soft는 결과가 다를 수 있다

Hard Voting은 각 모델의 최종 라벨만 봅니다.

Soft Voting은 확률 자체를 사용합니다.

예를 들어 다음과 같습니다.

```text
0.49
0.49
0.90
```

Hard Voting에서는 음성 2표, 양성 1표입니다.

하지만 확률 평균은 다음과 같습니다.

$$\frac{0.49+0.49+0.90}{3}\approx0.627$$

Soft Voting에서는 양성이 될 수 있습니다.

## 8. 확률 보정이 중요한 이유

Soft Voting은 확률을 직접 평균하므로 확률 신뢰도가 서로 다르면 한 모델이 평균을 과도하게 지배할 수 있습니다.

따라서 필요하면 확률 보정을 고려합니다.

## 9. 회귀 Voting

회귀에서는 다수결을 할 수 없습니다.

숫자 예측값을 평균합니다.

$$\hat{y}=\sum_{t=1}^{T}w_t h_t(x)$$

같은 가중치라면 단순 평균입니다.

## 10. Voting이 잘 되는 조건

모델들이 **서로 다른 방식으로 틀릴 때** 효과가 큽니다.

<mark>다양한 모델을 모으는 이유는 오류 패턴을 다르게 만들기 위해서입니다.</mark>

## 11. OOB는 Voting의 기본 도구가 아니다

Voting은 부트스트랩을 전제로 하지 않습니다.

따라서 OOB가 기본적으로 생기지 않습니다.

성능 평가는 검증셋이나 교차검증을 사용합니다.

## 12. Stacking의 기본 생각

Stacking은 **1층 모델들의 예측값을 새로운 특징으로 사용하고, 2층 메타 모델이 최종 예측을 학습**하는 방식입니다.

```text
원 특징
→ 모델 A 예측
→ 모델 B 예측
→ 모델 C 예측
→ 이 예측값들을 새 특징으로 사용
→ 메타 모델
→ 최종 예측
```

## 13. Voting과 Stacking 차이

Voting은 결합 규칙이 고정입니다.

Stacking은 결합 규칙을 데이터에서 학습합니다.

```text
Voting
→ 평균 또는 다수결

Stacking
→ 메타 모델이 어떻게 합칠지 학습
```

## 14. 가장 중요한 규칙

<mark>2층 입력과 2층 정답은 반드시 같은 행이어야 합니다.</mark>

예를 들어 1~20행의 예측값을 2층 입력으로 만들었다면, 정답도 1~20행의 실제 라벨이어야 합니다.

행을 서로 다르게 맞추면 안 됩니다.

## 15. 또 다른 잘못된 그림

1층 모델을 100행 전체로 학습한 뒤 같은 100행의 예측을 그대로 2층 입력으로 쓰면 누수가 생길 수 있습니다.

이미 그 행을 보고 만든 예측이기 때문입니다.

## 16. 왜 누수가 생기나

학습행에서 지나치게 좋은 예측을 그대로 쓰면 2층이 실제 새 데이터보다 낙관적인 1층 예측을 보고 학습하게 됩니다.

## 17. OOF

이 문제를 막기 위해 OOF 예측을 사용합니다.

OOF는 Out-of-Fold의 약자입니다.

<mark>각 행을 예측할 때 그 행을 학습에 사용하지 않은 모델의 예측만 사용합니다.</mark>

OOD와는 다른 개념입니다.

## 18. 5겹 OOF 예시

데이터가 100행이고 5겹 교차검증을 한다고 합시다.

한 겹은 20행입니다.

첫 번째 겹을 1~20행이라고 하면 다음과 같습니다.

```text
학습: 21~100행
예측: 1~20행
```

트리와 로지스틱 모두 같은 1~20행을 빼고 학습합니다.

## 19. 첫 번째 겹

1. 트리와 로지스틱을 21~100행으로 학습
2. 두 모델 모두 1~20행 예측
3. 예측값은 1~20행의 2층 입력
4. 실제 1~20행 라벨은 2층 정답

<mark>입력과 정답의 행은 반드시 같습니다.</mark>

## 20. 모든 행의 OOF 예측

5겹을 모두 돌리면 1~100행 각각에 대해 **그 행을 보지 않은 모델이 만든 예측**이 생깁니다.

이 OOF 예측 행렬을 2층 메타 모델의 학습 데이터로 사용합니다.

## 21. OOF 입력 예시

1층 모델이 세 개라면 OOF 예측 세 열이 메타 모델의 새로운 특징이 됩니다.

| 행 | 트리 | 로지스틱 | SVM | 정답 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0.82 | 0.71 | 0.66 | 1 |
| 2 | 0.20 | 0.34 | 0.40 | 0 |

## 22. 서비스용 1층 모델

OOF 예측으로 메타 모델을 학습한 뒤, 서비스용 1층 모델은 전체 학습 데이터로 다시 학습합니다.

새 데이터의 1층 예측을 메타 모델에 넣어 최종 예측을 만듭니다.

## 23. 메타 모델은 무엇을 쓰나

2층은 지나치게 복잡한 모델보다 단순한 모델을 많이 사용합니다.

예를 들면 다음과 같습니다.

- 분류: 로지스틱 회귀
- 회귀: Ridge, Elastic Net

1층 예측 자체가 이미 가공된 정보이므로 2층까지 지나치게 복잡하면 노이즈를 외울 수 있습니다.

## 24. Soft Voting과 Stacking

Soft Voting은 다음처럼 미리 정한 가중치를 사용하는 방식으로 볼 수 있습니다.

$$H(z)=\sum_t w_t z_t$$

여기서 z_t는 각 모델의 예측입니다.

Voting에서는 w_t를 사람이 정하거나 고정된 규칙을 사용합니다.

Stacking에서는 결합 관계를 메타 모델이 학습합니다.

## 25. Blending이란

Blending은 Stacking과 비슷하지만 교차검증 전체를 돌리지 않습니다.

학습 데이터 일부를 한 번 홀드아웃합니다.

```text
앞 80%
→ 1층 모델 학습

뒤 20%
→ 1층 예측 생성
→ 메타 모델 학습
```

## 26. Stacking과 Blending 차이

| 구분 | Stacking | Blending |
| --- | --- | --- |
| 2층 입력 | 모든 행의 OOF 예측 | 홀드아웃 한 덩어리 예측 |
| 데이터 활용 | 높음 | 일부 데이터만 2층 학습 |
| 계산량 | 큼 | 상대적으로 작음 |
| 핵심 | 여러 Fold 반복 | 한 번 분리 |

둘 다 목적은 같습니다.

<mark>1층이 학습에 사용한 행의 예측을 그대로 2층 학습 입력으로 쓰지 않는 것입니다.</mark>

## 27. Voting과 Stacking 전체 비교

| 항목 | Voting | Stacking |
| --- | --- | --- |
| 구성 모델 | 서로 다를 수 있음 | 서로 다를 수 있음 |
| 결합 방식 | 고정 | 학습 |
| 2층 모델 | 없음 | 있음 |
| OOF 필요 | 보통 없음 | 매우 중요 |
| 누수 위험 | 비교적 낮음 | 높음 |
| 구조 | 단순 | 복잡 |
| 유연성 | 낮음 | 높음 |

## 28. Bagging부터 Stacking까지

```text
Bagging
→ 같은 모델을 다른 가방에서 학습

Boosting
→ 앞 모델의 부족함을 다음 모델이 보완

Voting
→ 서로 다른 모델의 답을 고정 규칙으로 결합

Stacking
→ 서로 다른 모델의 예측을 특징으로 만들어
  메타 모델이 결합 규칙을 학습
```

## 잘 놓치는 핵심

### 1. Voting은 메타 학습이 없다

다수결이나 평균 규칙이 미리 정해져 있습니다.

### 2. Soft Voting은 확률 품질이 중요하다

확률 보정이 나쁘면 지나치게 자신 있는 모델이 평균을 지배할 수 있습니다.

### 3. Voting은 OOB가 기본이 아니다

부트스트랩을 전제로 하지 않습니다.

### 4. Stacking의 2층 입력과 정답은 같은 행

행이 어긋나면 안 됩니다.

### 5. 학습 데이터에 대한 fit 예측을 그대로 쓰면 누수

OOF 예측을 사용해야 합니다.

### 6. OOF와 OOD는 다르다

OOF는 교차검증에서 제외된 Fold이고, OOD는 학습 분포 밖 데이터입니다.

### 7. 최종 1층 모델은 전체 데이터로 다시 학습

OOF는 메타 모델 학습용 특징을 만드는 과정입니다.

### 8. Blending은 한 번 홀드아웃

Stacking은 모든 행이 한 번씩 OOF가 되도록 Fold를 순환합니다.

## 시험·면접에서 기억할 것

1. Hard Voting = 클래스 다수결
2. Soft Voting = 확률 평균
3. 회귀 Voting = 예측값 평균
4. Voting은 메타 모델이 없음
5. Stacking은 1층 예측을 2층 특징으로 사용
6. 2층 입력과 정답은 같은 행
7. OOF는 그 행을 보지 않은 1층 모델의 예측
8. 최종 1층 모델은 전체 학습 데이터로 재학습
9. Blending은 홀드아웃 한 덩어리 사용
10. Voting은 고정 규칙, Stacking은 학습 규칙
