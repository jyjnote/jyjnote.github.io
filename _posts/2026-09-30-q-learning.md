Q-Learning은 **상태와 행동의 가치를 직접 학습하여 최적의 행동을 찾는 강화학습 알고리즘**입니다.

환경의 전이확률이나 보상함수를 미리 알지 못해도, 실제 상호작용을 통해 Q값을 갱신할 수 있습니다.

<blockquote class="prompt-info">
<p>한 줄: Q-Learning은 현재 경험을 이용해 상태-행동 가치인 Q값을 반복적으로 수정하면서 최적 정책을 찾는 방법입니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

현재 Q값을 보상과 다음 상태의 최대 Q값을 이용해 조금씩 수정하는 알고리즘입니다.

</details>

## 1. Q-Learning이 필요한 이유

MDP에서는 상태, 행동, 보상, 전이확률을 이용해 강화학습 문제를 표현했습니다.

하지만 실제 문제에서는 전이확률을 정확히 모르는 경우가 많습니다.

예를 들어 로봇이 특정 방향으로 이동했을 때 정확히 어떤 상태로 이동할지 미리 알기 어려울 수 있습니다.

Q-Learning은 이런 상황에서도 사용할 수 있습니다.

<mark>환경 모델을 몰라도 실제 경험만으로 좋은 행동을 학습할 수 있다는 것이 Q-Learning의 핵심입니다.</mark>

## 2. Q값이란

Q값은 특정 상태에서 특정 행동을 선택했을 때 앞으로 얻을 수 있는 기대 누적 보상을 나타냅니다.

$$Q(s,a)$$

즉, 다음 질문에 대한 값입니다.

```text
현재 상태 s에서
행동 a를 선택하면
앞으로 얼마나 좋은가?
```

Q값이 크면 해당 상태에서 그 행동이 좋다는 의미입니다.

## 3. Q-Learning의 핵심 갱신식

Q-Learning의 핵심은 다음 갱신식입니다.

$$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\left[r_{t+1}+\gamma\max_a Q(s_{t+1},a)-Q(s_t,a_t)\right]$$

처음 보면 복잡하지만 구조는 단순합니다.

현재 Q값에 **목표값과 현재값의 차이**를 일부 반영합니다.

$$새로운값=기존값+\alpha(목표값-기존값)$$

Q-Learning에서는 목표값이 다음과 같습니다.

$$목표값=r_{t+1}+\gamma\max_a Q(s_{t+1},a)$$

<mark>현재 행동의 가치는 현재 받은 보상과 다음 상태에서 얻을 수 있는 최선의 미래 가치로 수정됩니다.</mark>

## 4. 갱신식의 각 요소

Q-Learning 갱신식의 구성 요소는 다음과 같습니다.

| 요소 | 의미 |
| --- | --- |
| 현재 Q값 | 현재 상태와 행동에 대한 기존 평가 |
| 학습률 | 새로운 정보를 얼마나 반영할지 결정 |
| 보상 | 현재 행동 후 받은 즉시 보상 |
| 할인율 | 미래 Q값을 얼마나 반영할지 결정 |
| 다음 상태 최대 Q값 | 다음 상태에서 가능한 행동 중 가장 큰 Q값 |

핵심은 다음 세 부분입니다.

```text
현재 평가
+
새로운 정보 반영
+
미래의 최선 가치 고려
```

## 5. 학습률

학습률은 새로운 경험을 현재 Q값에 얼마나 반영할지 정합니다.

$$0<\alpha\le1$$

학습률이 크면 새로운 경험을 크게 반영합니다.

학습률이 작으면 기존 Q값을 더 많이 유지합니다.

| 학습률 | 특징 |
| --- | --- |
| 작음 | 천천히 학습, 기존 정보 유지 |
| 큼 | 빠르게 변화, 최근 경험 크게 반영 |

예를 들어 학습률이 1이면 현재 Q값보다 새로운 목표값을 그대로 따르게 됩니다.

## 6. 할인율

할인율은 미래 보상을 얼마나 중요하게 볼지 결정합니다.

$$0\le\gamma\le1$$

할인율이 작으면 현재 보상을 중요하게 봅니다.

할인율이 크면 미래의 Q값도 중요하게 봅니다.

```text
할인율 작음 → 당장 보상 중요
할인율 큼 → 장기 보상 중요
```

학습률과 할인율은 서로 다른 역할을 합니다.

<blockquote class="prompt-warning">
<p>학습률은 새로운 정보를 얼마나 반영할지 결정하고, 할인율은 미래 보상을 얼마나 중요하게 볼지 결정합니다.</p>
</blockquote>

## 7. 왜 다음 상태에서 최대 Q값을 사용하는가

Q-Learning은 다음 상태에서 가능한 행동 중 가장 큰 Q값을 사용합니다.

$$\max_a Q(s_{t+1},a)$$

이는 다음 상태에 도착했을 때 가장 좋은 행동을 선택한다고 가정하는 것입니다.

예를 들어 다음 상태에서 가능한 행동의 Q값이 다음과 같다고 해봅시다.

| 행동 | Q값 |
| --- | ---: |
| 위 | 2 |
| 아래 | 5 |
| 오른쪽 | 8 |

이 경우 미래 가치로 8을 사용합니다.

$$\max Q=8$$

<mark>Q-Learning은 실제로 어떤 행동을 했는지와 관계없이 다음 상태에서 가장 좋은 행동의 가치를 학습에 사용합니다.</mark>

## 8. Off-Policy

Q-Learning은 Off-Policy 방식입니다.

행동을 실제로 선택하는 정책과 학습 목표에 사용하는 정책이 다를 수 있습니다.

실제 행동에서는 탐험을 위해 무작위 행동을 선택할 수 있습니다.

하지만 Q값을 갱신할 때는 다음 상태에서 가장 큰 Q값을 사용합니다.

```text
실제 행동 선택
→ 탐험 포함

Q값 갱신
→ 다음 상태의 최대 Q값 사용
```

즉, 행동 정책과 목표 정책이 다를 수 있습니다.

## 9. 입실론-탐욕 정책

Q-Learning에서는 탐험과 활용을 위해 입실론-탐욕 정책을 자주 사용합니다.

확률적으로 다음과 같이 행동합니다.

```text
확률 ε
→ 무작위 행동

확률 1-ε
→ Q값이 가장 큰 행동
```

입실론이 크면 탐험을 많이 합니다.

입실론이 작으면 활용을 많이 합니다.

| 입실론 | 행동 |
| --- | --- |
| 큼 | 탐험 증가 |
| 작음 | 활용 증가 |

## 10. Q-Table

상태와 행동의 수가 적다면 Q값을 표 형태로 저장할 수 있습니다.

예를 들어 상태가 세 개이고 행동이 두 개라고 해봅시다.

| 상태 | 왼쪽 | 오른쪽 |
| --- | ---: | ---: |
| 상태 1 | 0 | 0 |
| 상태 2 | 0 | 0 |
| 상태 3 | 0 | 0 |

처음에는 모든 Q값을 0으로 초기화할 수 있습니다.

학습이 진행되면 각 값이 갱신됩니다.

| 상태 | 왼쪽 | 오른쪽 |
| --- | ---: | ---: |
| 상태 1 | 2.1 | 5.8 |
| 상태 2 | 1.5 | 8.3 |
| 상태 3 | 0 | 0 |

상태 1에서는 오른쪽 행동의 Q값이 더 크므로 오른쪽을 선택할 가능성이 높습니다.

## 11. 간단한 예제

현재 상태에서 오른쪽 행동을 선택했다고 가정해봅시다.

현재 Q값은 4입니다.

보상은 2입니다.

다음 상태에서 가장 큰 Q값은 10입니다.

학습률은 0.5이고 할인율은 0.9입니다.

먼저 목표값을 계산합니다.

$$목표값=2+0.9\times10=11$$

현재값과 목표값의 차이는 다음과 같습니다.

$$11-4=7$$

학습률 0.5를 적용합니다.

$$0.5\times7=3.5$$

기존 Q값에 더합니다.

$$Q_{new}=4+3.5=7.5$$

따라서 새로운 Q값은 7.5가 됩니다.

<blockquote class="prompt-info">
<p>Q-Learning 계산에서는 목표값을 먼저 구하고, 현재값과의 차이에 학습률을 곱한 뒤 기존 Q값에 더하면 됩니다.</p>
</blockquote>

## 12. Q-Learning 학습 과정

전체 학습 과정은 다음과 같습니다.

1. Q값을 초기화한다.
2. 현재 상태를 확인한다.
3. 입실론-탐욕 정책으로 행동을 선택한다.
4. 행동을 실행한다.
5. 보상과 다음 상태를 얻는다.
6. Q값을 갱신한다.
7. 현재 상태를 다음 상태로 바꾼다.
8. 종료 상태까지 반복한다.
9. 여러 에피소드 동안 반복한다.

간단히 표현하면 다음과 같습니다.

```text
상태 확인
↓
행동 선택
↓
환경에서 보상과 다음 상태 획득
↓
Q값 갱신
↓
다음 상태로 이동
↓
반복
```

## 13. 벨만 최적 방정식과의 관계

최적 행동가치는 다음 관계를 만족합니다.

$$Q^*(s,a)=\mathbb{E}\left[r+\gamma\max_{a'}Q^*(s',a')\right]$$

Q-Learning은 실제 경험을 반복하며 벨만 최적 방정식의 Q값에 가까워지도록 학습합니다.

<mark>Q-Learning은 경험을 통해 벨만 최적 방정식의 최적 Q값에 가까워지도록 반복 갱신합니다.</mark>

## 14. Q-Learning과 SARSA 비교

Q-Learning과 SARSA는 자주 비교됩니다.

가장 큰 차이는 다음 상태의 Q값을 선택하는 방식입니다.

| 구분 | Q-Learning | SARSA |
| --- | --- | --- |
| 학습 방식 | Off-Policy | On-Policy |
| 다음 값 | 최대 Q값 | 실제 선택한 다음 행동의 Q값 |
| 목표 | 최적 행동 기준 | 현재 정책 기준 |

Q-Learning의 목표값은 다음과 같습니다.

$$r+\gamma\max_{a'}Q(s',a')$$

SARSA의 목표값은 다음과 같습니다.

$$r+\gamma Q(s',a')$$

<mark>Q-Learning은 다음 상태의 최선 행동을 기준으로 학습하고, SARSA는 실제 선택한 다음 행동을 기준으로 학습합니다.</mark>

## 잘 놓치는 핵심

### 1. Q값은 즉시 보상이 아니다

Q값은 현재 보상 하나가 아니라 미래까지 고려한 기대 누적 보상을 나타냅니다.

### 2. 학습률과 할인율은 다르다

학습률은 새로운 정보를 얼마나 반영할지 결정합니다.

할인율은 미래 보상을 얼마나 중요하게 볼지 결정합니다.

### 3. Q-Learning은 모델이 필요 없다

전이확률을 미리 알고 있지 않아도 실제 경험으로 Q값을 학습할 수 있습니다.

### 4. 다음 상태에서는 최대 Q값을 사용한다

실제로 어떤 다음 행동을 선택했는지가 아니라 가장 큰 Q값을 학습 목표에 사용합니다.

### 5. 탐험과 활용을 구분해야 한다

학습 중에는 항상 최대 Q값 행동만 선택하지 않습니다.

새로운 행동을 탐험해야 더 좋은 정책을 발견할 수 있습니다.

### 6. Q-Table은 상태 공간이 작을 때 적합하다

상태 공간이 매우 커지면 모든 상태-행동 조합을 표로 저장하기 어렵습니다.

이 문제를 신경망으로 확장한 대표적인 방법이 DQN입니다.

## 시험·면접

시험이나 면접에서는 다음 내용을 먼저 기억하면 됩니다.

- Q값의 의미
- Q-Learning 갱신식
- 학습률과 할인율 차이
- 시간차 오차
- 탐험과 활용
- 입실론-탐욕 정책
- Off-Policy
- Q-Learning과 SARSA 차이

가장 중요한 식은 다음과 같습니다.

$$Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max Q(s',a')-Q(s,a)\right]$$

자주 나오는 설명은 다음과 같습니다.

<blockquote class="prompt-info">
<p>Q-Learning은 현재 보상과 다음 상태에서의 최대 Q값을 이용해 현재 상태-행동의 Q값을 갱신하는 Off-Policy 강화학습 알고리즘입니다.</p>
</blockquote>

### 시험 함정

- Q값은 현재 보상만 의미하지 않습니다.
- 학습률과 할인율을 같은 개념으로 보면 안 됩니다.
- Q-Learning의 갱신에서는 다음 상태의 최대 Q값을 사용합니다.
- 실제 행동 선택에서는 탐험 행동을 할 수 있습니다.
- Off-Policy라는 이유로 행동 정책과 목표 정책이 다를 수 있습니다.
- 상태가 많아지면 Q-Table의 크기가 급격히 증가합니다.

## 핵심 정리

Q-Learning은 상태와 행동의 가치를 나타내는 Q값을 직접 학습합니다.

핵심 갱신 구조는 다음과 같습니다.

```text
현재 Q값
+
학습률
×
목표값과 현재값의 차이
```

목표값은 현재 보상과 다음 상태의 최대 Q값으로 구성됩니다.

$$목표값=r+\gamma\max Q(s',a')$$

Q-Learning은 이 과정을 여러 번 반복하면서 더 좋은 Q값을 학습합니다.

<mark>결국 Q-Learning은 각 상태에서 Q값이 가장 큰 행동을 찾을 수 있도록 Q값을 반복적으로 수정하는 방법입니다.</mark>
