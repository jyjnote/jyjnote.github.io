머신러닝에서는 하나의 데이터를 그대로 학습과 평가에 모두 사용하지 않습니다.

보통 데이터를 **훈련 데이터, 검증 데이터, 테스트 데이터**로 나누어 사용합니다.

<blockquote class="prompt-info">
<p>한 줄: 훈련 데이터로 학습하고, 검증 데이터로 조정하며, 테스트 데이터로 최종 성능을 확인합니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

훈련 = 학습, 검증 = 조정, 테스트 = 최종 평가

</details>

## 1. 왜 데이터를 나누는가

머신러닝의 목표는 학습 데이터만 잘 맞히는 것이 아닙니다.

처음 보는 새로운 데이터에서도 좋은 예측을 해야 합니다.

만약 학습에 사용한 데이터로 그대로 성능을 평가하면 모델이 실제보다 좋아 보일 수 있습니다.

<mark>데이터를 나누는 이유는 모델의 일반화 성능을 제대로 확인하기 위해서입니다.</mark>

## 2. 세 데이터의 역할

머신러닝 데이터는 보통 다음 세 종류로 나눕니다.

| 구분 | 역할 |
| --- | --- |
| 훈련 데이터 | 모델이 규칙을 학습 |
| 검증 데이터 | 모델과 설정을 조정 |
| 테스트 데이터 | 최종 성능 평가 |

세 데이터는 목적이 서로 다릅니다.

특히 테스트 데이터는 모델을 만드는 과정에서 최대한 사용하지 않는 것이 중요합니다.

## 3. 훈련 데이터

훈련 데이터는 모델이 실제로 학습하는 데이터입니다.

모델은 훈련 데이터의 입력과 정답을 이용해 내부 값을 조정합니다.

예를 들어 선형 회귀에서는 직선의 기울기와 절편을 훈련 데이터에 맞게 조정합니다.

$$\hat{y}=wx+b$$

여기서 w와 b는 훈련 데이터를 이용해 학습됩니다.

<blockquote class="prompt-info">
<p>훈련 데이터는 모델의 내부 값을 직접 학습시키는 데이터입니다.</p>
</blockquote>

## 4. 검증 데이터

검증 데이터는 학습된 여러 모델이나 설정을 비교할 때 사용합니다.

훈련 데이터로 모델을 학습한 뒤 검증 데이터에서 성능을 확인합니다.

검증 결과를 보고 모델의 설정을 바꾸거나 어떤 모델을 사용할지 결정할 수 있습니다.

예를 들어 나무의 최대 깊이, 이웃의 개수, 규제 강도, 학습 반복 횟수 등을 비교할 수 있습니다.

이처럼 사람이 미리 정하는 설정값을 **초매개변수**라고 합니다.

## 5. 테스트 데이터

테스트 데이터는 모델 개발이 끝난 뒤 최종 성능을 확인하는 데이터입니다.

훈련이나 모델 선택에 사용하지 않습니다.

실제 서비스에서 처음 만나는 데이터와 비슷한 역할을 합니다.

<mark>테스트 데이터는 마지막 평가용 데이터입니다.</mark>

## 6. 세 단계의 기본 흐름

전체 과정은 다음과 같습니다.

```text
전체 데이터
    ↓
훈련 데이터 → 모델 학습
    ↓
검증 데이터 → 모델 선택 및 설정 조정
    ↓
테스트 데이터 → 최종 성능 평가
```

핵심은 테스트 데이터를 마지막까지 남겨두는 것입니다.

## 7. 왜 훈련 데이터만으로 평가하면 안 되는가

모델은 훈련 데이터를 직접 보며 학습하므로 훈련 성능은 높게 나올 수 있습니다.

하지만 새로운 데이터에서도 같은 성능이 나온다는 보장은 없으며, 이 문제가 과적합과 연결됩니다.

## 8. 과적합과 데이터 분할

과적합은 모델이 훈련 데이터에 지나치게 맞춰진 상태입니다.

훈련 데이터에서는 높은 성능을 보이지만 새로운 데이터에서는 성능이 떨어질 수 있습니다.

| 상태 | 훈련 성능 | 검증 성능 |
| --- | --- | --- |
| 과소적합 | 낮음 | 낮음 |
| 적절한 학습 | 높음 | 높음 |
| 과적합 | 매우 높음 | 상대적으로 낮음 |

검증 데이터를 사용하면 훈련 데이터에만 지나치게 맞춰지고 있는지 확인할 수 있습니다.

## 9. 일반화

일반화는 학습하지 않은 새로운 데이터에서도 좋은 성능을 내는 능력입니다.

테스트 데이터는 이 일반화 성능을 최종적으로 확인하는 데 사용됩니다.

<blockquote class="prompt-warning">
<p>훈련 정확도가 높다는 이유만으로 좋은 모델이라고 판단하면 안 됩니다.</p>
</blockquote>

## 10. 검증 데이터가 필요한 이유

테스트 데이터 성능을 계속 확인하며 모델을 고르면 테스트 데이터가 사실상 검증 데이터처럼 사용됩니다.

<mark>검증 데이터는 테스트 데이터를 최종 평가용으로 보호하기 위해 필요합니다.</mark>

## 11. 테스트 데이터로 모델을 고르면 안 되는 이유

테스트 결과를 보고 모델을 계속 수정하면 테스트 데이터의 정보가 모델 개발 과정에 간접적으로 사용됩니다.

따라서 테스트 데이터가 완전히 처음 보는 데이터라는 의미가 약해집니다.

## 12. 초매개변수

초매개변수는 모델이 훈련 과정에서 자동으로 학습하는 값이 아니라 사람이 미리 설정하는 값입니다.

예를 들어 의사결정나무의 최대 깊이를 생각할 수 있습니다.

```text
최대 깊이 = 3
최대 깊이 = 5
최대 깊이 = 10
```

각 설정으로 모델을 훈련한 뒤 검증 데이터에서 성능을 비교합니다.

가장 적절한 설정을 선택한 뒤 마지막에 테스트 데이터로 평가합니다.

## 13. 매개변수와 초매개변수

두 개념은 구분해야 합니다.

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 매개변수 | 모델이 훈련 데이터에서 학습 | 선형 회귀의 기울기와 절편 |
| 초매개변수 | 사람이 미리 설정 | 나무 깊이, 이웃 수 |

매개변수는 훈련 데이터로 학습합니다.

초매개변수는 보통 검증 데이터 성능을 보면서 결정합니다.

## 14. 데이터 분할 비율

데이터는 상황에 따라 여러 비율로 나눌 수 있습니다.

예를 들어 다음과 같은 방식이 있습니다.

| 훈련 | 검증 | 테스트 |
| ---: | ---: | ---: |
| 60% | 20% | 20% |
| 70% | 15% | 15% |
| 80% | 10% | 10% |

항상 정해진 하나의 정답이 있는 것은 아닙니다.

데이터가 충분히 많다면 테스트와 검증에 일정 비율을 확보하면서 훈련 데이터를 많이 사용할 수 있습니다.

## 15. 데이터가 적을 때

데이터가 적으면 검증과 테스트 데이터를 따로 확보하면서 훈련 데이터가 부족해질 수 있습니다.

이럴 때 대표적으로 교차검증을 사용합니다.

## 16. 교차검증

교차검증은 훈련 데이터를 여러 조각으로 나눈 뒤 일부를 검증용으로 번갈아 사용하는 방법입니다.

예를 들어 데이터를 다섯 조각으로 나누었다고 가정합니다.

```text
1회: 1번 조각 검증, 나머지 훈련
2회: 2번 조각 검증, 나머지 훈련
3회: 3번 조각 검증, 나머지 훈련
4회: 4번 조각 검증, 나머지 훈련
5회: 5번 조각 검증, 나머지 훈련
```

각 결과를 종합해 모델의 성능을 평가합니다.

<blockquote class="prompt-info">
<p>교차검증은 데이터를 여러 번 나누어 검증하므로 데이터가 적을 때 특히 유용합니다.</p>
</blockquote>

## 17. 교차검증과 테스트 데이터

교차검증을 사용해도 테스트 데이터는 따로 남겨둡니다.

훈련 데이터 안에서 교차검증으로 모델을 선택하고 마지막에 테스트 데이터로 최종 평가합니다.

## 18. 데이터 누수

데이터 누수는 학습 과정에서 원래 알 수 없어야 할 정보가 모델에 들어가는 문제입니다.

예를 들어 테스트 데이터의 평균과 표준편차까지 사용해 전체 데이터를 표준화한 뒤 데이터를 나누면 테스트 정보가 훈련 과정에 섞일 수 있습니다.

<blockquote class="prompt-danger">
<p>테스트 데이터의 정보가 훈련 과정에 들어가면 최종 평가 결과를 신뢰하기 어려워질 수 있습니다.</p>
</blockquote>

## 19. 전처리와 데이터 분할

표준화나 결측값 처리처럼 데이터에서 어떤 값을 계산하는 전처리는 주의해야 합니다.

올바른 흐름은 다음과 같습니다.

1. 먼저 훈련 데이터와 테스트 데이터를 나눈다.
2. 훈련 데이터에서 전처리 기준을 계산한다.
3. 같은 기준을 검증 데이터와 테스트 데이터에 적용한다.

예를 들어 평균과 표준편차는 훈련 데이터에서 계산합니다.

$$z=\frac{x-\mu}{\sigma}$$

검증 데이터와 테스트 데이터에도 훈련 데이터에서 구한 평균과 표준편차를 사용합니다.

## 20. 잘못된 전처리 예시

다음 방식은 데이터 누수를 만들 수 있습니다.

```text
전체 데이터에서 평균 계산
→ 전체 데이터 표준화
→ 훈련·테스트 데이터 분할
```

테스트 데이터의 정보가 평균 계산에 이미 사용되었기 때문입니다.

더 안전한 방식은 다음과 같습니다.

```text
훈련·테스트 데이터 분할
→ 훈련 데이터에서 평균 계산
→ 훈련 데이터 표준화
→ 같은 평균을 테스트 데이터에 적용
```

## 21. 분류 문제의 데이터 분할

분류에서는 훈련과 테스트 데이터에서도 각 범주의 비율이 지나치게 달라지지 않도록 주의합니다.

특정 범주가 한쪽에 몰리면 평가가 불안정해질 수 있습니다.

## 22. 시계열 데이터는 주의한다

시간 순서가 있는 데이터는 무작위로 섞어 나누면 문제가 될 수 있습니다.

예를 들어 과거 주가로 미래 주가를 예측하는 문제에서 미래 데이터가 훈련 데이터에 포함되어서는 안 됩니다.

보통 시간 순서를 유지해 과거 데이터를 훈련에 사용하고 더 최근 데이터를 평가에 사용합니다.

<mark>시계열에서는 미래 정보가 과거 학습 과정으로 들어가지 않도록 주의합니다.</mark>

## 23. 훈련·검증·테스트 비교

| 구분 | 훈련 | 검증 | 테스트 |
| --- | --- | --- | --- |
| 모델 학습 | 사용 | 사용하지 않음 | 사용하지 않음 |
| 모델 선택 | 간접적 | 사용 | 사용하지 않음 |
| 초매개변수 조정 | 사용하지 않음 | 사용 | 사용하지 않음 |
| 최종 평가 | 사용하지 않음 | 사용하지 않음 | 사용 |
| 반복 사용 | 여러 번 | 여러 번 가능 | 최소화 |

<mark>훈련은 배우는 데이터, 검증은 선택하는 데이터, 테스트는 시험 보는 데이터입니다.</mark>

## 24. 검증 성능이 나빠지는 경우

훈련 성능은 좋아지는데 검증 성능이 나빠지기 시작하면 과적합의 신호로 볼 수 있습니다.

## 25. 조기 종료

검증 성능이 더 이상 좋아지지 않으면 학습을 중단할 수 있습니다.

이를 조기 종료라고 하며 과적합을 줄이는 데 활용됩니다.

<blockquote class="prompt-info">
<p>조기 종료는 검증 성능을 이용해 과적합이 심해지기 전에 학습을 멈추는 방법입니다.</p>
</blockquote>

## 26. 잘 놓치는 핵심

### 1. 훈련 데이터는 모델 학습용이다

모델의 매개변수는 훈련 데이터에서 학습됩니다.

### 2. 검증 데이터는 모델 선택용이다

어떤 모델이나 초매개변수를 사용할지 결정할 때 사용합니다.

### 3. 테스트 데이터는 최종 평가용이다

모델 개발 과정에서 반복적으로 사용하면 안 됩니다.

### 4. 테스트 데이터로 모델을 조정하면 안 된다

테스트 결과를 보고 계속 모델을 수정하면 테스트 데이터에 맞춘 모델이 될 수 있습니다.

### 5. 전처리에서도 데이터 누수를 주의한다

평균이나 표준편차 같은 전처리 기준은 훈련 데이터에서 계산합니다.

### 6. 교차검증과 테스트는 역할이 다르다

교차검증은 모델 선택을 돕고 테스트 데이터는 최종 평가에 사용합니다.

## 27. 시험·면접에서 기억할 것

### 핵심 암기

- 훈련 데이터: 모델 학습
- 검증 데이터: 모델과 초매개변수 선택
- 테스트 데이터: 최종 평가
- 일반화: 새로운 데이터에서의 성능
- 과적합: 훈련 성능은 높지만 검증 성능은 낮음
- 데이터 누수: 평가 데이터의 정보가 학습 과정에 들어감
- 교차검증: 훈련 데이터를 여러 번 나누어 검증

### 자주 나오는 질문

**검증 데이터와 테스트 데이터의 차이는 무엇인가요?**

검증 데이터는 모델이나 초매개변수를 선택하는 과정에서 사용합니다.

테스트 데이터는 모든 선택이 끝난 뒤 최종 성능을 확인하는 데 사용합니다.

**왜 테스트 데이터로 모델을 선택하면 안 되나요?**

테스트 결과를 반복해서 보고 모델을 바꾸면 테스트 데이터의 정보가 모델 선택에 반영되기 때문입니다.

**전처리는 언제 해야 하나요?**

데이터를 먼저 나눈 뒤 훈련 데이터에서 전처리 기준을 계산하고 같은 기준을 검증과 테스트 데이터에 적용하는 것이 기본입니다.

## 28. 예시로 한 바퀴

고객의 연체 여부를 예측한다고 가정합니다.

전체 1만 건 중 7천 건으로 모델을 학습하고, 1천5백 건으로 모델과 설정을 비교합니다.

남은 1천5백 건은 마지막까지 사용하지 않고 최종 성능 평가에 사용합니다.

이것이 훈련·검증·테스트 데이터의 기본 흐름입니다.
