GloVe는 **Corpus 전체의 단어 동시출현 통계를 이용해 Dense Word Embedding을 학습하는 방법**입니다.  
이름은 **Global Vectors for Word Representation**의 약자입니다.

<blockquote class="prompt-info">
<p>GloVe = Corpus 전체의 Global Co-occurrence Statistics를 이용해 단어 사이의 관계를 Dense Vector에 학습하는 Word Embedding 방법입니다.</p>
</blockquote>

Word2Vec이 주변 단어를 예측하는 문제를 통해 Embedding을 학습했다면 GloVe는 **동시출현 횟수와 그 비율**을 직접 활용합니다.

```text
Word2Vec
→ Local Context 기반 예측

GloVe
→ Global Co-occurrence Statistics 활용
```

<mark>GloVe의 핵심은 전체 Corpus의 동시출현 통계를 Word Vector에 반영하는 것입니다.</mark>

<details>
<summary>한 줄로</summary>

단어들이 Corpus 전체에서 어떤 단어와 얼마나 함께 등장하는지를 이용해 Dense Vector를 학습합니다.

</details>

## 왜 GloVe가 등장했나

앞서 살펴본 두 계열을 생각해봅시다.

```text
Count 기반
→ Co-occurrence Matrix
→ PPMI

Prediction 기반
→ Word2Vec
→ CBOW · Skip-gram
```

Count 기반 방식은 Corpus 전체 통계를 명확하게 사용할 수 있지만 동시출현 행렬 자체는 매우 크고 Sparse할 수 있습니다.

Word2Vec은 Dense Vector를 직접 학습하지만 학습 과정은 주변 Context를 예측하는 Local Window에 초점을 둡니다.

GloVe는 두 아이디어의 장점을 연결하려고 합니다.

```text
Global Statistics
+
Dense Embedding
=
GloVe
```

## 동시출현 행렬

GloVe의 출발점은 Co-occurrence Matrix입니다.

단어 $$i$$와 Context Word $$j$$가 함께 등장한 횟수를

$$X_{ij}$$

라고 하겠습니다.

예를 들어

| Word | ice | steam | solid | gas |
| --- | ---: | ---: | ---: | ---: |
| water | 10 | 8 | 3 | 2 |
| ice | 5 | 1 | 9 | 0 |

처럼 단어들이 Window 안에서 얼마나 함께 등장했는지를 기록할 수 있습니다.

여기서 중요한 것은 단순히 Count 하나만 보는 것이 아니라 **단어 사이의 통계적 관계**를 학습한다는 점입니다.

## 왜 비율이 중요한가

GloVe 논문의 핵심 직관은 단순한 확률 하나보다 **두 단어에 대한 동시출현 확률의 비율**이 관계를 더 잘 보여줄 수 있다는 것입니다.

예를 들어 `ice`와 `steam`을 비교한다고 하겠습니다.

Context가 `solid`라면

```text
solid
→ ice와 강하게 연결
→ steam과는 상대적으로 약함
```

Context가 `gas`라면 반대일 수 있습니다.

```text
gas
→ steam과 강하게 연결
→ ice와는 상대적으로 약함
```

따라서 다음과 같은 비율이 정보를 제공합니다.

$$\frac{P(k\mid i)}{P(k\mid j)}$$

비율이 1에 가까우면 Context $$k$$가 두 단어를 구분하는 정보가 적고, 크게 1보다 크거나 작으면 두 단어의 관계를 구분하는 정보가 될 수 있습니다.

<mark>GloVe는 동시출현 확률의 비율에 단어 관계 정보가 있다는 아이디어에서 출발합니다.</mark>

## GloVe의 핵심 목표

최종적으로 GloVe는 Word Vector의 내적이 동시출현 Count의 로그와 가까워지도록 학습합니다.

대표적인 형태는

$$w_i^T\tilde{w}_j+b_i+\tilde{b}_j\approx\log X_{ij}$$

입니다.

여기서

```text
w_i       → 중심 Word Vector
w_j       → Context Word Vector
b         → Bias
X_ij      → Co-occurrence Count
```

입니다.

즉 Vector의 관계가 Corpus에서 관찰한 동시출현 통계를 설명하도록 만드는 것입니다.

## 왜 log를 사용하나

동시출현 Count는 차이가 매우 클 수 있습니다.

```text
1
10
100
1000
10000
```

Log를 취하면 값의 규모가 압축됩니다.

```text
log(1)
log(10)
log(100)
log(1000)
```

큰 Count가 목적함수를 지나치게 지배하는 것을 줄이고, 곱셈적 비율 관계를 더 다루기 쉬운 형태로 바꿀 수 있습니다.

앞서 PMI에서 본 것처럼 Log는 비율과 Count 기반 통계를 다룰 때 자주 등장합니다.

## 목적함수

GloVe의 대표적인 목적함수는 다음과 같습니다.

$$J=\sum_{i,j=1}^{V}f(X_{ij})\left(w_i^T\tilde{w}_j+b_i+\tilde{b}_j-\log X_{ij}\right)^2$$

처음 보면 복잡하지만 구조는 단순합니다.

```text
예측값
w_i^T w_j + bias

실제 통계
log(X_ij)

둘의 차이
→ 제곱

그리고
f(X_ij)로 중요도 조절
```

즉

<mark>Word Vector의 내적이 Log Co-occurrence Count를 잘 설명하도록 학습합니다.</mark>

## Weighting Function

목적함수의 $$f(X_{ij})$$는 모든 동시출현 Pair를 똑같이 취급하지 않도록 하는 Weighting Function입니다.

대표적인 형태는

$$f(x)=\begin{cases}(x/x_{max})^\alpha & x<x_{max}\\1 & x\geq x_{max}\end{cases}$$

입니다.

역할을 직관적으로 보면

```text
너무 희귀한 Pair
→ 신뢰도가 낮을 수 있음

매우 빈번한 Pair
→ 영향력이 지나치게 커질 수 있음
```

이런 Count의 영향을 적절하게 조절하는 것입니다.

<blockquote class="prompt-info">
<p>Weighting Function은 희귀한 동시출현과 지나치게 빈번한 동시출현이 학습을 과도하게 지배하지 않도록 조절합니다.</p>
</blockquote>

## Word2Vec과 비교

| 구분 | Word2Vec | GloVe |
| --- | --- | --- |
| 핵심 | Context 예측 | 동시출현 통계 |
| 정보 | Local Context | Global Statistics |
| 결과 | Dense Vector | Dense Vector |
| 대표 학습 | CBOW, Skip-gram | Weighted Least Squares |
| Corpus 활용 | 학습 Pair 생성 | Co-occurrence Count 활용 |

둘 모두 Word Embedding을 만들지만 학습 관점이 다릅니다.

```text
Word2Vec
→ 예측을 잘하도록 Vector 학습

GloVe
→ 전체 동시출현 통계를 잘 설명하도록 Vector 학습
```

## PPMI와 비교

PPMI 역시 동시출현 통계를 이용합니다.

$$PPMI(x,y)=\max(PMI(x,y),0)$$

PPMI Matrix에서는 단어와 Context 사이의 연관성을 Matrix 값으로 직접 표현할 수 있습니다.

GloVe는 동시출현 통계를 기반으로 **저차원의 Dense Parameter를 최적화**합니다.

```text
PPMI
→ Count 기반 Matrix 변환

GloVe
→ Count Statistics 기반 Dense Embedding 학습
```

둘 다 Global Co-occurrence Statistics와 연결되지만 결과를 만드는 방식은 다릅니다.

## GloVe의 한계

기본 GloVe는 Word2Vec과 마찬가지로 **Static Word Embedding**입니다.

하나의 Word Type에 하나의 Vector를 사용합니다.

예:

```text
bank
```

가

```text
은행
강둑
```

이라는 서로 다른 의미를 가져도 기본 GloVe에서는 하나의 Vector로 표현됩니다.

또 Vocabulary에 없는 OOV Word를 직접 표현하기 어렵습니다.

## 잘 놓치는 핵심

### 1. GloVe는 Global Vectors의 약자다

Corpus 전체의 Co-occurrence Statistics를 활용한다는 점과 연결됩니다.

### 2. Co-occurrence Matrix 자체가 최종 Embedding은 아니다

동시출현 통계를 이용해 더 작은 Dense Vector를 학습합니다.

### 3. 핵심 Target은 Log Co-occurrence다

Word Vector의 내적과 Bias가 $$\log X_{ij}$$를 설명하도록 학습합니다.

### 4. Weighting Function이 존재한다

모든 Co-occurrence Pair의 영향을 동일하게 취급하지 않습니다.

### 5. Word2Vec과 학습 방식이 다르다

Word2Vec은 Prediction 중심, GloVe는 Global Co-occurrence Statistics 중심입니다.

### 6. PPMI와도 같은 것은 아니다

둘 다 Count Statistics를 활용하지만 GloVe는 목적함수를 최적화해 Dense Embedding을 학습합니다.

### 7. GloVe는 기본적으로 Static Embedding이다

같은 단어가 문맥에 따라 자동으로 다른 Vector를 갖는 방식이 아닙니다.

</blockquote>

핵심 암기:

- GloVe는 Global Vectors for Word Representation이다
- Corpus 전체의 Co-occurrence Statistics를 활용한다
- 결과는 Dense Word Embedding이다
- Vector 내적이 Log Co-occurrence Count를 설명하도록 학습한다
- Weighting Function으로 Count의 영향을 조절한다
- Word2Vec은 Prediction, GloVe는 Global Statistics 관점이 강하다
- 기본 GloVe는 Static Word Embedding이다

## 예시로 한 바퀴

Corpus에서 다음과 같은 패턴이 반복된다고 하겠습니다.

```text
ice is solid
ice is cold
steam is gas
steam is hot
```

Co-occurrence를 계산하면

```text
ice   ↔ solid
ice   ↔ cold

steam ↔ gas
steam ↔ hot
```

같은 관계가 강하게 나타날 수 있습니다.

이를 $$X_{ij}$$에 기록합니다.

```text
Corpus
 ↓
Co-occurrence Matrix
 ↓
log(X_ij)
 ↓
Weighted Objective
 ↓
Dense Word Vectors
```

GloVe는 학습된 Vector의 내적이 이런 Global Co-occurrence Statistics를 잘 설명하도록 Parameter를 수정합니다.

최종적으로 `ice`, `steam`, `solid`, `gas` 등의 단어를 Dense Vector로 사용할 수 있습니다.
