SQL 명령은 비슷해 보여도 **구조를 바꾸는지, 데이터를 바꾸는지, 권한을 바꾸는지**를 구분하면 이해하기 쉽습니다.

<mark>ALTER는 기존 Table의 Column 추가, 이름 변경, 구조 수정 등에 사용합니다.</mark>

## ALTER TABLE 기본

이미 존재하는 Table을 변경할 때 사용합니다.

```sql
ALTER TABLE EMPLOYEE
ADD COLUMN EMAIL TEXT;
```

새 Column을 하나 추가하는 예시입니다.

## ADD COLUMN

새 Column을 추가합니다.

```sql
ALTER TABLE EMPLOYEE
ADD COLUMN EMAIL TEXT;
```

기존 Row에는 새 Column 값이 NULL이 되거나 DEFAULT가 적용될 수 있습니다.

## DEFAULT와 함께 추가

기본값을 지정하면서 Column을 추가할 수 있습니다.

```sql
ALTER TABLE ORDERS
ADD COLUMN PRIORITY TEXT DEFAULT 'NORMAL';
```

기존 데이터에 어떤 값이 보이는지는 DBMS의 구현과 정의 방식에 따라 확인해야 합니다.

## RENAME COLUMN

Column 이름을 바꿀 수 있는 DBMS가 많습니다.

```sql
ALTER TABLE EMPLOYEE
RENAME COLUMN EMP_NAME TO NAME;
```

SQLite 최신 버전도 `RENAME COLUMN`을 지원합니다.

## RENAME TABLE

Table 이름 자체를 변경할 수 있습니다.

```sql
ALTER TABLE EMPLOYEE
RENAME TO STAFF;
```

관련 View, Trigger, Query 코드에 영향이 있는지 함께 확인해야 합니다.

## DROP COLUMN

Column을 제거하는 문법입니다.

```sql
ALTER TABLE EMPLOYEE
DROP COLUMN EMAIL;
```

SQLite도 비교적 최신 버전에서는 `DROP COLUMN`을 지원하지만 제약조건이나 의존 객체가 있으면 제한될 수 있습니다.

## Data Type 변경

DBMS마다 Data Type 변경 문법이 다릅니다.

예를 들어 어떤 DBMS는 다음과 비슷한 문법을 사용합니다.

```text
ALTER TABLE ...
ALTER COLUMN ...
```

SQLite는 다른 DBMS처럼 자유로운 `ALTER COLUMN TYPE` 문법을 제공하지 않습니다.

복잡한 구조 변경은 새 Table 생성 후 데이터 이동 방식이 필요할 수 있습니다.

## Constraint 변경

기존 제약조건 추가·삭제 문법도 DBMS마다 차이가 큽니다.

일부 DBMS에서는 다음과 같이 제약조건을 추가할 수 있습니다.

```text
ALTER TABLE
ADD CONSTRAINT ...
```

SQLite는 많은 Constraint 변경을 직접 지원하지 않으므로 Table 재생성 전략을 쓰는 경우가 있습니다.

## SQLite Table 재구성

SQLite에서 복잡한 Schema 변경이 필요한 경우 일반적으로 다음 흐름을 생각합니다.

```text
1. 새 구조의 Table 생성
2. 기존 데이터 복사
3. 기존 Table 삭제
4. 새 Table 이름 변경
5. Index와 Trigger 재생성
```

실제 작업에서는 Transaction과 백업을 함께 고려해야 합니다.

## ALTER의 위험

ALTER는 기존 데이터가 있는 Schema를 바꾸므로 영향 범위가 큽니다.

Column 삭제나 제약조건 변경은 기존 Query, View, 프로그램 코드에 영향을 줄 수 있습니다.

<blockquote class="prompt-warning">
<p>운영 데이터베이스에서 ALTER를 수행하기 전에는 의존 객체와 기존 데이터를 반드시 확인합니다.</p>
</blockquote>

## CREATE와 ALTER 비교

| 구분 | CREATE | ALTER |
| --- | --- | --- |
| 목적 | 새 객체 생성 | 기존 객체 변경 |
| 대상 | 없는 객체 | 이미 존재하는 객체 |
| 대표 작업 | CREATE TABLE | ADD, RENAME, DROP COLUMN |

둘 다 Schema를 다루는 DDL입니다.
