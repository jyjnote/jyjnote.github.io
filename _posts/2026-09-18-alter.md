`ALTER`는 <mark>이미 존재하는 데이터베이스 객체의 구조를 변경하는 DDL 명령어</mark>입니다.

주로 `ALTER TABLE`을 사용해 Column을 추가하거나 기존 구조를 변경합니다.

<blockquote class="prompt-info">
<p>한 줄: ALTER는 이미 만들어진 Table의 Schema를 변경합니다.</p>
</blockquote>

<details markdown="1">
<summary>한 줄로</summary>

`ALTER`는 기존 Table의 구조를 수정하는 명령어입니다.

</details>

## 대표 예시

기존 EMPLOYEE Table에 이메일 Column을 추가한다고 가정합니다.

### 입력 Table 구조

| Column | 자료형 |
| --- | --- |
| EMP_ID | INTEGER |
| EMP_NAME | TEXT |
| DEPT_ID | INTEGER |

```sql
ALTER TABLE EMPLOYEE
ADD COLUMN EMAIL TEXT;
```

### 결과 Table 구조

| Column | 자료형 |
| --- | --- |
| EMP_ID | INTEGER |
| EMP_NAME | TEXT |
| DEPT_ID | INTEGER |
| EMAIL | TEXT |

기존 Row를 추가한 것이 아니라 Table의 구조 자체가 바뀐 것입니다.

```text
ALTER
→ Schema 변경
```

## 기본 문법

```sql
ALTER TABLE Table명
변경_내용;
```

ALTER TABLE 뒤에 변경할 Table을 적고, 그 뒤에 수행할 구조 변경 내용을 작성합니다.

## Column 추가

새로운 Column을 추가할 때 사용합니다.

### 입력 Table 구조

| Column | 자료형 |
| --- | --- |
| PRODUCT_ID | TEXT |
| PRODUCT_NAME | TEXT |
| PRICE | INTEGER |

```sql
ALTER TABLE PRODUCT
ADD COLUMN STOCK INTEGER;
```

### 결과 Table 구조

| Column | 자료형 |
| --- | --- |
| PRODUCT_ID | TEXT |
| PRODUCT_NAME | TEXT |
| PRICE | INTEGER |
| STOCK | INTEGER |

기존 Table에 `STOCK` Column이 추가됩니다.

## Column 이름 변경

일부 데이터베이스에서는 `RENAME COLUMN`을 사용할 수 있습니다.

### 입력 Table 구조

| Column | 자료형 |
| --- | --- |
| EMP_ID | INTEGER |
| EMP_NAME | TEXT |
| SALARY | INTEGER |

```sql
ALTER TABLE EMPLOYEE
RENAME COLUMN EMP_NAME TO NAME;
```

### 결과 Table 구조

| Column | 자료형 |
| --- | --- |
| EMP_ID | INTEGER |
| NAME | TEXT |
| SALARY | INTEGER |

`EMP_NAME`이라는 Column 이름이 `NAME`으로 변경됩니다.

## Table 이름 변경

Table 자체의 이름을 바꿀 수도 있습니다.

### 입력 상태

| Table | 상태 |
| --- | --- |
| EMPLOYEE | 존재 |
| STAFF | 없음 |

```sql
ALTER TABLE EMPLOYEE
RENAME TO STAFF;
```

### 결과 상태

| Table | 상태 |
| --- | --- |
| EMPLOYEE | 없음 |
| STAFF | 존재 |

Table의 데이터가 삭제되는 것이 아니라 이름이 변경됩니다.

## Column 삭제

일부 데이터베이스에서는 `DROP COLUMN`으로 Column을 삭제할 수 있습니다.

### 입력 Table 구조

| Column | 자료형 |
| --- | --- |
| EMP_ID | INTEGER |
| EMP_NAME | TEXT |
| EMAIL | TEXT |

```sql
ALTER TABLE EMPLOYEE
DROP COLUMN EMAIL;
```

### 결과 Table 구조

| Column | 자료형 |
| --- | --- |
| EMP_ID | INTEGER |
| EMP_NAME | TEXT |

`EMAIL` Column 자체가 구조에서 제거됩니다.

<blockquote class="prompt-warning">
<p>ALTER TABLE에서 지원되는 세부 문법은 사용하는 데이터베이스 시스템에 따라 차이가 있을 수 있습니다.</p>
</blockquote>

## ALTER와 UPDATE 차이

ALTER와 UPDATE는 모두 무엇인가를 바꾼다는 점에서 헷갈리기 쉽습니다.

### ALTER

```sql
ALTER TABLE EMPLOYEE
ADD COLUMN EMAIL TEXT;
```

```text
Table 구조 변경
→ Schema 변경
```

### UPDATE

```sql
UPDATE EMPLOYEE
SET SALARY = 4000
WHERE EMP_ID = 1001;
```

```text
기존 Row의 값 변경
→ 데이터 변경
```

| 명령 | 변경 대상 |
| --- | --- |
| ALTER | 구조 |
| UPDATE | 실제 데이터 값 |

## ALTER와 CREATE 차이

`CREATE`는 새로운 객체를 만들고, `ALTER`는 이미 존재하는 객체의 구조를 바꿉니다.

```text
CREATE
→ 새 구조 생성

ALTER
→ 기존 구조 변경
```

예를 들어 다음은 새 Table을 만드는 명령입니다.

```sql
CREATE TABLE DEPARTMENT(
    DEPT_ID INTEGER PRIMARY KEY,
    DEPT_NAME TEXT NOT NULL
);
```

반면 다음은 이미 존재하는 Table을 수정합니다.

```sql
ALTER TABLE DEPARTMENT
ADD COLUMN REGION TEXT;
```

## 잘 놓치는 핵심

### 1. ALTER는 DDL이다

```text
ALTER
→ Data Definition Language
→ Schema 변경
```

### 2. ALTER는 실제 Row 값을 수정하는 명령이 아니다

실제 값을 변경하려면 `UPDATE`를 사용합니다.

### 3. 기존 Table을 대상으로 한다

`CREATE`와 달리 이미 존재하는 객체의 구조를 변경합니다.

### 4. 세부 문법은 DBMS마다 차이가 있을 수 있다

Column 삭제, 자료형 변경, 제약조건 변경 등의 문법은 데이터베이스 시스템마다 다를 수 있습니다.

## 시험·면접

### 핵심 암기

```text
ALTER
→ 구조 변경
→ DDL
```

```text
ADD COLUMN
→ Column 추가
```

```text
RENAME COLUMN
→ Column 이름 변경
```

```text
DROP COLUMN
→ Column 삭제
```

```text
ALTER
→ 구조 변경

UPDATE
→ 값 변경
```

### 시험 함정

`ALTER TABLE`을 사용했다고 기존 Row 값 자체를 수정한 것은 아닙니다.

구조를 변경하는 명령과 데이터를 변경하는 명령을 구분해야 합니다.

### 면접 짧은 답변

`ALTER`는 이미 존재하는 Table 같은 데이터베이스 객체의 구조를 변경하는 DDL 명령어입니다. Column 추가, 이름 변경, 삭제 등의 작업에 사용하며, 실제 Row의 값을 바꾸는 `UPDATE`와는 목적이 다릅니다.

## 객관식 문제

### 문제 1 · ALTER

다음 중 `ALTER`의 역할로 가장 적절한 것은?

① 새로운 Row 추가  
② 기존 Table 구조 변경  
③ Row 조회  
④ 기존 Row 값 수정

<details markdown="1">
<summary>정답</summary>

②

`ALTER`는 기존 데이터베이스 객체의 구조를 변경하는 DDL입니다.

</details>

### 문제 2 · Column 추가

다음 SQL의 결과로 옳은 것은?

```sql
ALTER TABLE EMPLOYEE
ADD COLUMN EMAIL TEXT;
```

① EMPLOYEE Table이 삭제된다.  
② EMAIL Row가 하나 추가된다.  
③ EMAIL Column이 추가된다.  
④ EMPLOYEE 이름이 EMAIL로 변경된다.

<details markdown="1">
<summary>정답</summary>

③

`ADD COLUMN`은 기존 Table에 새로운 Column을 추가합니다.

</details>

### 문제 3 · ALTER와 UPDATE

다음 중 옳은 연결은?

① ALTER → 실제 Row 값 변경  
② UPDATE → Table 구조 생성  
③ ALTER → Schema 변경  
④ UPDATE → Column 추가

<details markdown="1">
<summary>정답</summary>

③

`ALTER`는 Schema를 변경하고, `UPDATE`는 기존 Row의 값을 변경합니다.

</details>

### 문제 4 · 이름 변경

다음 SQL의 역할은?

```sql
ALTER TABLE EMPLOYEE
RENAME COLUMN EMP_NAME TO NAME;
```

① Table 삭제  
② Column 이름 변경  
③ Row 삭제  
④ Column 값 수정

<details markdown="1">
<summary>정답</summary>

②

`EMP_NAME` Column의 이름을 `NAME`으로 변경합니다.

</details>

### 문제 5 · DDL

다음 중 DDL에 해당하는 명령은?

① SELECT  
② UPDATE  
③ ALTER  
④ INSERT

<details markdown="1">
<summary>정답</summary>

③

`ALTER`는 데이터 구조를 변경하는 DDL 명령어입니다.

</details>
