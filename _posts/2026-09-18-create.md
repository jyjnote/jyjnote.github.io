<mark>CREATE는 Table, View, Index 같은 데이터베이스 객체를 정의하고 생성합니다.</mark>

## CREATE TABLE 기본

가장 대표적인 사용법은 Table 생성입니다.

```sql
CREATE TABLE DEPARTMENT(
    DEPT_ID INTEGER PRIMARY KEY,
    DEPT_NAME TEXT NOT NULL,
    REGION TEXT
);
```

Table 이름과 Column 이름, Data Type, 제약조건을 함께 정의합니다.

```text
CREATE TABLE
→ Table 이름
→ Column 정의
→ Data Type
→ Constraint
```

## Column 정의

각 Column은 이름과 Data Type을 가집니다.

```sql
EMP_ID INTEGER
EMP_NAME TEXT
SALARY INTEGER
```

Column 정의에는 필요에 따라 `NOT NULL`, `DEFAULT`, `CHECK`, `PRIMARY KEY` 같은 제약조건을 추가합니다.

## Primary Key

Primary Key는 Row를 식별합니다.

```sql
EMP_ID INTEGER PRIMARY KEY
```

복합 Primary Key는 Table 수준에서 정의할 수 있습니다.

```sql
PRIMARY KEY(ORDER_ID, PRODUCT_ID)
```

실습 DB의 ORDER_ITEM과 같은 구조입니다.

## Foreign Key

Table 사이 참조 관계를 정의할 수 있습니다.

```sql
FOREIGN KEY(DEPT_ID)
    REFERENCES DEPARTMENT(DEPT_ID)
```

이 구조는 EMPLOYEE의 `DEPT_ID`가 DEPARTMENT의 `DEPT_ID`를 참조한다는 뜻입니다.

## NOT NULL · DEFAULT · CHECK

Column 값 규칙을 CREATE 단계에서 함께 정의할 수 있습니다.

```sql
EMP_NAME TEXT NOT NULL
```

```sql
STATUS TEXT DEFAULT 'READY'
```

```sql
SALARY INTEGER CHECK(SALARY >= 0)
```

Schema를 만들 때부터 데이터 품질 규칙을 정의하는 것이 중요합니다.

## CREATE VIEW

View는 SELECT 결과를 논리적인 Table처럼 사용할 수 있게 합니다.

```sql
CREATE VIEW HIGH_SALARY_EMP AS
SELECT EMP_ID, EMP_NAME, SALARY
FROM EMPLOYEE
WHERE SALARY >= 4000;
```

View는 실제 데이터를 별도로 저장하는 Table과는 개념이 다릅니다.

## CREATE INDEX

검색 성능을 위해 Index를 만들 수 있습니다.

```sql
CREATE INDEX IDX_EMP_DEPT
ON EMPLOYEE(DEPT_ID);
```

Index는 조회 성능에 도움을 줄 수 있지만 저장 공간과 변경 비용도 발생합니다.

## IF NOT EXISTS

SQLite를 포함한 여러 DBMS에서는 이미 객체가 있을 때 오류를 피하기 위해 `IF NOT EXISTS`를 지원합니다.

```sql
CREATE TABLE IF NOT EXISTS TEST(
    ID INTEGER PRIMARY KEY
);
```

지원 여부와 문법은 DBMS마다 확인해야 합니다.

## CREATE와 Schema

CREATE는 단순히 빈 Table을 만드는 명령이 아닙니다.

```text
Column 이름
Data Type
Primary Key
Foreign Key
NOT NULL
CHECK
DEFAULT
```

같은 Schema 규칙을 함께 정의합니다.

## CREATE와 INSERT

CREATE는 구조를 만들고 INSERT는 데이터를 넣습니다.

```text
CREATE
→ 구조 생성

INSERT
→ Row 추가
```

둘을 구분해야 합니다.

## CREATE와 ALTER

처음 구조를 만들 때는 CREATE를 사용합니다.

이미 존재하는 객체의 구조를 변경하려면 ALTER를 사용합니다.

```text
CREATE
→ 처음 생성

ALTER
→ 기존 구조 변경
```

## SQLite에서 CREATE

SQLite에서는 `CREATE TABLE`, `CREATE INDEX`, `CREATE VIEW`, `CREATE TRIGGER` 등을 사용할 수 있습니다.

Data Type 처리 방식은 MySQL이나 PostgreSQL과 차이가 있으므로 SQLite의 Type Affinity도 별도로 이해하면 좋습니다.
