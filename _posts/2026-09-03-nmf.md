NMF는 음수가 없는 표 $$X$$를 음수가 없는 두 표의 곱으로 근사합니다.

$$
X \approx WH,\qquad W\ge 0,\quad H\ge 0
$$

PCA처럼 축을 회전하는 것이 아닙니다.  
더해서 원래 표를 설명하는 **부분**을 찾습니다.

<blockquote class="prompt-info">
  <p>NMF = Non-negative Matrix Factorization. 입력이 음수면 쓸 수 없습니다. sklearn은 <code>sklearn.decomposition.NMF</code>입니다.</p>
</blockquote>

## PCA·SVD와 질문이 다름

PCA/SVD: 분산이 큰 직각 방향. 로딩은 음수여도 됨.  
NMF: 음이 아닌 계수만 허용. 부분을 **더해서** 복원.

얼굴 사진이면 PCA 1축은 “전체 얼굴의 +/− 패턴”이 되기 쉽습니다.  
NMF 성분은 “눈”, “코”, “입”처럼 조각이 나오기 쉽습니다. 음수가 없어서 빼기가 안 되기 때문입니다.

라벨은 쓰지 않습니다. 분류기가 아닙니다.

## 기호

$$X$$가 문서 $$n$$개, 단어 $$p$$개이면

- $$X$$: $$n\times p$$. 칸 $$(i,j)$$는 i번 문서에서 j번 단어가 나온 횟수(또는 TF-IDF). $$X_{ij}\ge 0$$
- $$r$$: 남길 부분 수. `n_components`. $$r \ll \min(n,p)$$
- $$W$$: $$n\times r$$. i번 문서가 각 부분을 얼마나 쓰는지
- $$H$$: $$r\times p$$. 각 부분이 단어를 얼마나 가지고 있는지
- $$WH$$의 $$(i,j)$$: i번 문서를 부분으로 조립했을 때 j번 단어의 예측 횟수

한 줄:

<span style="color:#c0392b"><strong>문서 = 부분의 가중합. 계수도 부분도 0 이상.</strong></span>

## 왜 음수를 막나

$$W$$나 $$H$$에 음수가 있으면 “이 단어를 빼라”가 됩니다.  
횟수·픽셀·에너지처럼 원래 0 이상인 자료에는 그 말이 안 맞습니다.

음수 금지의 대가:

- 직각(직교)이 깨짐. 부분끼리 상관이 있을 수 있음
- 분해가 유일하지 않음. 초기값에 따라 $$W$$, $$H$$가 달라질 수 있음
- 입력에 음수가 하나라도 있으면 그대로 못 넣음

## 무엇을 줄이나

자주 쓰는 목표:

$$
\min_{W\ge 0,\,H\ge 0}\ \|X-WH\|_{F}^{2}
$$

- $$\|A\|_{F}^{2}$$: 모든 원소 제곱합
- $$X-WH$$: 복원 오차
- $$W\ge 0$$, $$H\ge 0$$: 음수 금지

문서-단어처럼 횟수면 KL 형태의 목표를 쓰기도 합니다.  
sklearn `NMF`의 `beta_loss="frobenius"`가 제곱합, `"kullback-leibler"`가 횟수에 더 가깝습니다.

$$r$$은 교차검증·해석으로 고릅니다. 고유값 누적 95% 같은 공식이 없습니다.

## 숫자로 한 바퀴

단어는 무료, 당첨, 회의 세 개. 문서 3개. $$r=2$$.

| 문서 | 무료 | 당첨 | 회의 |
| :---: | ---: | ---: | ---: |
| D1 | 4 | 2 | 0 |
| D2 | 3 | 1 | 0 |
| D3 | 0 | 0 | 5 |

광고 문서 D1·D2, 업무 문서 D3입니다.

한 해의 예(정확한 최적은 초기값에 따라 조금 다름):

부분 1이 광고, 부분 2가 업무라고 두면 $$H$$는 대략

| | 무료 | 당첨 | 회의 |
| :---: | ---: | ---: | ---: |
| 부분 1 | 큼 | 중간 | 0 근처 |
| 부분 2 | 0 근처 | 0 근처 | 큼 |

$$W$$는 대략

| | 부분 1 | 부분 2 |
| :---: | ---: | ---: |
| D1 | 큼 | 0 근처 |
| D2 | 큼 | 0 근처 |
| D3 | 0 근처 | 큼 |

D1의 무료 칸 복원:

$$
(WH)_{D1,\text{무료}} = W_{D1,1}H_{1,\text{무료}} + W_{D1,2}H_{2,\text{무료}}
$$

부분 2 계수가 0이면 광고 부분만 더합니다.  
PCA처럼 “업무 부분을 음수로 빼서 광고를 강조”하지 않습니다.

## 학습이 하는 일

1. $$W$$, $$H$$를 0 이상으로 초기화
2. $$WH$$가 $$X$$에 가까워지도록 번갈아 갱신
3. 음수가 나오면 0으로 자름(또는 음수가 안 나오는 갱신식을 씀)

sklearn:

```python
from sklearn.decomposition import NMF

nmf = NMF(n_components=2, init="nndsvda", random_state=0)
W = nmf.fit_transform(X)
H = nmf.components_
X_hat = W @ H
```

- `fit_transform(X)` → $$W$$
- `components_` → $$H$$
- `transform(X_new)`: 학습된 $$H$$를 고정하고 새 행의 $$W$$만 구함
- `init`, `random_state`: 분해가 유일하지 않아서 필요

새 문서는 $$H$$를 다시 외우지 않습니다. 이미 배운 부분에 얼마나 올라타는지($$W$$)만 구합니다.

## 언제 표를 먼저 바꾸나

- 횟수: 그대로 또는 TF-IDF. 음수가 생기면 NMF 금지
- 픽셀: 0–255를 0–1로만 스케일. 평균을 빼면 음수가 생김
- 표준화(평균 0, 분산 1)는 평균 때문에 음수가 나옴. NMF 전에 쓰지 않음

PCA는 평균을 빼는 것이 기본입니다.  
NMF는 평균을 빼면 안 되는 경우가 많습니다.

## 토픽 모델 LDA와의 이름

여기 NMF는 행렬 분해입니다.  
토픽 모델 Latent Dirichlet Allocation도 문서를 주제 혼합으로 봅니다.

- NMF: $$X\approx WH$$. 확률 모형이 아님
- 토픽 LDA: 단어가 주제에서 나온다고 보는 생성 모형
- 선형판별 LDA: 아예 다른 분류기

시험에 “LDA”만 나오면 문맥을 봅니다. 차원축소·시각화면 선형판별, 문서 주제면 토픽 모델입니다.

## PCA와 비교

| | PCA | NMF |
| :--- | :--- | :--- |
| 음수 | 허용 | 금지 |
| 의미 | 분산 축 | 더해서 복원하는 부분 |
| 직교 | 예 | 아님 |
| 입력 | 평균 제거가 기본 | 0 이상 유지 |
| 유일성 | 부호만 임의 | 초기값에 따라 달라질 수 있음 |
| 새 점 | $$v^{\top}(x-\bar{x})$$ | 고정된 $$H$$에 대한 $$W$$ |

## 잘 놓치는 핵심

- 입력·$$W$$·$$H$$ 모두 0 이상
- 부분의 합이지 직교 축이 아님
- $$r$$은 초매개변수
- 평균 제거·표준화는 음수를 만들 수 있음
- 분해가 유일하지 않음
- 라벨을 안 봄
- 선형판별 LDA·토픽 LDA와 약자만 겹칠 수 있음
