한 문서에서는 자주 등장하지만 **전체 Corpus에서는 드물게 등장하는 Term**에 높은 가중치를 주는 방법입니다.  
TF와 IDF를 곱해 단순 Count보다 문서를 잘 구분하는 단어를 강조합니다.

<blockquote class="prompt-info">
<p>TF-IDF = 문서 내부의 빈도 TF와 Corpus 전체의 희소성 IDF를 결합한 가중치입니다.</p>
</blockquote>

예:

```text
D1: AI AI model
D2: AI system
D3: NLP model

```
`AI`는 D1에서 자주 등장하지만 여러 문서에도 등장합니다.
`NLP`는 한 문서에만 등장합니다.
TF-IDF는 이런 차이를 함께 반영합니다.

<mark>현재 문서에서는 자주 나오고 다른 문서에서는 드문 Term일수록 높은 TF-IDF를 가집니다.</mark>

<details>
<summary>한 줄로</summary>

TF는 문서 내부 빈도, IDF는 전체 Corpus 희소성이고 둘을 곱한 값이 TF-IDF입니다.

</details>

## 기본 공식
가장 기본적인 형태는 다음과 같습니다.
$$TFIDF(t,d)=TF(t,d)\times IDF(t)$$
여기서

```text
t → Term
d → Document

```
입니다.
TF:
$$TF(t,d)$$
는 문서 $$d$$ 안에서 Term $$t$$의 빈도를 나타냅니다.
IDF:
$$IDF(t)$$
는 Term $$t$$가 전체 Corpus에서 얼마나 희귀한지를 나타냅니다.

## TF 다시 보기
가장 단순한 Raw TF는 등장 횟수를 그대로 사용합니다.
$$TF(t,d)=f_{t,d}$$
예:

```text
D1: AI AI model

```
이라면

```text
TF(AI, D1) = 2
TF(model, D1) = 1

```
입니다.
문서 길이를 고려하고 싶다면 정규화 TF를 사용할 수 있습니다.
$$TF(t,d)=\frac{f_{t,d}}{\sum_k f_{k,d}}$$
TF 정의는 구현에 따라 달라질 수 있습니다.

## IDF 다시 보기
가장 대표적인 기본 IDF는 다음과 같습니다.
$$IDF(t)=\log\frac{N}{DF(t)}$$
여기서

```text
N     → 전체 문서 수
DF(t) → Term t가 등장한 문서 수

```
입니다.
DF가 높으면 흔한 Term이므로 IDF는 작아집니다.
DF가 낮으면 희귀한 Term이므로 IDF는 커집니다.

```text
DF 증가
→ IDF 감소

DF 감소
→ IDF 증가

```

## 왜 곱하나
TF만 보면 현재 문서 안의 빈도만 알 수 있습니다.
IDF만 보면 Corpus 전체에서의 희귀성만 알 수 있습니다.
둘을 곱하면

```text
현재 문서에서 자주 등장하는가?
+
전체 문서에서는 드문가?

```
를 동시에 볼 수 있습니다.
예:

```text
Term A
TF 높음
IDF 높음
→ 높은 TF-IDF

Term B
TF 높음
IDF 낮음
→ 낮거나 중간 TF-IDF

```

<blockquote class="prompt-info">
<p>TF-IDF는 Local 정보인 TF와 Global 정보인 IDF를 결합합니다.</p>
</blockquote>

## 계산 예시
Corpus:

```text
D1: AI AI model
D2: AI system
D3: NLP model

```
전체 문서 수는
$$N=3$$
입니다.
`AI`는 D1, D2에 등장합니다.
$$DF(AI)=2$$
따라서
$$IDF(AI)=\log\frac{3}{2}$$
입니다.
D1에서 `AI`는 2번 등장합니다.
Raw TF를 사용하면
$$TF(AI,D1)=2$$
입니다.
따라서
$$TFIDF(AI,D1)=2\times\log\frac{3}{2}$$
입니다.

## 희귀한 Term 비교
같은 Corpus에서 `NLP`는 D3에만 등장합니다.
$$DF(NLP)=1$$
따라서
$$IDF(NLP)=\log\frac{3}{1}=\log 3$$
입니다.
D3에서 `NLP`의 Raw TF는 1입니다.
$$TF(NLP,D3)=1$$
따라서
$$TFIDF(NLP,D3)=\log 3$$
입니다.
`NLP`는 Corpus에서 더 희귀하므로 IDF가 더 큽니다.

## 모든 문서에 등장하는 Term
어떤 Term이 모든 문서에 등장한다고 하겠습니다.
$$DF(t)=N$$
기본 IDF를 사용하면
$$IDF(t)=\log\frac{N}{N}=\log 1=0$$
입니다.
따라서
$$TFIDF(t,d)=TF(t,d)\times 0=0$$
이 됩니다.
즉 모든 문서에 공통으로 등장하는 Term은 문서를 구분하는 데 거의 도움이 없다고 보는 것입니다.

<blockquote class="prompt-warning">
<p>기본 IDF 공식에서는 모든 문서에 등장하는 Term의 IDF가 0이 됩니다.</p>
</blockquote>

## DTM에서 TF-IDF Matrix로
Count DTM:

```text
        AI  NLP  model  system
D1       2    0    1      0
D2       1    0    0      1
D3       0    1    1      0

```
각 열의 DF를 구합니다.

```text
DF(AI)     = 2
DF(NLP)    = 1
DF(model)  = 2
DF(system) = 1

```
그다음 각 Term의 IDF를 계산합니다.
각 문서의 TF에 IDF를 곱하면 TF-IDF Matrix가 됩니다.

```text
Count DTM
→ TF 계산
→ DF 계산
→ IDF 계산
→ TF × IDF
→ TF-IDF Matrix

```

<mark>TF-IDF Matrix는 DTM의 각 Count를 중요도 가중치로 바꾼 형태로 이해할 수 있습니다.</mark>

## Sparse Vector
TF-IDF도 Vocabulary 전체를 기준으로 벡터를 만듭니다.
문서에 등장하지 않은 Term은 TF가 0이므로 TF-IDF도 0입니다.
따라서 대부분의 값이 0이 될 수 있습니다.

```text
[0, 0, 0.72, 0, 0, ..., 1.31, ..., 0]

```
즉 TF-IDF 역시 대규모 Vocabulary에서는 **Sparse Vector**가 됩니다.

<blockquote class="prompt-warning">
<p>TF-IDF가 가중치를 사용한다고 해서 희소성 문제가 사라지는 것은 아닙니다.</p>
</blockquote>

## 문서 유사도와 연결
TF-IDF Vector는 문서 간 유사도를 계산하는 데 자주 사용됩니다.
예:

```text
D1 → [0.8, 0.0, 0.6]
D2 → [0.7, 0.0, 0.5]
D3 → [0.0, 1.2, 0.1]

```
D1과 D2는 비슷한 방향을 가집니다.
D3는 다른 방향입니다.
텍스트에서는 코사인 유사도를 자주 사용합니다.
$$\cos(\theta)=\frac{\mathbf{A}\cdot\mathbf{B}}{\|\mathbf{A}\|\|\mathbf{B}\|}$$

```text
TF-IDF Vector
+
Cosine Similarity
→ 문서 유사도

```
입니다.

## TF-IDF와 BoW 차이
BoW Count:

```text
단어 등장 횟수

```
TF-IDF:

```text
단어 등장 빈도
+
Corpus 전체 희소성

```
예:

```text
BoW
the → 10
AI  → 2

```
단순 Count에서는 `the`가 더 큽니다.
하지만 `the`가 모든 문서에 흔하다면 IDF가 낮습니다.
TF-IDF에서는 `AI`가 더 큰 가중치를 받을 수 있습니다.

## 순서 정보는 여전히 없다
TF-IDF는 BoW 계열 표현이므로 기본적으로 단어 순서를 저장하지 않습니다.

```text
dog bites man
man bites dog

```
같은 단어가 같은 빈도로 등장하면 비슷한 벡터가 만들어질 수 있습니다.
TF-IDF는 **단어 중요도**를 조절하지만 **문장 순서**를 복원하지는 않습니다.

<blockquote class="prompt-danger">
<p>TF-IDF는 단어 중요도를 잘 표현하지만 문맥과 단어 순서를 직접 이해하지는 못합니다.</p>
</blockquote>

## 단점
대표적인 약점:
1. 단어 순서를 기본적으로 잃음
2. 문맥을 직접 이해하지 못함
3. 의미가 비슷한 단어를 별개로 봄
4. Vocabulary가 크면 고차원 Sparse Vector
5. Corpus가 바뀌면 IDF도 바뀔 수 있음
6. 희귀한 오타나 잡음이 높은 IDF를 받을 수 있음
즉 통계적 중요도는 표현하지만 의미 자체를 이해하는 것은 아닙니다.

## 잘 놓치는 핵심

### 1. TF와 IDF를 곱한다
$$TFIDF=TF\times IDF$$입니다.

### 2. TF는 Local, IDF는 Global
TF는 현재 문서, IDF는 전체 Corpus를 봅니다.

### 3. 흔한 Term은 가중치가 낮아진다
DF가 높으면 IDF가 낮아집니다.

### 4. 등장하지 않으면 TF-IDF는 0
TF가 0이기 때문입니다.

### 5. 순서 정보는 기본적으로 없다
TF-IDF는 BoW 계열 표현입니다.

### 6. 실제 구현은 공식이 조금 다를 수 있다
Smooth IDF와 Normalization 여부를 확인해야 합니다.

## 시험·면접

<blockquote class="prompt-info">
<p>단골: TF-IDF 공식, TF와 IDF 역할, 흔한 단어의 가중치, Sparse Vector, Cosine Similarity, BoW와 차이.</p>
</blockquote>

자주 나오는 문장:
- TF-IDF는 TF와 IDF의 곱이다
- TF는 문서 내부 빈도를 나타낸다
- IDF는 Corpus 전체에서의 희소성을 나타낸다
- 모든 문서에서 흔한 Term은 낮은 가중치를 받는다
- TF-IDF는 기본적으로 단어 순서를 고려하지 않는다
- 문서 유사도 계산에는 Cosine Similarity를 자주 사용한다

```text

```


$$IDF(AI)=\log\frac{4}{2}=\log 2$$
따라서
$$TFIDF(AI,D1)=2\times\log 2$$
입니다.


$$IDF(vision)=\log\frac{4}{1}=\log 4$$
따라서
$$TFIDF(vision,D4)=\log 4$$
입니다.
`vision`은 전체 Corpus에서 더 희귀하므로 더 높은 IDF를 가집니다.
