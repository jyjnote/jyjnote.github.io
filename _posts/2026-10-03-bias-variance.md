편향과 분산은 **모델이 왜 과소적합되거나 과적합되는지를 이해하는 핵심 개념**입니다.

편향이 너무 크면 모델이 단순해서 중요한 규칙을 놓치고, 분산이 너무 크면 훈련 데이터에 지나치게 민감해집니다.

<blockquote class="prompt-info">
<p>한 줄: 편향이 크면 너무 단순하고, 분산이 크면 데이터 변화에 너무 민감합니다.</p>
</blockquote>

<details>
<summary>한 줄로</summary>

높은 편향 = 과소적합, 높은 분산 = 과적합

</details>

## 1. 편향과 분산이 왜 중요한가

머신러닝의 목표는 훈련 데이터를 외우는 것이 아닙니다.

새로운 데이터에서도 좋은 예측을 해야 합니다.

모델이 너무 단순하면 데이터의 중요한 규칙을 충분히 학습하지 못합니다.

반대로 모델이 너무 복잡하면 훈련 데이터의 잡음까지 학습할 수 있습니다.

<mark>좋은 모델은 편향과 분산 사이에서 적절한 균형을 찾아야 합니다.</mark>

## 2. 편향이란

편향은 모델이 실제 데이터의 규칙을 얼마나 단순하게 가정하는지와 관련된 개념입니다.

편향이 크다는 것은 모델의 가정이 너무 단순해 실제 패턴을 충분히 표현하지 못한다는 뜻입니다.

예를 들어 실제 관계가 곡선인데 직선 하나만 사용해 표현하려고 하면 중요한 구조를 놓칠 수 있습니다.

<blockquote class="prompt-info">
<p>높은 편향은 모델이 데이터의 구조를 충분히 학습하지 못하는 상태와 연결됩니다.</p>
</blockquote>

## 3. 높은 편향의 특징

높은 편향 모델은 너무 단순해 훈련과 검증 데이터 모두에서 성능이 낮을 수 있습니다.

이 상태는 과소적합과 연결됩니다.

## 4. 과소적합

과소적합은 모델이 훈련 데이터의 기본적인 패턴조차 충분히 학습하지 못한 상태입니다.

예를 들어 복잡한 곡선 관계를 지나치게 단순한 직선으로 표현하면 과소적합이 발생할 수 있습니다.

| 구분 | 성능 |
| --- | --- |
| 훈련 데이터 | 낮음 |
| 검증 데이터 | 낮음 |

<mark>높은 편향은 과소적합과 연결됩니다.</mark>

## 5. 분산이란

분산은 훈련 데이터가 조금 달라졌을 때 모델의 결과가 얼마나 크게 달라지는지를 나타냅니다.

분산이 크면 모델이 훈련 데이터의 작은 변화에도 민감하게 반응합니다.

훈련 데이터에 있는 잡음이나 우연한 패턴까지 학습할 수 있습니다.

## 6. 높은 분산의 특징

높은 분산 모델은 훈련 성능은 매우 높지만 검증 성능은 상대적으로 낮고, 훈련 데이터의 작은 변화에도 민감할 수 있습니다.

이 상태는 과적합과 연결됩니다.

## 7. 과적합

과적합은 모델이 훈련 데이터에 지나치게 맞춰진 상태입니다.

훈련 데이터에서는 거의 완벽한 성능을 보일 수 있지만 새로운 데이터에서는 성능이 떨어집니다.

| 구분 | 성능 |
| --- | --- |
| 훈련 데이터 | 매우 높음 |
| 검증 데이터 | 상대적으로 낮음 |

<mark>높은 분산은 과적합과 연결됩니다.</mark>

## 8. 편향과 분산 비교

| 구분 | 높은 편향 | 높은 분산 |
| --- | --- | --- |
| 모델 | 너무 단순 | 너무 복잡 |
| 대표 문제 | 과소적합 | 과적합 |
| 훈련 성능 | 낮음 | 매우 높음 |
| 검증 성능 | 낮음 | 훈련보다 낮음 |
| 원인 | 규칙을 충분히 학습하지 못함 | 훈련 데이터에 지나치게 맞춤 |

시험에서는 이 표의 관계를 자주 확인합니다.

## 9. 가장 쉬운 직관

과녁에 비유하면 편향이 큰 경우 화살이 한쪽으로 치우치고, 분산이 큰 경우 화살이 넓게 퍼집니다.

좋은 모델은 중심에 가깝고 결과도 일정하게 모이는 상태를 목표로 합니다.

## 10. 모델 복잡도와 편향

모델이 매우 단순하면 표현할 수 있는 패턴이 제한됩니다.

따라서 편향이 커질 가능성이 있습니다.

예를 들어 직선 하나로 복잡한 곡선 데이터를 설명하려고 하면 실제 관계를 충분히 표현하지 못합니다.

모델 복잡도를 높이면 일반적으로 편향은 줄어들 수 있습니다.

## 11. 모델 복잡도와 분산

모델이 복잡해질수록 훈련 데이터의 세부적인 패턴까지 표현할 수 있습니다.

이 과정에서 잡음까지 학습하면 분산이 커질 수 있습니다.

즉, 모델 복잡도를 계속 높이는 것이 항상 좋은 것은 아닙니다.

<blockquote class="prompt-warning">
<p>모델 복잡도를 높이면 훈련 성능은 좋아질 수 있지만 새로운 데이터 성능은 오히려 떨어질 수 있습니다.</p>
</blockquote>

## 12. 편향-분산 절충

모델을 단순하게 만들면 분산은 줄어들 수 있지만 편향이 커질 수 있습니다.

반대로 모델을 복잡하게 만들면 편향은 줄어들 수 있지만 분산이 커질 수 있습니다.

이 관계를 편향-분산 절충이라고 합니다.

<mark>편향과 분산을 동시에 무조건 최소화하는 것이 아니라 전체적인 일반화 오차를 작게 만드는 것이 목표입니다.</mark>

## 13. 오차의 구성

회귀 문제에서는 예측 오차를 개념적으로 여러 부분으로 나누어 생각할 수 있습니다.

$$Error=Bias^2+Variance+Noise$$

여기서 편향은 모델의 체계적인 오차와 관련됩니다.

분산은 데이터 변화에 따른 모델의 민감도와 관련됩니다.

잡음은 데이터 자체에 존재하여 모델이 완전히 제거하기 어려운 부분입니다.

## 14. 잡음

현실의 데이터에는 측정 오류나 설명하기 어려운 변동이 있으며, 모델을 개선해도 완전히 제거하기 어려운 오차가 존재할 수 있습니다.

<blockquote class="prompt-info">
<p>모든 오차가 모델의 문제는 아닙니다. 데이터 자체에 존재하는 잡음도 있습니다.</p>
</blockquote>

## 15. 모델 복잡도에 따른 변화

모델 복잡도가 증가할 때 일반적인 관계를 정리하면 다음과 같습니다.

| 모델 복잡도 | 편향 | 분산 |
| --- | --- | --- |
| 낮음 | 높음 | 낮음 |
| 적절함 | 적절함 | 적절함 |
| 높음 | 낮음 | 높음 |

너무 단순한 모델과 너무 복잡한 모델 사이에서 적절한 수준을 찾는 것이 중요합니다.

## 16. 훈련 오차와 검증 오차

모델 복잡도가 높아질수록 훈련 오차는 계속 줄어드는 경우가 많습니다.

하지만 검증 오차는 어느 지점까지 줄어들다가 다시 증가할 수 있습니다.

초반에는 모델이 충분히 학습하지 못한 과소적합 상태입니다.

중간에서는 일반화 성능이 좋은 지점을 찾을 수 있습니다.

후반에는 모델이 훈련 데이터에 지나치게 맞춰져 과적합이 발생할 수 있습니다.

## 17. 과소적합을 줄이는 방법

과소적합은 더 복잡한 모델 사용, 유용한 특성 추가, 지나치게 강한 규제 완화 등으로 줄일 수 있습니다.

핵심은 모델이 데이터의 중요한 패턴을 더 잘 표현하도록 만드는 것입니다.

## 18. 과적합을 줄이는 방법

과적합은 모델 복잡도 감소, 데이터 증가, 규제, 교차검증, 조기 종료 등으로 줄일 수 있습니다.

<mark>과적합을 줄인다는 것은 훈련 성능이 아니라 일반화 성능을 높이는 것입니다.</mark>

## 19. 규제와 편향·분산

규제는 모델이 지나치게 복잡해지는 것을 억제하는 방법입니다.

규제를 강하게 하면 모델의 복잡도가 줄어들 수 있습니다.

이 경우 분산은 줄어들 수 있지만 편향은 증가할 수 있습니다.

반대로 규제가 너무 약하면 모델이 복잡해져 분산이 커질 수 있습니다.

## 20. 릿지와 라쏘

릿지와 라쏘는 선형 모델에서 사용하는 대표적인 규제 방법입니다.

릿지는 계수가 지나치게 커지는 것을 막습니다.

라쏘는 일부 계수를 0으로 만들 수 있습니다.

두 방법 모두 모델의 복잡도를 조절해 과적합을 줄이는 데 활용할 수 있습니다.

## 21. 데이터가 많아지면 어떻게 되는가

훈련 데이터가 많아지면 특정 데이터의 우연한 패턴에 덜 의존하게 되어 높은 분산을 줄이는 데 도움이 될 수 있습니다.

다만 모델 자체가 지나치게 단순한 높은 편향 문제는 데이터 증가만으로 해결되지 않을 수 있습니다.

## 22. 교차검증과 편향·분산

교차검증은 여러 데이터 분할에서 모델의 성능을 확인합니다.

이를 통해 특정 분할에서만 성능이 좋은 모델을 선택하는 위험을 줄일 수 있습니다.

모델이나 초매개변수의 복잡도를 비교할 때도 활용할 수 있습니다.

<blockquote class="prompt-info">
<p>교차검증은 모델의 일반화 성능을 비교하고 적절한 복잡도를 선택하는 데 유용합니다.</p>
</blockquote>

## 23. 의사결정나무 예시

의사결정나무의 깊이를 생각해봅시다.

깊이가 너무 작으면 조건을 충분히 나누지 못합니다.

이 경우 높은 편향과 과소적합이 나타날 수 있습니다.

반대로 깊이가 지나치게 크면 훈련 데이터를 세부적으로 나누면서 높은 분산과 과적합이 발생할 수 있습니다.

| 나무 깊이 | 가능성 |
| --- | --- |
| 너무 얕음 | 높은 편향 |
| 적절함 | 균형 |
| 너무 깊음 | 높은 분산 |

## 24. 최근접 이웃 예시

최근접 이웃에서도 비슷한 관계를 볼 수 있습니다.

주변 이웃을 매우 많이 참고하면 예측 경계가 단순해질 수 있습니다.

반대로 이웃 하나만 보는 경우 개별 데이터에 매우 민감해질 수 있습니다.

따라서 이웃의 개수도 편향과 분산의 균형에 영향을 줄 수 있습니다.

## 25. 앙상블과 분산

여러 모델의 결과를 결합하면 개별 모델의 불안정성을 줄일 수 있습니다.

대표적인 예가 랜덤 포레스트입니다.

여러 의사결정나무의 결과를 종합하면서 하나의 나무가 가진 높은 분산을 줄이는 효과를 기대할 수 있습니다.

<mark>여러 모델을 평균하거나 결합하는 방법은 분산을 줄이는 데 활용될 수 있습니다.</mark>

## 26. 성능으로 편향과 분산 확인하기

훈련과 검증 성능이 모두 낮으면 높은 편향을 의심할 수 있습니다.

반대로 훈련 성능은 매우 높지만 검증 성능이 크게 낮다면 높은 분산을 의심할 수 있습니다.

```text
높은 편향: 훈련 낮음 / 검증 낮음
높은 분산: 훈련 매우 높음 / 검증 상대적으로 낮음
```

## 27. 편향과 분산을 판단할 때 주의할 점

훈련과 검증 성능만으로 모든 문제를 판단할 수는 없으며 데이터 양, 평가 방법, 데이터 누수 등도 함께 확인해야 합니다.

## 28. 잘 놓치는 핵심

### 1. 높은 편향은 과소적합과 연결된다

모델이 너무 단순해서 훈련 데이터의 패턴도 충분히 학습하지 못합니다.

### 2. 높은 분산은 과적합과 연결된다

훈련 데이터에 지나치게 맞춰져 새로운 데이터에서 성능이 떨어집니다.

### 3. 복잡한 모델이 항상 좋은 것은 아니다

복잡도가 증가하면 편향은 줄어들 수 있지만 분산이 증가할 수 있습니다.

### 4. 규제를 강하게 하면 편향이 증가할 수 있다

모델을 단순하게 만들기 때문입니다.

### 5. 데이터를 늘리면 높은 분산을 줄이는 데 도움이 될 수 있다

특정 훈련 데이터에 대한 의존이 줄어들 수 있습니다.

### 6. 목표는 편향 또는 분산 하나만 최소화하는 것이 아니다

새로운 데이터에서의 전체 오차를 줄이는 것이 중요합니다.

## 29. 시험·면접에서 기억할 것

### 핵심 암기

- 높은 편향: 너무 단순한 모델
- 높은 분산: 훈련 데이터에 민감한 모델
- 높은 편향 → 과소적합
- 높은 분산 → 과적합
- 모델 복잡도 증가 → 편향 감소 가능
- 모델 복잡도 증가 → 분산 증가 가능
- 규제 강화 → 분산 감소, 편향 증가 가능
- 일반화 성능이 가장 중요

### 자주 나오는 질문

**편향과 분산의 차이는 무엇인가요?**

편향은 모델이 실제 규칙을 지나치게 단순하게 가정해 발생하는 오차와 관련됩니다.

분산은 훈련 데이터가 달라졌을 때 모델의 결과가 크게 달라지는 정도와 관련됩니다.

**높은 편향은 어떤 문제와 연결되나요?**

모델이 너무 단순해 훈련 데이터조차 충분히 학습하지 못하는 과소적합과 연결됩니다.

**높은 분산은 어떤 문제와 연결되나요?**

훈련 데이터에 지나치게 맞춰져 새로운 데이터의 성능이 떨어지는 과적합과 연결됩니다.

**편향-분산 절충이란 무엇인가요?**

모델을 복잡하게 만들면 편향은 줄어들 수 있지만 분산은 커질 수 있기 때문에 둘 사이의 적절한 균형을 찾는 것을 의미합니다.

## 30. 예시로 한 바퀴

시험 점수를 예측하는 모델을 만든다고 가정합니다.

### 모델이 너무 단순한 경우

공부 시간 하나만 사용해 매우 단순한 직선으로 모든 학생의 점수를 설명하려고 합니다.

훈련 데이터에서도 오차가 크고 검증 데이터에서도 오차가 큽니다.

이 경우 높은 편향과 과소적합을 의심할 수 있습니다.

### 모델이 너무 복잡한 경우

각 학생의 세부적인 특징과 우연한 패턴까지 모두 맞추도록 지나치게 복잡한 모델을 만듭니다.

훈련 데이터에서는 거의 완벽하지만 검증 데이터에서 성능이 크게 떨어집니다.

이 경우 높은 분산과 과적합을 의심할 수 있습니다.

### 적절한 모델

훈련 데이터의 핵심 패턴은 학습하면서 불필요한 잡음에는 지나치게 반응하지 않는 모델을 선택합니다.

이것이 편향과 분산의 균형을 찾는 과정입니다.

## 32. 마지막 정리

편향은 모델이 너무 단순해서 중요한 규칙을 놓치는 문제와 관련되고, 분산은 훈련 데이터에 지나치게 민감한 문제와 관련됩니다.

높은 편향은 과소적합, 높은 분산은 과적합과 연결됩니다.
