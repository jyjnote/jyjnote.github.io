# 1. 전체 지도
| 방법 | 핵심 질문 | 라벨 | 대표 용도 |
| --- | --- | --- | --- |
| PCA | 가장 많이 퍼진 방향은? | 안 봄 | 압축·전처리 |
| Kernel PCA | 휘어진 구조를 펼칠 수 있나? | 안 봄 | 비선형 차원축소 |
| SVD | 행렬의 중요한 저랭크 구조는? | 안 봄 | 압축·추천·PCA 계산 |
| t-SNE | 가까운 점을 2차원에서도 가깝게 둘 수 있나? | 안 봄 | 시각화 |
| UMAP | 이웃 그래프를 저차원에 유지할 수 있나? | 기본은 안 봄 | 시각화·임베딩 |
| NMF | 양의 부분들을 더해 원본을 설명할 수 있나? | 안 봄 | 토픽·부분 기반 표현 |
| ICA | 섞인 관측에서 독립 신호를 분리할 수 있나? | 안 봄 | 신호 분리 |
시험에서는 먼저 다음을 구분합니다.
```text
전체 분산
→ PCA
비선형 분산 구조
→ Kernel PCA
행렬 분해
→ SVD
이웃 시각화
→ t-SNE / UMAP
양의 부분 조합
→ NMF
독립 신호 분리
→ ICA
```
# 2. 왜 차원을 줄이나
차원이 커지면 다음 문제가 생길 수 있습니다.
- 거리의 의미가 약해짐
- 표본 수보다 변수 수가 많아지기 쉬움
- 같은 정보를 여러 변수가 반복
- 회귀 계수와 공분산 추정이 흔들릴 수 있음
- 시각화가 어려움
- 계산량이 증가함
<mark>차원 축소는 단순히 변수를 삭제하는 것이 아니라 중요한 구조를 더 적은 좌표로 다시 표현하는 것입니다.</mark>
# 3. PCA
## 3.1 핵심
PCA는 데이터가 가장 많이 퍼진 방향부터 새로운 축을 잡습니다.
첫 번째 축은 분산이 가장 큰 방향이고, 다음 축은 앞의 축과 직교하면서 남은 분산을 가장 많이 담는 방향입니다.
## 3.2 평균 제거
PCA에서는 먼저 각 변수 평균을 뺍니다.
$$x_i-\bar{x}$$
평균을 제거하지 않으면 데이터의 퍼짐이 아니라 원점과 평균 위치를 잇는 방향이 주성분으로 잡힐 수 있습니다.
<mark>PCA의 기본 입력은 평균을 제거한 데이터입니다.</mark>

## 3.3 주성분 점수
첫 번째 주성분 방향을 \(v_1\)이라 하면 점 \(x_i\)의 주성분 점수는 다음과 같습니다.
$$z_{i1}=(x_i-\bar{x})^\top v_1$$
- \(v_1\): 첫 번째 주성분 방향
- \(z_{i1}\): 첫 번째 주성분에서 관측값의 좌표

## 3.4 분산 최대화
첫 번째 주성분은 사영된 값의 분산을 최대화합니다.
두 번째 주성분은 첫 번째 주성분과 직교하면서 남은 분산을 가장 많이 담습니다.
따라서 서로 다른 주성분 점수는 표본 기준으로 상관이 0입니다.

## 3.5 공분산과 고유값
공분산 행렬 \(S\)의 고유벡터가 주성분 방향이 됩니다.
$$Sv=\lambda v$$
- \(v\): 주성분 방향
- \(\lambda\): 해당 주성분이 설명하는 분산
총 분산은 고유값의 합과 같습니다.
$$\operatorname{tr}(S)=\lambda_1+\lambda_2+\cdots+\lambda_p$$

## 3.6 설명분산비
각 주성분이 전체 분산 중 얼마나 설명하는지 봅니다.
$$\text{설명분산비}_j=\frac{\lambda_j}{\sum_k\lambda_k}$$
앞쪽 성분 몇 개의 누적 설명분산비를 보고 차원을 정할 수 있습니다.

## 3.7 스케일
변수 단위가 크게 다르면 분산이 큰 단위의 변수가 주성분을 지배할 수 있습니다.
따라서 변수 단위가 서로 다르면 표준화를 먼저 고려합니다.

## 3.8 PCA의 해석
PCA는 원래 변수를 그대로 고르는 방법이 아닙니다.
새 축은 원래 변수의 가중합입니다.
```text
PC1
→ 여러 변수의 선형결합
PC2
→ PC1과 직교하는 다른 선형결합
```

# 4. Kernel PCA

## 4.1 왜 필요한가
선형 PCA는 직선 방향만 찾습니다.
초승달처럼 휘어진 구조는 축을 아무리 돌려도 직선 축 몇 개로 잘 펼쳐지지 않을 수 있습니다.
Kernel PCA는 데이터를 높은 차원의 공간으로 보낸 뒤 그 공간에서 PCA를 수행하는 관점입니다.

## 4.2 커널 트릭
직접 \(\phi(x)\)를 만들지 않고 내적만 계산합니다.
$$k(x,x')=\phi(x)^\top\phi(x')$$
이것이 커널 트릭입니다.

## 4.3 대표 커널
선형 커널:
$$k(x,x')=x^\top x'$$
다항 커널:
$$k(x,x')=(\gamma x^\top x'+c)^d$$
RBF 커널:
$$k(x,x')=\exp(-\gamma\|x-x'\|^2)$$

## 4.4 RBF의 감마
```text
감마 작음
→ 먼 점도 어느 정도 비슷하게 봄
→ 더 부드러운 구조
감마 큼
→ 가까운 점만 강하게 연결
→ 매우 국소적인 구조
```
너무 크면 점마다 따로 노는 형태가 될 수 있습니다.

## 4.5 커널 행렬 중심화
PCA에서 원자료 평균을 빼듯 Kernel PCA에서는 커널 행렬을 중심화해야 합니다.
입력만 표준화하고 커널 행렬을 그대로 고유분해하면 PCA의 평균 제거를 빠뜨린 것과 비슷한 문제가 생깁니다.

## 4.6 PCA와 비교
| 구분 | PCA | Kernel PCA |
| --- | --- | --- |
| 축 | 원래 공간의 직선 | 특징공간의 직선 |
| 구조 | 선형 | 비선형 가능 |
| 계산 | 공분산·SVD | 커널 행렬 고유분해 |
| 새 점 | 직접 사영 | 학습점과 커널 계산 필요 |
| 역변환 | 비교적 명확 | 정확한 역변환 어려움 |

## 4.7 시험 핵심
- Kernel PCA는 비지도학습
- 선형 커널이면 PCA와 가까움
- \(\phi(x)\)를 직접 만들지 않음
- 커널 행렬을 중심화
- 표본 수가 크면 커널 행렬 비용이 큼
- RBF는 스케일에 민감

# 5. SVD

## 5.1 핵심
SVD는 행렬을 세 행렬의 곱으로 분해합니다.
$$A=U\Sigma V^\top$$
- \(U\): 왼쪽 특잇벡터
- \(\Sigma\): 특잇값
- \(V\): 오른쪽 특잇벡터

## 5.2 특잇값
특잇값은 0 이상이며 큰 값부터 정렬합니다.
$$\sigma_1\ge\sigma_2\ge\cdots\ge0$$
0이 아닌 특잇값 개수가 행렬의 랭크입니다.

## 5.3 왜 중요한가
큰 특잇값에 해당하는 성분만 남기면 원래 행렬을 저랭크 행렬로 근사할 수 있습니다.
$$A\approx U_k\Sigma_kV_k^\top$$
이를 이용해
- 차원 축소
- 압축
- 노이즈 제거
- 추천 시스템
- PCA 계산
등에 사용할 수 있습니다.

## 5.4 PCA와 SVD 관계
평균을 제거한 데이터 행렬을 \(X\)라고 하면 PCA의 주성분 방향은 SVD의 \(V\)에서 얻을 수 있습니다.
표본 공분산 기준으로 고유값과 특잇값의 관계는 다음과 같습니다.
$$\lambda_j=\frac{\sigma_j^2}{n-1}$$
<mark>PCA의 고유값과 SVD의 특잇값은 같은 값이 아닙니다.</mark>

## 5.5 SVD의 장점
SVD는 정사각형뿐 아니라 직사각형 행렬에도 사용할 수 있어 고유분해보다 적용 범위가 넓습니다.

## 5.6 시험 함정
- 특잇값은 음수가 아님
- 직사각형 행렬도 가능
- 큰 특잇값부터 남김
- \(U\)와 \(V\)의 역할이 다름
- 특잇벡터 부호는 뒤집혀도 같은 분해 가능
- PCA와 연결할 때는 평균 제거 여부를 확인

# 6. t-SNE

## 6.1 핵심
t-SNE는 고차원에서 가까운 점들이 저차원에서도 가깝도록 배치하는 시각화 방법입니다.
PCA처럼 분산이 큰 축을 찾는 것이 아닙니다.

## 6.2 고차원 이웃
고차원에서는 가우시안 형태로 이웃 확률을 만듭니다.
가까운 점은 큰 확률, 먼 점은 작은 확률을 갖습니다.

## 6.3 저차원 이웃
저차원에서는 꼬리가 두꺼운 t분포를 사용합니다.
이 때문에 먼 점들이 모두 한곳에 뭉개지는 현상을 줄일 수 있습니다.

## 6.4 목적함수
고차원 이웃 확률 \(P\)와 저차원 이웃 확률 \(Q\)의 KL 발산을 줄입니다.
$$KL(P\|Q)=\sum_{i\ne j}p_{ij}\log\frac{p_{ij}}{q_{ij}}$$
고차원에서 가까운데 저차원에서 멀어지는 경우 큰 벌점을 줍니다.

## 6.5 퍼플렉서티
퍼플렉서티는 한 점이 대략 몇 개의 점을 이웃으로 볼지 결정하는 감각의 하이퍼파라미터입니다.
```text
작음
→ 매우 국소적인 이웃 강조
큼
→ 더 넓은 이웃 구조 반영
```
학습률과는 다릅니다.

## 6.6 해석 주의
t-SNE에서 주로 믿을 것은 **가까운 점들의 이웃 관계**입니다. 군집 사이 절대 거리·상대 크기·축 의미·그림 방향은 함부로 해석하면 안 됩니다.
<mark>t-SNE에서 군집 사이 거리를 자로 재는 해석은 위험합니다.</mark>

# 7. UMAP

## 7.1 핵심
UMAP도 고차원 이웃 구조를 저차원에 보존합니다.
다만 이웃 확률보다는 이웃 그래프를 만든 뒤 그 그래프 구조를 저차원에 재현하는 관점입니다.

## 7.2 흐름
```text
최근접 이웃 탐색
→ 이웃 그래프 생성
→ 연결 강도 계산
→ 저차원 그래프와 비슷하게 배치
```

## 7.3 이웃 수
`n_neighbors`는 얼마나 넓은 이웃 구조를 볼지 정합니다.
```text
작음
→ 국소 구조 강조
큼
→ 더 전역적인 구조 반영
```

## 7.4 최소 거리
`min_dist`는 저차원에서 같은 묶음의 점들이 얼마나 가까이 붙을 수 있는지 조절합니다.
```text
작음
→ 군집 내부가 더 빽빽
큼
→ 군집 내부 간격이 더 넓음
```

## 7.5 t-SNE와 비교
| 구분 | t-SNE | UMAP |
| --- | --- | --- |
| 핵심 | 이웃 확률 | 이웃 그래프 |
| 지역 구조 | 강함 | 강함 |
| 새 점 | 기본적으로 어려움 | transform 가능 |
| 속도 | 상대적으로 느릴 수 있음 | 비교적 빠른 편 |
| 축 의미 | 없음 | 없음 |
둘 다 주로 시각화·임베딩에 사용하며, 저차원 축 자체에 원래 변수와 같은 직접적인 의미를 부여하지 않습니다.

# 8. NMF

## 8.1 핵심
NMF는 음수가 없는 행렬을 음수가 없는 두 행렬의 곱으로 근사합니다.
$$X\approx WH$$
조건은 다음과 같습니다.
$$W\ge0,\qquad H\ge0$$

## 8.2 의미
- \(H\): 어떤 부분이 존재하는가
- \(W\): 각 관측값이 그 부분을 얼마나 사용하는가
예를 들어 문서-단어 행렬이라면 각 부분을 주제처럼 해석할 수 있습니다.

## 8.3 PCA와 차이
PCA는 양수와 음수를 모두 사용해 직교 방향을 찾습니다.
NMF는 음수 없이 부분을 **더해서** 원본을 복원합니다.
```text
PCA
→ 방향의 조합
→ 더하기와 빼기 가능
NMF
→ 양의 부분 조합
→ 더하기 중심
```

## 8.4 목적함수
대표적으로 복원 오차를 줄입니다.
$$\min_{W,H\ge0}\|X-WH\|_F^2$$

## 8.5 장점과 제약
부분 기반 해석과 문서·이미지·빈도 데이터에 자연스럽지만, 음수 입력에 제약이 있고 분해가 유일하지 않을 수 있으며 성분은 직교하지 않아도 됩니다.

# 9. ICA

## 9.1 핵심
ICA는 여러 독립 신호가 섞여 만들어진 관측을 다시 독립적인 근원 신호로 분리합니다.
$$x=As$$
- \(s\): 원래 독립 신호
- \(A\): 혼합 행렬
- \(x\): 관측 신호
분리 행렬을 통해 근원을 추정합니다.
$$\hat{s}=Wx$$

## 9.2 PCA와 차이
PCA가 찾는 것은 **무상관 방향**입니다.
ICA는 더 강한 조건인 **통계적 독립**을 찾습니다.
```text
독립
→ 무상관
무상관
→ 반드시 독립은 아님
```

## 9.3 비정규성
ICA는 독립 성분을 찾기 위해 비정규성을 이용합니다.
모든 근원이 정규분포라면 회전해도 구분하기 어려워 ICA가 잘 작동하지 않습니다.

## 9.4 화이트닝
ICA에서는 먼저 화이트닝을 사용하는 경우가 많습니다.
목표는
$$\operatorname{Cov}(Z)=I$$
입니다.
즉,
- 평균 0
- 분산 1
- 공분산 0
상태로 만든 뒤 추가 회전을 통해 독립 성분을 찾습니다.
<mark>화이트닝은 ICA 자체가 아니라 ICA 전처리 단계입니다.</mark>

## 9.5 식별 불가능성
ICA 성분의 **순서·부호·크기**는 정확히 고정되지 않을 수 있으므로 복원 신호가 원본과 부호나 순서가 달라도 같은 근원일 수 있습니다.

# 10. PCA · NMF · ICA 비교

# 13. 잘 놓치는 핵심
- PCA는 평균 제거가 기본
- PCA 주성분은 원래 변수의 가중합
- 고유값은 주성분 분산
- Kernel PCA는 라벨을 쓰지 않음
- Kernel PCA는 커널 행렬 중심화가 필요
- SVD는 직사각형 행렬에도 가능
- PCA 고유값과 SVD 특잇값은 다름
- t-SNE는 군집 사이 거리 해석에 주의
- t-SNE의 퍼플렉서티는 학습률이 아님
- UMAP의 n_neighbors는 이웃 범위
- UMAP의 min_dist는 저차원 군집 내부 간격
- NMF는 입력과 두 분해 행렬이 모두 0 이상
- NMF 성분은 직교할 필요가 없음
- ICA는 무상관이 아니라 독립을 목표
- 화이트닝은 ICA 자체가 아님
- ICA 성분의 순서·부호·크기는 고정되지 않을 수 있음

# 14. 시험·면접에서 기억할 것
1. PCA = 분산 최대 직교축
2. Kernel PCA = 커널 공간에서 PCA
3. 선형 커널 Kernel PCA ≈ PCA
4. SVD = \(U\Sigma V^\top\)
5. PCA의 방향은 SVD의 오른쪽 특잇벡터와 연결
6. t-SNE = 고차원 이웃을 저차원에서도 가깝게
7. t-SNE 그림의 군집 간 거리를 절대거리처럼 해석하지 않음
8. UMAP = 이웃 그래프 보존
9. NMF = 양의 부분 기반 표현
10. ICA = 독립 성분 분리
